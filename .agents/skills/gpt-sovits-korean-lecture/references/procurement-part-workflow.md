# 공공조달 Part 강의와 구간 분할

Part 전체 강의 또는 세부 구간별 음성을 만들 때 참고한다. 이 문서는 고정 제작 순서가
아니며, 사용자 요청과 자료 상태에 맞춰 필요한 단계만 사용한다.

## 내용 구성

- 프로젝트의 출처 우선순위와 정확성 원칙은 루트 `AGENTS.md`를 따른다.
- 관련 표준교재, 범위 INDEX, 숫자 자료, 기존 강의·노트·템플릿 중 필요한 자료를 선택한다.
- 민간 수험서는 보조 자료이며 표준교재의 시험 기준을 대체하지 않는다.
- 기존 통합문서나 대본을 수정할 때는 사용자가 보존을 요청한 내용과 확정된 사실을 임의로
  없애지 않는다. 나머지 구성, 예시, 반복, 질문과 연습문제는 학습 효과에 맞춰 편집한다.
- 통합문서와 음성 대본을 따로 만들지, 바로 대본을 만들지, Part를 한 번에 처리할지는
  에이전트가 결정한다.

기존 프로젝트 경로를 활용할 수 있다.

```text
output/part_lectures/4과목/
output/gpt_sovits_audio/
```

다른 위치나 이름이 더 적합하면 그렇게 해도 된다.

## 구간 분할을 사용할 때의 입력 규칙

`--split-sections`를 사용할 때만 각 발화 구간을 다음 표시로 감싼다.

```text
[[SECTION_START|P02|C01|S01|구간 제목]]
실제로 합성할 문장
[[SECTION_END|P02|C01|S01]]
```

- 시작·종료 코드가 정확히 짝을 이루고 블록이 겹치지 않아야 한다.
- 표시는 독립된 줄에 둔다.
- 발화하지 않을 제작 메모와 Markdown 구조는 블록 밖에 둔다.
- 코드와 제목은 파일명이 되므로 같은 대본 안에서 고유하게 한다.

구간 수, 코드 체계와 제목은 작업에 맞게 정할 수 있다. 위 `Pxx/Cxx/Sxx` 체계는 기존
프로젝트와 호환되는 기본 예시다.

## 합성 전 확인

정확성, 발음, 구간 쌍과 출력 경로를 작업 위험에 비례해 확인한 뒤
`scripts/generate_gpt_sovits.py --split-sections`를 실행한다. 합성기는 표시를 제거하고
구간을 개별 파일로 만든다. 표시가 있는 대본을 파싱하지 않은 채 음성 엔진에 직접 전달하지
않는다.
