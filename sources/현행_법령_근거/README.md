# 현행 법령 근거

학습자료에 `현행(시행일)` 값을 병기할 때 근거로 사용한 국가법령정보센터의
공식 본문을 수집 시점 그대로 보관한다. 시험 학습의 본문 기준은 조달청
표준교재이며, 이 디렉터리의 자료가 표준교재 기준을 대체하지 않는다.

## 구성

- `manifest.json`: 법령·행정규칙의 명칭, 시행일, 버전, 원문 URL, 수집일,
  로컬 스냅숏 경로와 SHA-256
- `snapshots/`: `2026-08-16`에 내려받은 국가법령정보센터 HTML 본문

스냅숏은 당시 근거를 재현하기 위한 고정 자료다. 최신 여부를 판단할 때에는
manifest의 `source_url`에서 현행 원문과 시행일을 다시 확인한다.

## 검증과 갱신

```bash
python3 tools/verify_legal_sources.py
```

갱신할 때에는 다음 순서를 지킨다.

1. 국가법령정보센터에서 실제 시행 중인 버전의 본문을 내려받는다.
2. manifest의 `retrieved_at`, `effective_date`, `version`, `source_url`을 갱신한다.
3. `shasum -a 256 snapshots/<파일>.html` 결과를 `sha256`에 기록한다.
4. 검증기와 전체 테스트를 통과시킨다.

국가법령정보센터 원문에는 각 제공기관의 이용조건이 적용된다. 공개·저장 범위는
저장소의 `docs/자료_공개_및_저장_정책.md`를 함께 따른다.
