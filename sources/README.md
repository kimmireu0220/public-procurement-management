# sources — 외부 학습 자료

조달관리사 시험 준비에 쓰는 **외부 원본 자료**만 둔다. 문제·정답은 `output/`에 있다.

> 이 디렉터리에는 대용량 PDF·스캔 이미지가 포함된다. 공개 저장소에 배포하기 전에는 각 자료의 이용·배포 권한을 확인하고, 동일 원본을 다른 경로에 중복 보관하지 않는다. 저장소 용량을 줄여야 할 때는 참조 경로와 Git 이력을 먼저 점검한 뒤 별도 작업으로 진행한다.

## 출처·용도

| 경로 | 발행·배포 | 용도 |
|------|-----------|------|
| [`민간_박문각_수험서_jpg/`](민간_박문각_수험서_jpg/) | ㈜박문각 | 수험서 스캔 (주 교재) |
| [`공식_조달청_표준교재_pdf/`](공식_조달청_표준교재_pdf/) | 조달청 | 표준교재 PDF |
| [`공식_qnet_예제문제/`](공식_qnet_예제문제/) | Q-Net | 필기 예제 6문항 |
| [`공식_qnet_시행공고/`](공식_qnet_시행공고/) | Q-Net | 시행공고 |
