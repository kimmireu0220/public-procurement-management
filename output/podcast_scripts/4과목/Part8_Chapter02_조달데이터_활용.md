# [Part 8 Chapter 2 팟캐스트 대본 — 조달데이터 활용]

문제 1.
공공조달 과정에서 생성되는 모든 정보와 기록을 무엇이라 하는가?

정답은 조달데이터입니다. 발주계획과 입찰, 계약, 납품, 대금지급 과정에서 만들어지는 정보를 모두 포함합니다.

문제 2.
조달사업 계획 단계에서 생성되는 데이터는 무엇인가?

정답은 발주계획 데이터입니다. 무엇을 어느 규모로 언제 구매할지에 관한 미래 수요정보입니다.

문제 3.
계약금액과 계약기간 등 계약 이행 상태를 분석하기 위해 활용되는 데이터는 무엇인가?

정답은 계약 데이터입니다. 계약금액과 기간, 계약상대자 정보를 통해 시장규모와 이행상태를 분석합니다.

문제 4.
조달 참여 기업의 기본정보와 실적 등 경쟁업체의 실적 분석에 활용되는 데이터는 무엇인가?

정답은 공급업체 데이터입니다. 업체의 기본정보와 낙찰·계약실적을 이용해 경쟁사의 강점과 시장점유를 살펴봅니다.

문제 5.
계약 이행 후 지급되는 금액과 관련된 데이터는 무엇인가?

정답은 대금지급 데이터입니다. 실제 지급액과 지급시기 등을 통해 계약집행과 현금흐름을 확인할 수 있습니다.

문제 6.
입찰 공고 건수, 경쟁률 등을 분석하여 시장 경쟁 상황을 파악하는 것은 무엇인가?

정답은 입찰 현황 분석입니다. 공고 수와 참여업체 수, 낙찰률을 함께 보면 시장의 활발함과 경쟁강도를 알 수 있습니다.

문제 7.
경쟁업체의 입찰 참여와 낙찰 실적을 분석하는 것은 무엇인가?

정답은 경쟁사 분석입니다. 어떤 업체가 자주 참여하고 실제로 얼마나 낙찰되는지를 비교합니다.

문제 8.
입찰 참여 업체 수를 기준으로 나타나는 경쟁 정도는 무엇인가?

정답은 경쟁률입니다. 참여업체가 많을수록 일반적으로 낙찰 경쟁이 치열합니다.

문제 9.
낙찰 가격 수준을 분석하는 지표는 무엇인가?

정답은 낙찰률입니다. 예정가격에 비해 실제 낙찰가격이 어느 수준인지 비율로 나타냅니다.

문제 10.
특정 발주기관에서 이루어진 계약 결과를 분석하는 것은 무엇인가?

정답은 발주기관별 계약실적 분석입니다. 기관별 구매규모와 반복 품목을 파악해 목표기관을 정하는 데 활용합니다.

문제 11.
조달시장 규모를 파악하기 위해 활용되는 데이터는 무엇인가?

정답은 계약실적 데이터입니다. 일정 기간의 계약금액을 합산하면 해당 품목이나 시장의 실제 규모를 추정할 수 있습니다.

문제 12.
경쟁사의 낙찰 실적을 분석하는 목적은 무엇인가?

정답은 경쟁력 파악입니다. 낙찰빈도와 계약금액을 보면 어떤 업체가 시장에서 강한지 알 수 있습니다.

문제 13.
조달데이터 분석의 궁극적인 목적은 무엇인가?

정답은 합리적인 의사결정을 지원하는 것입니다. 감에 의존하지 않고 수요와 경쟁, 가격자료를 근거로 참여 여부를 정합니다.

문제 14.
조달데이터를 일정 기준에 따라 분석하는 것을 무엇이라 하는가?

정답은 데이터 분석입니다. 목적에 맞게 기간과 기관, 품목, 업체 같은 기준으로 자료를 나누고 의미를 찾습니다.

문제 15.
연도별 계약 금액 변화를 분석하는 기준은 무엇인가?

정답은 기간 기준 분석입니다. 연도별 금액을 비교해 시장의 증가와 감소 추세를 확인합니다.

문제 16.
발주기관별 계약 규모를 분석하는 것은 무엇인가?

정답은 발주기관 기준 분석입니다. 어느 기관이 얼마나 구매하는지 비교해 핵심 수요처를 찾습니다.

문제 17.
물품·용역·공사 등 조달 대상에 따라 데이터를 분석하는 것은 무엇인가?

정답은 조달대상물 기준 분석입니다. 물품과 용역, 공사를 나눠 서로 다른 시장구조와 계약특성을 살펴봅니다.

문제 18.
업체별 낙찰 실적을 분석하는 것은 무엇인가?

정답은 업체 기준 분석입니다. 업체별 참여와 낙찰, 계약금액을 비교해 경쟁구조를 파악합니다.

문제 19.
항목 간 비교를 쉽게 하기 위해 사용하는 그래프는 무엇인가?

정답은 막대그래프입니다. 기관이나 연도처럼 여러 항목의 크기를 나란히 비교하기 좋습니다.

문제 20.
전체 중 비율을 나타내는 그래프는 무엇인가?

정답은 원그래프입니다. 전체 시장에서 각 기관이나 업체가 차지하는 구성비를 보여줄 때 적합합니다.

문제 21.
데이터의 출처와 정확성을 확인하는 과정은 무엇인가?

정답은 데이터 신뢰성 검토입니다. 출처가 공식적인지, 누락과 오류가 없는지를 확인해야 잘못된 결론을 피할 수 있습니다.

문제 22.
공공조달 과정에서 생성되는 공식 데이터를 제공하는 시스템은 무엇인가?

정답은 전자조달시스템입니다. 공고와 개찰, 계약 등 실제 조달절차에서 생성된 공식 기록을 제공합니다.

문제 23.
정부가 공개하는 다양한 공공 정보를 제공하는 것은 무엇인가?

정답은 공공데이터입니다. 조달자료에 예산과 기업, 지역정보 등을 결합하면 더 넓은 분석이 가능합니다.

문제 24.
데이터가 최신 정보인지 확인하는 것은 무엇인가?

정답은 데이터 최신성 확인입니다. 오래된 자료는 현재 시장과 제도를 반영하지 못할 수 있으므로 기준일과 갱신일을 확인합니다.
