# [Part 8 Chapter 1 팟캐스트 대본 — 전자조달시스템 이용]

문제 1.
전자조달시스템의 대표적 국가 시스템은 무엇인가?

정답은 국가종합전자조달시스템, 나라장터입니다. 공고 조회부터 입찰, 계약, 대금청구까지 공공조달 절차를 전자적으로 처리합니다.

문제 2.
조달기업이 전자입찰에 참여할 때 사용하는 기업 인증서는 무엇인가?

정답은 사업자용 공동인증서입니다. 전자입찰에서 기업의 신원과 전자서명의 유효성을 확인합니다.

문제 3.
입찰에 참여하는 기업 소속 개인을 무엇이라 하는가?

정답은 입찰대리인입니다. 기업을 대신해 입찰업무를 수행하도록 정식으로 등록된 사람입니다.

문제 4.
입찰공고에서 조달 대상물을 분류하는 국제 표준 코드는 무엇인가?

정답은 유엔에스피에스씨입니다. 물품과 용역을 공통 기준으로 분류해 공고 검색과 통계분석에 활용합니다.

문제 5.
전자조달시스템에서 계약금 지급 요청을 무엇이라 하는가?

정답은 대금청구입니다. 계약이행과 검사 합격 뒤 지급받을 금액을 전자적으로 요청하는 절차입니다.

문제 6.
전자조달시스템에서 입찰가격 등을 입력하여 제출하는 문서는 무엇인가?

정답은 입찰서입니다. 업체가 제시하는 가격과 입찰 의사를 마감 전까지 전자적으로 제출합니다.

문제 7.
낙찰자와 발주기관이 전자서명으로 계약을 체결하는 방식은 무엇인가?

정답은 전자계약입니다. 종이문서 대신 전자서명으로 계약을 확정하며 동일한 계약상 효력을 가집니다.

문제 8.
계약 체결 후 계약 수행을 위해 지급하는 자금은 무엇인가?

정답은 선금입니다. 자재와 인력 등 계약이행에 필요한 초기 비용을 지원하기 위해 미리 지급합니다.

문제 9.
납품 후 발주기관이 수행하는 품질 확인 절차는 무엇인가?

정답은 검사와 검수입니다. 수량과 외관뿐 아니라 규격과 품질이 계약조건에 맞는지 확인합니다.

문제 10.
입찰 마감 전에 입찰서를 수정할 수 있는가?

정답은 마감 전에는 가능합니다. 다만 최종 제출상태와 접수 여부를 확인해야 하며 마감 뒤에는 수정할 수 없습니다.

문제 11.
전자계약 체결 후 계약 이력은 어디에 저장되는가?

정답은 전자조달시스템입니다. 계약서와 전자서명, 변경 이력이 저장되어 이후 이행과 감사의 근거가 됩니다.

문제 12.
혁신제품 정보를 제공하고 구매를 지원하는 플랫폼은 무엇인가?

정답은 혁신장터입니다. 혁신제품을 검색하고 시범구매와 관련 정보를 확인하는 플랫폼입니다.

문제 13.
창업기업과 벤처기업 제품 판로 지원 플랫폼은 무엇인가?

정답은 벤처나라입니다. 공공조달 실적이 부족한 창업·벤처기업 제품의 초기 판로를 지원합니다.

문제 14.
클라우드 서비스 조달 플랫폼은 무엇인가?

정답은 디지털서비스몰입니다. 공공기관이 클라우드와 디지털 서비스를 비교하고 구매할 수 있는 전문몰입니다.

문제 15.
혁신제품은 최대 몇 년의 수의계약이 가능한가?

정답은 최대 3년입니다. 혁신제품의 수의계약 가능기간이라는 점을 기억하세요.

문제 16.
벤처나라 등록 제품의 지정 유효기간은 몇 년인가?

정답은 6년입니다. 벤처나라 등록제품의 지정 유효기간입니다.

문제 17.
디지털서비스몰에서 활용되는 계약 방식은 무엇인가?

정답은 카탈로그 계약입니다. 표준화된 서비스 조건과 가격을 카탈로그로 제시해 수요기관이 필요한 서비스를 선택합니다.

문제 18.
이음장터 거래 대상 서비스 금액 기준은 무엇인가?

정답은 2천만원 이하입니다. 이음장터에서 거래할 수 있는 서비스의 금액 기준입니다.

문제 19.
전자입찰에서 마감시간 이후 제출되는 입찰서는 어떻게 처리되는가?

정답은 무효입니다. 전자입찰은 시스템상 마감시간을 엄격하게 적용하므로 늦게 제출한 입찰서는 접수되지 않습니다.
