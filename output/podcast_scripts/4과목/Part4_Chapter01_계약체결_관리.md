# [Part 4 Chapter 1 팟캐스트 대본 — 계약체결 관리]

문제 1.
공공조달 계약서 작성의 기본 법적 근거는 무엇인가?

정답은 국가계약법과 지방계약법입니다. 국가기관 계약은 국가계약법, 지방자치단체 계약은 지방계약법을 기준으로 계약서를 작성합니다.

문제 2.
계약 체결 시 계약자의 인감 확인을 위해 제출하는 서류는?

정답은 인감증명서입니다. 계약서에 찍힌 인감이 계약자 본인의 것인지 확인하는 서류입니다.

문제 3.
대리인이 계약 체결 시 필요한 서류는 무엇인가?

정답은 위임장입니다. 대리인이 계약할 권한을 정당하게 위임받았다는 사실을 확인하기 위해 제출합니다.

문제 4.
계약이행보증의 목적은 무엇인가?

정답은 계약 불이행으로 생길 발주기관의 손해를 담보하는 것입니다. 업체가 계약을 이행하지 못했을 때 보증을 통해 손실을 보전합니다.

문제 5.
계약이행보증의 가장 일반적인 방식은 무엇인가?

정답은 이행보증보험증권입니다. 현금을 직접 맡기는 대신 보증기관이 발급한 증권으로 이행을 담보하는 방식입니다.

문제 6.
계약보증금 면제 시 제출하는 문서는 무엇인가?

정답은 지급각서입니다. 보증금 납부는 면제되더라도 문제가 생기면 해당 금액을 지급하겠다는 약속은 문서로 남깁니다.

문제 7.
계약변경 시 검토해야 하는 보증 관련 사항은 무엇인가?

정답은 보증금 증액 여부와 보증기간 변경 여부입니다. 계약금액이나 이행기간이 바뀌면 기존 보증이 변경된 계약을 충분히 담보하는지 다시 확인해야 합니다.

문제 8.
계약완료 시 보증금은 어떻게 처리되는가?

정답은 반환입니다. 계약이 정상적으로 완료되어 담보할 위험이 사라지면 보증금을 계약상대자에게 돌려줍니다.

문제 9.
계약해지 시 계약보증금은 어떤 조치가 가능한가?

정답은 국고 귀속이 가능합니다. 계약상대자의 책임으로 계약이 해지되면 계약보증금이 발주기관에 귀속될 수 있습니다.

문제 10.
계약이행보증 서류 확인 시 필수 점검 항목 중 1가지는 무엇인가?

정답은 보증기간입니다. 실제 계약 이행기간을 빠짐없이 포함하는지 확인해야 보증 공백이 생기지 않습니다.

문제 11.
계약서 초안을 송부하는 주체는 누구인가?

정답은 발주기관입니다. 발주기관이 계약조건을 담은 초안을 보내면 업체가 내용을 검토하고 필요한 서류로 응답합니다.

문제 12.
계약응답서 작성 시 함께 제출하는 서류 2가지는 무엇인가?

정답은 지급각서와 청렴서약서입니다. 보증 관련 책임과 청렴한 계약이행 의사를 함께 확인하는 서류입니다.

문제 13.
변경계약 요청 시 조달업체가 제출하는 문서는 무엇인가?

정답은 계약변경요청서입니다. 무엇을 왜 바꿔야 하는지와 금액·기간에 미치는 영향을 근거자료와 함께 제출합니다.

문제 14.
계약내용 설명의 주요 목적은 무엇인가?

정답은 분쟁 예방입니다. 계약 당사자가 과업과 책임, 일정, 대금지급 조건을 같은 의미로 이해하도록 확인하는 과정입니다.

문제 15.
계약 목적은 무엇을 판단하는 기준인가?

정답은 과업 범위입니다. 계약이 무엇을 달성하려는지 알아야 어디까지 수행해야 하는지를 판단할 수 있습니다.

문제 16.
지체상금 산정의 기준이 되는 계약 요소는 무엇인가?

정답은 이행기간입니다. 약정한 완료일을 넘긴 기간을 기준으로 지체일수를 계산하고 지체상금을 산정합니다.

문제 17.
계약보증금의 기능은 무엇인가?

정답은 계약이행 담보입니다. 계약상대자가 약속대로 이행하도록 책임을 확보하고 불이행 시 손해를 보전하는 기능입니다.

문제 18.
계약설명 시 확인해야 하는 문서는 무엇인가?

정답은 계약문서입니다. 계약서뿐 아니라 과업지시서와 규격서, 산출내역서 등 계약내용을 구성하는 문서를 함께 확인해야 합니다.

문제 19.
지체상금의 법적 성격은 무엇인가?

정답은 손해배상 예정액입니다. 지연 때마다 실제 손해를 새로 입증하기보다 계약에서 미리 정한 기준으로 배상액을 계산합니다.

문제 20.
계약설명 기록의 실무적 의미는 무엇인가?

정답은 분쟁 발생 시 증거자료가 된다는 것입니다. 어떤 조건을 설명했고 상대방이 어떻게 이해했는지 기록해 두면 책임범위를 판단하는 근거가 됩니다.
