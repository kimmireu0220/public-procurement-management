# [Part 7 Chapter 2 팟캐스트 대본 — 분쟁 대응]

문제 1.
공공조달에서 입찰 과정의 공정성 문제로 발생하는 분쟁을 무엇이라 하는가?

정답은 입찰단계 분쟁입니다. 공고조건과 참가자격, 평가절차의 공정성 문제처럼 계약 체결 전에 생기는 다툼입니다.

문제 2.
계약 내용의 해석 차이로 발생하는 분쟁은 무엇인가?

정답은 계약조건 분쟁입니다. 같은 문구를 두고 과업범위나 대금, 책임을 서로 다르게 이해할 때 발생합니다.

문제 3.
계약이행 중 납기지연 등으로 발생하는 분쟁은 무엇인가?

정답은 계약이행 분쟁입니다. 납기지연과 품질불량처럼 계약을 실제로 수행하는 과정에서 생기는 다툼입니다.

문제 4.
납품 지연 시 부과되는 금전적 제재는 무엇인가?

정답은 지체상금입니다. 계약상대자의 책임으로 납품이 늦어진 기간에 따라 계산합니다.

문제 5.
공정한 경쟁을 제한하는 입찰 조건 관련 분쟁은 무엇인가?

정답은 경쟁 제한 분쟁입니다. 특정 업체만 충족할 수 있는 규격이나 과도한 지역제한 등이 대표적인 원인입니다.

문제 6.
입찰 평가의 공정성 문제로 제기되는 분쟁은 무엇인가?

정답은 평가 공정성 분쟁입니다. 배점 적용이나 위원 선정, 점수 산정이 공정하지 않았다는 이의에서 발생합니다.

문제 7.
계약상대자가 제재를 받는 행정처분 관련 분쟁은 무엇인가?

정답은 부정당업자 제재 분쟁입니다. 제재사유와 기간, 절차의 적법성을 두고 다투는 행정처분 관련 분쟁입니다.

문제 8.
분쟁을 사전에 방지하기 위한 관리 활동을 무엇이라 하는가?

정답은 분쟁 예방관리입니다. 계약조건을 명확히 하고 협의내용을 기록해 다툼의 원인을 미리 줄이는 활동입니다.

문제 9.
공공조달에서 발생한 갈등을 해결하기 위한 관리 활동은 무엇인가?

정답은 분쟁대응입니다. 발생한 갈등의 사실과 근거를 확인하고 협의나 조정, 소송 등 적절한 해결수단을 선택합니다.

문제 10.
분쟁 대응의 첫 단계는 무엇인가?

정답은 사실관계 확인입니다. 주장부터 판단하지 말고 계약문서와 공문, 이행기록으로 무엇이 실제로 일어났는지 정리해야 합니다.

문제 11.
계약 분쟁 해결을 위해 법원에 제기하는 절차는 무엇인가?

정답은 소송입니다. 법원에 판단을 구하는 공식 절차로 시간과 비용이 크므로 다른 해결수단과 비교해 선택합니다.

문제 12.
분쟁 해결을 위해 제3자가 중립적으로 판단하는 절차는 무엇인가?

정답은 중재입니다. 당사자가 합의해 중립적인 제3자의 판단에 분쟁 해결을 맡기는 방식입니다.

문제 13.
분쟁 대응 시 객관적 판단의 기준이 되는 것은 무엇인가?

정답은 법령과 계약조건입니다. 어느 쪽 주장이 더 강한지가 아니라 미리 정한 계약내용과 적용 법규를 기준으로 판단합니다.
