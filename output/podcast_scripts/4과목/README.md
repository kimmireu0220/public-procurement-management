# 4과목 공공조달 관리실무 듣기 강의 대본

공공조달관리사 실기 4과목의 박문각 Part 1~8, 총 25개 CHAPTER를 챕터별 듣기 강의로 정리한 자료입니다.

- 박문각 교재의 Part·CHAPTER 구조를 따릅니다.
- 각 CHAPTER의 원문 이미지를 확인하여 이론 내용을 강의 흐름으로 재구성했습니다.
- 숫자·기한·절차는 조달청 표준교재의 해당 장을 우선하여 대조했습니다.
- `바로 Check`, 핵심 최종점검, 서술형 출제예상문제, 정답·해설은 포함하지 않습니다.
- 초보자가 현장에서 누가, 언제, 무엇을 하는지 순서대로 들을 수 있도록 구성했습니다.

## 권장 학습 흐름

전체 순서는 `입찰 준비 → 계획 → 실행 → 계약 → 유형별 관리 → 리스크 → 법제도 → 전자조달`입니다.

처음 들을 때는 절차의 주체와 순서에 집중하고, 두 번째부터 각 대본 마지막의 암기 순서를 소리 내어 연결하면 됩니다. 숫자와 기한은 문장만 따로 외우기보다 해당 숫자가 어느 단계에서 누구에게 적용되는지를 함께 기억하십시오.
