# [Part 4 Chapter 3 팟캐스트 대본 — 계약변경 관리]

문제 1.
계약 조정의 목적은 무엇인가?

정답은 계약목적을 달성하고 이행의 안정성을 확보하는 것입니다. 예상하지 못한 변화가 생겨도 계약을 현실에 맞게 조정해 계속 수행할 수 있도록 합니다.

문제 2.
설계변경의 대표적인 사유는 무엇인가?

정답은 물량의 증가나 감소입니다. 실제 현장 여건에 따라 설계된 공사량이 달라지면 설계와 계약금액을 함께 조정해야 합니다.

문제 3.
계약내용 변경 시 판단의 핵심 원칙은 무엇인가?

정답은 계약의 동일성 유지입니다. 변경 뒤에도 처음 계약한 사업과 본질적으로 같은 계약이어야 하며 전혀 다른 사업으로 바뀌어서는 안 됩니다.

문제 4.
계약내용 변경의 불가항력 사유 중 대표적 한 가지는 무엇인가?

정답은 천재지변입니다. 계약 당사자가 예측하거나 통제하기 어려운 사정이므로 불가항력에 따른 변경을 검토할 수 있습니다.

문제 5.
발주기관 정책 변경 시 조정 가능 여부는?

정답은 가능합니다. 발주기관의 정책 변경으로 기존 조건을 유지하기 어려워졌다면 계약 목적과 범위 안에서 조정할 수 있습니다.

문제 6.
계약상대자 귀책 사유 발생 시 조정 가능 여부는?

정답은 제한됩니다. 계약상대자의 잘못으로 생긴 문제까지 일반적인 계약조정으로 보전해 주는 것은 적절하지 않습니다.

문제 7.
설계변경 시 삭제 항목 처리는 무엇인가?

정답은 감액입니다. 수행하지 않게 된 물량과 비용은 변경계약에서 계약금액에서 빼야 합니다.

문제 8.
불가항력 판단 시 중요 판단 요소는 무엇인가?

정답은 누구에게 책임이 있는지입니다. 당사자의 잘못 없이 피할 수 없는 사정이었는지를 확인해야 불가항력으로 볼 수 있습니다.

문제 9.
계약 체결 후 물가변동·설계변경 등으로 계약금액·과업·기간 등을 변경하는 절차를 무엇이라 하는가?

정답은 계약변경입니다. 계약 후 물가나 설계, 과업이 달라졌을 때 금액과 기간 등을 공식적으로 다시 정하는 절차입니다.

문제 10.
물가변동에 따른 계약금액 조정을 위해 계약체결일부터 최소 며칠이 경과해야 하는가?

정답은 계약체결일부터 90일입니다. 물가변동 조정의 기간 요건이며, 다음 문제의 3퍼센트 변동 요건과 함께 기억하세요.

문제 11.
물가변동으로 계약금액 조정을 하기 위한 품목조정률 또는 지수조정률의 기준 증감률은 얼마 이상인가?

정답은 3퍼센트 이상입니다. 품목조정률이나 지수조정률이 이 기준 이상 변동해야 계약금액 조정을 검토합니다.

문제 12.
설계변경으로 기존 비목의 증가된 공사량의 단가 산정 시 적용하는 단가는 무엇인가?

정답은 계약단가입니다. 새 비목이 아니라 기존 계약에 이미 있던 비목의 공사량이 늘었다면 기존 단가가 출발점입니다.

문제 13.
설계변경으로 공사량 증감이 발생한 경우 작성하는 내역서는 무엇인가?

정답은 공사량 증감 내역서입니다. 어떤 항목의 물량이 얼마나 늘거나 줄었는지 정리해 금액 조정의 근거로 사용합니다.

문제 14.
변경계약 체결 시 계약금액 산정의 근거가 되는 문서는 무엇인가?

정답은 산출내역서입니다. 변경된 물량과 단가를 적용해 새 계약금액이 어떻게 계산됐는지 보여주는 문서입니다.

문제 15.
계약변경 사유를 공식적으로 요청하는 문서는 무엇인가?

정답은 계약변경 요청서입니다. 변경이 필요한 사유와 내용, 금액과 기간에 미치는 영향을 적어 공식적으로 제출합니다.

문제 16.
설계변경 시 변경된 설계 내용을 표시한 문서는 무엇인가?

정답은 변경 설계도서입니다. 기존 도면과 시방서에서 무엇이 달라졌는지 명확하게 표시해야 실제 시공과 검사 기준이 됩니다.

문제 17.
변경계약 체결 시 계약의 핵심 문서는 무엇인가?

정답은 변경계약서입니다. 합의한 변경내용과 금액, 기간을 공식적인 계약조건으로 확정하는 문서입니다.

문제 18.
계약기간 변경이 필요한 대표적인 사유는 무엇인가?

정답은 불가항력, 설계변경, 발주자 책임으로 생긴 지연입니다. 계약상대자의 책임이 아닌 사유로 일정이 영향을 받았는지가 중요합니다.

문제 19.
변경계약 체결의 법적 효력이 발생하는 시점은 언제인가?

정답은 변경계약을 체결한 시점입니다. 협의 중이라는 이유만으로 변경내용이 곧바로 계약조건이 되는 것은 아닙니다.

문제 20.
변경계약 체결 전 수행 시 발생 가능한 위험은 무엇인가?

정답은 무단 수행에 따른 분쟁과 대금 미지급 위험입니다. 서면으로 변경을 확정하기 전에 추가 작업을 하면 그 비용을 계약상 대가로 인정받지 못할 수 있습니다.

문제 21.
변경계약 설명 시 필수 설명 항목 3가지는 무엇인가?

정답은 계약목적, 변경내용과 과업범위, 계약금액, 계약기간입니다. 원문에는 세 가지라고 되어 있지만 실제 답은 네 묶음이므로 네 항목을 모두 빠뜨리지 않는 것이 안전합니다.

문제 22.
계약금액 설명 시 포함되는 정보는 무엇인가?

정답은 변경 전후 금액과 증감액, 산정근거입니다. 얼마가 바뀌었는지만 아니라 왜 그 금액이 나왔는지까지 설명해야 합니다.

문제 23.
계약기간 변경 설명 시 확인사항은 무엇인가?

정답은 기간을 바꾸는 사유와 변경된 이행일정입니다. 단순히 완료일만 고치는 것이 아니라 지연 원인과 새 추진계획을 함께 확인합니다.

문제 24.
설계변경 설명 시 활용 문서는 무엇인가?

정답은 설계도면과 시방서 같은 설계도서입니다. 말로만 설명하지 않고 변경 전후의 기술적 차이를 문서로 비교해야 합니다.

문제 25.
변경계약 설명 기록 유지의 목적은 무엇인가?

정답은 설명을 제대로 했다는 사실을 증명하고 분쟁에 대비하기 위해서입니다. 나중에 합의 여부가 문제 되면 확인서와 회의록이 중요한 근거가 됩니다.

문제 26.
변경계약 설명 시 금액 산정 근거 제시의 이유는 무엇인가?

정답은 금액 산정의 투명성을 확보하고 합의를 이루기 위해서입니다. 계산 근거가 공개되어야 양쪽이 변경금액을 납득할 수 있습니다.

문제 27.
계약보증 변경 설명 시 확인사항은 무엇인가?

정답은 보증금액과 보증기간의 변경 여부입니다. 계약금액이나 기간이 늘면 보증도 그에 맞게 보완해야 합니다.

문제 28.
변경계약 설명 방법 2가지는 무엇인가?

정답은 서면 설명과 구두 또는 대면 설명입니다. 구두로 설명했더라도 합의내용은 나중에 확인할 수 있게 기록으로 남기는 것이 중요합니다.

문제 29.
변경계약 설명 후 수행해야 할 기록 행위는 무엇인가?

정답은 설명 확인서나 회의록을 작성하는 것입니다. 설명한 내용과 상대방의 확인 여부를 남겨야 변경조건에 대한 다툼을 예방할 수 있습니다.
