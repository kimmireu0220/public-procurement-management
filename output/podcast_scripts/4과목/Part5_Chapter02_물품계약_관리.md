# [Part 5 Chapter 2 팟캐스트 대본 — 물품계약 관리]

문제 1.
물품계약의 계약이행 판단 기준은 무엇인가?

정답은 검사 합격입니다. 물건을 가져다놓는 것만으로는 부족하고 규격과 품질이 계약조건에 맞아야 이행이 완료됩니다.

문제 2.
물품계약에서 품질 판단의 기준 문서는 무엇인가?

정답은 규격서입니다. 요구된 성능과 재질, 치수 등을 실제 납품물과 비교하는 기준입니다.

문제 3.
물품 납기 미준수 시 부과되는 금전적 제재는 무엇인가?

정답은 지체상금입니다. 계약상대자의 책임으로 납품이 늦어지면 지체일수에 따라 부과합니다.

문제 4.
물품 납품 후 품질책임 기간은 무엇인가?

정답은 하자담보기간입니다. 검사에 합격한 뒤에도 이 기간에 발견된 하자는 계약상대자가 책임집니다.

문제 5.
물품계약에서 특정 브랜드 지정을 제한하는 원칙은 무엇인가?

정답은 경쟁성 확보 원칙입니다. 특별한 사유 없이 특정 브랜드만 지정하면 동등한 제품의 참여를 부당하게 막을 수 있습니다.

문제 6.
물품계약 완료 판단 기준 2가지는 무엇인가?

정답은 납품 완료와 검사 합격입니다. 수량을 전부 납품하고 품질검사까지 통과해야 계약이 완료됩니다.

문제 7.
물품계약에서 검사 기준 명확화의 목적은 무엇인가?

정답은 분쟁 예방입니다. 합격과 불합격 기준을 미리 분명히 해야 품질을 둘러싼 다툼을 줄일 수 있습니다.

문제 8.
물품 납품 후 실시하는 적합성 확인 절차는 무엇인가?

정답은 검사입니다. 납품물이 규격서와 계약조건에 맞는지 성능과 품질을 확인합니다.

문제 9.
검사 합격 후 가능한 행위는 무엇인가?

정답은 대가지급 청구입니다. 검사 합격이 확인되어야 납품대금을 지급해 달라고 청구할 수 있습니다.

문제 10.
수량·외관 확인 절차는 무엇인가?

정답은 검수입니다. 납품된 수량과 외관상 상태를 확인하는 절차로, 성능과 품질을 보는 검사와 구분합니다.

문제 11.
제조공정 감독 권한의 주체는 누구인가?

정답은 발주기관입니다. 필요한 경우 제조과정을 감독해 규격에 맞는 제품이 생산되는지 확인할 수 있습니다.

문제 12.
대가 지급 전 필수 선행절차는 무엇인가?

정답은 검사 합격입니다. 계약조건에 맞는 물품을 받았다는 확인 없이 대금을 먼저 지급할 수는 없습니다.

문제 13.
MAS 계약의 계약상대자 수 기준은 얼마인가?

정답은 2인 이상입니다. 다수공급자계약은 같은 품목에 여러 공급자를 두는 제도라는 뜻과 연결하세요.

문제 14.
MAS 기본계약 체결 단계의 첫 절차는 무엇인가?

정답은 적격성 평가입니다. 먼저 업체가 계약자격과 공급능력을 갖췄는지 확인한 뒤 가격협상 등 다음 단계로 갑니다.

문제 15.
MAS 계약이행실적평가 결과 활용 목적은 무엇인가?

정답은 계약연장과 재계약, 2단계 경쟁 평가에 활용하는 것입니다. 납품 실적과 품질 같은 과거 이행성과가 이후 거래기회에 반영됩니다.

문제 16.
MAS 2단계 경쟁 대상 금액(일반제품 기준)은 얼마인가?

정답은 일반제품 기준 5천만원 이상입니다. 이 금액부터 여러 계약업체를 다시 경쟁시키는 2단계 경쟁 대상이 됩니다.

문제 17.
단가계약의 핵심 특징은 무엇인가?

정답은 수량을 미리 확정하지 않는 계약입니다. 품목별 단가를 정해두고 실제 필요가 생길 때 수량을 주문합니다.

문제 18.
단가계약 종료 사유는 무엇인가?

정답은 계약기간 만료, 계약한도액 소진, 해지 또는 해제입니다. 기간이나 금액 한도에 도달하거나 계약관계가 종료되면 더 주문할 수 없습니다.

문제 19.
단가계약 대가지급 요건은 무엇인가?

정답은 검사 합격입니다. 개별 납품요구에 따라 공급한 물품도 검사에 합격해야 대금을 지급받습니다.

문제 20.
단가계약 납품 후 필수 절차는 무엇인가?

정답은 검사와 검수입니다. 수량과 외관을 확인하고 규격과 품질의 적합성까지 확인해야 합니다.
