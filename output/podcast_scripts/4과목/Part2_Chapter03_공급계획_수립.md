# [Part 2 Chapter 3 팟캐스트 대본 — 공급계획 수립]

문제 1.
제조원가의 기본 비목 5가지는 무엇인가?

정답은 재료비, 노무비, 경비, 일반관리비, 이윤입니다. 앞의 세 가지가 생산에 직접 연결되는 원가이고, 여기에 일반관리비와 이윤을 더해 가격을 구성합니다.

문제 2.
공사 직접노무비 단가의 적용 기준은 무엇인가?

정답은 대한건설협회가 발표하는 시중노임단가입니다. 공사 직접노무비를 계산할 때 직종별 노임 기준으로 활용합니다.

문제 3.
일반관리비 계산식을 쓰시오.

정답은 재료비, 노무비, 경비를 더한 금액에 일반관리비율을 곱하는 것입니다. 이윤까지 더한 뒤 계산하는 것이 아니라는 점을 구분하세요.

문제 4.
이윤 계산식을 쓰시오.

정답은 노무비, 경비, 일반관리비를 더한 금액에 이윤율을 곱하는 것입니다. 재료비는 이윤 계산의 기초금액에 넣지 않습니다.

문제 5.
외주가공비는 이윤 계산 시 포함되는가?

정답은 포함하지 않습니다. 외주가공비는 이윤 계산의 기초가 되는 비목에서 제외합니다.

문제 6.
공공조달 원가계산에서 적용되는 부가가치세율은 얼마인가?

정답은 10퍼센트입니다. 원가계산으로 공급가액을 산정한 뒤 부가가치세 10퍼센트를 반영합니다.

문제 7.
면세사업자가 낙찰된 경우 계약금액은 어떻게 산정되는가?

정답은 부가가치세를 제외한 금액으로 계약합니다. 면세사업자는 부가가치세를 납부하지 않으므로 낙찰금액에서 해당 세액을 빼고 계약금액을 정합니다.

문제 8.
공사원가 구성에서 순공사원가 구성요소는 무엇인가?

정답은 재료비, 노무비, 경비입니다. 순공사원가는 공사를 직접 수행하는 데 드는 이 세 비용을 합한 금액입니다.

문제 9.
일위대가표 작성 시 활용되는 기준은 무엇인가?

정답은 표준품셈입니다. 단위 작업에 필요한 인력과 자재, 장비의 수량을 산정할 때 표준품셈을 기준으로 일위대가표를 작성합니다.

문제 10.
기존 시설 철거로 발생한 부산물은 재료비에서 공제하는가?

정답은 공제하지 않습니다. 기존 시설을 철거하면서 나온 부산물은 재료비에서 바로 빼는 항목이 아니라는 점을 기억하세요.

문제 11.
학술연구용역 인력의 등급 4단계를 쓰시오.

정답은 책임연구원, 연구원, 연구보조원, 보조원입니다. 책임 수준이 높은 순서대로 내려간다고 생각하면 기억하기 쉽습니다.

문제 12.
공동연구형 용역에서 일반관리비는 어떻게 처리하는가?

정답은 일반관리비를 따로 계상하지 않습니다. 공동연구형 용역의 원가를 계산할 때 적용되는 처리방식입니다.

문제 13.
설계변경 시 원가계산의 목적은 무엇인가?

정답은 계약금액 조정입니다. 설계가 바뀌면 물량과 비용도 달라지므로 변경된 내용에 맞춰 계약금액을 다시 계산합니다.

문제 14.
공구손료의 산정 기준은 무엇인가?

정답은 해당 공종의 노무비에 품셈률을 곱하는 것입니다. 공구손료는 별도의 실구매가격이 아니라 이 산식으로 계산합니다.

문제 15.
소모 잡자재의 산정 기준은 무엇인가?

정답은 주재료비에 품셈률을 곱하는 것입니다. 공구손료는 노무비, 소모 잡자재는 주재료비가 기준이라는 차이를 구분하세요.

문제 16.
이윤 산정 시 제외되는 비목 2가지를 쓰시오.

정답은 외주가공비와 기술료입니다. 두 비목 모두 이윤 산정의 기초금액에서는 제외합니다.

문제 17.
거래실례가격이 존재하는데, 원가계산가격이 더 낮다면 예정가격 결정 시 어떤 가격을 적용해야 하는가?

정답은 거래실례가격을 우선 적용합니다. 실제 거래가격이 확인된다면 원가계산 결과가 더 낮더라도 임의로 낮은 가격을 선택하지 않습니다.

문제 18.
특정 상표만을 지시하는 규격은 무엇에 위반될 수 있는가?

정답은 경쟁원칙입니다. 특별한 이유 없이 특정 상표만 지정하면 다른 업체와 제품의 참여를 막아 경쟁을 부당하게 제한할 수 있습니다.

문제 19.
기술 적합도 검증은 입찰절차 중 어느 단계에서 수행되는가?

정답은 입찰 참여를 결정하기 전의 사전검토 단계입니다. 요구 규격과 인증, 수행능력을 미리 확인해야 자격 미달이나 이행 실패를 피할 수 있습니다.

문제 20.
입찰에서 요구한 인증서를 보유하지 못한 경우 어떻게 처리하는가?

정답은 부적격 처리입니다. 공고에서 필수로 요구한 인증서가 없다면 가격평가까지 가기 전에 참가요건을 충족하지 못한 것으로 처리됩니다.

문제 21.
공사의 기술 적합성 검증에서 핵심은 무엇인가?

정답은 설계도서를 충족하는지 여부입니다. 도면과 시방서에 적힌 재료, 성능, 시공조건을 실제로 맞출 수 있는지 확인합니다.

문제 22.
공급계획 수립 전에 반드시 수행해야 하는 단계는 무엇인가?

정답은 환경분석입니다. 수요와 가격, 경쟁, 제도를 먼저 파악해야 현실적인 공급계획을 세울 수 있습니다.

문제 23.
발주물량과 발주기관 분석은 어떤 환경분석에 해당하는가?

정답은 수요환경 분석입니다. 누가 얼마나 발주하는지를 보는 것이므로 발주물량과 발주기관이 핵심 자료가 됩니다.

문제 24.
평균 낙찰 분석은 어떤 환경분석에 해당하는가?

정답은 가격환경 분석입니다. 평균 낙찰률을 보면 시장에서 어느 정도 가격으로 계약이 형성되는지 알 수 있습니다.

문제 25.
계약 방법 분석은 어떤 환경분석에 해당하는가?

정답은 제도환경 분석입니다. 일반경쟁인지 제한경쟁인지처럼 계약방법을 정하는 규칙과 제도를 살펴보는 분석입니다.

문제 26.
낙찰률이 낮은 시장은 무엇이 강한 시장인가?

정답은 경쟁 강도가 강한 시장입니다. 낙찰률이 낮다는 것은 예정가격보다 더 낮게 써야 이길 가능성이 크다는 뜻이므로 가격경쟁이 치열하다고 볼 수 있습니다.

문제 27.
중소기업자 간 경쟁제품 여부는 어느 환경에 해당하는가?

정답은 경쟁환경입니다. 중소기업자 간 경쟁제품으로 지정되면 참여할 수 있는 기업의 범위가 달라지기 때문에 경쟁구조에 직접 영향을 줍니다.

문제 28.
공급계획 수립의 궁극적 목적은 무엇인가?

정답은 수익성과 시장점유율 확대입니다. 많이 수주하는 것만이 아니라 적정한 이익을 남기면서 공공시장 내 입지를 키우는 것이 궁극적인 목표입니다.
