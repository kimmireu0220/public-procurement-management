# [Part 4 Chapter 2 팟캐스트 대본 — 계약이행 관리]

문제 1.
계약이 달성하려는 최종 목표를 의미하는 계약내용 요소는 무엇인가?

정답은 계약 목적입니다. 이 계약을 통해 최종적으로 무엇을 이루려는지를 나타냅니다.

문제 2.
계약 수행 범위와 규격을 의미하는 계약요소는 무엇인가?

정답은 계약 대상입니다. 무엇을 납품하거나 수행해야 하는지 그 범위와 규격을 정하는 요소입니다.

문제 3.
계약 대가로 지급되는 금전적 요소는 무엇인가?

정답은 계약금액입니다. 계약상대자가 목적물을 납품하거나 과업을 수행한 대가로 지급받는 금액입니다.

문제 4.
계약 수행 시작부터 완료까지의 기간을 의미하는 것은 무엇인가?

정답은 이행기간입니다. 착수일부터 완료일까지 계약을 수행해야 하는 기간을 말합니다.

문제 5.
발주자의 요구사항을 구체적으로 제시한 문서를 무엇이라 하는가?

정답은 과업지시서, 규격서 또는 제안요청서입니다. 발주기관이 원하는 업무와 성능, 수행조건을 구체적으로 적은 문서입니다.

문제 6.
계약내용 파악 활동은 계약관리의 어느 단계에서 핵심적인가?

정답은 계약 초기 단계입니다. 시작할 때 계약내용을 정확히 파악해야 이후 일정과 품질, 비용을 제대로 관리할 수 있습니다.

문제 7.
계약 대상의 성능·품질 기준을 명시한 문서를 무엇이라 하는가?

정답은 규격서입니다. 납품할 물품이나 결과물이 갖춰야 할 성능과 품질을 판단하는 기준입니다.

문제 8.
이행기간 지연 시 발생하는 금전적 제재는 무엇인가?

정답은 지체상금입니다. 계약상대자의 책임으로 납품이나 완료가 늦어지면 지체일수에 따라 부과합니다.

문제 9.
「국가계약법 시행규칙」 제75조에 따르면, 물품의 제조·구매 계약의 지체상금률은 얼마인가?

정답은 1천분의 0.75입니다. 물품 제조·구매 계약의 지체상금률이며, 공사나 용역의 요율과 구분해야 합니다.

문제 10.
계약 체결 후 계약목적 달성을 위해 수행절차 및 방법을 체계적으로 설계하는 활동은 무엇인가?

정답은 계약관리계획 수립입니다. 일정과 품질, 비용, 위험을 어떤 방식으로 관리할지 계약 초기에 체계적으로 정하는 활동입니다.

문제 11.
계약 수행 시작 시 발주자에게 제출하는 보고는 무엇인가?

정답은 착수보고입니다. 수행조직과 일정, 세부 추진방법을 발주기관에 알리고 계약이행의 시작을 공식화합니다.

문제 12.
계약목적물 품질 적합 여부 확인 절차는 무엇인가?

정답은 검사 또는 검수입니다. 납품된 물품이나 결과물이 계약서와 규격서의 품질기준을 충족하는지 확인합니다.

문제 13.
계약이행 중 위험요인을 식별·대응하는 활동은 무엇인가?

정답은 위험관리입니다. 납품지연이나 품질문제 같은 위험을 미리 찾아 대응하고 실제 문제가 생기면 영향을 줄이는 활동입니다.

문제 14.
계약이행 방법 중 주계약자가 전체 수행을 대표하는 방식은 무엇인가?

정답은 주계약자관리방식입니다. 주계약자가 전체 이행을 대표하고 참여업체의 업무를 조정하는 방식입니다.

문제 15.
계약이행 진행 상황을 점검하는 활동은 무엇인가?

정답은 진도관리입니다. 계획한 일정과 실제 진행률을 비교해 지연 여부를 확인하고 필요한 조치를 합니다.

문제 16.
수행방법 중 여러 업체가 공동으로 수행하는 방식은 무엇인가?

정답은 공동수급입니다. 여러 업체가 공동수급체를 구성해 각자의 전문분야나 지분에 따라 계약을 함께 수행합니다.

문제 17.
선급금의 목적은 무엇인가?

정답은 계약이행에 필요한 자금을 미리 지원하는 것입니다. 재료 구입이나 인력 투입에 필요한 초기 자금 부담을 덜어줍니다.

문제 18.
선급금 산정 기본 공식은 무엇인가?

정답은 계약금액에 선급금 지급률을 곱하는 것입니다. 지급률을 퍼센트로 바꿔 계약금액에 적용하면 됩니다.

문제 19.
선급금 지급의 법적 근거 규정은 무엇인가?

정답은 국고금관리법 시행령 제40조입니다. 선급금을 지급할 수 있는 법적 근거 조항으로 연결해 기억하세요.

문제 20.
선급금 지급 후 정산 방식은 무엇인가?

정답은 기성대가에서 상계하는 방식입니다. 계약이 진행되어 기성대가를 지급할 때 이미 준 선급금을 일정 부분씩 차감합니다.

문제 21.
선급금 사용 제한 원칙은 무엇인가?

정답은 목적 외 사용 금지입니다. 선급금은 해당 계약의 인건비나 자재비 등 이행에 필요한 용도로만 사용해야 합니다.

문제 22.
계약해제 시 선급금은 어떻게 처리하는가?

정답은 반환입니다. 계약이 해제되면 더 이상 이행자금으로 사용할 근거가 없으므로 정산 후 남은 선급금을 돌려줘야 합니다.

문제 23.
선급금 보증 목적은 무엇인가?

정답은 선급금 회수 위험에 대한 손해 담보입니다. 업체가 계약을 이행하지 못해 선급금을 돌려받지 못할 상황에 대비합니다.

문제 24.
선급금 지급률 상한은 얼마인가?

정답은 계약금액의 70퍼센트입니다. 선급금 지급률의 상한이라는 점을 기억하세요.

문제 25.
계약 수행 일정 준수 여부를 관리하는 활동은 무엇인가?

정답은 일정관리입니다. 주요 작업의 시작일과 완료일을 계획하고 실제 이행이 그 일정에 맞는지 확인합니다.

문제 26.
계약금액 범위 내 집행 관리 활동은 무엇인가?

정답은 비용관리입니다. 계약금액을 넘지 않도록 지출과 잔액을 확인하고 변경비용 발생 가능성을 관리합니다.
