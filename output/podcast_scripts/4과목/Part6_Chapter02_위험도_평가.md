# [Part 6 Chapter 2 팟캐스트 대본 — 위험도 평가]

문제 1.
위험도 평가의 1차 목적은 무엇인가?

정답은 우선순위 설정입니다. 모든 위험에 같은 자원을 쓸 수 없으므로 큰 위험부터 대응하기 위해 평가합니다.

문제 2.
기대손실값(EV)은 어떤 평가 방식인가?

정답은 정량적 평가입니다. 발생확률과 손실금액을 수치로 계산해 위험을 비교합니다.

문제 3.
위험 허용수준을 의미하는 용어는 무엇인가?

정답은 리스크 톨러런스입니다. 조직이 목표를 추진하면서 받아들일 수 있는 위험의 한계를 뜻합니다.

문제 4.
위험도 시각화 도구는 무엇인가?

정답은 위험도 매트릭스입니다. 발생확률과 영향도를 표에 배치해 고위험과 저위험을 한눈에 구분합니다.

문제 5.
조달계획 단계에서 위험도 평가를 실시하는 이유는 무엇인가?

정답은 사전 예방입니다. 계약 후 문제가 터진 뒤 수습하기보다 계획 단계에서 위험을 줄이는 편이 비용과 시간이 적게 듭니다.

문제 6.
위험 수용 전략은 언제 사용하는가?

정답은 영향이 경미할 때입니다. 대응비용이 예상손실보다 크다면 위험을 받아들이고 관찰하는 편이 합리적일 수 있습니다.

문제 7.
위험도 산정의 기본 산식은 무엇인가?

정답은 발생확률 곱하기 영향도입니다. 두 값 중 하나만 보지 말고 가능성과 피해크기를 함께 평가합니다.

문제 8.
과거 유사사업 통계 활용 방식은 어떤 추정 방법인가?

정답은 정량적 추정입니다. 과거 통계의 발생빈도와 손실액을 숫자로 활용하기 때문입니다.

문제 9.
공급자의 재무건전성은 어떤 요인에 해당하는가?

정답은 공급자 요인입니다. 재무상태가 나쁘면 생산중단이나 계약불이행 위험이 커집니다.

문제 10.
환율 변동은 어떤 요인인가?

정답은 외부 요인입니다. 환율은 시장에서 변하며 개별 계약 당사자가 통제하기 어렵습니다.

문제 11.
전문가 판단에 의존하는 방식의 단점은 무엇인가?

정답은 주관성이 개입될 수 있다는 점입니다. 경험이 유용하더라도 전문가마다 판단이 달라질 수 있습니다.

문제 12.
영향도는 무엇을 의미하는가?

정답은 리스크가 실제로 발생했을 때 피해가 얼마나 큰지입니다. 비용뿐 아니라 일정과 품질, 평판 피해도 포함할 수 있습니다.

문제 13.
일정 지연은 어떤 2차 리스크로 연결되는가?

정답은 비용 증가입니다. 일정이 늘어나면 인력과 장비를 더 오래 사용해 추가비용이 생깁니다.

문제 14.
검사 불합격은 어떤 영향 유형에 해당하는가?

정답은 품질 영향입니다. 검사 불합격은 결과물이 요구 수준을 충족하지 못했다는 뜻입니다.

문제 15.
실제 금액으로 손실을 산정하는 방식은 무엇인가?

정답은 정량적 평가입니다. 손실을 원 단위처럼 수치로 표현해 위험 간 크기를 비교합니다.

문제 16.
정성적 산정의 단점은 무엇인가?

정답은 주관성 개입입니다. 높음·중간·낮음 같은 등급은 평가자의 경험에 따라 달라질 수 있습니다.

문제 17.
대규모 사업에 적합한 산정 방식은 무엇인가?

정답은 정량적 산정입니다. 사업 규모가 클수록 작은 판단 차이도 큰 금액으로 이어져 수치에 근거한 분석이 중요합니다.

문제 18.
조직의 외부 환경 요인 중 1가지는 무엇인가?

정답은 정치적 요인입니다. 경제상황이나 법령 변화도 조직 밖에서 발생하는 대표적인 외부 환경 요인입니다.

문제 19.
성공적 조달을 방해하는 구매자 측 위험은 무엇인가?

정답은 과도한 요구입니다. 예산과 기간에 비해 지나친 성능을 요구하면 경쟁이 줄고 이행 실패 가능성이 커집니다.

문제 20.
계약관리 과정에서 위험요소 1가지는 무엇인가?

정답은 납품지연입니다. 후속 일정과 대금지급, 사업 전체의 완료시점까지 영향을 줄 수 있습니다.
