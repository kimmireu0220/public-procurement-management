# [Part 4 Chapter 4 팟캐스트 대본 — 계약종결 관리]

문제 1.
계약이행 완료 판단 시 가장 기본적으로 확인하는 문서는 무엇인가?

정답은 계약서입니다. 무엇을 언제까지 이행하기로 했는지 계약서의 기본 조건과 실제 결과를 먼저 비교합니다.

문제 2.
공사계약에서 기술적 완성 여부 판단의 기준 문서는 무엇인가?

정답은 설계서 또는 설계도서입니다. 도면과 시방서대로 시공됐는지를 확인해야 공사가 기술적으로 완성됐다고 판단할 수 있습니다.

문제 3.
용역계약에서 이행 완료 판단의 주요 기준 문서는 무엇인가?

정답은 과업지시서입니다. 요구한 업무와 산출물이 모두 제출됐는지 과업지시서의 항목별로 확인합니다.

문제 4.
계약이행 완료 판단 시 변경사항 반영 여부를 확인하는 문서는 무엇인가?

정답은 변경계약서입니다. 최초 계약서만 보면 이후 합의한 변경내용을 놓칠 수 있으므로 최종 변경계약까지 함께 확인해야 합니다.

문제 5.
계약이행 완료 판단 시 하자 발생 여부를 확인하는 목적은 무엇인가?

정답은 하자책임을 판단하기 위해서입니다. 완료 처리 뒤 발견된 문제를 누가 어떤 기간 동안 보수해야 하는지 정하는 근거가 됩니다.

문제 6.
계약이행 완료 판단 결과는 무엇의 선행요건인가?

정답은 대금지급입니다. 계약이행이 완료되고 검사에 합격해야 계약상대자가 잔금을 청구할 수 있습니다.

문제 7.
계약이행 완료 판단 시 기간 준수 여부 확인의 목적은 무엇인가?

정답은 지체상금 적용 여부를 판단하기 위해서입니다. 약정한 완료일을 넘겼는지와 그 지연에 계약상대자의 책임이 있는지를 확인합니다.

문제 8.
계약종결 처리의 출발점이 되는 절차는 무엇인가?

정답은 계약이행 완료 확인입니다. 목적물이 계약조건에 맞게 완성됐다는 확인이 있어야 검사와 대금지급, 보증금 반환으로 넘어갈 수 있습니다.

문제 9.
검사 수행을 위해 제출하는 서류는 무엇인가?

정답은 검사요청서입니다. 계약상대자가 이행을 마쳤으니 검사를 진행해 달라고 공식적으로 요청하는 문서입니다.

문제 10.
검사 결과를 기록하는 문서는 무엇인가?

정답은 검사조서입니다. 무엇을 검사했고 합격 여부가 어떤지를 공식 기록으로 남깁니다.

문제 11.
공사 완료 시 제출하는 서류는 무엇인가?

정답은 준공계입니다. 시공업체가 공사를 모두 마쳤음을 발주기관에 알리는 대표적인 완료서류입니다.

문제 12.
대가지급을 요청하는 문서는 무엇인가?

정답은 대가지급 청구서입니다. 검사 합격 뒤 계약금액을 지급해 달라고 요청할 때 제출합니다.

문제 13.
하자책임 확보를 위한 서류는 무엇인가?

정답은 하자보증서입니다. 계약종결 뒤 하자가 발생했을 때 보수책임과 비용을 담보합니다.

문제 14.
계약종결 후 보증금 반환을 요청하는 문서는 무엇인가?

정답은 계약보증금 반환신청서입니다. 계약을 정상적으로 마친 뒤 맡겨 둔 보증금을 돌려받기 위해 제출합니다.

문제 15.
공사·용역 기성대가를 지급하는 근거 문서는 무엇인가?

정답은 기성검사조서입니다. 전체 완료 전이라도 실제로 진행된 부분을 검사하고 그만큼의 대가를 지급하는 근거가 됩니다.

문제 16.
계약이행 완료 사실을 통보하는 대표 서류는 무엇인가?

정답은 공사의 준공계, 물품의 납품완료서, 용역의 완료보고서입니다. 계약 유형마다 완료 사실을 알리는 서류가 다릅니다.

문제 17.
대가지급의 회계 근거가 되는 서류는 무엇인가?

정답은 지급결의서입니다. 검사와 청구 내용을 확인한 뒤 회계상 실제 지급을 결정하는 문서입니다.

문제 18.
용역 완료 시 제출하는 대표 서류는 무엇인가?

정답은 용역완료보고서입니다. 수행한 업무와 결과물을 정리해 과업이 끝났음을 공식적으로 알립니다.

문제 19.
검사합격 후 발급되는 지급 관련 통보서는 무엇인가?

정답은 검사합격 통보서입니다. 목적물이 계약조건을 충족했다는 사실을 알리고 대금지급 절차로 넘어가는 근거가 됩니다.

문제 20.
계약이행 완료 여부를 확인하는 공식 문서는 무엇인가?

정답은 검사조서입니다. 검사 결과와 합격 여부가 적혀 있어 계약이행 완료를 공식적으로 확인할 수 있습니다.

문제 21.
장래를 향하여 계약 효력을 소멸시키는 것은 무엇인가?

정답은 해지입니다. 해지는 앞으로의 계약관계를 끝내는 것이고, 해제는 원칙적으로 계약을 처음부터 없었던 상태로 돌리는 개념입니다.

문제 22.
계약상대자 귀책 시 국고귀속되는 것은 무엇인가?

정답은 계약보증금입니다. 계약상대자의 책임으로 계약이 해제되거나 해지되면 이행 담보로 낸 보증금이 국고에 귀속될 수 있습니다.

문제 23.
해제·해지 전 실시하는 절차는 무엇인가?

정답은 시정요구와 의견청취, 즉 청문입니다. 바로 계약을 끝내기보다 위반을 고칠 기회와 당사자가 의견을 밝힐 절차를 거칩니다.

문제 24.
해제 후 재산관계 정리의 원칙은 무엇인가?

정답은 원상회복입니다. 계약으로 주고받은 급부를 되돌려 계약 전 상태로 복귀시키는 것이 원칙입니다.

문제 25.
계약 해지 후 기존 이행 부분의 효력은 어떻게 되는가?

정답은 유효합니다. 해지는 장래를 향해 효력이 사라지므로 해지 전에 이미 적법하게 이행된 부분까지 소급해 없어지지는 않습니다.
