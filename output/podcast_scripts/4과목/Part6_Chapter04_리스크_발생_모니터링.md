# [Part 6 Chapter 4 팟캐스트 대본 — 리스크 발생 모니터링]

문제 1.
리스크 대응계획의 궁극적 목적은 무엇인가?

정답은 실효성 확보입니다. 계획을 세우는 데서 끝내지 않고 실제로 실행돼 위험을 줄였는지 확인해야 합니다.

문제 2.
실행 상태 구분의 기본 3단계는 무엇인가?

정답은 완료, 진행 중, 미실행입니다. 각 대응조치가 어디까지 진행됐는지 세 단계로 나누어 관리합니다.

문제 3.
실행 여부 확인 시 형식적 점검을 지양해야 하는 이유는 무엇인가?

정답은 실질적인 이행을 확보하기 위해서입니다. 서류에 완료라고 표시됐는지가 아니라 현장에서 실제 조치가 작동하는지를 봐야 합니다.

문제 4.
실행되지 않은 리스크는 어떻게 해야 하는가?

정답은 재평가입니다. 실행하지 못한 이유와 현재 위험도를 다시 확인해 계획을 수정하거나 우선순위를 높입니다.

문제 5.
현장 확인의 목적은 무엇인가?

정답은 실질적인 이행 확인입니다. 보고서 내용과 실제 현장상태가 일치하는지를 직접 검증합니다.

문제 6.
대응조치 성과 확인의 궁극적 목적은 무엇인가?

정답은 위험이 실제로 감소했는지 확인하는 것입니다. 조치 실행 자체가 아니라 결과가 중요합니다.

문제 7.
리스크 감소의 2대 지표는 무엇인가?

정답은 발생확률과 영향도입니다. 대응 전후 두 값이 얼마나 낮아졌는지를 비교합니다.

문제 8.
성과를 수치로 측정하는 방법은 무엇인가?

정답은 정량적 분석입니다. 지연일수나 손실금액처럼 측정 가능한 값으로 성과를 확인합니다.

문제 9.
대응비용 대비 효과를 분석하는 것은 무엇인가?

정답은 비용효과 분석입니다. 대응에 든 비용과 줄어든 손실을 비교해 조치가 경제적이었는지 판단합니다.

문제 10.
대응계획을 실행했더라도 성과가 없을 경우 필요한 조치는 무엇인가?

정답은 대응방안 재설계입니다. 실행했다는 이유로 유지하지 말고 효과가 없으면 원인부터 다시 분석해야 합니다.

문제 11.
핵심성과지표를 무엇이라 하는가?

정답은 케이피아이입니다. 목표 달성 정도를 측정하는 핵심성과지표의 영문 약자입니다.

문제 12.
성과 확인 후 등급을 다시 조정하는 것을 무엇이라 하는가?

정답은 리스크 등급 재조정입니다. 대응 결과에 따라 고위험을 낮추거나 새로 커진 위험의 등급을 높입니다.

문제 13.
기존 계획에 없는 위험을 무엇이라 하는가?

정답은 신규 리스크입니다. 처음 목록에 없었더라도 환경이 바뀌면 새 위험으로 등록해야 합니다.

문제 14.
새로운 리스크는 주로 언제 발생하는가?

정답은 환경이 변할 때입니다. 법령과 정책, 시장가격, 공급업체 상태 변화가 새로운 위험을 만들 수 있습니다.

문제 15.
리스크 등록 문서는 무엇인가?

정답은 리스크 레지스터입니다. 위험의 내용과 등급, 대응조치, 담당자를 한곳에 기록하는 문서입니다.

문제 16.
법령 개정의 리스크 원인은 무엇인가?

정답은 외부 환경 변화입니다. 법령은 조직 밖에서 바뀌지만 계약조건과 절차에는 직접 영향을 줍니다.

문제 17.
현장 의견을 수집하는 목적은 무엇인가?

정답은 위험의 조기 감지입니다. 현장 담당자는 서류에 나타나기 전의 지연과 품질 징후를 가장 먼저 발견할 수 있습니다.

문제 18.
사업범위 변경은 무엇을 초래하는가?

정답은 새로운 비용과 일정 리스크입니다. 해야 할 일이 달라지면 필요한 자원과 완료시점도 함께 변합니다.

문제 19.
리스크 모니터링의 최종 목적은 무엇인가?

정답은 개선조치를 이끌어내는 것입니다. 상태를 보고하는 데 그치지 않고 필요한 의사결정과 행동으로 이어져야 합니다.

문제 20.
리스크 모니터링 결과 공유의 핵심 가치는 무엇인가?

정답은 투명성입니다. 위험과 대응상태를 숨기지 않고 공유해야 관계자들이 같은 정보를 바탕으로 판단할 수 있습니다.

문제 21.
신규 리스크 발생 시 필요한 조치는 무엇인가?

정답은 등록과 보고입니다. 위험목록에 추가하고 의사결정권자와 담당자에게 즉시 알려야 합니다.

문제 22.
보고의 필수 요소는 무엇인가?

정답은 문서화입니다. 구두보고만으로 끝내지 않아야 조치내용과 책임, 변화 추적이 가능합니다.

문제 23.
공공조달에서 공유가 중요한 이유는 무엇인가?

정답은 책임성 확보입니다. 공공자금과 서비스에 영향을 주는 위험이므로 누가 무엇을 판단하고 조치했는지 확인할 수 있어야 합니다.
