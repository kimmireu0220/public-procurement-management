# Part 1 CHAPTER 02 입찰참가자격 정보 관리

> 박문각 수험서 Part 1 CHAPTER 02를 바탕으로 하며, 숫자와 절차는 조달청 표준교재 제1장을 우선하여 정리하였다.

## 1. 학습 목표

- 품명·세부품명·품목의 차이와 번호체계를 구분할 수 있다.
- 품명 신설과 품목 등록의 선후관계를 설명할 수 있다.
- 경쟁입찰참가자격 등록정보의 변경 대상을 구분할 수 있다.
- 목록화 요청과 입찰 제출서류 관리 절차를 정리할 수 있다.

## 2. 한눈에 보는 구조

`품명 검색·신설 → 등록정보 변경 → 제품 목록화 → 제출서류 관리`

| 업무 | 주체 | 결과 |
|---|---|---|
| 분류 확인 | 공급업체 | 기존 품명 사용 또는 신설 요청 |
| 정보 갱신 | 공급업체·조달청 | 실제 회사정보와 나라장터 정보 일치 |
| 목록화 | 공급업체·조달청 | 물품식별번호 부여 |
| 서류 관리 | 입찰 담당자 | 자격·가격·기술·심사 서류 적기 제출 |

## 3. 품명·세부품명·품목

| 용어 | 의미 |
|---|---|
| 품명 | 비슷한 기능과 용도를 가진 물품 유형 |
| 세부품명 | 입찰·계약에 활용하도록 품명을 더 구체화한 단위 |
| 품목 | 제조업체, 모델, 규격과 속성까지 결합한 실제 제품 단위 |

물품분류는 대분류 2자리, 중분류 4자리, 소분류 6자리, 세분류 8자리로 내려간다. 세부품명번호는 10자리다.

신제품이 있더라도 즉시 새 분류를 요청하지 않는다. 목록정보시스템에서 동일·유사 분류를 먼저 검색하고 적절한 분류가 없을 때만 신설을 요청한다.

### 세부품명 신설 판단기준

- 기존 품명으로 분류하기 어려운가
- 독립적인 기능이 있는가
- 실제 시장 수요가 있는가
- 공공조달에서 별도로 관리할 필요가 있는가

업체는 기존 품명과의 차이, 제품의 용도·기능·성능을 설명하는 자료를 제출한다. 조달청이 중복 여부, 독립적 상품성과 조달 활용 가능성을 심사하고 승인하면 새 코드 아래에서 품목 등록을 진행한다.

## 4. 품명 신설과 품목 등록

`세부품명 검색 → 세부품명이 없으면 신설 요청 → 신설 승인 → 자사 제품 품목 등록`

세부품명이 이미 있으면 새 품명을 만들지 않고 그 분류 아래에서 품목 등록을 요청한다. 품명 신설은 분류체계를 만드는 일이고, 품목 등록은 그 분류 아래 실제 제품에 식별번호를 받는 일이다.

## 5. 경쟁입찰참가자격 등록정보 갱신

회사명, 대표자, 주소, 공장, 제조물품과 업종이 변경되면 나라장터 정보도 실제 상태에 맞게 갱신해야 한다.

| 업체 자체 수정 가능 | 조달청 확인·승인 필요 |
|---|---|
| 전화·팩스, 종업원 수, 홈페이지, 담당자 연락처 | 상호, 주소, 법인 대표자, 기업구분 |
| 행정상 연락정보 | 공장정보, 제조물품, 공사·용역 업종 |
|  | 지사등록, 등기부등본 관련 사항 |

대표자나 상호가 바뀌었는데 등록정보를 고치지 않은 상태로 입찰하면 입찰무효가 될 수 있다. 변경신청 후 시행문과 제출서류 요구 여부를 확인하고 승인 완료까지 추적해야 한다.

법인 상호가 변경되면 공동인증서를 새로 발급받아 나라장터에 추가 등록하고 사업자등록증, 면허·인가 관련 서류도 변경한다. 퇴사자는 입찰대리인과 소속직원 정보에서 즉시 삭제한다.

지사 대표자는 본점 법인의 법정대표자가 아니라 사용인에 해당한다. 지사 대표자 변경 문제와 법인 대표자 변경 문제를 동일하게 판단하지 않는다.

## 6. 공급물품 목록화

목록화는 공공조달에서 거래되는 물품에 고유한 식별체계를 부여하는 절차다. 중복 등록을 방지하고 제조업체와 모델을 명확히 식별하며 전자계약·납품관리와 종합쇼핑몰 업무에 활용한다.

### 번호체계

- 품명번호: 8자리
- 물품식별번호: 8자리
- 물품목록번호: 품명번호 8자리 + 물품식별번호 8자리 = 16자리

### 목록화 요청 항목

- 활용용도와 세부품명
- 제조업체, 모델명, 단위와 제품 설명
- 규격서, 도면과 매뉴얼
- 크기, 무게, 재질, 사용인원 등 속성값
- 실제 제품 사진

그래픽 이미지는 실물 식별자료로 사용할 수 없다. 모델명과 속성값은 규격서·카탈로그와 일치해야 한다.

활용용도에는 다수공급자계약, 우수제품, 일반 또는 제3자단가계약, 총액계약, 벤처나라, 혁신제품 계약 등이 있다. 품목구분은 일반용, 계약용, 시설자재용, 입찰공고용, 물품관리용으로 나뉘며 사용 목적이 다르다.

### 등록 방식

- 개별요청: 품목별로 직접 입력하거나 유사품목을 참조하여 등록한다.
- 일괄요청: 동일 세부품명 아래 등록할 품목이 10개 이상일 때 사용할 수 있다. 정해진 엑셀 양식으로 최대 500건까지 신청한다.
- 참조등록: 이전 요청자료나 유사한 물품식별번호를 불러와 필요한 항목을 수정한다.

융합상품은 서로 다른 세부품명이 결합하여 하나의 몸체로 기능하는 상품이다. 복합상품은 독립된 여러 품목이 하나의 시스템을 구성하는 상품이다.

## 7. 입찰참가 제출서류

입찰공고문, 입찰유의서와 제안요청서가 실제 제출서류와 시기를 판단하는 기준이다.

| 구분 | 주요 서류 |
|---|---|
| 참가자격 | 사업자등록증, 등기부등본, 인감 관련 서류, 업종등록증, 직접생산확인증명서 |
| 가격 | 입찰서, 가격제안서, 산출내역서, 입찰보증금 서류 |
| 기술·제안 | 기술제안서, 수행계획서, 인력투입계획, 실적증명서, 신용평가등급 |
| 심사·협상 | 재무제표, 납세·4대보험 완납증명서, 실적증명서 원본 |

사전제출 서류는 입찰서와 함께 내며 누락하면 입찰무효나 평가 제외가 될 수 있다. 사후제출 서류는 낙찰예정자 등 지정 대상이 제출하며 기한을 넘기면 낙찰이 취소될 수 있다.

전자제출 시에는 파일형식, 유효기간, 발급일 기준, 원본대조 필요 여부와 정상 전송 여부를 확인한다.

## 실무 절차 정리

1. 공급업체가 목록정보시스템에서 기존 품명과 세부품명을 검색한다.
2. 적합한 분류가 없으면 차이·기능·수요·조달 필요성을 설명하여 신설을 요청한다.
3. 신설 승인 후 자사 제품의 품목 등록을 요청한다.
4. 회사정보가 변경되면 자체 수정 항목과 승인 필요 항목을 구분하여 나라장터 정보를 갱신한다.
5. 목록화 전에 동일·유사 물품식별번호의 존재 여부를 확인한다.
6. 제품정보, 속성, 규격자료와 실물사진을 제출하여 물품식별번호를 받는다.
7. 공고문을 기준으로 제출서류를 자격·가격·기술·심사로 구분한다.
8. 각 서류의 사전·사후 제출 여부와 누락 효과를 확인한다.

## 비교·주의사항

| 구분 | 핵심 차이 |
|---|---|
| 품명 신설 / 품목 등록 | 분류체계 생성 / 실제 제품 식별 |
| 세부품명번호 / 물품목록번호 | 10자리 / 16자리 |
| 자체 수정 / 승인 변경 | 연락정보 / 자격에 영향을 주는 정보 |
| 개별요청 / 일괄요청 | 품목별 입력 / 동일 세부품명 10개 이상 |
| 융합상품 / 복합상품 | 하나의 몸체 / 독립 품목의 시스템 |
| 사전제출 / 사후제출 | 입찰 단계 / 낙찰예정자 등 후속 단계 |

## 숫자·기한·시스템

| 항목 | 기준 |
|---|---:|
| 품명 등록 처리 | 원칙적으로 24일 |
| 신산업 품명 처리 | 17일 |
| 품목 등록 처리 | 8일 |
| 품목 변경 처리 | 5일 |
| 보완기한 | 보완요청 후 15일 이내 |
| 일괄요청 사용 | 동일 세부품명 10개 이상 |
| 일괄요청 최대 | 500건 |

위 처리기간과 보완기한은 조달청 표준교재 제1장 기준이다. 분류와 목록화에는 목록정보시스템을, 경쟁입찰참가자격 정보 관리에는 나라장터를 사용한다.

## 최종 정리

- 품명은 물품 유형, 세부품명은 구체화된 계약 단위, 품목은 실제 제품 단위다.
- 기존 분류를 먼저 검색하고 적절한 분류가 없을 때만 신설을 요청한다.
- 품명 신설 승인 후 실제 제품의 품목 등록이 가능하다.
- 실제 회사정보와 나라장터 등록정보는 항상 일치해야 한다.
- 자격에 영향을 주는 정보는 조달청 확인과 승인이 필요하다.
- 목록화 결과 개별 제품에 물품식별번호가 부여된다.
- 물품목록번호는 품명번호 8자리와 물품식별번호 8자리로 구성된다.
- 제출서류는 목적과 제출시기, 누락 효과를 함께 관리한다.
