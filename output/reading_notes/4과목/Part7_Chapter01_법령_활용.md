# Part 7 Chapter 1 법령 활용

## 자료 기준

- 박문각 Part 7 `page_0002.jpg`~`page_0008.jpg`
- 표준교재 제7장 연결: 종합쇼핑몰과 다수공급자계약(MAS)
- 문제·정답·핵심 최종점검 영역 제외

## 학습 목표

- 발주기관과 계약 대상에 따라 적용 법령을 찾는다.
- 입찰공고와 계약조건을 상위 법령에 비추어 검토한다.
- 해석이 갈릴 때 유권해석과 판례를 구분해 활용한다.
- 법령 활용 구조를 MAS의 법적·실무적 절차와 연결한다.

## 한눈에 보는 구조

`기관 확인 → 계약 대상 확인 → 기본법·특별법 확인 → 공고 검토 → 계약조건 검토 → 해석자료 확인 → 기록 관리`

| 확인 대상 | 핵심 질문 |
|---|---|
| 발주기관 | 국가기관, 지방자치단체, 공공기관 중 어디인가 |
| 계약 대상 | 물품·용역·공사 중 무엇이며 특별법이 적용되는가 |
| 규범 단계 | 상위 법령부터 개별 공고·계약조건까지 일치하는가 |
| 공고 | 참가제한에 근거와 필요성이 있고 평가기준이 공정한가 |
| 계약 | 업무 범위, 위험 배분, 가격 조정, 분쟁 조항이 명확한가 |
| 해석자료 | 사실관계가 유사한 유권해석·판례인가 |

## 핵심 내용

### 1. 적용 법령의 출발점

- 국가기관의 계약: 국가계약법 체계가 기본이다.
- 지방자치단체의 계약: 지방계약법 체계가 기본이다.
- 공공기관의 계약: 기관 자체 계약규정과 상위 법령·관련 법률을 함께 확인한다.
- 공사, 중소기업제품 구매, 하도급, 전자조달 등에는 건설산업·판로지원·하도급·전자조달 관련 특별법이 함께 적용될 수 있다.
- 특별한 사항을 정한 법률이 있으면 해당 특별규정을 우선 검토한다.

적용범위는 `기관 → 계약 대상 → 금액 → 특별법 → 국제입찰 해당 여부`의 순서로 확인한다.

### 2. 규범의 단계

`법률 → 시행령 → 시행규칙 → 계약예규·고시·지침 → 개별 입찰공고·계약조건`

아래 단계의 기준은 상위 단계의 근거 안에서 작성되어야 한다. 공고나 계약조건에 적혀 있다는 이유만으로 상위 법령과 충돌하는 내용이 정당화되지는 않는다. 계약예규는 중요한 실무기준이지만 법률·시행령과 같은 단계로 보지 않는다.

### 3. 공고와 계약조건의 검토

공고 전에는 다음을 확인한다.

- 적용 법령이 정확한가
- 특정 실적·지역·기술 등의 참가제한에 법적 근거가 있는가
- 제한이 계약 목적과 직접 관련되고 필요한 범위를 넘지 않는가
- 평가항목과 배점이 객관적이며 공고에 명확히 제시되었는가

계약 체결 전에는 목적물, 업무 범위, 대금 지급, 변경 절차, 손해배상, 지체 책임, 가격 조정, 분쟁 해결 절차를 확인한다. 일방적인 위험 전가, 가격 조정의 일률적 배제, 자의적으로 해석할 수 있는 조항을 특히 주의한다.

입찰자가 불명확하거나 부당한 조건을 발견하면 공고기간 중 질의하고 필요한 경우 정정 요청·이의제기를 검토한다. 계약 전에는 남은 위험을 가격과 수행계획에 반영하고 참여 여부를 결정한다.

### 4. 유권해석과 판례

| 구분 | 유권해석 | 판례 |
|---|---|---|
| 주체 | 소관 행정기관 | 법원 |
| 성격 | 법령 의미·적용방법에 관한 공식적 행정해석 | 구체적 분쟁에 대한 법적 판단 |
| 효력·활용 | 직접적인 재판상 구속력은 없으나 실무처리의 중요 참고자료 | 유사 사건의 법적 판단기준, 특히 대법원 판례가 중요 |

결론만 가져오지 않고 `사실관계 → 적용 법령 → 유권해석·판례 → 판단기준 → 결론`으로 정리한다.

### 5. 표준교재 연결: MAS

MAS는 조달사업법 제13조를 근거로 조달청이 품질·성능이 비슷한 상용·표준화 물품에 대해 **2인 이상 공급자**와 단가계약을 체결하는 방식이다.

- 조달청: 공급자와 단가계약을 체결하고 상품을 종합쇼핑몰에 등록한다.
- 공급자: 계약조건과 가격에 따라 상품정보를 관리하고 납품한다.
- 수요기관: 별도 입찰 없이 쇼핑몰에서 상품을 비교해 납품을 요구한다.
- 이행: 납품 후 검사·검수를 거쳐 대금을 청구한다.

MAS 참여 전에는 입찰참가자격, 물품 목록화, 공고상 최소 품질요건을 갖춘다. 법적 검토는 `조달사업법 → MAS 업무처리규정 → 구매입찰공고 → 계약조건` 순으로 한다.

## 실무 절차(누가·언제·무엇)

| 시점 | 주체 | 할 일 |
|---|---|---|
| 사업계획 수립 | 사업부서·조달담당자 | 기관 유형, 계약 대상, 금액, 특별법 여부 확인 |
| 공고 작성 전 | 조달담당자·법무담당자 | 참가제한의 근거·필요성, 평가기준의 객관성 검토 |
| 공고기간 | 입찰자 | 공고·첨부서류 검토, 질의·정정 요청·이의제기 검토 |
| 계약 체결 전 | 계약담당자·계약상대자 | 범위, 위험, 변경, 가격 조정, 분쟁 조항 확인 |
| 해석 충돌 시 | 담당자·법무담당자 | 쟁점과 사실관계 정리 후 유권해석·판례 비교 |
| 계약 이행 중 | 사업관리자·계약상대자 | 회의록, 합의서, 변경 승인서 등 증거 보존 |

## 비교·주의사항

- 기본 계약법만 확인하고 특별법을 누락하지 않는다.
- 참가제한은 그 자체가 위법한 것이 아니라 근거·목적 관련성·비례성이 핵심이다.
- 계약예규를 상위 법령과 같은 지위로 보지 않는다.
- 유권해석과 판례는 사실관계가 유사한지 확인한 뒤 적용한다.
- 공고 단계에서 확인 가능한 문제를 계약 후에 처음 제기하지 않도록 한다.
- MAS의 **구매입찰공고 기간**과 개별 계약기간을 혼동하지 않는다.

## 최종 정리

법령 활용은 단순 검색이 아니라 조달 전 과정의 통제절차다. 발주기관과 계약 대상을 먼저 확인하고, 기본법과 특별법을 찾은 다음, 공고와 계약조건을 상위 법령에 비추어 검토한다. 해석이 갈리면 사실관계를 기준으로 유권해석과 판례를 비교하고 모든 협의와 변경을 문서화한다.

핵심 암기 구조는 `기관 → 대상 → 상위법 → 공고 → 계약 → 해석자료 → 기록`이다. MAS는 2인 이상 공급자와 체결하는 단가계약이며, 표준교재 기준 구매입찰공고는 10년을 원칙으로 하고 다음 공고는 종료 6개월 전에 낸다.
