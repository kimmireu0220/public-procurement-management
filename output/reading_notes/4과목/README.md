# 4과목 공공조달 관리실무 읽기용 학습노트

공공조달관리사 실기 4과목의 박문각 Part 1~8, 총 25개 CHAPTER를 눈으로 읽고 복습하기 좋게 재구성한 자료입니다.

- 박문각 교재의 Part·CHAPTER 구조를 따릅니다.
- 완성된 듣기 강의 대본의 사실·숫자·절차를 유지했습니다.
- 반복적인 방송 문구를 제거하고 표, 절차, 비교, 체크 항목으로 재편했습니다.
- 숫자·기한·절차는 조달청 표준교재의 해당 장을 우선합니다.
- 박문각에만 있는 숫자는 표준교재 수치와 혼동하지 않도록 출처를 구분합니다.
- 문제, 정답, 퀴즈는 포함하지 않습니다.

전체 91개 수행준거는 [출제기준_수행준거_전체.md](출제기준_수행준거_전체.md), 빈칸 학습지는 [학습템플릿/4과목](../../학습템플릿/4과목/README.md)에서 확인할 수 있습니다.

## 읽는 방법

1. `학습 목표`에서 해당 CHAPTER가 답하는 질문의 범위를 확인합니다.
2. `한눈에 보는 구조`에서 전체 흐름과 주체를 먼저 잡습니다.
3. `핵심 내용`과 `실무 절차`를 읽으며 누가, 언제, 무엇을 하는지 연결합니다.
4. `비교·주의사항`에서 혼동하기 쉬운 개념을 구분합니다.
5. 마지막으로 `숫자·기한·시스템`과 `최종 정리`만 다시 읽어 복습합니다.

숫자는 값만 떼어 외우지 않고 적용 주체와 시점을 함께 확인합니다. 실제 입찰 참여나 계약업무에 적용할 때는 최신 법령과 해당 공고·계약조건을 다시 확인해야 합니다.
