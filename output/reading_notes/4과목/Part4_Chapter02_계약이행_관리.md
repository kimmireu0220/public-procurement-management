## 한눈에 보는 구조

`계약내용 파악 → 요구사항 구체화 → 이행계획 수립 → 착수·실행 → 일정·비용·품질 통제 → 완료 준비`

관리 축은 다음 6개이다.

- 내용
- 요구사항
- 계획
- 선급금
- 진행 통제
- 품질

## 핵심 내용

### 1. 계약내용의 5요소

계약이행은 계약문서의 정확한 이해에서 시작한다.

| 요소 | 확인 내용 |
|---|---|
| 계약목적 | 사업이 최종적으로 달성하려는 결과 |
| 계약대상 | 물품 규격·수량, 공사 범위·설계, 용역 과업·산출물 |
| 계약금액 | 총액·단가계약 구분, 부가가치세·운송·설치비 포함 여부 |
| 이행기간 | 착수일부터 납품·준공·용역완료일까지, 중간일정 포함 |
| 발주자 요구 | 기능·성능·품질·수행조건 |

계약대상은 계약서뿐 아니라 규격서·설계서·과업지시서·제안서 등 계약문서 전체로 구체화된다. 문서 해석의 우선순위는 해당 계약의 일반조건과 특수조건을 확인한다.

### 2. 요구사항 분석

1. 문서에 명시된 규격·수량·성능·장소·기한·보고서 형식을 찾는다.
2. 요구사항 간 관계를 분석한다. 기능 추가는 일정·비용·시험방법에 영향을 줄 수 있다.
3. 추상적 표현을 검사 가능한 기준으로 바꾼다.
4. 불명확하거나 충돌하는 내용은 발주기관에 질의한다.
5. 근거문서·담당자·완료시점·확인방법·산출물을 요구사항 목록에 연결한다.

계약상대자가 임의로 해석하거나 발주기관 담당자가 계약문서에 없는 요구를 구두로 추가해서는 안 된다. 제안서, 기술협상 결과와 최종 계약문서가 서로 일치해야 한다.

### 3. 계약이행계획

| 단계 | 주요 업무 |
|---|---|
| 착수 | 수행조직·역할·책임, 세부일정, 인력·장비·자재, 협력업체 계획 확정 |
| 실행 | 물품 생산·조달, 공사 시공, 용역 수행 및 과정 기록 |
| 통제 | 일정·비용·품질·위험의 계획 대비 실적 비교와 시정조치 |
| 완료 | 최종 산출물·완료서류 정리, 미완료사항 확인, 검사·검수 준비 |

수행계획에는 인력, 장비, 자재, 품질과 공정관리가 포함된다. 공정표로 계획일정과 실제 진행률을 비교한다. 이행계획은 일회성 제출물이 아니라 실제 진행상태를 반영하는 관리기준이다.

### 4. 이행기간과 지체상금

계약상대자의 책임으로 납품·준공기한을 넘기면 지체상금을 부과할 수 있다.

`지체상금 = 부과대상 금액 × 지체상금률 × 지체일수`

| 계약유형 | 교재의 1일 지체상금률 |
|---|---:|
| 공사 | `1천분의 0.5` |
| 물품 제조·구매 | 원칙적으로 `1천분의 0.75` |
| 계약 후 설계·제조 및 발주기관 승인이 필요한 물품 | `1천분의 0.5` |
| 물품 수리·가공·대여, 용역, 기타 | `1천분의 1.25` |
| 군용 음·식료품 제조·구매 | `1천분의 1.5` |
| 운송·보관·양곡가공 | `1천분의 2.5` |

지연 발생만으로 책임이 확정되는 것은 아니다. 계약상대자 귀책, 발주기관 귀책, 불가항력을 구분한다. 설계변경이나 발주기관의 자료제공 지연처럼 계약상대자에게 책임을 물을 수 없는 사유는 기간연장과 지체상금 면제를 검토한다. 지연사유·발생시점·통보·대응조치를 기록한다.

### 5. 선급금

선급금은 원재료·자재·인력 등 초기 이행자금을 미리 지원하는 제도이다.

`선급금 = 계약금액 × 선급금 지급률`

교재는 일반적으로 최대 `70퍼센트` 범위에서 지급할 수 있다고 설명하며, 사업 성격과 예산상황에 따라 조정할 수 있다고 정리한다. 계약금액 1억원에 지급률 50퍼센트를 적용하면 선급금은 5천만원이다.

선급금의 핵심 관리원칙은 다음과 같다.

- 해당 계약의 자재비·노무비·이행비용에 사용
- 다른 사업이나 사적 용도로 전용 금지
- 선급금 지급보증 유지
- 기성대가 또는 준공대가 지급 시 정산
- 계약 해제 시 미정산 선급금 반환

### 6. 실행 통제

- **진도관리:** 공정표와 실제 진행률을 비교하고 지연 시 원인·만회계획을 확인한다.
- **비용관리:** 추가요구나 설계변경은 정식 변경계약 후 반영한다.
- **품질관리:** 규격서·설계서·과업지시서에 따라 원재료, 공정, 중간·최종 산출물을 검사한다.
- **위험관리:** 인력 이탈, 원자재 수급, 장비 고장, 설계변경, 물가변동, 정보보안 사고 등의 발생가능성과 영향을 평가하고 대응책·담당자를 정한다.

통제의 기준은 개인적 기대나 구두지시가 아니라 확정된 계약문서와 변경계약이다.

## 실무 절차: 누가·언제·무엇

| 순서 | 누가 | 언제 | 무엇을 하는가 |
|---:|---|---|---|
| 1 | 계약담당자·사업부서 | 체결 직후 | 목적·대상·금액·기간·요구사항을 계약문서에서 확정한다. |
| 2 | 계약상대자 | 착수 전 | 요구사항을 분석하고 조직·인력·장비·자재·품질·공정계획을 수립한다. |
| 3 | 계약상대자 | 착수 시 | 용역은 착수계·착수보고서, 공사는 공정계획과 현장관리체계를 마련한다. |
| 4 | 계약상대자 | 이행 중 | 계획에 따라 수행하고 작업·산출물·의사결정을 기록한다. |
| 5 | 발주기관 | 이행 중 | 진도·비용·품질·위험을 계약문서와 비교하고 보완을 요구한다. |
| 6 | 계약상대자 | 자금 필요 시 | 선급금 신청서와 원칙적으로 지급보증서를 제출한다. |
| 7 | 발주기관 | 신청 접수 후 | 필요성·지급률·보증을 검토하고 승인·지급하며 사용과 정산을 관리한다. |
| 8 | 양 당사자 | 지연 발생 시 | 귀책과 영향기간을 확인해 지체상금·기간연장 여부를 판단한다. |
| 9 | 계약상대자·발주기관 | 완료 시 | 최종 산출물과 완료서류를 정리하고 검사·검수로 넘긴다. |

## 비교·주의사항

| 구분 | 핵심 |
|---|---|
| 총액계약 | 계약 전체 금액을 확정 |
| 단가계약 | 단가를 정하고 실제 수량에 따라 최종 금액 결정 |
| 선급금 | 이행 전에 자금을 지원하고 이후 대가에서 정산 |
| 기성대가 | 실제 이행한 부분에 대한 대가 |
| 계약상대자 귀책 지연 | 지체상금 검토 |
| 발주기관 귀책·불가항력 | 기간연장과 지체상금 면제 여부 검토 |

- 변경계약 없이 추가업무를 먼저 시키거나 수행하지 않는다.
- 품질문제는 최종검사 이전의 수행과정에서 조기에 발견한다.
- 선급금 지급보증서는 원칙적으로 제출하며, 구체적인 적용은 계약조건을 확인한다.
- 지체상금률은 최신 법령과 해당 계약조건을 함께 확인한다.

## 숫자·기한·시스템

- 계약내용: `5요소`
- 이행계획: `착수 → 실행 → 통제 → 완료`
- 선급금: 교재상 일반적 상한 `70퍼센트`
- 지체상금: `부과대상 금액 × 지체상금률 × 지체일수`
- 계약유형별 1일 지체상금률: `0.5 / 0.75 / 1.25 / 1.5 / 2.5`천분율

## 최종 정리

계약이행 관리의 흐름은 `내용 → 요구 → 계획 → 선급금 → 통제 → 품질`이다. 계약문서에서 목적·대상·금액·기간·요구사항을 확정하고, 이를 검사 가능한 기준과 수행계획으로 바꾼다. 이행 중에는 일정·비용·품질·위험을 통제한다. 지연은 귀책을 먼저 판단하고, 선급금은 보증·목적사용·기성정산·해제 시 반환까지 관리한다.
