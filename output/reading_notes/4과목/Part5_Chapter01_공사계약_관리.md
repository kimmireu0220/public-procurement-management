## 한눈에 보는 구조

`공사 특성 분석 → 특화조건 작성 → 계약보증·전자계약 → 착공 → 공정·품질·안전관리 → 변경계약 → 준공검사·대금 → 하자관리`

하도급이 있는 경우 다음 흐름을 본선 절차와 병행한다.

`하도급 계획 → 적격업체 선정 → 서면계약 → 승인·통보 → 이행·대금관리 → 변경 → 준공·하자관리`

| 구분 | 관리의 중심 |
|---|---|
| 계약 전 | 현장과 위험 분석, 특화조건 작성 |
| 계약체결 | 계약보증, 전자계약, 계약문서 확정 |
| 착공·시공 | 착공계, 공정, 품질, 안전, 감독 |
| 변경 | 변경사유, 물량·금액·기간 검토, 변경계약 |
| 종결 | 준공검사, 준공금, 하자담보책임 |

## 핵심 내용

### 1. 공사계약의 특성

공사계약은 정해진 현장에서 시설물을 시공하는 장기적인 이행계약이다. 계약서 작성만으로 끝나지 않고 착공부터 준공과 하자관리까지 계속 관리해야 한다.

- **현장 중심:** 지형, 기후, 지반, 주변 환경에 따라 작업조건이 달라질 수 있다.
- **장기 수행:** 물가변동, 설계변경, 공정지연 등 계약금액과 기간의 조정사유가 발생할 수 있다.
- **설계·물량 변경 가능성:** 현장지시만으로 추가작업을 처리하지 않고 공식 변경절차를 거쳐야 한다.
- **공정·품질 연계:** 공기를 맞추기 위한 무리한 시공은 품질과 안전을 훼손할 수 있다.
- **하도급 구조:** 여러 전문공종이 결합하므로 하수급자의 자격, 계약, 대금과 품질을 함께 관리한다.
- **안전·환경 책임:** 산업재해, 소음, 진동, 비산먼지, 폐기물과 민원 위험을 예방하고 대응한다.

주요 참여자는 계약담당자, 사업부서, 감독관, 감리자, 현장대리인, 안전관리자, 원수급자와 하수급자이다.

### 2. 공사 특화 계약조건

공사 특화 계약조건은 공사 수행 중 예상되는 위험과 처리방법을 계약 전에 문서로 정하는 장치이다.

| 항목 | 주요 내용 |
|---|---|
| 설계 | 설계도면·시방서·물량내역서의 적용기준, 변경 요청·검토·승인 |
| 계약금액 | 설계변경, 물가변동, 기간연장, 법령 변경, 공사중지에 따른 조정 |
| 공사기간 | 착공일·준공일, 공정계획, 지연원인, 연장과 지체상금 |
| 대가지급 | 선금, 기성금, 준공금의 지급조건 |
| 하자 | 하자담보책임기간, 보수절차, 책임 귀속, 하자보수보증금 |
| 하도급 | 승인·통보, 서면계약, 대금보호, 직접지급, 부당행위 금지 |
| 안전·환경 | 안전계획, 교육, 위험작업 통제, 환경보호와 사고대응 |

계약금액은 현장비용이 늘었다는 사실만으로 자동 조정되지 않는다. 계약상 조정사유, 계약상대자의 책임 여부와 증빙을 확인해야 한다.

대금의 기본 흐름은 `선금 → 기성금 → 준공금`이다.

### 3. 특화조건의 계약 반영

발주기관은 다음 순서로 공사 특성에 맞는 계약조건을 확정한다.

1. 사업부서와 계약담당자가 공사의 규모, 공종, 공기, 현장 여건과 기술적 난이도를 분석한다.
2. 설계변경, 물가변동, 공기지연, 안전사고, 환경민원과 하도급 분쟁 등의 위험을 식별한다.
3. 국가·지방계약 법령과 공사계약 일반조건을 검토한다.
4. 일반조건만으로 부족한 내용을 특수조건으로 작성한다.
5. 특수조건을 입찰공고와 설계도서에 반영하여 입찰 전에 공개한다.
6. 낙찰자 결정 후 계약서와 계약문서에 명시한다.
7. 계약상대자에게 책임범위와 위험부담을 설명한다.

낙찰자 결정 후 새로운 의무를 임의로 추가하면 공정한 경쟁이 훼손될 수 있으므로 조건은 입찰 전에 공개하는 것이 중요하다.

### 4. 전자계약과 계약보증

나라장터 전자계약의 기본 절차는 세 단계이다.

1. 발주기관이 계약서 초안을 작성하여 계약상대자에게 송신한다.
2. 계약상대자가 금액, 기간, 공사내용과 특수조건을 확인하고 계약응답서를 제출한다.
3. 발주기관이 계약체결통보서를 보내 계약을 확정한다.

`발주기관 초안 → 업체 응답서 → 발주기관 체결통보`

계약상대자는 이의가 있으면 사유를 적어 반려하고, 이의가 없으면 지급각서·청렴서약서 등을 확인한 뒤 전자서명한다.

계약체결 단계에서는 국가계약법 제12조에 따른 계약보증금 또는 보증서를 확인한다. 보증기관은 국가계약법 시행령 제37조의 기준을 확인한다. 나라장터에서는 납부유형, 보증금률·금액, 보증 시작일과 만료일을 입력하고 전자보증요청을 선택할 수 있다.

- 보증기간은 계약기간과 일치해야 한다.
- 계약기간이 연장되면 보증기간도 연장하거나 추가 보증을 확보한다.
- 계약보증은 계약체결 단계에서 확인하고, 체결 후 착공계를 제출한다.

표준교재의 네트워크론은 공공계약서를 담보로 협약 금융기관에서 대출받고 계약대금 지급 시 자동 상환하는 구조이다. 채권양도통보로 대금채권의 양도 사실을 발주기관에 알린다.

|---|---|---|

| 시공 중 | 계약상대자 | 인력·장비 투입, 공정표에 따른 시공, 품질·안전관리 |
| 시공 중 | 감독관·감리자 | 진도, 자재, 시험, 검측, 안전과 환경 확인 |
| 지연 발생 | 발주기관·계약상대자 | 귀책사유 확인, 만회대책·기간연장·지체상금 검토 |
| 변경 필요 | 계약상대자 또는 발주기관 | 변경사유·범위·물량·금액·기간 검토 |
| 변경 승인 | 발주기관 | 변경초안 송신, 변경응답 접수, 체결승인통보 |
| 기성 발생 | 계약상대자·발주기관 | 기성검사 후 확인된 부분에 기성금 지급 |
| 공사 완료 | 계약상대자 | 준공계 제출 |
| 준공 단계 | 발주기관 | 준공검사, 합격 시 준공금 지급과 시설물 인수 |
| 준공 후 | 발주기관·계약상대자 | 하자검사, 보수요구, 하자보수보증 관리 |

변경계약의 승인 흐름은 다음과 같다.

`변경요청 → 승인 시 변경초안 → 변경응답 → 체결승인통보`

반려된 경우에는 변경초안으로 진행하지 않는다.

`반려사유 확인 → 보완 → 재요청`

### 하도급 병행 절차

하도급은 준공 후 별도로 처리하는 마지막 단계가 아니라 계약 전후부터 이행, 대금과 하자까지 계속 병행하는 관리영역이다.

1. 원수급자가 하도급 공종을 정하고 적격한 전문업체를 선정한다.
2. 위탁내용, 금액, 기간, 지급일, 검사방법과 하자책임을 서면계약에 명시한다.
3. 법령과 공고에서 정한 승인 또는 통보 절차를 이행한다.
4. 발주기관이 하수급자의 자격, 공종, 하도급 비율과 조건을 검토한다.
5. 원수급자가 하수급자의 공정, 품질, 안전과 대금지급을 관리한다.
6. 법정 사유가 있으면 발주기관이 하도급대금을 직접 지급할 수 있다.
7. 하도급 내용이 바뀌면 변경계약을 체결한다.
8. 하도급 부분의 준공과 하자보수를 확인한다.

## 공사·물품·용역의 비교·주의사항

| 구분 | 공사 | 물품 | 용역 |
|---|---|---|---|
| 주된 대상 | 현장에서 시공하는 시설물 | 제조·구매하여 납품하는 물품 | 지식·기술·인력으로 수행하는 서비스 |
| 이행 시작 문서 | 착공계 | 납품 준비·검사 요청 | 착수계 |
| 관리 중심 | 공정, 품질, 안전, 설계변경 | 규격, 수량, 납품, 검사·검수 | 과업, 인력, 일정, 성과 |
| 완료 확인 | 준공검사 | 규격·성능 검사와 수량·외관 검수 | 산출물과 과업성과 검사 |

주의사항은 다음과 같다.

- 공사는 현장지시만으로 추가작업을 진행하지 않고 변경계약으로 확정한다.
- 설계변경 시 물량뿐 아니라 계약금액과 공사기간을 함께 검토한다.
- 공정지연은 계약상대자, 발주기관, 불가항력 중 누구의 책임인지 구분한다.
- 품질과 공기를 별개로 관리하지 않으며 안전을 착공 전부터 예방 관리한다.
- 하도급은 업체 선정부터 대금과 하자까지 본선 절차와 병행한다.
- 계약보증은 착공 이후가 아니라 계약체결 단계에서 확인한다.

## 최종 정리

공사계약은 계약조건을 현장에서 끝까지 구현하는 관리이다. 발주기관은 공사 특성과 위험을 분석해 설계, 금액, 기간, 대가, 하자, 하도급, 안전·환경 조건을 입찰 전에 공개한다.

낙찰 후에는 `초안 → 응답서 → 체결통보` 순서로 전자계약을 확정하고 계약보증을 확인한다. 계약상대자는 착공계를 제출한 뒤 공사를 시작하며, 발주기관은 공정·품질·안전을 감독한다.

설계나 물량이 달라지면 변경사유와 금액·기간을 문서로 검토하고 변경계약을 체결한다. 공사 완료 후 준공검사와 준공금 지급을 거쳐도 하자담보책임은 계속된다.

핵심 암기 구조는 다음과 같다.

- 전체: `조건 → 보증·체결 → 착공 → 시공 → 변경 → 준공 → 하자`
- 특화조건: `설계 → 금액 → 기간 → 대가 → 하자 → 하도급 → 안전·환경`
- 전자계약: `초안 → 응답서 → 체결통보`
- 하도급 병행: `선정·서면계약 → 승인·통보 → 이행·대금 → 변경 → 준공·하자`
