## 학습 목표

- 대응계획의 실행 여부와 실제 위험감소 성과를 구분해 점검한다.
- 조기경보와 신규위험을 탐지해 레지스터와 계획을 갱신한다.
- 계약유형별 지표를 축적하고 결과를 의사결정에 연결한다.

## 한눈에 보는 구조

`실행 확인 → 성과 측정 → 신규위험 식별·재평가 → 결과 공유·추가조치 → 계획 보완`

이 순환은 `식별 → 평가 → 대응계획 → 모니터링 → 재식별`로 계속된다.

## 핵심 내용

### 1. 실행점검

리스크 레지스터의 대응항목을 완료·진행 중·미실행으로 구분하고, 기한·담당자·실행상태를 확인한다. 계획과 실제 실행의 차이, 축소된 품질시험, 미확보 대체공급자, 부족한 안전재고 등을 점검한다.

미실행 원인이 인력·일정·예산승인·권한 부족인지 분석하여 인력 보강, 일정 재조정, 예산 확보, 계획 수정을 실시한다. 계약변경 공문, 보증서, 시험성적서, 사전점검 결과서, 회의록, 현장사진을 증빙으로 보되 서류만으로 완료를 판단하지 않고 현장 작동 여부를 확인한다.

물품은 검수요청 접수만으로 성과가 완성되지 않는다. 실제 규격·수량 확인과 검수합격, 물납영수증, 대금청구까지 확인한다. 공사는 착공계 제출뿐 아니라 공정표 준수, 기성검사, 설계변경, 하도급을 현장에서 확인한다.

### 2. 형식적 점검 방지

회의·교육·점검표의 존재보다 지연원인, 오류율, 사고가능성이 줄었는지를 본다.

1. 조치의 실제 이행을 확인한다.
2. 일정 지연 시 즉시 수정한다.
3. 조치별 책임소재를 명확히 한다.
4. 미이행 위험의 발생가능성과 영향도를 재평가한다.
5. 중요 결과를 상위 관리자에게 보고한다.

### 3. 성과 측정

| 항목 | 측정 예 |
|---|---|
| 발생가능성 | 납기지연 가능성 40% → 15% |
| 영향도 | 예상손실 5억원 → 1억원, 지연 30일 → 10일 |
| 비용 대비 효과 | 통제비용 5천만원으로 손실 3억원 예방 |
| 이해관계자 반응 | 민원, 기관평가, 감독기관 의견, 현장 체감 |
| 조기경보 | 문제가 커지기 전 지연·가격·품질 징후 탐지 |

KPI로 납기지연률, 하자발생률, 민원건수, 계약변경 횟수, 검사합격률, 감사 지적 건수를 사용할 수 있다. 현장 의견, 내부감사, 경영진과 리스크관리위원회 평가도 반영한다. 사고가 없었다는 사실만으로 조치가 성공했다고 단정하지 않고 외부환경의 우연한 개선과 대응 효과를 구분한다.

### 4. 신규위험 탐지

| 원천 | 확인 항목 |
|---|---|
| 외부환경 | 법령·정책, 예산, 물가·환율 |
| 사업범위 | 설계변경, 과업추가, 일정단축 |
| 이해관계자 | 민원, 주민 반대, 언론, 참여업체 불만 |
| 조직 내부 | 담당자 교체, 의사소통 단절, 통제 약화 |
| 기술·시장 | 신기술, 공급자 감소, 담합 징후, 보안위협 |

회의·현장 피드백·데이터 이상징후·외부환경 점검으로 새 위험을 찾는다. 지연률 급상승, 반복 계약변경, 입찰참가자 감소, 하자·민원 증가는 원인을 분석해야 할 신호다. 발견 즉시 레지스터에 등록하고 발생가능성·영향도·중요도를 평가한 뒤 책임자·전략·관리방식을 수정한다.

## 실무 절차(누가·언제·무엇)

| 누가 | 언제 | 무엇 |
|---|---|---|
| 대응조치 담당자 | 실행 시마다 | 상태·증빙 기록 |
| 사업관리자·계약담당자 | 월간·분기·사업관리회의 및 주요 계약시점 | 기한·책임·실행·효과 점검 |
| 검사자·감독자 | 검수·기성·준공 등 | 품질·공정·현장 확인 |
| 재무담당자 | 선금·대금·정산 시 | 예산·지급 위험 확인 |
| 공급업체 계약관리자 | 생산·물류·품질·현장 진행 중 | 자체 데이터를 취합하고 이상징후 보고 |
| 상위 관리자·리스크관리위원회 | 중요 위험 또는 긴급징후 발생 시 | 추가예산·일정·범위·통제 의사결정 |

중대한 이상징후는 정기보고일까지 기다리지 않고 즉시 점검·보고한다.

## 비교·주의사항

### 계약유형별 관찰 지표

| 유형 | 주요 지표·징후 |
|---|---|
| 물품 | 생산진척률, 원자재, 출하일, 규격일치, 검사합격률, 검수 반려·서류 보완, 대금·세금계산서 |
| 용역 | 핵심인력 투입·교체, 착수계, 중간산출물, 과업증가, 보안, 회의 대비 진척 |
| 공사 | 계획·실제 공정률, 기성률, 장기자재, 안전, 설계변경, 하도급대금, 민원 |
| 공통 | 계약변경, 분쟁·이의제기, 보증 유효성, 재무상태, 담당자 교체, 정책변화 |

평상시 데이터를 축적해야 현재 변화가 일시적 흔들림인지 위험의 시작인지 판단할 수 있다. 공정 지연은 공정표 재제출로 끝내지 않고 인력·자재·의사결정 중 실제 원인을 찾는다.

## 평가척도·시스템

리스크 레지스터와 리스크 대시보드에 현재 등급, 대응상태, 성과, 신규위험, 추가조치를 표시한다. 공유 수단은 정기보고서, 경영회의, 전산시스템, 중대위험 특별보고다.

보고 대상은 내부의 사업·계약·조달·감사부서, 경영진, 리스크관리위원회와 외부의 감독·감사·상급기관, 참여업체, 필요한 경우 지역사회다. 보고에는 원인·영향·대안·권고조치를 함께 제시한다. 문서화와 기록보존을 통해 의사결정·감사·책임추적이 가능해야 한다.

추가조치는 대응계획 수정, 추가예산·인력, 일정 재조정, 책임자 보강·변경, 승인·이중점검 강화, 사업범위 조정이다. 불리한 정보도 숨기지 않고 의사결정에 필요한 수준으로 투명하게 공유한다.

## 최종 정리

모니터링은 계획서의 완료 표시가 아니라 실제 위험감소를 확인하는 과정이다. 레지스터를 기준으로 실행·기한·책임자·증빙·현장을 점검하고, 대응 전후의 확률·영향·비용·KPI를 비교한다. 환경변화와 데이터 이상징후에서 새 위험을 발견하면 등록·재평가하고 대응계획을 수정한다. 물품·용역·공사에 맞는 지표를 지속적으로 축적하며, 결과와 권고조치를 이해관계자에게 보고해 의사결정과 재계획으로 연결한다.
