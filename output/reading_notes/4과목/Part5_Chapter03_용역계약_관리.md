| 핵심 | 관리 내용 |
|---|---|

| 인력 | 자격, 투입, 핵심인력 교체승인 |
| 일정 | 착수, 중간보고, 진도, 지연과 연장 |
| 성과 | 품질기준, 성과지표, 최종 산출물 |

## 핵심 내용

### 1. 용역계약의 특성

용역계약은 사람이 지식, 기술, 인력과 서비스를 제공하여 과업을 수행하는 계약이다. 완성품의 규격과 수량만 확인하는 물품계약과 달리 수행과정과 결과를 함께 관리한다.

- 과업지시서로 범위, 수행방법과 산출물을 구체화한다.
- 제안평가에서 제시한 투입인력과 실제 인력의 일치 여부를 관리한다.
- 착수계와 공정계획을 기준으로 일정과 진도를 확인한다.
- 중간보고, 회의와 산출물로 수행과정을 확인한다.
- 마지막에는 과업범위, 성과지표와 품질기준을 충족했는지 검사한다.

과업범위, 산출물, 기간과 투입인력이 모호하면 추가업무와 대금분쟁이 발생하기 쉽다.

### 2. 발주 준비와 낙찰자 선정

수요부서는 사업 목적, 과업범위, 수행기간, 필요한 인력과 산출물을 정한다. 계약담당자는 계약방법, 입찰참가자격과 평가방식을 검토한다.

복잡한 용역은 사업설명회 또는 과업설명회를 열어 사업의 배경, 수행조건과 현장여건을 설명할 수 있다.

협상에 의한 계약은 기술제안서와 가격제안서를 함께 평가한다. 제안서평가위원회는 다음 내용을 심의한다.

- 제안내용과 수행방법
- 투입인력의 적정성
- 사업관리 방안
- 산출물과 성과 달성 가능성

평가결과에 따라 협상적격자와 협상순서를 정하고 과업과 가격을 협상하여 계약상대자를 결정한다.

용역 공고는 나라장터에서 일반용역과 기술용역을 구분하여 조회할 수 있다. 입찰참가자는 공고문뿐 아니라 과업지시서와 제안요청서를 함께 검토해야 한다.

### 3. 공동수급체

한 업체가 모든 분야를 수행하기 어려운 경우 여러 업체가 공동수급체를 구성할 수 있다.

| 방식 | 책임 구조 |
|---|---|
| 공동이행 | 구성원들이 계약 전체를 공동 수행하고 지분에 따라 책임 부담 |
| 분담이행 | 전문분야별로 과업을 나누고 각자 맡은 부분을 책임 |
| 주계약자관리 | 주계약자가 중심이 되어 공동수급을 관리 |

공동수급 방식, 구성원 수, 최소 지분, 업종과 자격요건은 계약 유형과 규모에 따라 달라질 수 있으므로 공고문과 최신 공동계약 기준을 확인한다.

공동수급협정 절차는 다음과 같다.

1. 대표업체가 협정서를 작성하고 구성업체를 등록한다.
2. 협정서에 이행방식, 업종, 구성원, 지분 또는 분담내용을 입력한다.
3. 각 구성업체가 내용을 확인하고 승인한다.
4. 대표업체가 발주기관에 전송한다.
5. 발주기관이 방식, 자격, 지분과 분담내용을 검토한다.
6. 보완이 필요하면 반려하고, 대표업체는 수정 후 구성원의 승인을 다시 받아 제출한다.

`대표업체 작성 → 구성업체 확인·승인 → 대표업체 전송 → 발주기관 검토 → 승인 또는 반려·재작성`

### 4. 전자계약과 착수

용역 전자계약은 다음 세 단계로 진행한다.

1. 발주기관이 계약서 초안을 작성하여 계약상대자에게 보낸다.
2. 계약상대자가 금액, 과업, 기간, 인력과 특수조건을 확인하고 응답서를 제출한다.
3. 발주기관이 계약체결통보서를 보내 계약을 확정한다.

`초안 → 응답서 → 체결통보`

이의가 있으면 반려사유를 첨부한다. 이의가 없으면 지급각서와 청렴서약서 등을 확인하고 전자서명한다.

계약 후 계약상대자는 착수계를 제출하여 실제 이행을 시작한다. 공사는 착공계, 물품과 용역은 착수계라는 용어를 쓴다.

착수계에는 다음 내용을 포함한다.

- 사업범위와 수행방법
- 용역공정 예정표
- 인력·장비 투입계획
- 책임자와 참여기술자의 이력
- 서약서와 계약담당자가 요구하는 자료

나라장터 이행 메뉴에서 착수일과 관련 정보를 입력하고 첨부서류를 전자서명하여 제출한다. 발주기관은 접수 후 승인한다. 착수계는 이후 일정, 인력과 성과를 비교하는 기준계획이다.

표준교재는 착수 또는 착공이 이루어진 뒤 선금청구가 가능하다는 흐름을 제시한다.

### 5. 과업·인력·일정관리

계약상대자는 착수계와 과업지시서에 따라 인력을 투입하고, 중간보고·회의·산출물 제출로 진행상황을 알린다. 발주기관 감독자는 계획공정과 실제 진도를 비교하고 과업의 품질과 성과를 확인한다.

전문지식이 필요하거나 직접 감독하기 어려운 경우 전문기관을 통해 감독할 수 있다.

인력관리에서는 제안평가 단계의 핵심인력을 임의로 바꾸지 않는 것이 중요하다. 교체가 필요하면 변경사유와 대체인력의 자격을 제출하여 발주기관 승인을 받는다. 부적합한 인력에 대해서는 발주기관이 교체를 요구할 수 있다.

일정 지연 시에는 원인을 구분한다.

- 계약상대자의 인력부족·관리소홀
- 발주기관의 자료제공 지연
- 과업변경
- 불가항력

계약상대자 책임이면 만회계획과 필요한 진도자료를 요구하고 지체상금을 검토한다. 발주기관 책임이나 불가항력이면 기간연장과 추가비용 조정을 검토한다.

### 6. 과업변경과 계약금액 조정

과업변경은 계약의 본질을 해치지 않는 범위에서 필요성과 내용을 확인한다. 추가·특별업무, 용역공정계획 변경, 특정 항목의 삭제·감소 등이 대표적이다.

계약상대자의 변경요청 또는 발주기관의 필요 확인 후 과업, 금액과 기간을 검토한다. 승인되면 변경된 산출물, 인력, 기간과 대가를 계약문서에 반영하고 변경계약 확정 후 수행한다.

과업을 먼저 추가하고 나중에 대가를 정하는 방식은 피한다.

계약금액 조정사유는 다음과 같이 구분한다.

| 조정사유 | 검토 내용 |
|---|---|
| 물가변동 | 정해진 기간과 조정률 요건 충족 여부 |
| 과업내용 변경 | 추가·감소 업무량, 인력, 기간 |
| 최저임금 등 계약내용 변경 | 법령과 계약조건에 따른 실제 추가비용 |

### 7. 기간연장·지체·제재

계약상대자의 책임 없는 사유가 있으면 계약기간이 끝나기 전에 서면으로 연장을 신청한다. 불가항력, 발주기관 책임의 착수지연·용역중단, 계약상대자 책임 없는 인력투입 지연 등이 해당할 수 있다.

발주기관은 연장사유와 필요한 기간을 검토하고, 인정되면 계약기간과 필요한 추가비용을 조정한다. 기간이 연장되면 계약보증 만료일도 맞추어 연장한다.

계약상대자 책임으로 늦어지면 지체상금을 검토한다. 지체상금은 `계약금액 × 지체상금률 × 지체일수`로 계산한다.

지체가 중대하면 계약 해제·해지 또는 추가 계약보증을 받고 계약을 유지할지 검토한다. 귀책사유가 인정되는 경우 계약보증금 국고귀속과 부정당업자 제재로 이어질 수 있다.

입찰참가자격 제한은 행정절차법에 따라 처분내용을 사전통지하고 의견제출 기회를 부여한 뒤 진행한다.

### 8. 완료·검사·정산

과업 완료 후 계약상대자는 완료 사실을 서면 통지하고 산출물을 제출한다. 발주기관은 과업지시서, 계약서, 착수계와 변경계약을 기준으로 범위, 성과지표와 품질기준 충족 여부를 검사한다.

불합격하면 보완 또는 재수행을 요구하고 다시 검사한다. 합격하면 계약상대자가 대금을 청구하며 발주기관은 검사결과, 세금계산서, 보험료 정산자료 등을 확인한다.

국민건강보험료, 노인장기요양보험료와 퇴직공제부금 등 사후정산 대상은 실제 납부자료를 확인하여 정산한다.

`완료통지 → 산출물 제출 → 검사 → 보완 또는 합격 → 정산 → 대금청구 → 지급`

## 실무 절차(누가·언제·무엇)

| 시점 | 누가 | 무엇을 하는가 |
|---|---|---|
| 발주 준비 | 수요부서 | 목적, 과업범위, 기간, 인력과 산출물 설계 |
| 입찰 준비 | 계약담당자 | 계약방법, 참가자격, 평가방식과 공고 검토 |
| 평가 | 제안서평가위원회 | 수행방법, 인력, 사업관리와 산출물 평가 |
| 공동수급 구성 | 대표업체·구성업체 | 협정서 작성, 구성원 승인, 발주기관 전송 |
| 계약체결 | 발주기관·계약상대자 | 초안 송신, 응답서 제출, 체결통보 |
| 계약 후 | 계약상대자 | 착수계와 인력·장비·공정계획 제출 |
| 착수 전 | 발주기관 | 착수계 검토·승인 |
| 수행 중 | 계약상대자 | 인력투입, 과업수행, 중간보고와 산출물 제출 |
| 수행 중 | 발주기관 감독자 | 진도, 인력, 품질과 성과 확인 |
| 인력 변경 | 계약상대자·발주기관 | 변경사유와 대체인력 자격 제출·승인 |
| 과업 변경 | 계약상대자 또는 발주기관 | 필요성, 범위, 기간과 금액 검토 후 변경계약 |
| 지연 발생 | 발주기관·계약상대자 | 귀책사유에 따라 만회, 연장, 비용·지체상금 검토 |
| 과업 완료 | 계약상대자 | 완료통지와 산출물 제출 |
| 완료 후 | 발주기관 | 검사, 보완요구 또는 합격, 사후정산 |
| 검사 합격 | 계약상대자·발주기관 | 대금청구와 지급 |

### 용역 하도급 병행 절차

하도급은 검사 후 별도로 처리하는 단계가 아니라 과업 설계와 계약 이후 수행, 품질과 대금관리까지 본선 절차와 병행한다.

1. 발주기관이 공고와 계약조건에서 하도급 허용 여부와 승인·통보기준을 정한다.
2. 원수급자가 적격한 하수급자를 선정한다.
3. 위탁내용, 대금, 지급기일, 검사방법과 하자책임을 서면계약에 명시한다.
4. 원수급자가 발주기관에 승인신청 또는 통지를 한다.
5. 발주기관이 하수급자의 자격, 기술·인력, 하도급 비율과 조건을 검토한다.
6. 원수급자가 하수급자의 수행과 품질을 감독하고 발주기관에 최종 책임을 진다.
7. 원수급자가 하도급대금을 지급한다.
8. 법정 사유가 있으면 발주기관의 직접지급과 제재를 검토한다.

과도한 하도급, 핵심업무의 일괄하도급, 부당한 대금결정·감액, 부당반품, 기술자료 요구와 보복조치는 금지된다.

## 공사·물품·용역의 비교·주의사항

| 구분 | 공사 | 물품 | 용역 |
|---|---|---|---|
| 대상 | 현장 시설물 시공 | 규격화된 물품 제조·구매 | 지식·기술·인력 서비스 |
| 관리 중심 | 공정, 품질, 안전, 설계변경 | 규격, 수량, 납품, 검사·검수 | 과업, 인력, 일정, 성과 |
| 시작 문서 | 착공계 | 납품과 검사 요청 | 착수계 |
| 변경 중심 | 설계, 물량, 공기 | 규격, 수량, 납기 | 과업, 인력, 기간 |
| 완료 확인 | 준공검사 | 품질·성능 검사와 수량·외관 검수 | 과업범위·성과·산출물 검사 |

주의사항은 다음과 같다.

- 공고문, 과업지시서와 제안요청서를 함께 검토한다.
- 제안평가에 반영된 핵심인력을 승인 없이 교체하지 않는다.
- 추가과업은 먼저 수행하게 한 뒤 대가를 정하지 않고 변경계약으로 확정한다.
- 지연은 계약상대자, 발주기관 또는 불가항력 중 귀책사유를 구분한다.
- 공동수급체의 실제 분담과 인력은 공동수급협정서와 일치해야 한다.
- 계약기간 연장 시 계약보증기간도 함께 조정한다.
- 하도급은 선정·서면계약부터 수행·품질·대금까지 병행 관리한다.

## 숫자·기한·시스템

| 항목 | 기준 | 자료 구분 |
|---|---|---|
| 착수계 | 계약 체결 후 10일 이내 제출·승인 구조 | 박문각 수험서의 용역계약 일반조건 설명 |
| 과업변경 통지 | 제안요청을 받은 날부터 14일 이내 승인 여부 통지 | 박문각 수험서 기준 |
| 물가변동 조정 | 계약 체결 후 90일 경과, 품목·지수조정률 3% 이상 증감 | 박문각 수험서 기준 |
| 금액조정 처리 | 요건에 해당하는 청구일부터 30일 이내 | 박문각 수험서 기준 |
| 완료검사 | 완료 통지일부터 원칙적으로 14일 이내 | 박문각 수험서 기준 |
| 별도 검사기간 | 재난·경제위기 기간에는 7일로 정할 수 있음 | 박문각 수험서 기준 |
| 대금 지급 | 청구일부터 기본 5일 이내 | 박문각 수험서 기준 |
| 하도급대금 | 원수급자가 발주기관에서 대금을 받은 날부터 15일 이내 | 박문각 수험서 기준 |
| 전자계약 | 초안 → 응답서 → 체결통보 | 표준교재 제5장 |
| 시스템 | 나라장터 | 입력 대본 |

위 표의 착수·변경·물가변동·조정·검사·대금·하도급대금 기한은 표준교재 제5장에 수록된 숫자가 아니라 박문각 수험서가 설명한 계약 일반조건 기준이다. 실제 업무에서는 최신 법령, 계약예규, 공고와 계약조건을 확인한다.

공동수급체 구성원 수, 최소 지분, 업종과 자격요건도 계약 유형과 규모에 따라 달라질 수 있다.

## 최종 정리

용역계약은 보이지 않는 서비스를 관리 가능한 약속으로 바꾸는 계약이다. 과업지시서로 범위를 정하고 착수계로 기준계획을 확정하며, 수행 중에는 인력·일정·성과를 관리한다.

수요부서가 목적과 과업을 설계하면 계약담당자는 입찰과 평가방법을 정한다. 공동수급이 있으면 대표업체 작성, 구성업체 승인, 발주기관 검토 순으로 협정서를 처리한다. 낙찰 후 전자계약은 `초안 → 응답서 → 체결통보`로 확정한다.

수행 중 과업·인력·기간이 바뀌면 변경계약을 체결한다. 완료 후에는 산출물과 성과를 검사하고 사후정산을 거쳐 대금을 지급한다. 하도급은 본선 절차와 병행하여 허용 여부, 서면계약, 승인·통보, 수행품질과 대금을 관리한다.

핵심 암기 구조는 다음과 같다.

- 전체: `과업설계 → 입찰·평가 → 공동수급 → 계약 → 착수 → 과업·인력·일정 → 검사 → 대금`
- 관리 중심: `과업 → 인력 → 일정 → 성과`
- 공동수급: `대표업체 작성 → 구성업체 승인 → 대표업체 전송 → 발주기관 검토`
- 이행: `착수계 → 인력투입 → 과업수행 → 중간보고 → 변경 → 완료통지 → 검사 → 대금`
- 하도급 병행: `허용 확인 → 선정·서면계약 → 승인·통보 → 수행·품질·대금관리`
