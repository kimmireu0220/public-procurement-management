## 핵심 내용

### 1. 물품계약의 특성

물품계약은 공공기관이 필요한 물품을 제조하게 하거나 완성품을 구매하는 계약이다. 관리의 중심은 약속한 물품이 정해진 규격과 수량으로 제때 납품되었는지 확인하는 데 있다.

- **규격 중심:** 규격서와 성능요건이 이행과 검사의 기준이다.
- **납품 중심:** 제조를 마쳤더라도 지정한 장소에 정해진 수량을 납품하지 않으면 이행이 완료되지 않는다.
- **검사·검수:** 품질과 성능뿐 아니라 수량과 외관도 확인한다.
- **금액 조정 가능성:** 물가변동이나 계약조건 변경 등 정해진 사유가 있으면 조정을 검토한다.
- **하자책임:** 검사 합격 후에도 하자담보책임기간의 수리·교체 책임이 남는다.

### 2. 물품 특화 계약조건

| 조건 | 주요 내용 |
|---|---|
| 규격·성능 | 기능, 품질수준, 시험기준, 구성품을 검사 가능한 형태로 명시 |
| 납품 | 기한, 장소, 운송·포장·보관, 분할납품 허용 여부 |
| 검사·검수 | 시험방법, 합격기준, 불합격 시 보완·교환·재납품 |
| 대가지급 | 선금, 부분대금, 검사 합격 후 지급과 필요서류 |
| 하자 | 하자기간, 보수절차, 보증금, 교체·수리 기준 |

특정 브랜드를 특별한 사유 없이 지정하거나 과도한 규격으로 경쟁을 제한해서는 안 된다. 필요한 기능과 성능을 중심으로 규격을 작성하여 동등 이상의 제품이 경쟁할 수 있게 한다.

납품기한은 제조기간과 운송여건을 고려하여 현실적으로 설정한다. 불가능한 납기는 이행과 품질을 동시에 훼손할 수 있다.

### 3. 검사와 검수

검사와 검수는 목적이 다르다.

| 구분 | 확인 대상 |
|---|---|
| 검사 | 규격, 품질, 성능, 시험결과 |
| 검수 | 수량, 외관, 포장, 납품장소와 상태 |

계약상대자가 납품을 완료하고 검사 요청을 하면 계약담당공무원 또는 지정 검사자가 규격서, 계약서, 물품명세와 시험성적서를 기준으로 검사한다. 필요하면 샘플시험이나 성능시험을 실시한다.

불합격 시 발주기관은 보완, 교환 또는 재납품을 요구한다. 계약상대자 책임으로 재검사가 필요하면 관련 비용과 지연 책임이 발생할 수 있다. 계약상대자는 계약조건에 따라 재검사를 요청할 수 있다.

검사·검수 흐름은 다음과 같다.

`납품완료 → 검사요청 → 규격·성능 검사 → 수량·외관 검수 → 합격 또는 보완·재납품`

### 4. 대금과 하자관리

검사와 검수에 합격하면 계약상대자가 대금을 청구한다. 발주기관은 청구서, 검사·검수 결과와 세금계산서 등의 서류를 확인하고 지급한다.

납품만 완료했거나 검사에서 불합격한 상태는 정상적인 대가지급 단계가 아니다. 검사 합격이 대금지급의 전제이다.

표준교재는 중앙조달이나 다수공급자계약 납품요구에서 조달청이 회전자금으로 먼저 지급하는 대지급 구조도 설명한다. 이는 수요기관이 직접 지급하는 일반 선금·대금과 달리 조달청이 먼저 지급하는 방식이다.

대금지급 후에도 하자담보책임은 남는다. 결함이 확인되면 발주기관은 수리, 교체 또는 재납품을 요구하고, 이행하지 않으면 하자보수보증금 등 계약상 조치를 검토한다.

### 5. 다수공급자계약(MAS)

다수공급자계약은 품질, 성능 또는 효율이 같거나 비슷한 종류의 물품을 수요기관이 선택할 수 있도록 두 곳 이상의 계약상대자와 단가계약을 체결하는 방식이다.

기본계약 단계와 실제 구매 단계를 구분한다.

1. 조달청이 적격성평가와 가격협상을 거쳐 여러 공급자와 기본계약을 체결한다.
2. 계약물품을 종합쇼핑몰에 등록한다.
3. 수요기관이 필요한 물품을 선택하여 구매요청 또는 납품요구를 한다.
4. 계약상대자가 납품한다.
5. 검사·검수 후 대금을 지급한다.

`조달청 기본계약 → 종합쇼핑몰 등록 → 수요기관 선택 → 납품요구 → 납품 → 검사·검수 → 대금`

계약이행실적평가에서는 납기, 품질, 수요기관 만족도, 서비스와 계약이행 성실도를 평가한다. 결과는 계약연장, 재계약, 차기계약과 이후 경쟁평가에 활용될 수 있다.

일정 금액 이상의 구매에서는 여러 계약상대자를 다시 비교하는 2단계 경쟁을 실시할 수 있다. 구체적인 적용금액과 예외는 제품 유형과 당시 업무처리기준에 따라 달라질 수 있으므로 최신 기준을 확인한다.

계약단가는 임의로 바꾸지 않는다. 가격자료 제출과 적정성 검토 후 수정계약을 체결한다.

### 6. 단가계약

단가계약은 반복구매하는 물품의 품목별 단가를 미리 정하고, 실제 수량은 필요할 때 개별 주문으로 확정하는 계약이다.

`단가·기간·한도 확정 → 개별 주문 → 납품 → 검사·검수 → 대금지급`

계약 시 단가, 계약기간과 최대 계약한도액을 정한다. 수요부서는 필요할 때 주문하고 계약상대자는 주문서의 수량과 납품기한에 따라 공급한다.

원가, 규격이나 법령이 바뀌면 계약조건에 따라 단가조정 또는 규격변경을 검토한다. 계약기간 만료, 계약한도액 소진 또는 계약 해제·해지 후에는 더 주문할 수 없다.

단가계약은 반복구매의 행정절차를 줄이지만 예산, 재고와 계약한도를 계속 관리해야 한다.

## 실무 절차(누가·언제·무엇)

| 시점 | 누가 | 무엇을 하는가 |
|---|---|---|
| 수요 발생 | 수요부서 | 물품 종류, 수량, 사용목적과 필요시기 확인 |
| 발주 준비 | 수요부서·계약담당자 | 성능 중심 규격서 작성, 납품·검사·대금·하자조건 설정 |
| 입찰 전 | 계약담당자 | 규격과 계약조건을 공고에 반영 |
| 낙찰 후 | 발주기관 | 나라장터에서 계약서 초안 송신 |
| 계약체결 | 계약상대자 | 금액, 물품명세, 납품조건 확인 후 응답서 제출 |
| 계약 확정 | 발주기관 | 계약체결통보서 송신 |
| 제조·공급 | 계약상대자 | 원재료·공정·품질관리, 운송·포장·설치 준비 |
| 제조 중 | 발주기관 | 계약 성질상 필요한 경우 제조공정 감독 |
| 납품 | 계약상대자 | 지정 장소에 물품 납품 후 검사 요청 |
| 검사·검수 | 검사자·발주기관 | 규격·성능과 수량·외관 확인 |
| 불합격 | 계약상대자 | 보완, 교환 또는 재납품 |
| 합격 후 | 계약상대자 | 대금 청구 |
| 청구 후 | 발주기관 | 검사결과와 지급서류 확인 후 대금 지급 |
| 납품 후 | 발주기관·계약상대자 | 하자 통보, 수리·교체·재납품 관리 |

전자계약은 `초안 → 응답서 → 체결통보` 순서이다.

변경계약은 다음 순서로 처리한다.

`변경요청 → 사유·기간·금액 검토 → 승인 시 변경초안 → 변경응답 → 체결승인통보`

반려되면 보완 후 다시 요청한다. 계약상대자의 책임 없는 정당한 사유로 납품기한이 연장되는 경우에는 지체상금 면제 여부를 함께 검토한다.

## 공사·물품·용역의 비교·주의사항

| 구분 | 공사 | 물품 | 용역 |
|---|---|---|---|
| 관리 대상 | 현장 시공과 시설물 | 제조·구매한 물품 | 무형의 서비스와 산출물 |
| 핵심 | 공정·품질·안전 | 규격·납품·검사 | 과업·인력·일정·성과 |
| 시작 | 착공계 | 제조·납품 준비 | 착수계 |
| 완료 판단 | 준공검사 | 검사·검수 합격 | 과업과 산출물 검사 |

주의사항은 다음과 같다.

- 제품명보다 필요한 기능과 성능 중심으로 규격을 작성한다.
- 물품 도착과 계약 완료를 구분한다. 납품과 검사 합격이 모두 필요하다.
- 검사는 품질·규격·성능, 검수는 수량·외관·납품상태를 확인한다.
- 다수공급자계약은 조달청의 기본계약과 수요기관의 개별구매를 구분한다.
- 단가계약은 단가가 확정되어도 실제 수량은 주문 시 확정된다.
- 납품요구 뒤 실제 납품을 거쳐 검사·검수와 대금지급으로 진행한다.
- 하자책임은 검사 합격과 대금지급 이후에도 남는다.

## 최종 정리

물품계약은 규격이 기준을 만들고, 납품이 이행을 진행하며, 검사 합격이 대금지급으로 이어지는 구조이다.

수요부서가 필요한 물품과 시기를 정하면 계약담당자는 성능 중심의 규격서와 납품·검사·대금·하자조건을 마련한다. 낙찰 후에는 `초안 → 응답서 → 체결통보`로 전자계약을 확정한다.

계약상대자가 제조·납품하고 검사 요청을 하면 발주기관은 규격·성능을 검사하고 수량·외관을 검수한다. 불합격 시 보완·교환·재납품을 요구하며, 합격 후 대금을 지급한다. 하자책임은 이후에도 계속된다.

핵심 암기 구조는 다음과 같다.

- 일반 물품계약: `수요 → 규격 → 조건 → 계약 → 제조·납품 → 검사·검수 → 대금 → 하자`
- 검사와 검수: `검사 = 규격·품질·성능 / 검수 = 수량·외관·납품상태`
- 다수공급자계약: `기본계약 → 종합쇼핑몰 → 선택 → 납품요구 → 납품 → 검사·검수 → 대금`
- 단가계약: `단가·기간·한도 → 주문 → 납품 → 검사·검수 → 대금`
