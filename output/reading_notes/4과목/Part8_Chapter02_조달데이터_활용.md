## 핵심 내용

### 1. 이용주체와 목적

- 발주기관 조달담당자: 과거 구매실적·시장가격·공급자 수를 보고 계획을 세우며 경쟁성, 일정, 예산집행을 관리한다.
- 조달기업: 시장규모, 주요 발주기관, 경쟁업체, 낙찰가격 수준을 분석해 참여 여부와 준비시기를 정한다.
- 정책담당자: 기업군·제품군의 구매목표와 실적, 지역·기관별 현황을 분석해 정책 이행을 확인한다.

개별 단계의 숫자보다 한 사업의 `계획 → 입찰 → 계약 → 이행·지급`을 연결해 보는 것이 중요하다.

### 2. 우선구매 데이터

중소기업제품의 법정 의무구매 비율은 공공기관 총구매액의 **50% 이상**이다. 공공기관은 매년 **4월 말**까지 전년도 구매실적과 당해 연도 구매계획을 공표하는 흐름으로 관리한다.

표준교재의 2024년 자료:

- 중소기업제품 구매액: **131조원**
- 총구매액 대비 실제 구매비율: **76.8%**
- 대상기관: **842개**
- 50% 이상 구매기준 준수기관: **823개**
- 준수 비율: **97.7%**

50%는 법정 의무구매 비율이고 76.8%는 2024년 실제 비율이다. 나머지 금액·기관 수·준수율에도 2024년 실적이라는 시점을 붙여 기억한다.

기술개발제품은 표준교재에서 **13종**으로 정리한다. 성능인증, 우수조달물품, NEP, NET, 우수조달공동상표, 혁신제품 등이 포함되며 13종 전체 명칭은 별도 암기대상이다.

| 대상 | 채널·구분 |
|---|---|
| 중소기업제품 | 공공구매 종합정보망 |
| 녹색제품 | 환경표지제품·저탄소제품·GR, 에코스퀘어 |
| 여성기업 | 관련 포털·와우몰 |
| 사회적기업 | 관련 포털·가치장터 |
| 장애인기업 | 장애인기업 종합지원센터, 입찰판로지원, MAS·이음장터 컨설팅 |
| 중증장애인생산품 | 꿈드래쇼핑몰 |

표준교재는 와우몰과 가치장터의 소액 거래 기준으로 **2천만원 이하**를 제시한다. 모든 여성기업·사회적기업 거래에 공통 적용되는 일반 기준으로 확대하지 않는다.

우선구매 분석은 `대상별 목표 확인 → 기관별 실적 수집 → 목표·실적 차이 분석 → 잠재수요기관 선정 → 발주계획·과거품목 분석 → 공급계획` 순이다.

### 3. 목적 설정과 데이터 수집

목적은 구체적인 판단 질문으로 정한다.

- 기업: 시장규모와 증가 추세, 주요 기관, 주요 경쟁자, 과거 낙찰가격
- 발주기관: 경쟁성, 가격·납기 안정성, 특정 업체 의존, 계획 대비 계약·지급

주요 출처는 전자조달시스템, 조달데이터허브·조달통계, 공공데이터포털, 우선구매 목적별 정책 포털이다. 수집할 때 출처, 기준일, 조회기간, 기관범위, 품목분류, 금액기준, 중복 포함 여부를 함께 기록한다.

### 4. 정제와 신뢰성 검토

기관명·업체명, 품목분류, 날짜·금액 형식을 통일한다.

**[보충]** 동일 계약이 변경계약과 함께 중복 집계되는지, 취소 공고가 포함되는지, 금액·기관정보가 누락되는지 확인한다.

신뢰성은 다음 네 기준으로 검토한다.

1. 출처: 공식 기관·시스템 자료인가
2. 최신성: 조회 기준일과 갱신일이 적절한가
3. 정확성: 금액 오류·중복·누락이 없는가
4. 일관성: 자료별 수치와 분류기준이 일치하는가

수치가 다르면 임의로 하나를 고르지 않고 조회조건과 집계기준의 차이를 확인한다. 해결되지 않는 차이는 보고서에 한계로 밝힌다.

### 5. 분석 기준

| 기준 | 분석 내용 |
|---|---|
| 기간 | 월·분기·연도별 건수와 금액, 추세와 계절성 |
| 발주기관 | 기관별 건수·금액·반복품목, 주요 수요기관 |
| 조달대상물 | 물품·용역·공사 및 세부 품목·서비스 |
| 업체 | 참여·낙찰 건수, 계약금액, 주요 발주기관 |
| 계약·경쟁방식 | 일반·제한·지명경쟁, 수의계약 등 |

성격이 다른 시장을 섞지 않고 계약방식의 적용 여부는 관련 법령·공고와 함께 확인한다.

### 6. 입찰·가격·시장 분석

입찰현황은 `공고 수 → 참여업체 수 → 경쟁 정도 → 낙찰가격 수준 → 유찰원인`으로 읽는다.

- 경쟁률: 참여업체 수를 보여 주지만 규모, 계약방법, 참가제한이 다르면 단순 비교하지 않는다.
- 낙찰률: 해당 데이터가 정의한 **기준가격 대비 낙찰가격 비율**이다. 자료마다 기준가격과 산식이 다르므로 정의를 먼저 확인한다.
- 과거 낙찰률: 전략의 참고자료일 뿐 다음 낙찰가격을 보장하지 않는다.
- **[보충]** 유찰은 참여업체 부족, 가격 불일치, 자격 미충족 등 공개자료에서 확인 가능한 원인을 검토한다.

시장분석은 전체 계약건수·금액, 추세, 지역, 구매분야를 본다. 발주기관 분석은 반복품목과 발주시기, 자사 적합성을 본다. 경쟁사 분석은 참여·낙찰·계약실적과 강점 품목·기관을 본다.

**[보충]** 공개된 공동수급 정보가 있으면 단독·공동참여를 구분할 수 있다. 공개자료로 확인되지 않는 기업 내부 원가나 전략을 단정하지 않는다.

### 7. 시각화와 보고서

- 막대그래프: 기관·업체 간 규모 비교
- 선그래프: 기간별 증감
- 원그래프: 구성비

제목, 기간, 단위, 출처를 명시하고 금액과 건수 또는 서로 다른 기간을 같은 조건처럼 섞지 않는다. 그래프 뒤에는 변화, 집중도, 필요한 행동을 문장으로 해석한다.

보고서는 `분석 목적 → 데이터 출처·기준일 → 분석 방법 → 주요 결과 → 결론·시사점`으로 작성한다. 기업에는 목표시장·기관, 보완할 자격·실적, 준비시기를 제안하고 발주기관에는 경쟁성, 규격, 공급위험, 우선구매 개선방안을 제시할 수 있다.

## 비교·주의사항

- 분석 목적 없이 데이터를 먼저 모으지 않는다.
- 50% 법정 비율과 76.8% 실제 비율을 혼동하지 않는다.
- 2천만원은 표준교재의 와우몰·가치장터 소액 거래 문맥이다.
- NET는 신기술 인증이며 NEP는 신제품 인증이다.
- 낙찰률은 자료가 사용하는 기준가격과 산식을 확인한다.
- 공식 데이터도 중복·누락·분류 차이를 검토한다.
- 사실과 해석을 구분하며 공개자료 밖의 내부전략을 단정하지 않는다.
- `[보충]` 항목은 입력 대본에서 실무 설명으로 추가된 내용이다.

## 최종 정리

조달데이터는 발주계획·입찰·계약·공급업체·대금지급 정보를 연결한 의사결정 근거다. 분석은 `목적 → 수집 → 검토 → 분석 → 보고`로 진행한다. 공식 출처를 사용하더라도 출처·최신성·정확성·일관성을 검토하고, 기간·기관·대상·업체·계약방법별로 나누어 본다.

우선구매에서는 목표와 실제 실적을 구분한다. 중소기업제품 50%는 법정 의무구매 비율이고, 131조원·76.8%·842개·823개·97.7%는 표준교재의 2024년 실적이다. 최종 보고서는 수치 나열이 아니라 출처가 명확한 사실을 실행 가능한 판단으로 바꾸어야 한다.
