# Part 6 · CHAPTER 04 리스크 발생 모니터링

> 박문각 4과목 「공공조달 리스크 관리」 · Check/Q&A 제외 · 문제+정답

---

## 핵심 최종점검

**1.** 리스크 대응계획의 궁극적 목적은 무엇인가?

→ 실효성 확보

**2.** 실행 상태 구분의 기본 3단계는 무엇인가?

→ 완료, 진행 중, 미실행

**3.** 실행 여부 확인 시 형식적 점검을 지양해야 하는 이유는 무엇인가?

→ 실질적 이행 확보

**4.** 실행되지 않은 리스크는 어떻게 해야 하는가?

→ 재평가

**5.** 현장 확인의 목적은 무엇인가?

→ 실질 이행 확인

**6.** 대응조치 성과 확인의 궁극적 목적은 무엇인가?

→ 위험 감소 확인

**7.** 리스크 감소의 2대 지표는 무엇인가?

→ 발생확률, 영향도

**8.** 성과를 수치로 측정하는 방법은 무엇인가?

→ 정량적 분석

**9.** 대응비용 대비 효과를 분석하는 것은 무엇인가?

→ 비용-효과 분석

**10.** 대응계획을 실행했더라도 성과가 없을 경우 필요한 조치는 무엇인가?

→ 대응방안 재설계

**11.** 핵심성과지표를 무엇이라 하는가?

→ KPI

**12.** 성과 확인 후 등급을 다시 조정하는 것을 무엇이라 하는가?

→ 리스크 등급 재조정

**13.** 기존 계획에 없는 위험을 무엇이라 하는가?

→ 신규 리스크

**14.** 새로운 리스크는 주로 언제 발생하는가?

→ 환경 변화 시

**15.** 리스크 등록 문서는 무엇인가?

→ Risk Register

**16.** 법령 개정의 리스크 원인은 무엇인가?

→ 외부 환경 변화

**17.** 현장 의견을 수집하는 목적은 무엇인가?

→ 조기 위험 감지

**18.** 사업범위 변경은 무엇을 초래하는가?

→ 새로운 비용·일정 리스크

**19.** 리스크 모니터링의 최종 목적은 무엇인가?

→ 개선 조치 유도

**20.** 리스크 모니터링 결과 공유의 핵심 가치는 무엇인가?

→ 투명성

**21.** 신규 리스크 발생 시 필요한 조치는 무엇인가?

→ 등록 및 보고

**22.** 보고의 필수 요소는 무엇인가?

→ 문서화

**23.** 공공조달에서 공유가 중요한 이유는 무엇인가?

→ 책임성 확보

## 서술형 출제예상문제

**1.** 리스크 대응계획 실행 여부 확인의 필요성을 설명하시오.

→ 형식적 관리 방지, 실제 이행 점검, 실효성 확보

**2.** Risk Register를 활용한 실행 점검 방법을 설명하시오.

→ Risk Register 기준 완료/진행/미실행 구분·정기 갱신

**3.** 일정 지연 시 필요한 관리조치를 설명하시오.

→ 원인 분석, 일정 수정, 책임자 재지정, 예산 확보

**4.** 공공조달에서 실행 점검이 중요한 이유를 설명하시오.

→ 정책·예산·사회 영향 크므로 미흡 시 감사·평판 리스크

**5.** A기관 100억원 공공공사: 공기지연 리스크 대응계획(주간 공정회의 미개최 시 계약변경 검토)이 2개월 미실행, 공정률 15% 지연. 문제점과 개선방안을 서술하시오.

→ ① 미실행, 점검체계 미흡, 일정관리 실패 ② 체크리스트, 자동보고, Trigger, 월간 점검

**6.** 총 대응조치 20개(완료 12, 진행 5, 미실행 3).
   ① 실행률(완료기준)을 계산하시오.
   ② 완료+진행 포함 실행률을 계산하시오.
   ③ 관리상태를 평가하시오.

→ 1) 60% 2) 85% 3) 실질 완료 60%, 미실행 3건 보완 필요

**7.** 실행 여부 확인과 성과 확인의 차이를 설명하시오.

→ 실행=이행 여부, 성과=위험 감소 효과

**8.** 리스크 대응방안 성과를 측정하는 방법을 설명하시오.

→ 전·후 확률·영향 비교, KPI, 정량·정성 병행

**9.** 비용 대비 효과 분석의 필요성을 설명하시오.

→ 투입 비용 대비 위험 감소 효과 검증

**10.** B기관 입찰담합 리스크 대응 후 담합 의심 신고 10건→3건. 성과를 분석하고 향후 관리방향을 제시하시오.

→ ① 신고 70% 감소 ② 투명성 개선 ③ 잠재 담합 고려 ④ 지속 모니터링 ⑤ 비용-효과 분석

**11.** 대응 전 발생확률 50%/예상손실 4억원 → 대응 후 20%/1억원.
   ① 발생확률 감소율은?
   ② 예상손실 감소액은?
   ③ 성과를 평가하시오.

→ 1) 60% 2) 3억원 3) 효과 우수, 지속 관리

**12.** 새로운 리스크 식별의 필요성을 설명하시오.

→ 환경 변화에 따른 조기 발견·대응

**13.** 신규 리스크 식별 방법을 설명하시오.

→ 정기 회의, 현장 의견, 데이터 이상, 이해관계자, 외부 모니터링

**14.** 데이터 이상 징후 분석의 의미를 설명하시오.

→ 통제 약화·신규 위험 신호

**15.** 신규 리스크 식별 후 절차를 설명하시오.

→ Register 등록→확률·영향→중요도→대응전략

**16.** 공공조달에서 신규 리스크 관리의 중요성을 설명하시오.

→ 정책·예산·사회 영향으로 조기대응 실패 시 전체 영향

**17.** C기관 공공용역 수행 중 예산 삭감 가능성 제기, Risk Register에 미포함. 어떻게 관리해야 하는지 서술하시오.

→ ① 신규 식별 ② Register 등록 ③ 확률·영향 ④ 대응전략 ⑤ 공유

**18.** 계약변경 2건→8건, 지연율 5%→18%. 이 수치 변화가 시사하는 바를 분석하시오.

→ ① 통제 약화 ② 설계·범위 변경 ③ 일정 실패 ④ 신규 식별·재평가

**19.** 리스크 모니터링 결과 공유 대상의 유형을 설명하시오.

→ 내부·외부(감독·감사) 이해관계자

**20.** 리스크 모니터링 결과 공유 내용의 구성요소를 설명하시오.

→ 현황, 등급 변화, 실행 상태, 성과, 신규 리스크, 개선 제안

**21.** 모니터링 결과를 바탕으로 제안할 수 있는 조치를 설명하시오.

→ 계획 수정, 예산, 일정, 책임자, 통제 강화, 범위 조정

**22.** D기관 공사 지연율 20% 상승, 계약변경 건수 증가. 경영진 보고 내용과 제안 조치를 서술하시오.

→ ① 지연·계약변경 현황·원인 ② 등급 상향 ③ 일정·인력·예산 제안

**23.** 하자 발생률 2%→7%, 민원 3건→12건, 감사 지적 0건→4건. 공유 대상과 제안 조치를 제시하시오.
