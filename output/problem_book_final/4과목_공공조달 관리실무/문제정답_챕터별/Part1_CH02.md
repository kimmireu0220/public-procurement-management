## 핵심 최종점검

**1.** 중소기업자 간 경쟁제품 물품 등록 시 직접생산확인이 관련된 법령은 무엇인가?

→ 「중소기업제품 구매촉진 및 판로지원에 관한 법률」(판로지원법).

**2.** 공사의 경우 품명등록보다 우선적으로 요구되는 것은 무엇인가?

→ 해당 공사업종 등록.

**3.** 기존에 세부품명이 존재하는 경우 신규등록이 가능한가?

→ 원칙적으로 별도 신설이 불필요하며, 기존 세부품명으로 분류한다.

**4.** 세부품명 등록은 향후 어떤 제도 참여의 기초가 되는가?

→ 다수공급자계약(MAS), 우수조달물품, 혁신제품 신청 등의 기초가 된다.

**5.** 상호 또는 대표자 변경 후 변경등록을 하지 않고 입찰에 참여한 경우 어떻게 되는가?

→ 상호 또는 법인의 대표자를 변경등록하지 않고 제출한 입찰은 「국가계약법 시행규칙」 제44조 제1항 제6의3호에 따른 무효사유이다.

**6.** 법인의 상호가 변경된 경우 추가로 수행해야 할 조치는 무엇인가?

→ 변경된 상호에 맞춰 인증서를 재발급받아 나라장터에 추가등록하고 사업자등록증·면허·인가 등 관계서류도 변경한다.

**7.** 지사의 대표자를 변경하지 않고 입찰에 참가한 경우 입찰은 무효인가?

→ 지사 대표자는 법인의 대표자가 아닌 사용인이므로, 법인 대표자 변경이 아니라면 그 사유만으로 입찰무효가 되지 않는다.

**8.** 입찰대리인 삭제는 자체 수정이 가능한가, 조달청 승인사항인가?

→ 자체 수정 가능.

**9.** 제조물품 변경은 자체 수정이 가능한가, 조달청 승인사항인가?

→ 조달청 승인 대상.

**10.** 품목식별번호는 몇 자리로 구성되는가?

→ 8자리.

**11.** MAS 계약 납품을 위해 필요한 번호는 무엇인가?

→ 16자리 물품목록번호(8자리 품명번호 + 8자리 품목식별번호).

**12.** 목록화 요청을 수행하는 시스템은 무엇인가?

→ 목록정보시스템.

**13.** 등록 대상 품목이 10개 미만일 경우 사용하는 등록 방법은 무엇인가?

→ 개별요청.

**14.** 융복합상품의 대분류 코드는 어떤 숫자로 시작하는가?

→ 99.

**15.** 목록화 요청 시 요청자 정보는 어떻게 입력되는가?

→ 나라장터 로그인 정보가 자동 입력된다.

**16.** KS표준번호는 어느 단계에서 입력하는가?

→ 참고자료 입력 단계.

**17.** 용역 협상계약에서 핵심 제출서류는 무엇인가?

→ 기술제안서.

**18.** 입찰참가자격을 증명하는 기본 서류는 무엇인가?

→ 사업자등록증. 다만 실제 참가자격은 관계 법령상 허가·등록과 나라장터 등록정보 및 공고조건을 함께 확인한다.

**19.** 직접생산 대상 물품의 경우 필수 제출서류는 무엇인가?

→ 직접생산확인증명서. 정보통신망으로 확인되는 경우 서류 제출을 생략할 수 있으므로, ‘보유·유효·전자확인 가능’이 핵심이다.

**20.** 입찰대리인이 입찰에 참여할 때 필요한 서류는 무엇인가?

→ 위임장.

**21.** 인감 대신 사용할 수 있도록 제출하는 서류는 무엇인가?

→ 사용인감계.

**22.** 제안서 미제출 시 어떤 결과가 발생하는가?

→ 평가 제외.

**23.** 전자입찰에서 제출서류는 어떤 형태로 제출하는가?

→ 공고에서 정한 전자파일(통상 스캔본 또는 전자문서).

## 서술형 출제예상문제

**1.** 물품 세부품명 신규등록의 필요성을 설명하시오.

→ ① 기존 분류에 없는 신기술 제품에 대응 ② 제품 간 기술적 차별성 확보 ③ 유사 물품 간 시장 혼선 방지 ④ 조달 목적에 맞는 분류의 명확화 ⑤ MAS·우수조달물품·혁신제품 등 조달제도 진입 기반 마련.

**2.** 물품·용역·공사의 등록 방식 차이를 설명하시오.

→ 물품은 세부품명 중심, 용역은 업종과 업무범위 중심, 공사는 개별 법령상 공사업 등록 중심으로 관리한다. 즉 물품은 코드체계, 공사는 면허·등록체계가 핵심이다.

**3.** 직접생산확인과 세부품명 등록의 관계를 설명하시오.

→ 직접생산확인은 경쟁제품의 해당 세부품명을 기준으로 발급·확인하며, 중소기업자 간 경쟁입찰의 참가 가능 여부와 제조등록의 근거가 된다.

**4.** 신규 세부품명 등록 시 기업이 준비해야 할 자료는 무엇인가?

→ 제품설명서, 기술사양서, 기능·성능 비교표, 시장수요 자료 및 기존 품명과의 차별성을 입증하는 자료를 준비한다.

**5.** 물품 세부품명 신규등록 절차를 서술하시오.

→ 기존 품명 검색 → 유사성 검토 → 신설 필요성 판단 → 기술설명자료와 차이점 자료 제출 → 조달청 심사 → 승인 및 코드 부여 순이다.

**6.** 신기술 제품을 개발한 기업이 세부품명 신규등록을 신청하려 한다. 검토 절차와 정책적 의미를 설명하시오.

→ 기술의 독립성 판단 → 기존 코드 존재 여부 검토 → 신규 세부품명 필요성 입증 → 시장수요·조달 활용 가능성 분석 → 조달청 심사 대응 순으로 검토한다. 이는 신기술의 공공조달시장 진입을 촉진하면서 분류체계를 일관되게 관리한다는 의미가 있다.

**7.** 입찰참가자격 변경신청의 개념과 필요성을 설명하시오.

→ 등록사항에 변동이 생겼을 때 이를 갱신하는 절차이다. 계약당사자 정보를 정확히 유지하여 허위·착오를 방지하고 공정한 입찰질서를 확보하기 위해 필요하며, 상호·법인 대표자 미변경은 입찰무효사유가 된다.

**8.** 기본정보 변경 시 자체 수정 가능 항목과 조달청 승인 필요 항목을 구분하여 설명하시오.

→ 자체 수정 가능 항목은 전화번호·팩스번호·홈페이지·종업원수·대표자 연락처·공급물품 추가·삭제·입찰대리인 삭제 등이다. 조달청 승인 필요 항목은 상호·대표자·주소·기업구분·공장정보·제조물품·공사·용역·기타업종·입찰대리인 등록·등기사항 등이다. 실제 화면과 승인대상은 2026년 현행 나라장터 안내를 우선한다.

**9.** 입찰참가자격 변경신청 메뉴 경로를 쓰시오.

→ 이용자관리 → 업체정보관리 → 입찰참가자격변경/제조물품 갱신등록신청.

**10.** 지사 대표자를 변경하지 않고 입찰에 참여한 경우 입찰무효가 되지 않는 이유를 설명하시오.

→ 지사 대표자는 법인의 대표자가 아닌 사용인이므로 계약당사자인 법인의 대표자 변경에 해당하지 않는다.

**11.** 직원 탈퇴 처리 방법을 설명하시오.

→ 직원 본인은 이용자관리 → 회원정보관리 → 개인회원 소속선택 → 소속탈퇴로 처리한다. 업체 관리자는 이용자관리 → 소속직원관리 → 업체소속직원 정보목록 → 해당 직원 → 탈퇴로 처리한다.

**12.** 목록화의 목적을 설명하시오.

→ 물품에 고유 식별체계를 부여해 중복 등록을 막고 정확한 모델 식별, 전자계약·납품관리 및 MAS 등 계약제도의 기반을 마련하는 것이다.

**13.** 개별요청과 일괄요청의 차이를 설명하시오.

→ 개별요청은 등록대상 10개 미만을 하나씩 입력하는 방식이고, 일괄요청은 동일 세부품명 10개 이상을 일괄 등록하는 방식이다.

**14.** 융복합상품 등록 시 유의사항을 설명하시오.

→ 대분류 99 해당 여부를 확인하고, 융합상품은 세부품명, 복합상품은 물품식별번호를 조회하여 구성 품목 간 연계와 실제 조달 활용 가능성을 검토한다.

**15.** 입찰 제출서류의 유형을 구분하여 설명하시오.

→ ① 참가자격: 사업자등록증, 등기사항증명서, 인감증명서, 사용인감계, 업종등록증, 직접생산확인증명서 ② 가격: 입찰서, 산출내역서, 가격제안서, 입찰보증금 자료 ③ 기술·제안: 기술제안서, 수행계획서, 인력계획, 실적, 신용평가 ④ 적격심사·협상: 재무제표, 납세증명서, 4대보험 완납증명서, 실적증명서 등이다. 최종 목록은 공고문을 따른다.

**16.** 사전제출과 사후제출의 차이를 설명하시오.

→ 사전제출은 입찰서 제출 시 함께 내며 누락 시 무효·평가제외 등 공고상 효과가 발생할 수 있다. 사후제출은 낙찰예정자 등에게 요구되며 미제출 시 낙찰취소·계약체결 불가가 될 수 있다. 효력은 법령과 공고문을 기준으로 개별 판단한다.

**17.** 입찰보증금 관련 제출요건을 설명하시오.

→ 공고에서 정한 보증금·보증서 또는 면제 시 지급각서를 기한 내 제출하고, 보증금률과 보증기간을 확인한다. 미납의 효력은 적용 법령과 공고·입찰유의서를 따른다.

**18.** 제출서류 유효기간 검토의 중요성을 설명하시오.

→ 발급일 요건과 입찰서 제출마감일·계약일 등 공고에서 정한 기준시점의 유효성을 확인하여 만료·허위서류와 자격상실을 방지한다.

**19.** 전자입찰에서 제출서류 준비 시 유의사항을 설명하시오.

→ 스캔 해상도, 서명·날인, 명확한 파일명, 마감시간, 정상 업로드·접수 여부 및 시행문을 확인한다.

**20.** B사는 기술제안 입찰에 참여하였다. 입찰서와 가격제안서는 제출하였으나 기술제안서를 마감시간 이후에 제출하였고, 낙찰예정자로 선정되었으나 납세증명서를 제출하지 못하였다. ① 기술제안서 지연 제출의 효과는 무엇인가? ② 사후서류 미제출 시 효과는 무엇인가? ③ 종합적으로 입찰 결과는 어떻게 되는가?

→ 기술제안서를 마감 후 제출하면 공고상 제출요건을 충족하지 못하여 통상 평가 제외 대상이다. 낙찰예정자가 공고상 계약체결 필수서류인 납세증명서를 제출하지 못하면 계약체결이 불가능하고 차순위 검토 등 공고 절차를 따른다.

**21.** A사는 기존에 나라장터에 등록된 “공기청정기” 세부품명으로는 자사의 신제품을 등록할 수 없다고 판단하였다. 해당 제품은 공기정화 기능, 바이러스 실시간 감지 기능, IoT 기반 원격 모니터링 시스템을 탑재하여 기존 공기청정기와 기능적으로 차별화되어 있다. A사는 MAS 계약을 추진하기 위해 새로운 세부품명 신설을 요청하려 한다. ① 신규 세부품명 신설 필요성 판단 기준을 설명하시오. ② 세부품명 신설 가능 여부를 검토하시오. ③ 신청 절차를 설명하시오. ④ 관련 법령 및 규정을 제시하시오.

→ 기존 세부품명으로 분류할 수 없는 독립 기능·기술적 차별성, 시장수요와 조달 필요성이 입증될 때 신설을 검토한다. 기존 분류의 확장으로 수용할 수 있으면 기존 분류를 사용한다. 목록정보시스템에서 유사품명 검색 → 품명신설 요청 → 상위분류·기능·성능·차이점·기술자료 입력 → 조달청 심사 → 승인 시 10자리 세부품명번호 부여 순으로 진행한다. 근거는 「물품목록정보의 관리 및 이용에 관한 법률」, 같은 법 시행령과 「물품목록정보의 관리 및 이용에 관한 규정」이다.
