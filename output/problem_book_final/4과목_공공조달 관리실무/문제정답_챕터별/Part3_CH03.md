# Part 3 · CHAPTER 03 협상 관리

## 핵심 최종점검

**1.** 기술협상 시 과업 조정의 기준은 무엇인가?

→ 입찰공고 · 제안요청서

**2.** 협상에서 과업 추가의 기본 요건은 무엇인가?

→ 기존 과업과의 연계성

**3.** 협상에서 과업 변경 대상 중 하나는 무엇인가?

→ 수행 방법

**4.** 협상 과정에서 신규 독립 과업 요구는 어떻게 처리되는가?

→ 제한됨

**5.** 협상 결과가 반영되는 주요 문서는 무엇인가?

→ 계약서

**6.** 협상 과정에서 비용 조정이 필요한 대표적인 경우는 무엇인가?

→ 과업 추가

**7.** 협상 과정에서 과업을 구체화하는 목적은 무엇인가?

→ 분쟁 예방

**8.** 협상 결과는 어떤 방식으로 기록되는가?

→ 문서화

**9.** 기술협상의 목적은 무엇인가?

→ 과업 범위 및 수행 가능성 확정

**10.** 과업 조정이 수행되는 계약 방식은 무엇인가?

→ 협상에 의한 계약

**11.** 협상 기간은 기본적으로 며칠인가?

→ 15일

**12.** 협상 결과 과업이 조정되면 무엇을 조정할 수 있는가?

→ 계약금액

**13.** 협상이 결렬될 경우 다음 절차는 무엇인가?

→ 차순위자 협상

**14.** 과업 조정의 유형 3가지는 무엇인가?

→ 추가·변경·삭제

**15.** 기술협상의 주요 대상 주요 항목은 무엇인가?

→ 사업 내용, 수행 방법, 수행 기간

**16.** 가격협상 시 과업 재협상은 원칙적으로 가능한가?

→ 제한됨

**17.** 가격협상은 어떤 범위 내에서 진행되는가?

→ 예정가격 또는 예산 범위

**18.** 가격협상 검토 시 핵심적으로 활용되는 자료는 무엇인가?

→ 산출내역서

**19.** 가격협상이 성립되면 어떤 조치가 이루어지는가?

→ 계약 체결

## 서술형 출제예상문제

**1.** 입찰공고 기준 과업 협상의 개념을 설명하시오.

→ 입찰공고 및 제안요청서를 기준으로 과업 내용을 수행 가능한 범위로 구체화·조정하는 협상 절차이다.

**2.** 과업 추가 협상의 허용 범위를 설명하시오.

→ 기존 과업과 연계되고 수행 필요성이 인정되는 범위 내에서 허용되며, 독립적 신규 사업 수준의 과업 추가는 제한된다.

**3.** 과업 삭제 협상의 필요성을 설명하시오.

→ 환경 변화·중복·불필요한 과업을 제거하여 계약 수행 효율성을 높이기 위해 필요하다.

**4.** 과업 변경 협상의 주요 유형을 설명하시오.

→ 수행 방법, 일정, 기술기준 등을 조정하는 형태로 이루어진다.

**5.** 기술협상의 개념을 설명하시오.

→ 발주기관 요구사항과 업체 수행 가능성을 검토하여 과업 범위·수행방법·일정을 확정하는 협상 절차이다.

**6.** 과업 조정의 필요성을 설명하시오.

→ 예산·기술·법규 등 제약을 반영하여 현실적 과업 범위를 확정하고, 계약 불이행·분쟁을 예방하기 위해 필요하다.

**7.** 협상 진행 절차를 설명하시오.

→ 요구사항 분석 → 협상안 제시 → 합의 도출 → 문서화 → 계약 반영

**8.** 기술협상 시 신규 과업 요구 쟁점을 설명하시오.

→ RFP 미포함 과업 요구 시 비용 부담·계약 범위 확대 문제가 발생하므로 수용 여부를 신중히 판단해야 한다.

**9.** 가격협상의 개념을 설명하시오.

→ 기술협상으로 확정된 과업 범위를 기준으로 계약금액을 최종 확정하는 협상 절차이다.

**10.** 가격협상의 기본 원칙을 설명하시오.

→ ① 기술협상 결과 기반 ② 예정가격 범위 내 ③ 우선협상대상자 순차 협상

**11.** 가격협상의 주요 검토 항목을 설명하시오.

→ 계약금액, 산출내역, 원가 구성, 지급 조건 등

**12.** 가격협상 시 산출내역 검증 필요성을 설명하시오.

→ 저가 투찰로 인한 계약 이행 위험·품질 저하 방지를 위해 원가 타당성을 검증하기 위함이다.

**13.** 발주기관이 협상 과정에서 입찰공고에 명시되지 않은 신규 기능 개발을 요구하였다.
   ① 협상 쟁점을 설명하시오.
   ② 대응 방안을 설명하시오.

→ ① 입찰공고 범위 외 신규 과업 추가로 계약 범위 확대·추가비용 부담 문제 발생 ② 과업 연계성 검토, 독립 과업 여부 판단, 비용 조정 협상, 합의 시 문서화

**14.** 협상 과정에서 일부 과업이 환경 변화로 수행이 불필요하게 되었다.
   ① 협상 유형을 설명하시오.
   ② 계약 영향을 분석하시오.

→ ① 과업 삭제 협상 ② 계약금액 감액, 일정 조정, 협상 결과 문서화

**15.** SW 구축 사업 협상 과정에서 발주기관이 RFP에 없던 신규 기능 개발을 요구하였다.
   ① 협상 쟁점을 설명하시오.
   ② 조달업체의 대응방안을 설명하시오.

→ ① RFP 미포함 과업 요구로 계약 범위 확대·추가비용 부담 문제 발생 ② 기존 과업 포함 여부 검토, 독립 과업이면 추가 계약 또는 금액 조정 협상, 문서화 후 계약 반영

**16.** 협상 결과 일부 과업이 삭제되고 일정이 변경되었다.
   ① 과업 조정 유형을 설명하시오.
   ② 후속 조치를 설명하시오.

→ ① 삭제 + 변경 조정 ② 제안서 조정 내용 문서화, 계약금액 조정 협의, 계약서 반영, 일정 재확정

**17.** 우선협상대상자와 가격협상 과정에서 발주기관이 과업 범위 확대를 요구하였다.
   ① 협상 쟁점을 설명하시오.
   ② 대응 방안을 설명하시오.

→ ① 가격협상 단계에서 과업 재협상 요구 문제 ② 기술협상 결과 기준으로 과업 범위 재확인, 과업 변경 시 금액 조정 또는 재협상, 문서화 후 계약 반영

**18.** 가격협상 과정에서 업체가 예정가격 초과 금액을 요구하였다.
   ① 협상 가능 여부를 설명하시오.
   ② 후속 절차를 설명하시오.
