# Part 2 · CHAPTER 03 공급계획 수립

> 박문각 4과목 「공공조달 입찰계획 수립」 · Check/Q&A 제외 · 문제+정답

---

## 핵심 최종점검

**1.** 제조원가의 기본 비목 5가지는 무엇인가?

→ 재료비, 노무비, 경비, 일반관리비, 이윤

**2.** 공사 직접노무비 단가의 적용 기준은 무엇인가?

→ 대한건설협회 시중노임단가

**3.** 일반관리비 계산식을 쓰시오.

→ (재료비 + 노무비 + 경비) × 일반관리비율

**4.** 이윤 계산식을 쓰시오.

→ (노무비 + 경비 + 일반관리비) × 이윤율

**5.** 외주가공비는 이윤 계산 시 포함되는가?

→ 제외

**6.** 공공조달 원가계산에서 적용되는 부가가치세율은 얼마인가?

→ 10%

**7.** 면세사업자가 낙찰된 경우 계약금액은 어떻게 산정되는가?

→ 부가가치세를 제외한 금액으로 계약

**8.** 공사원가 구성에서 순공사원가 구성요소는 무엇인가?

→ 재료비, 노무비, 경비

**9.** 일위대가표 작성 시 활용되는 기준은 무엇인가?

→ 표준품셈

**10.** 기존 시설 철거로 발생한 부산물은 재료비에서 공제하는가?

→ 공제하지 않음

**11.** 학술연구용역 인력의 등급 4단계를 쓰시오.

→ 책임연구원, 연구원, 연구보조원, 보조원

**12.** 공동연구형 용역에서 일반관리비는 어떻게 처리하는가?

→ 계상하지 않음

**13.** 설계변경 시 원가계산의 목적은 무엇인가?

→ 계약금액 조정

**14.** 공구손료의 산정 기준은 무엇인가?

→ 해당 공종 노무비 × 품셈률

**15.** 소모 잡자재의 산정 기준은 무엇인가?

→ 주재료비 × 품셈률

**16.** 이윤 산정 시 제외되는 비목 2가지를 쓰시오.

→ 외주가공비, 기술료

**17.** 거래실례가격이 존재하는데, 원가계산가격이 더 낮다면 예정가격 결정 시 어떤 가격을 적용해야 하는가?

→ 거래실례가격 우선 적용

**18.** 특정 상표만을 지시하는 규격은 무엇에 위반될 수 있는가?

→ 경쟁원칙

**19.** 기술 적합도 검증은 입찰절차 중 어느 단계에서 수행되는가?

→ 입찰참여 결정 이전의 사전검토 단계

**20.** 입찰에서 요구한 인증서를 보유하지 못한 경우 어떻게 처리하는가?

→ 부적격 처리

**21.** 공사의 기술 적합성 검증에서 핵심은 무엇인가?

→ 설계도서 충족 여부

**22.** 공급계획 수립 전에 반드시 수행해야 하는 단계는 무엇인가?

→ 환경분석

**23.** 발주물량과 발주기관 분석은 어떤 환경분석에 해당하는가?

→ 수요환경 분석

**24.** 평균 낙찰 분석은 어떤 환경분석에 해당하는가?

→ 가격환경 분석

**25.** 계약 방법 분석은 어떤 환경분석에 해당하는가?

→ 제도환경 분석

**26.** 낙찰률이 낮은 시장은 무엇이 강한 시장인가?

→ 경쟁 강도

**27.** 중소기업자 간 경쟁제품 여부는 어느 환경에 해당하는가?

→ 경쟁환경

**28.** 공급계획 수립의 궁극적 목적은 무엇인가?

→ 수익성과 시장점유(율) 확대

## 서술형 출제예상문제

**1.** 예정가격 결정 방법의 적용 순서를 설명하시오.

→ ① 거래실례가격 ② 원가계산에 따른 가격 ③ 표준시장단가 ④ 감정가격·유사거래실례가격·견적가격.

**2.** 제조원가와 공사원가의 차이를 설명하시오.

→ ① 제조원가: 직접재료비·간접재료비 구분, 기업 결산자료 활용 ② 공사원가: 직접공사비·간접공사비 구조, 표준품셈 중심, 일위대가표·단가산출서 활용.

**3.** 일반관리비 산정 시 유의사항을 설명하시오.

→ ① 판매비 제외 ② 접대비·광고비 등 제조와 무관한 비용 제외 ③ 「예정가격작성기준」에 따른 비율 적용 ④ 업종별 일반관리비율 상한 준수.

**4.** 학술연구용역 원가계산의 특징을 설명하시오.

→ ① 인건비 중심 ② 인력등급별 단가 적용 ③ 공동연구형 용역은 일반관리비 미계상 ④ 이윤율 10% 이내.

**5.** 공사원가계산서 작성 순서를 쓰시오.

→ 단가조사 → 단가산출서·일위대가표 작성 → 직접공사비 내역서 작성 → 공사원가계산서 작성.

**6.** 부가가치세 처리 원칙을 설명하시오.

→ ① 예정가격에는 부가가치세 포함 ② 면세사업자와 계약 시에는 부가가치세 제외 금액으로 계약 ③ 해당 사실을 입찰공고문에 명시 필수.

**7.** 작업설 및 부산물 처리 원칙을 설명하시오.

→ ① 경제적 가치가 있는 경우 재료비에서 공제 ② 기존 시설 철거공사에서 발생한 경우는 공제하지 않음.

**8.** 경제성 분석의 의사결정 활용 목적을 설명하시오.

→ ① 입찰 참여 여부 판단 ② 손익 예측 ③ 위험요인 분석 ④ 전략적 가격 결정.

**9.** 기술 적합도 검증 절차를 설명하시오.

→ ① 규격서 분석 ② 필수요건·선택요건 구분 ③ 자사제품 또는 기술과 비교 ④ 미충족 항목 분석 ⑤ 동등이상 여부 판단 ⑥ 인증·시험자료 확보.

**10.** 동등이상의 판단 기준을 설명하시오.

→ ① 기능 동일성 ② 성능 동등성 ③ 안전성 확보 여부 ④ 품질기준 충족 여부 ⑤ 법령상 제한 여부.

**11.** 물품 계약에서 기술 적합성 검토 시 유의사항을 설명하시오.

→ ① 세부품명 일치 여부 확인 ② 직접생산확인 여부 확인 ③ 인증서 요구사항 확인 ④ 시험성적서 유효기간 확인 ⑤ 규격 과도성 여부 판단.

**12.** 용역계약에서 기술 적합도 판단 요소를 설명하시오.

→ ① 기술인력 보유 여부 ② 유사실적 ③ 수행계획의 타당성 ④ 법정 등록요건 충족 여부.

**13.** 규격이 과도한 경우 대응 방안을 설명하시오.

→ ① 공고문 질의 ② 이의신청(규격 완화 요청).

**14.** 공급계획 수립을 위한 환경분석 요소를 설명하시오.

→ 수요환경·경쟁환경·가격환경·제도환경·내부역량환경으로 구성되며, 이를 통해 시장성·수익성 및 참여가능성을 종합적으로 판단한다.

**15.** 경쟁환경 분석의 주요 내용을 설명하시오.

→ 경쟁업체 수, 평균 낙찰률, 기존 수주업체, 지역제한 여부, 시장 진입장벽 분석.

**16.** 가격환경 분석의 중요성을 설명하시오.

→ 낙찰하한율과 평균 낙찰률을 분석하여 입찰 참여 시 수익 가능 여부를 판단하기 위함이다.

**17.** 내부역량 분석의 필요성을 설명하시오.

→ ① 계약이행 가능성 검토 ② 생산·인력·재무 능력 점검 ③ 납기 대응 능력 확인 ④ 수주 이후 리스크 관리.

**18.** 환경분석 결과를 공급계획으로 전환하는 절차를 설명하시오.

→ 시장 선정 → 품목 선정 → 참여 전략 수립 → 가격 전략 수립 → 목표 설정.

**19.** 제조원가계산에서 재료비 2억원, 노무비 1억원, 경비 5천만원, 일반관리비율 10%, 이윤율 20%일 때 부가가치세 포함 금액을 계산하시오.

→ ① 일반관리비 = (2 + 1 + 0.5)억원 × 10% = 0.35억원 ② 이윤 = (1 + 0.5 + 0.35)억원 × 20% = 0.37억원 ③ 총원가 = (2 + 1 + 0.5 + 0.35 + 0.37)억원 = 4.22억원 ④ 부가세 = 4.22억원 × 10% = 0.422억원 ⑤ 총금액 ≈ 4.642억원.

**20.** A기업이 최근 3년간 LED 가로등 시장을 분석한 결과, 평균 낙찰률 84%, 경쟁업체 평균 25개, 예정가격 지속 하락, 자사 원가율 88%일 때, 공급계획을 수립하시오.

→ ① 낙찰률 84% < 원가율 88% → 적자 구조 ② 경쟁업체 평균 25개로 경쟁 강도 매우 높음 ③ 단가 하락 추세 ④ 공급계획: 시장 축소 전략, 고부가 제품 전환, 종합평가 시장 진입, 타 품목 다각화 필요.

**21.** B기업이 시설관리용역 시장을 분석한 결과, 경쟁업체 평균 5개, 평균 낙찰률 90%, 자사 원가율 82%, 기술점수 우위 확보가 가능할 때, 공급계획을 수립하시오.
---

→ ① 낙찰률 90% > 원가율 82% → 수익성 양호 ② 경쟁업체 평균 5개로 경쟁 강도 낮음 ③ 기술점수 우위 확보 가능 ④ 공급계획: 적극적 참여 전략, 연간 목표물량 설정, 기술제안서 강화, 시장확대 전략 수립.
