## ① 한눈에 보기

- 해외 공공조달도 규격·인증·공급자 평가·검사·성과관리를 하나의 체계로 연결한다.
- ISO 9001은 조직의 품질경영시스템, TQM은 전사적 지속개선, Six Sigma는 데이터 기반 변동·결함 감소에 초점이 있다.
- 국제표준과 상호인정은 품질 신뢰를 높이면서 불필요한 무역장벽을 줄이는 수단이다.
- 해외 사례의 핵심은 제도를 그대로 복사하는 것이 아니라 위험기반·성과기반 원리를 적용하는 데 있다.

## ② 차근차근 설명

국제조달에서는 여러 국가의 공급자가 참여하므로 규격과 품질증명의 호환성이 중요하다. 특정 국가·기업만 이해할 수 있는 규격보다 국제표준, 객관적 시험방법, 동등성 인정기준을 활용하면 경쟁성과 품질을 함께 확보할 수 있다.

| 접근법 | 중심 질문 | 공공조달 적용 |
|---|---|---|
| ISO 9001 | 품질경영 절차가 일관되게 운영되는가 | 공급자 시스템·문서·시정조치 확인 |
| TQM | 조직 전체가 고객가치와 지속개선에 참여하는가 | 부서 간 품질책임과 이용자 피드백 연계 |
| Six Sigma | 공정의 변동과 결함 원인을 데이터로 줄이는가 | 불량률·납기지연 원인 측정과 개선 |
| 성과기반 계약 | 무엇을 어떻게 달성해야 하는가 | 투입보다 서비스수준·성과지표 중심 관리 |

미국 등은 중앙조달기관이 표준계약조건, 공급자 정보, 성과기록을 활용하여 품질위험을 관리한다. 유럽의 공공조달도 기술규격이 경쟁을 부당하게 제한하지 않도록 성능기준과 표준을 활용하고, 환경·사회적 가치와 생애주기비용을 품질판단에 연결한다.

해외 품질관리의 공통 흐름은 `요구성능 정의 → 객관적 증명방법 설정 → 공급자 능력 확인 → 이행성과 측정 → 결과 환류`다. 인증서는 품질능력을 보여 주는 하나의 증거이지 모든 납품물의 자동 합격을 의미하지 않는다.

상호인정은 외국 시험·인증 결과가 동등한 신뢰성을 갖는 경우 이를 인정하는 접근이다. 동일 시험을 반복하는 비용을 줄일 수 있지만, 적용범위·시험방법·인정기관의 적격성을 확인해야 한다.

위험기반 관리는 모든 물품에 같은 수준의 검사를 하지 않는다. 안전·보건 영향, 기술 복잡성, 공급자 과거 실적, 결함 발생 가능성이 높을수록 심사를 강화하고, 검증된 저위험 공급자에는 절차를 합리화한다.

국내 적용 시에는 해외 기관의 명칭이나 형식을 암기하기보다 표준화, 공급자 품질시스템, 데이터 기반 성과관리, 지속개선이라는 원리를 기억한다. 국내 법령상 검사·검수와 책임까지 외국 인증으로 대체되는 것은 아니다.

## ③ 시험 포인트

- 국제표준은 품질의 공통언어이자 경쟁촉진 수단이다.
- ISO 9001은 품질경영시스템, TQM은 전사적 참여, Six Sigma는 데이터 기반 결함감소다.
- 인증 보유가 개별 납품물의 무조건 합격을 뜻하지 않는다.
- 상호인정은 중복시험을 줄이되 동등성과 인정범위를 확인한다.
- 해외 사례의 공통축은 위험기반·성과기반·지속개선이다.
