## 학습목표

이 Chapter를 학습한 뒤에는 다음을 할 수 있어야 한다.

1. 공공계약이 사법상 계약이면서 공공계약 특별규율을 함께 받는 구조를 설명한다.
2. 계약자유 4요소·계약기능 5가지·성립요건 4가지를 서로 다른 묶음으로 구분한다.
3. 계약행정과 계약관리의 차이를 설명한다.
4. `계획 → 체결 → 이행 → 변경 → 종결 → 사후관리`의 흐름을 말한다.
5. 계약관리계획에 담을 목적·범위·역할·일정·비용·품질·위험·변경·검사·종결 기준을 든다.
6. MOU·MOA의 구속력을 제목만으로 판단하지 않아야 하는 이유를 설명한다.

## ① 한눈에 보기

- 계약관리는 낙찰·협상 이후 계약목표를 실제 성과로 만드는 통제활동이다.
- 공공계약은 원칙적으로 사법상 계약이지만 국가·지방계약법의 특별규율과 공정성 원칙을 함께 받는다.
- 계약의 자유 4요소, 계약의 5대 기능, 계약 성립 4요건을 서로 다른 묶음으로 구분한다.
- 계약관리계획은 범위·일정·비용·품질·역할·위험·변경·검사·지급·종결 기준을 미리 정한다.
- 전체 관리 흐름은 `계획 → 체결 → 이행 → 변경 → 종결 → 사후관리`이며, 실제 변경은 이행 중 되먹임된다.

## ② 차근차근 설명

### 1. 낙찰자를 정했다고 조달이 끝난 것은 아니다

어떤 기관이 교육용 분석장비 100대를 주문 제작한다고 가정해 보자. 낙찰자와 금액만 정한 뒤 바로 생산을 시작하면 다음 문제가 생길 수 있다.

- 장비의 성능을 어느 시험방법으로 확인할지 정하지 않았다.
- 시제품 승인과 양산 착수의 관계가 불명확하다.
- 핵심부품이 단종됐을 때 대체품 승인권자가 없다.
- 중간 진도보고와 공장점검 시점이 없다.
- 납품지연과 검사불합격을 어떤 절차로 처리할지 모른다.

이런 문제는 계약 체결 뒤에 문서를 더 많이 만드는 것만으로 해결되지 않는다. 계약을 체결하기 전에 무엇을, 누가, 언제, 어떤 기준으로 관리할지 설계해야 한다. 이것이 **계약관리계획**이다.

조달 전체 과정에서 계약관리의 위치를 잡으면 다음과 같다.

`수요 제기 → 조달계획·규격 → 공급자 탐색 → 입찰·평가·낙찰 → 계약체결 → 이행·변경 → 검사·지급 → 종결·사후관리`

1·2과목은 주로 수요를 구체화하고 계약상대자를 선정하는 앞부분을 다룬다. 3과목은 선정된 계약상대자가 약속한 결과를 내도록 계약조건을 현실의 업무로 바꾸는 뒷부분에 중심을 둔다.

### 2. 계약관리의 의미

계약관리는 계약서 보관이나 대금지급 같은 한 가지 행위를 뜻하지 않는다. 계약에서 정한 **범위·일정·비용·품질·성과·위험**을 기준선으로 삼아 실제 이행상태를 비교하고, 차이가 생기면 승인된 절차로 바로잡는 활동이다.

핵심 질문은 다섯 가지다.

1. 계약으로 달성하려는 결과는 무엇인가?
2. 현재 이행상태는 계약기준과 일치하는가?
3. 차이가 있다면 원인과 귀책은 누구에게 있는가?
4. 변경·시정·제재 중 어떤 조치가 필요한가?
5. 검사·지급·종결의 근거가 기록으로 남아 있는가?

### 3. 공공계약의 법적 성격

국가나 지방자치단체가 계약당사자라는 이유만으로 모든 공공계약이 곧 행정처분이 되는 것은 아니다. 판례와 수험서의 기본 설명은 공공계약을 원칙적으로 **사법상 계약**으로 본다. 따라서 당사자의 의사표시, 신의성실, 채무이행과 손해배상 등에는 민법의 계약원리가 적용된다.

다만 공공계약은 세금과 공공목적을 다루므로 국가계약법·지방계약법 등 특별규율을 받는다. 경쟁성·투명성·공정성을 확보하고 예산을 통제하기 위해 계약상대자 선택과 계약내용 결정의 자유가 일반 사인 간 계약보다 제한된다.

| 구분 | 일반 사법계약의 원리 | 공공계약의 특별규율 |
|---|---|---|
| 기본관계 | 대등한 당사자의 의사 합치 | 국가·지방자치단체도 계약당사자로 참여 |
| 적용원칙 | 계약자유·신의성실·채무이행 | 경쟁·투명·공정·예산통제 절차 추가 |
| 상대방 선택 | 당사자가 자유롭게 선택 | 입찰·낙찰·수의계약 요건에 따라 제한 |
| 계약내용 | 합의로 결정 | 법령·계약예규·공고·예산의 제한 |
| 제재 | 손해배상·해제·해지 등 | 보증금 귀속·부정당업자 제재 등이 별도 문제 |

계약 자체의 사법관계와 부정당업자 입찰참가자격 제한 같은 행정제재는 구분해야 한다. 같은 거래에서 함께 문제될 수 있지만 법적 성질과 다투는 절차가 같지 않다.

### 4. 계약의 자유 4요소와 공공계약의 제한

계약의 자유는 다음 네 요소로 정리한다.

| 요소 | 의미 | 공공계약에서의 제한 예시 |
|---|---|---|
| 체결의 자유 | 계약을 할지 말지 결정 | 예산·사업 필요성과 법정 절차에 따라 체결 |
| 상대방 선택의 자유 | 누구와 계약할지 결정 | 경쟁입찰과 낙찰자 결정기준 적용 |
| 내용 결정의 자유 | 가격·기간·책임을 정함 | 법령·계약조건·부당특약 금지의 제한 |
| 방식의 자유 | 구두·서면 등 형식을 선택 | 공공계약은 정해진 문서·전자절차 준수 |

국가계약법상 계약담당자는 신의성실의 원칙에 따라 계약을 이행해야 한다. 계약상대자의 정당한 이익을 부당하게 제한하는 특약이나 조건은 그 부분이 무효가 될 수 있다. 따라서 ‘상대방이 서명했으므로 어떤 조건이든 유효하다’고 볼 수 없다.

계약자유와 공공규율은 서로 모순되는 개념이 아니다. 계약이라는 사법적 형식을 사용하되, 공공성 때문에 자유의 범위를 법률로 통제하는 관계다.

### 5. 계약행정과 계약관리

두 용어는 비슷해 보이지만 초점이 다르다.

| 구분 | 계약행정 | 계약관리 |
|---|---|---|
| 중심 | 계약을 준비·체결·처리하는 개별 행동 | 계약목표를 달성하도록 통제하는 방법 |
| 대표 업무 | 공고, 문서작성, 보증서 접수, 지급결의 | 기준선 설정, 성과점검, 위험·변경·품질관리 |
| 판단기준 | 절차를 적법하게 완료했는가 | 비용·일정·품질·성과가 목표와 일치하는가 |
| 결과 | 행정절차와 기록의 완성 | 계약목적의 실질적 달성 |

계약행정이 필요 없다는 뜻이 아니다. 행정절차는 계약관리의 기반이다. 다만 서류를 기한에 맞춰 처리했다고 해서 납기·품질·성과까지 자동으로 달성되는 것은 아니다.

### 6. 계약의 5대 기능

계약은 다섯 가지 기능을 동시에 수행한다.

| 기능 | 핵심 질문 | 분석장비 제조계약의 예 |
|---|---|---|
| 증거 | 무엇을 합의했는가 | 규격·수량·가격·납기·서명 기록 |
| 관리 | 무엇을 누가 통제하는가 | 시제품 승인, 월간 진도보고, 공장점검 |
| 위험전가 | 어떤 위험을 누가 부담하는가 | 운송 중 손상, 지연, 결함·하자 책임 |
| 지불 | 어떤 성과에 얼마를 지급하는가 | 선금·중도금·납품대가와 지급조건 |
| 동기부여 | 바람직한 이행을 어떻게 유도하는가 | 성과조건, 지체상금, 인센티브·감액 구조 |

**증거 기능**만 강조하면 계약서를 과거의 합의를 기록한 문서로만 보게 된다. 효과적인 계약은 앞으로의 보고·승인·지급·위험대응을 안내하는 관리도구여야 한다.

위험전가는 모든 위험을 계약상대자에게 떠넘긴다는 뜻이 아니다. 위험을 통제할 능력이 있는 당사자에게 합리적으로 배분하고, 발생 시 처리절차와 비용부담을 명확히 하는 것이 핵심이다. 통제할 수 없는 위험까지 일방에게 전가하면 가격이 올라가거나 부당특약 문제가 생길 수 있다.

### 7. 계약 성립의 4요건

수험서에서는 계약이 유효하게 성립하기 위한 기본요건을 네 가지로 정리한다.

| 요건 | 설명 | 부족할 때 생기는 문제 |
|---|---|---|
| 의사표시의 합치 | 청약과 승낙 등 당사자의 의사가 일치 | 서로 다른 조건을 합의했다고 주장 |
| 이행가능성 | 약속한 내용이 객관적으로 이행 가능 | 처음부터 실현할 수 없는 급부 |
| 법적·사회적 타당성 | 강행법규·선량한 풍속 등에 반하지 않음 | 위법·반사회적 내용의 효력 문제 |
| 확정성 | 목적물·가격·수량·기간 등을 정하거나 정할 수 있음 | 무엇을 이행해야 하는지 특정 불가 |

서명과 날인이 있다고 언제나 유효한 계약이 되는 것은 아니다. 의사능력, 대리권, 내용의 적법성과 확정성도 확인해야 한다.

표준교재의 일부 옛 표현인 ‘금치산자·한정치산자’는 현행 민법의 용어가 아니다. 현재는 **피성년후견인·피한정후견인**이라는 용어를 사용한다. 또한 의사능력이 있는지와 법률상 행위능력이 제한되는지는 구분해서 이해한다.

### 8. MOU와 MOA를 읽는 방법

수험서의 관리상 구분은 다음과 같다.

| 문서 | 교재상 중심 | 일반적 내용 |
|---|---|---|
| MOU | 협력 의사와 기본방향의 확인 | 공동목표·협력분야·추후 협의 |
| MOA | 구체적인 실행과 책임의 합의 | 역할·비용·일정·성과·책임 |

그러나 문서 제목만으로 법적 구속력을 기계적으로 결정하지 않는다. ‘MOU’라고 적혀 있어도 구체적인 권리·의무와 구속 의사가 확인되면 법적 효과가 문제될 수 있고, ‘MOA’라는 제목만으로 모든 조항이 반드시 구속력을 갖는 것도 아니다. 문언, 구체성, 체결 경위와 당사자의 의사를 함께 본다.

### 9. 계약관리 6단계

표준교재의 전체 관리단계는 다음과 같다.

`계획 → 체결 → 이행 → 변경 → 종결 → 사후관리`

| 단계 | 핵심 업무 | 다음 단계로 넘길 결과 |
|---|---|---|
| 계획 | 목표·범위·역할·위험·성과기준 설정 | 계약관리계획과 계약조건 |
| 체결 | 합의내용 확정, 보증·착수조건 정리 | 효력이 발생한 계약문서 |
| 이행 | 진도·비용·품질·성과·위험 점검 | 실적자료와 시정조치 |
| 변경 | 변경요청의 필요성·영향·권한 심사 | 승인된 변경계약과 새 기준선 |
| 종결 | 검사·검수·정산·인수·기록정리 | 종결기록과 잔존의무 목록 |
| 사후관리 | 하자·성과평가·교훈·보증관리 | 다음 조달에 활용할 정보 |

교재 목차는 설명 편의를 위해 변경을 이행보다 먼저 배치할 수 있지만, 실제 업무에서는 이행 중 차이가 발견되어 변경절차로 되돌아간다.

`이행상태 확인 → 차이 발견 → 변경 필요성·영향 분석 → 승인된 변경 → 새 기준으로 이행 계속`

따라서 변경은 원계약을 무시하는 별도 업무가 아니라, 계약의 확정성을 유지하면서 불가피한 변화를 통제하는 되먹임 과정이다.

### 10. 계약관리계획에 들어갈 내용

| 계획항목 | 미리 정할 내용 | 예방하려는 문제 |
|---|---|---|
| 목적·성과 | 최종 결과와 성공기준 | 활동은 했지만 목적 미달 |
| 범위 | 포함·제외 업무, 목적물·수량 | 추가업무와 책임 공방 |
| 역할·권한 | 계약담당·수요부서·검사자·상대자 책임 | 무권한 지시와 승인 지연 |
| 일정 | 착수·마일스톤·납기·준공 | 지연을 뒤늦게 발견 |
| 비용·지급 | 계약금액, 선금·기성·대가 조건 | 성과보다 빠른 지급·중복지급 |
| 품질·성과 | 규격, 시험방법, SLA, 합격기준 | 주관적인 합격·불합격 다툼 |
| 보고·소통 | 보고서, 회의, 비상연락, 기록방식 | 구두지시와 정보단절 |
| 위험 | 원자재·인력·안전·보안 위험과 담당자 | 위험 발생 뒤 책임 전가 |
| 보증·보험 | 보증 종류·금액·기간·갱신 | 보증 공백과 회수 곤란 |
| 변경통제 | 요청서, 영향분석, 승인권자 | 선이행 후 사후정산 |
| 검사·인수 | 검사자, 장소·방법·기한, 불합격 조치 | 납품과 인수의 혼동 |
| 분쟁·종료 | 협의·조정·중재, 해제·해지, 인계 | 갈등 장기화와 자료 미반환 |

좋은 계획은 항목이 많기만 한 문서가 아니다. 계약규모·복잡성·안전위험에 비례해 관리강도를 정하고, 각 기준을 측정 가능하게 만드는 문서다.

### 11. 역할과 권한을 분리한다

| 참여자 | 대표 역할 |
|---|---|
| 계약담당자 | 계약문서·보증·변경·대가·제재 절차 총괄 |
| 수요부서·사업관리자 | 사업목표·범위·일정·성과 확인 |
| 검사·검수 담당 | 계약 적합성과 수량·인수상태 확인 |
| 품질·기술 담당 | 시험·규격·공정·기술자료 검토 |
| 계약상대자 | 약정한 목적물·성과의 이행과 보고 |

사업부서의 담당자가 편의를 위해 추가업무를 구두로 지시했다고 해서 곧바로 유효한 계약변경이 되는 것은 아니다. 누가 기술적 지시를 할 수 있는지, 누가 계약금액·기간을 바꿀 수 있는지 권한을 나눠 두어야 한다.

### 12. 분쟁 예방과 해결수단

분쟁을 줄이는 가장 좋은 방법은 처음부터 범위·기준·승인·기록을 명확히 하는 것이다. 그래도 분쟁이 발생하면 당사자 협의, 조정·중재 같은 ADR, 행정심판·소송 등의 수단을 검토한다.

- **조정**: 제3자가 합의를 돕는다.
- **중재**: 중재합의에 따라 중재판정부가 판단한다.
- **행정심판·행정소송**: 부정당업자 제재 등 행정처분을 다툴 때 문제된다.
- **집행정지**: 처분의 집행으로 회복하기 어려운 손해가 예상될 때 본안 판단 전 효력정지를 구하는 수단이다.

계약대금·손해배상 같은 사법상 분쟁과 입찰참가자격 제한 같은 처분을 같은 절차로 다툰다고 단정해서는 안 된다.

## ③ 시험 포인트

- 공공계약은 원칙적으로 사법상 계약이고 국가·지방계약법의 특별규율을 함께 받는다.
- 계약의 자유 4요소는 체결·상대방 선택·내용 결정·방식의 자유다.
- 공공계약의 계약자유는 경쟁·공정·예산통제와 부당특약 금지에 의해 제한된다.
- 계약행정은 개별 절차의 수행, 계약관리는 비용·일정·품질·성과의 통제에 초점이 있다.
- 계약의 5대 기능은 증거·관리·위험전가·지불·동기부여다.
- 계약 성립 4요건은 의사합치·이행가능성·법적·사회적 타당성·확정성이다.
- MOU와 MOA의 구속력은 제목만이 아니라 문언·구체성·당사자의 의사로 판단한다.
- 계약관리 6단계와 계약의 5기능을 같은 묶음으로 혼동하지 않는다.
- 계약 자체의 사법관계와 부정당업자 제재 같은 행정처분을 구분한다.
- 계약변경은 이행 중 발견한 차이를 승인된 새 기준선으로 바꾸는 통제절차다.
