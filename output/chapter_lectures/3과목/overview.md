> 이 과목은 한국산업인력공단의 2026~2028년 적용 출제기준을 중심으로 조달청 표준교재 3권 419쪽을 다시 조직한 자체 제작 강의입니다. 공식 4개 주요항목·11개 세부항목·55개 세세항목을 빠짐없이 연결하고, 표준교재의 품질·혁신제품 내용까지 포함해 6개 Part, 29개 Chapter로 학습합니다.

Part 5와 Part 6을 별도의 공식 주요항목인 것처럼 세지 않습니다. 공식 출제기준의 구조는 끝까지 **4개 주요항목**이며, 강의 Part 수가 6개인 것은 긴 표준교재를 학습하기 좋게 나눈 편집 방식입니다.

## 이 과목의 최종 목표

3과목은 계약 용어를 외우는 과목이 아닙니다. 계약을 체결한 뒤 계획·변경·이행·종결을 통제하고, 물품·용역·MAS·공사의 서로 다른 절차를 구별하는 능력을 묻습니다. 강의를 끝내면 다음을 할 수 있어야 합니다.

1. 사건이 계약의 어느 단계에 있는지 판정한다.
2. 국가·지방, 물품·용역·공사, 일반계약·MAS를 먼저 구분한다.
3. 적용 법령, 계약예규, 공고, 계약문서의 우선관계를 확인한다.
4. 숫자·기한·비율의 적용대상과 기준일을 함께 설명한다.
5. 변경·검사·대금·보증·제재의 요건과 효과를 연결한다.
6. 계산 문제는 산식뿐 아니라 기준금액·공제항목·적용시점을 검증한다.

## 모든 사례 문제에 쓰는 판단 순서

사례를 읽으면 바로 숫자부터 찾지 말고 다음 여덟 칸을 먼저 채웁니다.

1. **기관**: 국가기관, 지방자치단체, 조달청, 수요기관 중 누구인가?
2. **대상**: 물품, 용역, 공사 중 무엇인가?
3. **단계**: 공고, 입찰, 체결, 착수, 이행, 변경, 검사, 종결 중 어디인가?
4. **문서**: 법령, 계약예규, 공고서, 계약서, 특수조건, 설계서 중 무엇을 확인하는가?
5. **요건**: 금액, 기간, 비율, 귀책, 통지, 신청 요건이 충족되는가?
6. **주체**: 발주기관과 계약상대자 중 누가 신청·확인·통지하는가?
7. **효과**: 조정, 지급, 보완, 제재, 해제·해지 중 무엇이 발생하는가?
8. **증거**: 어떤 문서와 시스템 기록을 남겨야 하는가?

## 숫자를 외우는 규칙

| 숫자 종류 | 외우는 방식 |
|---|---|
| 법령·계약예규 수치 | `대상 + 수치 + 기산점 + 예외 + 시행일`을 한 묶음으로 암기 |
| 공고·평가기준 수치 | 적용기관과 계약유형을 붙이고 해당 공고에서 재확인 |
| 교재 사례값 | 계산 훈련값으로만 쓰며 일반 기준처럼 확장하지 않음 |
| 통계·지정 품목 수 | 조사시점을 붙이고 고정된 법정 숫자로 암기하지 않음 |
| 강의 숙달점수 | 학습용 기준일 뿐 시험의 법정 합격기준과 구분 |

표준교재의 설명과 2026년 8월 24일 현재 공식 원문이 다르면 강의 안에 둘을 나란히 표시합니다. 교재의 오기 가능성이 있는 값은 그대로 암기시키지 않고, 왜 충돌하는지와 시험에서 안전하게 판정하는 방법을 설명합니다.

## 세 번 완주하는 방법

### 1회독 — 구조

- 각 장의 흐름도와 비교표를 먼저 읽습니다.
- `기관·대상·단계`를 말하지 못하면 숫자를 외우지 않습니다.
- 장 끝 회상질문에 자료 없이 한 문장으로 답합니다.

### 2회독 — 적용과 계산

- 완성 예시를 가리고 빈 서식을 직접 채웁니다.
- 산식 문제는 단위와 공제항목까지 적습니다.
- 오답 원인을 `대상 혼동 / 순서 오류 / 숫자 오류 / 법적 효과 오류 / 계산 오류`로 분류합니다.

### 3회독 — 시험 전환

- 각 장의 자체 제작 4지선다 문제를 시간 안에 풉니다.
- 정답 근거가 있는 문단을 다시 찾아 설명합니다.
- 24시간·3일·7일 간격으로 오답만 반복합니다.
