> 자체 제작 강의입니다. 분쟁의 구체적 구제수단과 기한은 발주기관·계약단계·청구내용에 따라 달라지므로, 이 강의는 모든 사건에 하나의 절차나 기한이 있다고 가정하지 않습니다.

## 이 강의 하나의 완료 기준

이 단원의 질문은 **“의견 차이가 분쟁으로 커지기 전에 무엇을 관리하고, 실제 분쟁이 나면 어떤 순서로 대응할 것인가?”**입니다. 학습 후에는 다음을 할 수 있어야 합니다.

- 입찰·계약 분쟁의 주요 원인을 사실과 문서의 관점에서 분류한다.
- 예방 통제와 조기경보 기준을 설계한다.
- 분쟁 발생 시 증거보전, 통지, 내부 의사결정, 협의·구제 절차를 순서대로 진행한다.
- 법무 담당자나 외부 전문가에게 전달할 사건요약서를 작성한다.

## 공식 출제기준과 학습 결과

| 공식 수행능력 | 학습 결과 |
|---|---|
| 주요 분쟁 원인 파악 및 선제적 예방관리 | 원인·징후·예방통제·담당자를 분쟁예방대장에 기록한다. |
| 분쟁 발생 시 대응 절차 진행 | 권리 보전과 이행 연속성을 함께 고려한 대응 흐름을 적용한다. |
| 법무·전문가와 협력해 법적 문제 대응 | 사실·쟁점·증거·기한·질문을 사건요약서로 전달한다. |

## 시작 사례

다온서비스는 발주기관 담당자의 구두 요청에 따라 과업을 추가 수행했다. 담당자는 나중에 계약변경을 해주겠다고 말했지만 공문이나 변경계약은 없다. 준공 단계에서 발주기관은 “원래 과업에 포함된 업무”라며 추가대가를 인정하지 않고, 업체는 잔여 업무를 즉시 중단하겠다고 한다.

누가 옳은지를 먼저 주장하기보다 다음을 확인해야 합니다. 계약문서가 정한 과업 범위, 요청의 주체·내용·시각, 업체의 이의·통지 여부, 실제 수행과 비용, 검사·대가 절차, 중단이 새 위반을 만들 가능성입니다. 분쟁 대응의 첫 단계는 감정적 반박이 아니라 **사실과 시계를 고정하는 것**입니다.

## 1. 분쟁 원인을 여섯 묶음으로 식별한다

| 원인 묶음 | 대표 쟁점 | 조기 징후 |
|---|---|---|
| 범위·규격 | 과업 포함 여부, 성능·품질 기준, 문서 간 불일치 | 같은 요구를 서로 다르게 해석 |
| 기간·지연 | 착수·납기·공정, 지연 원인, 연장 가능성 | 선행조건 미충족, 승인 지연, 일정 회복계획 부재 |
| 금액·대가 | 계약금액 조정, 추가비용, 지급·공제 | 미승인 작업, 산출근거 불일치, 청구 반려 |
| 검사·하자 | 검사기준, 인수, 보완·하자 책임 | 객관적 수락기준 부재, 반복 재작업 |
| 변경·종결 | 변경 권한, 해제·해지, 정산 | 구두지시 누적, 중단·철수 언급 |
| 절차·권한 | 통지방법, 승인권자, 제출기한, 대리권 | 비공식 채널만 사용, 담당자 교체, 기록 누락 |

원인은 하나로 끝나지 않습니다. 예를 들어 구두 추가과업은 `범위`, `변경`, `금액`, `권한`, `증거`가 겹친 사건입니다. 답안에서는 주원인과 연쇄 원인을 함께 적습니다.

## 2. 예방은 계약 전·이행 중·종결 전으로 나눈다

### 계약 전 예방통제

- 공고, 규격서, 과업지시서, 계약조건 사이의 모순을 쟁점표로 만든다.
- 납품물·성과물과 합격기준을 측정 가능한 문장으로 확인한다.
- 변경·승인·통지 권한자와 공식 채널을 정한다.
- 일정의 발주기관 선행조건과 업체 의무를 분리한다.
- 가격에 포함된 항목과 별도 조정 가능한 항목을 확인한다.

### 이행 중 예방통제

- 착수회의에서 범위, 일정, 의사결정권자, 보고주기를 확정한다.
- 회의 후 합의사항·미합의사항·담당·기한을 회의록으로 확인한다.
- 구두지시는 공식 문서로 재확인하고 변경 영향 분석 전에는 확정된 변경처럼 다루지 않는다.
- 지연·하자·추가비용의 징후를 발견하면 원인과 예상 영향을 조기에 통지한다.
- 계약 기준과 실제 이행을 정기적으로 대조한다.

### 종결 전 예방통제

- 미해결 쟁점, 제출물, 검사·보완, 정산항목을 마감목록으로 관리한다.
- 인수·검사 결과와 보완 완료 증거를 보존한다.
- 최종대가 청구 전에 변경분과 공제·상계 쟁점을 확인한다.

## 3. 분쟁이 생기면 ‘멈추고 보존하고 분류한다’

### 1단계 안전한 초기조치

1. 즉흥적인 책임 인정, 권리 포기, 이행 중단 선언을 피한다.
2. 공고부터 현재까지의 원본 파일과 전자기록을 변경 없이 보존한다.
3. 계약상 통지 의무와 임박한 절차·기한을 확인한다.
4. 안전·보안·서비스 연속성과 추가 손실 확대 가능성을 통제한다.

증거보전은 유리한 문서만 모으는 일이 아닙니다. 불리한 기록도 삭제하지 않고 사건의 전체 흐름을 보존해야 사실관계를 정확히 판단할 수 있습니다.

### 2단계 사건을 세 좌표로 분류

| 좌표 | 선택 | 의미 |
|---|---|---|
| 단계 | 공고·입찰 / 낙찰자결정 / 계약체결 / 이행·변경 / 검사·종결 | 적용 규정과 가능한 절차가 달라짐 |
| 요구 | 정정·취소 / 이행 / 기간연장 / 금액조정 / 대가지급 / 손해배상 등 | 원하는 결과를 명확히 함 |
| 긴급성 | 즉시 보전 / 단기 대응 / 통상 관리 | 기한·손실·업무중단 위험에 따라 우선순위 결정 |

`부당하다`는 감정은 요구가 아닙니다. 무엇을 언제까지 얻어야 하는지 구체화해야 대응수단을 고를 수 있습니다.

## 4. 대응 절차 여덟 단계

1. **사건 접수**: 발생시각, 당사자, 현상, 최초 통보를 기록한다.
2. **증거 보전**: 계약문서, 공문, 시스템 기록, 이메일, 회의록, 사진, 작업·원가자료를 확보한다.
3. **사실연표 작성**: 확인된 사실과 주장·추정을 구분한다.
4. **쟁점·근거 분석**: 각 당사자의 의무, 변경 여부, 인과관계, 손실과 절차를 검토한다.
5. **기한·권한 확인**: 통지·이의·청구·구제의 적용 절차와 결재권자를 확인한다.
6. **대응안 평가**: 계속이행, 보완, 협의, 변경계약, 정산, 공식 이의, 전문 절차의 비용·효과를 비교한다.
7. **공식 실행**: 권한 있는 명의와 정해진 채널로 명확한 요구·근거·증거를 제출한다.
8. **추적·학습**: 상대방 답변, 후속기한, 잠정합의, 재발방지 조치를 관리한다.

이 흐름은 학습용 공통 골격입니다. 실제로 이용할 수 있는 조정·심사·중재·소송 등은 적용 계약법령, 쟁점의 법적 성질, 계약조항에 따라 확인합니다.

### 법정 이의신청이 적용되는 경우의 현행 기한

국가계약법 제28조와 지방계약법 제34조의 이의신청은 **모든 계약상 의견 차이에 적용되는 일반 민원절차가 아닙니다.** 법이 정한 금액·계약과정·불이익 사유에 해당하는지 먼저 확인한 뒤 아래 기한을 적용합니다.

| 구분 | 최초 이의신청 | 기관의 심사·통지 | 결과에 대한 재심·조정 청구 |
|---|---|---|---|
| 국가계약 | 원인행위일부터 30일 이내 또는 안 날부터 25일 이내 | 받은 날부터 15일 이내 | 통지받은 날부터 30일 이내 |
| 지방계약 | 불이익 받은 날부터 20일 이내 또는 안 날부터 15일 이내 | 받은 날부터 15일 이내 | 통지받은 날부터 20일 이내 |

국가계약 기한은 2026년 6월 11일 시행 개정으로 늘어났습니다. 사건이 어느 시행본에 속하는지, 대상 금액과 사유가 법정 범위에 드는지 확인하지 않고 숫자만 적용하면 안 됩니다.

## 5. 사실연표와 증거목록을 만든다

### 사실연표 원칙

- 날짜와 시각을 가능한 한 정확히 적는다.
- `확인된 사실`, `상대방 주장`, `우리 측 판단`을 구분한다.
- 각 사실 옆에 증거 식별자를 붙인다.
- 문서의 원본 위치와 작성자·수신자를 남긴다.
- 누락 구간과 추가 확인 필요사항도 표시한다.

| 일시 | 사건 | 구분 | 증거 | 의미·후속 확인 |
|---|---|---|---|---|
| 8월 3일 10:10 | 발주담당자가 회의에서 추가 화면 요청 | 확인 사실 | E-03 회의녹취·M-02 회의록 | 요청 권한과 범위 확인 |
| 8월 3일 오후 | 계약변경 예정이라는 설명 | 상대방 발언 | M-02 | 승인권자의 확정 의사인지 미확인 |
| 8월 4~12일 | 업체가 추가 개발 수행 | 확인 사실 | W-01 작업기록, C-02 원가표 | 추가비용·인과관계 산정 |

### 증거의 품질 질문

| 질문 | 좋은 기록의 조건 |
|---|---|
| 진정성 | 누가 언제 생성·송수신했는지 확인 가능 |
| 완전성 | 일부 화면이나 문장만 잘라 맥락을 잃지 않음 |
| 연결성 | 쟁점 사실과 직접 연결됨 |
| 보존성 | 원본과 사본, 저장 위치, 접근권한이 관리됨 |
| 적법성 | 수집·이용 과정이 법과 내부정책에 맞음 |

## 6. 협의와 권리 보전을 함께 설계한다

협의는 권리를 포기하는 일이 아니고, 강경한 문구가 권리를 자동으로 지키는 것도 아닙니다. 공식 문서에는 보통 다음이 필요합니다.

- 계약과 사안을 식별하는 번호·제목
- 확인된 사실과 시간 순서
- 관련 계약조항·법령과 쟁점
- 현재·예상되는 일정·비용·품질 영향
- 요청하는 조치와 회신 희망시점
- 이행을 계속하거나 보류할 부분과 그 이유
- 첨부 증거목록과 담당자

상대방과 잠정 합의하면 무엇이 확정됐고 무엇이 남았는지, 권한 있는 자의 승인 여부와 계약문서 반영 필요성을 확인합니다.

## 7. 법무·전문가에게 넘길 사건요약서

전문가에게 파일만 전송하고 “검토해 달라”고 하면 핵심 기한을 놓칠 수 있습니다. 다음 한 장을 먼저 만듭니다.

| 항목 | 작성 내용 |
|---|---|
| 의사결정 질문 | 지금 어떤 결정을 내려야 하는가 |
| 긴급기한 | 근거, 만료 시 효과, 남은 시간 |
| 당사자·계약 | 기관, 계약유형, 번호, 기간, 금액 관련 범위 |
| 사실요약 | 확인된 사실 5~10줄과 연표 링크 |
| 쟁점 | 쟁점별 우리 입장·상대 입장·불확실성 |
| 근거 | 계약조항, 법령, 해석·판례의 정확한 위치 |
| 증거 | 핵심 증거와 누락 자료 |
| 선택지 | 기대효과, 비용, 관계·이행 위험 |
| 원하는 자문 | 답이 필요한 구체 질문 |

법무는 법적 판단을, 기술 전문가는 성능·하자·공정 원인을, 회계·원가 전문가는 손실과 금액을 검토할 수 있습니다. 내부 담당자는 사건의 사실과 업무목표를 정확히 제공하고 서로 다른 의견을 의사결정표로 통합합니다.

## 시작 사례 적용

잠정결론은 `분쟁 고위험, 즉시 사실·기한 확인 필요`입니다. 업체는 계약문서상 원래 과업 범위와 변경절차를 확인하고, 구두 요청의 시각·참석자·요청내용, 추가 작업·비용 자료를 보존합니다. 계약상 통지와 이행중단의 효과를 검토한 뒤 공식 문서로 사실, 영향, 요청하는 변경·정산 조치를 제시합니다. 승인권한과 변경계약이 확인되지 않은 상태에서 추가업무 인정이나 즉시 중단의 효과를 단정하지 말고 법무·계약·기술 담당자가 공동으로 선택지를 평가합니다.

### 법무·전문가 사건요약서

| 의사결정 질문 | 긴급기한·근거·만료 효과 | 사실연표·쟁점 | 핵심 증거·누락 자료 | 선택지·예상 효과 | 자문 필요사항·담당 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

서식을 채울 때는 확인된 사실과 당사자 주장을 같은 칸에 섞지 않습니다. 기한은 숫자만 쓰지 말고 적용 요건, 기산점, 만료일과 근거 조문을 같이 기록합니다.

## 필답형 답안 프레임

- 예방형: `분쟁원인 분류 → 조기징후 → 계약 전·이행 중·종결 전 통제 → 담당·점검주기`
- 대응형: `즉흥판단 금지 → 증거보전·사실연표 → 쟁점·근거·기한 확인 → 대응안 비교 → 권한 있는 실행 → 결과 추적`
- 협업형: `의사결정 질문·긴급기한 → 사실·쟁점·증거 → 우리·상대 입장 → 선택지·위험 → 전문가 의견 → 의사결정·통지`

사례형 결론에는 `바로 소송한다`처럼 적용요건을 뛰어넘는 문장 대신, 현재 확인된 사실·시급한 보전조치·추가 확인사항·권한 있는 다음 행위를 순서대로 적습니다.

## 자체 제작 연습문제 11선

1. O/X: 분쟁이 생기면 권리 보전을 위해 먼저 모든 이행을 중단하는 것이 원칙이다.
2. O/X: 불리한 이메일도 사건과 관련되면 삭제하지 않고 보존해야 한다.
3. O/X: `부당한 대우를 시정해 달라`는 문구만으로 요구 결과가 충분히 특정된다.
4. 분쟁 원인 여섯 묶음을 쓰시오.
5. 대응 절차 여덟 단계를 쓰시오.
6. 사실연표에서 사실·주장·판단을 구분해야 하는 이유를 설명하시오.
7. 공식 대응문서에 포함할 요소 다섯 가지를 쓰시오.
8. 법무 사건요약서에서 가장 먼저 제시할 두 항목을 쓰시오.
9. 납품검사 불합격 통보를 받았으나 합격기준과 측정기록이 첨부되지 않았다. 초기 대응을 서술하시오.
10. 시작 사례에서 업체가 수행해야 할 대응을 `보전 → 분석 → 통지 → 결정` 순서로 쓰시오.
11. 법정 적용요건을 충족하는 경우 국가계약과 지방계약 이의신청의 최초기한, 기관 처리기한, 재심·조정 청구기한을 비교하시오.

## 정답·해설

1. **X.** 중단이 새로운 계약위반과 손실을 만들 수 있으므로 계약상 근거, 안전·연속성, 전문가 검토 후 결정한다.
2. **O.** 유리·불리를 가리지 않는 완전한 보전이 필요하다.
3. **X.** 정정, 이행, 기간연장, 금액조정, 지급 등 원하는 결과를 특정해야 한다.
4. 범위·규격, 기간·지연, 금액·대가, 검사·하자, 변경·종결, 절차·권한. 각 1점.
5. 사건접수 → 증거보전 → 사실연표 → 쟁점·근거 → 기한·권한 → 대응안 → 공식실행 → 추적·학습. 각 1점.
6. 확인된 사실과 당사자의 주장·법적 평가를 섞으면 증거가 없는 내용을 사실처럼 전제하고 잘못된 대응을 선택할 수 있기 때문이다.
7. 사건 식별, 사실, 근거·쟁점, 영향, 구체적 요청, 회신시점, 이행상태, 증거·담당자 중 다섯 가지. 각 1점.
8. 의사결정 질문과 긴급기한. 각 2점.
9. 불합격 통보와 관련 원본을 보존하고 계약상 검사·합격기준, 검사권한과 재검사·보완절차 및 기한을 확인한다. 측정방법·원자료·불합격 항목을 공식 요청하고, 자체 기술검토와 보완 가능성을 평가한 뒤 권한 있는 명의로 답변한다.
10. 계약문서·구두요청·작업·원가자료를 보전하고, 원과업·변경절차·권한·인과관계를 분석한다. 일정·비용 영향과 요청 조치를 공식 통지하고, 계속이행·변경·정산·전문 대응의 위험을 비교해 결정한다.

11. 국가계약은 원인행위일부터 30일 또는 안 날부터 25일, 기관은 15일, 재심은 통지일부터 30일이다. 지방계약은 불이익 받은 날부터 20일 또는 안 날부터 15일, 기관은 15일, 재심·조정은 통지일부터 20일이다. 다만 각각 법이 정한 계약·금액·사유에 해당하는지 먼저 확인해야 한다.

9·10번은 결론과 초기통제 2점, 근거·사실 분석 3점, 공식 통지 2점, 후속 선택·추적 3점입니다.
