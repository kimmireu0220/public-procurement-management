## 합격에 필요한 필수 이론

### 협상의 기준선 네 문서

| 기준선 | 역할 | 확인할 것 |
|---|---|---|
| 입찰공고·정정공고 | 경쟁조건과 계약방식의 외곽 | 사업예산, 기간, 참가·평가·협상 조건 |
| 제안요청서·규격서 | 발주기관이 요청한 요구와 성과 | 필수요건, 산출물, 검수·서비스 수준 |
| 제출 제안서·가격서 | 협상대상자가 경쟁에서 약속한 내용 | 방법, 인력, 일정, 성과, 가격과 전제 |
| 평가·질의 기록 | 평가과정에서 확인된 쟁점 | 보완이 필요한 불명확성, 조건부 답변 |

협상 결과는 이 기준선을 지워버리는 메모가 아닙니다. 무엇이 왜 바뀌었는지, 최종 문서의 어느 위치로 들어가는지를 보여 주는 **변경이력**이어야 합니다.

### 협상 관리 9단계

| 단계 | 실행 | 통제 질문 |
|---:|---|---|
| 1. 통보·권한 확인 | 협상순위, 일정, 참석자와 의사결정 권한을 확인한다. | 누가 어떤 범위까지 합의할 수 있는가? |
| 2. 기준선 동결 | 공고·RFP·제안·가격서의 최종 제출본을 고정한다. | 협상 중 기준파일이 바뀌지 않는가? |
| 3. 쟁점 등록 | 요구사항 ID별 질문·차이를 쟁점대장에 적는다. | 누락된 구두요구가 없는가? |
| 4. 변경 분류 | 명확화·보완·추가·삭제·변경으로 구분한다. | 실제 과업량이 바뀌는가? |
| 5. 허용성 검토 | 법령·공고·필수규격·공정성에 어긋나지 않는지 본다. | 본질적 경쟁조건을 바꾸는가? |
| 6. 기술영향 분석 | 품질, 인력, 일정, 보안, 시험, 인수·유지관리 영향을 계산한다. | 연쇄영향까지 반영했는가? |
| 7. 가격영향 분석 | 증감 물량·단가·직접비·간접비·세금과 가격한도를 검토한다. | 변경과 금액이 1:1로 연결되는가? |
| 8. 합의·미합의 기록 | 합의문구, 담당자, 기한, 미결사항을 서면화한다. | `검토한다` 같은 미완료 문구가 남는가? |
| 9. 계약 연결 | 합의서·수정규격·산출내역·일정을 최종 계약문서에 반영한다. | 충돌 시 해석할 수 있게 문서가 정리됐는가? |

국가 계약예규 제10조에 따라 우선순위 협상대상자와 협상이 성립하면 다른 협상적격자와 협상하지 않습니다. 성립하지 않으면 같은 기준과 절차에 따라 차순위자와 순차 협상합니다. 선순위 업체가 다른 업체와 직접 거래하거나 순위를 조정하는 절차가 아닙니다.

### 변경을 다섯 종류로 분류한다

| 분류 | 뜻 | 가격영향의 출발점 | 예시 |
|---|---|---|---|
| 명확화 | 기존 약속의 뜻·방법을 구체화 | 과업량이 같으면 통상 0, 전제 확인 | `신속 대응`을 1시간 내 접수로 설명 |
| 보완 | 누락된 세부 실행·증빙을 채움 | 원래 필수범위인지 새 과업인지 판정 | 보고서 목차·검수증빙 구체화 |
| 추가 | 기준선에 없던 성과·작업을 넣음 | 증가 수량·인력·기간·비용 | API 추가, 교육 회차 증가 |
| 삭제 | 기준선의 성과·작업을 뺌 | 절감 가능한 실제 비용 | 보고서·장비·인력 일부 삭제 |
| 변경 | 방식·규격·일정·수량을 다른 것으로 치환 | 삭제분과 추가분을 각각 계산 | 월간보고를 현황판으로 대체 |

명칭이 아니라 실질을 봅니다. `명확화`라고 적었어도 새 개발·추가 시험·상시인력을 요구하면 추가 또는 변경일 수 있습니다. 반대로 문구가 바뀌어도 이미 제출 제안서에 포함된 방법을 정확히 표현한 것이라면 별도 과업증가가 아닐 수 있습니다.

### 기술영향 분석: 여섯 축

각 쟁점에 다음 여섯 축을 붙입니다.

1. **범위·성과물:** 무엇을 몇 개, 어느 수준으로 완성하는가?
2. **인력·역할:** 직무, 인원, 참여기간, 승인책임이 바뀌는가?
3. **일정·선후관계:** 착수·시험·인수일과 다른 과업의 경로가 바뀌는가?
4. **품질·검수:** 합격기준, 시험자료, 재수행 책임이 무엇인가?
5. **보안·법적 의무:** 개인정보, 접근권한, 저작권·라이선스, 하도급 등 영향이 있는가?
6. **운영·하자:** 교육, 자료이관, 유지관리, 장애대응 기간과 범위가 바뀌는가?

현황판 한 종을 추가하면 화면 개발비만 생기는 것이 아닙니다. 데이터 연계, 권한, 시험, 사용자 교육, 운영 모니터링, 인수자료와 유지관리 범위가 함께 움직일 수 있습니다.

### 가격협상의 법적 경계

국가 계약예규 제12조의 핵심은 다음과 같습니다.

- 가격협상의 기준가격은 해당 사업예산 이하이며, 예정가격을 작성한 경우에는 예정가격 이하인 **협상대상자의 제안가격**입니다.
- 제안내용을 가감하면 그 가감내용에 상당하는 금액을 사업예산 또는 예정가격 범위에서 조정할 수 있습니다.
- 제안내용의 가감조정이 없다면 협상대상자의 제안가격을 증감조정할 수 없습니다.
- 예정가격을 작성하는 경우 이를 제안서 제출 전에 정해진 절차로 작성해야 하며, 참가자의 제안가격을 기준으로 사후 작성해서는 안 됩니다.

따라서 발주기관이 “협상이니 일괄 5% 인하”라고 요구하거나 업체가 “기술내용은 같지만 가격을 올려 달라”고 요구하는 식의 설명은 제12조의 구조와 맞지 않습니다. 가격증감에는 대응하는 내용변경과 계산근거가 있어야 합니다.

### 가격영향 계산 사례

누리온의 제안가격이 120,000,000원이라고 가정합니다. 협상 분석 결과는 다음과 같습니다.

| 변경 | 증감 근거 | 금액 |
|---|---|---:|
| 주간보고 52회 → 월간보고 12회 | 실제 절감 가능한 작성·검토 인력 | -6,000,000 |
| 실시간 현황판 추가 | 분석·개발·시험·교육 | +9,000,000 |
| 외부 API 1종 추가 | 연계개발·보안시험·문서화 | +4,000,000 |
| 순변동 | -6,000,000+9,000,000+4,000,000 | +7,000,000 |

단순 계산상 조정안은 127,000,000원입니다. 그러나 사업예산 또는 예정가격이 125,000,000원이라면 127,000,000원으로 그대로 합의할 수 있다고 결론 내리면 안 됩니다. 범위·수량·방법을 다시 조정하거나, 근거단가와 부담주체를 검토해 허용 한도 안에서 기술·가격을 함께 확정해야 합니다. 반대로 예산 한도 아래라는 이유만으로 근거 없는 금액을 모두 인정하는 것도 아닙니다.

`무료 제공`도 가격영향을 0으로 숨기는 표현이 아닙니다. 계약금액이 늘지 않더라도 개발·시험·하자·유지관리 책임과 일정영향을 기술합의서에 명확히 적고, 회사가 그 비용을 감당할 권한과 이행가능성이 있는지 확인해야 합니다.

### 협상기간과 종결

국가 계약예규 제13조 기준으로 협상기간은 협상대상자에게 통보한 날부터 **15일 이내**입니다. 사업의 규모·특수성·난이도 등에 따라 협상대상자와 협의하여 **5일 범위에서 조정**할 수 있고, 정한 기간 안에 협상이 이루어지지 않으면 **10일 범위에서 연장**할 수 있습니다. 숫자는 국가 기준이므로 실제 공고의 적용기준과 통보기산점을 확인합니다.

협상이 성립되면 계약담당공무원은 해당 협상대상자와 다른 협상적격자에게 결과를 서면 통보합니다. 국가 기준은 협상 성립 후 10일 이내 계약체결을 규정합니다. 계약의 이행은 서면통보한 협상결과와 법령, 일반조건, 특수조건, 입찰유의서 등에 따르므로 협상합의서를 계약파일 밖에 방치해서는 안 됩니다.

## 혼동 방지와 오답 함정

- 절차명만 나열하고 주체·입력자료·판단기준을 빼면 부분점수를 잃는다.
- “관련 규정에 따른다”로 끝내지 말고 어떤 공고·계약조건·증빙을 대조할지 쓴다.
- 공고별 배점·비율과 일반 법령상 기준, 표준교재의 사례값을 섞지 않는다.
- 사실이 부족한 사례는 임의로 확정하지 말고 추가 확인사항과 조건별 결론을 짧게 쓴다.

## 필답형 답안 작성 방법

다음 골격을 먼저 적고 문제의 사실과 핵심어를 끼워 넣는다.

1. 담당자는 공고·계약서·요구자료와 적용근거를 확인한 뒤 ‘입찰공고 요구의 추가·삭제·변경 협상’을 수행한다.
2. ‘기술협상 중 추가·변경·삭제 과업 조정’ 단계에서는 적용요건과 제시된 사실·증빙을 대조하고 판단근거를 기록한다.
3. ‘조정결과에 따른 가격 증감 조정’ 결과를 문서화·설명하고 관계자 통지와 후속조치를 관리한다.

## 실전 인출·피드백 — 자체 작성

자료를 덮고 변경대장과 가격조정안을 먼저 만든 뒤 모범답안과 자체 채점표를 연다.

> 아래 금액과 10점 배점, 오답 분류, 복습 간격은 학습용 자체 사례·휴리스틱이며 공식 배점·공식 용어가 아니다. 실제 협상은 해당 공고·예정가격 작성 여부·계약예규의 적용시점을 다시 확인한다.

**사례 문제(10점·10분).** 누리온의 제안가격은 120,000,000원이고 사업예산 또는 예정가격 한도는 125,000,000원이라고 가정한다. 기술협상에서 주간보고를 월간보고로 바꾸어 실제 절감 가능한 비용 6,000,000원이 감소하고, 실시간 현황판 9,000,000원과 외부 API 연계 4,000,000원이 추가된다. 발주기관은 변경내용과 무관하게 제안가격에서 일괄 5%를 더 낮추자고 구두 제안했다. 변경을 분류하고 순가격조정안을 계산한 뒤 허용 가능한 협상·기록·계약연결 조치를 쓰시오.

**변형 1.** 외부 API 연계 추가가 철회되고 나머지 두 변경만 합의되었다. 순가격조정안과 한도 판단이 어떻게 달라지는지 쓰시오.

:::answer 모범답안·채점 보기
### 사례 문제 모범답안

공고·RFP·제출 제안서·가격서·평가질의 기록을 기준선으로 동결하고 요구사항 ID별 변경대장을 만든다. 주간보고를 월간보고로 바꾸는 것은 기존 과업의 변경으로서 실제 절감분 `-6,000,000원`, 현황판과 API는 기준선에 없던 과업이면 각각 추가 `+9,000,000원`, `+4,000,000원`으로 분류한다. 순변동은 `-6,000,000+9,000,000+4,000,000=+7,000,000원`, 단순 조정안은 `120,000,000+7,000,000=127,000,000원`이다.

127,000,000원은 주어진 한도 125,000,000원을 넘으므로 그대로 합의하지 않는다. 범위·수량·방법, 근거단가와 부담주체를 다시 조정하여 기술내용과 금액을 함께 한도 안에서 확정해야 한다. 내용 가감과 대응하지 않는 일괄 5% 인하는 별도 가격조정 근거가 되지 않으므로 구두로 수락하지 않는다. 각 변경의 범위·인력·일정·품질·보안·운영 영향과 금액근거, 합의·미합의 내용을 서면화하고 수정규격·산출내역·일정·협상합의서를 최종 계약문서에 연결한다.

### 변형 1 피드백

API 추가 4,000,000원이 빠지면 순변동은 `-6,000,000+9,000,000=+3,000,000원`, 단순 조정안은 `123,000,000원`으로 주어진 한도 안이다. 그러나 한도 이내라는 사실만으로 자동 승인하지 않고, 보고 변경의 실제 절감분과 현황판의 개발·시험·교육 범위 및 단가를 검증해 서면 합의한다.

### 10점 자체 채점

- 네 기준선을 동결하고 세 변경을 실질에 따라 분류함: 2점
- 증감액과 순변동 +7,000,000원을 계산함: 2점
- 127,000,000원과 125,000,000원 한도의 관계를 판정함: 2점
- 내용변경 없는 일괄 5% 인하를 근거 없는 조정으로 구분함: 2점
- 기술영향·금액근거·합의이력과 최종 계약문서 연결을 씀: 2점

### 오답 분류와 재학습 체크

- [ ] **개념:** 명확화·추가·삭제·변경과 가격증감의 대응관계를 구분하지 못했다.
- [ ] **혼동:** 한도 이내면 근거 없이 승인하거나, 협상이면 제안가격을 임의 조정할 수 있다고 보았다.
- [ ] **숫자:** 감소 부호·순변동·최종 조정안 또는 한도 비교를 틀렸다.
- [ ] **적용:** 구두 제안을 변경대장·합의서·수정 산출내역과 계약문서에 연결하지 못했다.

- [ ] **D+1:** 변경 5분류와 가격조정 원칙을 자료 없이 다시 썼다.
- [ ] **D+3:** 변형 1을 재계산하고 한도 이내라도 필요한 검증을 설명했다.
- [ ] **D+7:** 증감항목을 바꾼 새 협상사례를 10분 안에 작성·채점했다.
