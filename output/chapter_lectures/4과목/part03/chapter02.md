> 자체 제작 강의입니다. 조달청 표준교재 4권 149~165쪽의 평가 흐름을 출발점으로 삼고, 점수·법적 효과는 2026년 8월 24일 현재 국가계약법령, 계약예규와 조달청 공식 기준에 대조했습니다. 아래 계산사례의 금액과 업체는 모두 학습용입니다.

## 이 강의 하나의 완료 기준

입찰평가표를 받았을 때 단순히 점수를 더하는 데서 끝나지 않고 **적용 기준, 통과조건, 산식, 증빙, 이해상충을 모두 검증**할 수 있어야 합니다. 다음 일곱 가지를 수행하면 완료입니다.

- 공고의 낙찰자 선정방법을 먼저 특정하고 다른 방식의 산식을 섞지 않는다.
- 가격·기술평가의 배점과 세부항목을 공고 원문 그대로 옮긴다.
- 정량평가, 정성평가, 가격평가, 가·감점과 통과조건을 구분한다.
- 국가 협상계약의 현재 기본 산식을 계산하되 실제 공고가 달리 정하면 공고를 적용한다.
- 예상점수를 `확정`, `가정`, `평가위원 판단`으로 나누어 범위로 제시한다.
- 평가위원의 제척·기피·회피 또는 이해상충 징후를 식별하고 공식 절차로 기록한다.
- 사례형 답안을 `방식 특정 → 기준 전사 → 계산 → 통과검증 → 이해상충 조치`로 작성한다.

> 가장 중요한 경계: **기술 80점·가격 20점, 85% 통과기준, 가격평점 산식은 모든 공공입찰의 공통 규칙이 아닙니다.** 이 강의에서 그 숫자를 사용하는 곳은 국가기관의 일반적인 협상에 의한 계약 기준을 연습하는 부분입니다. 지방자치단체, 적격심사, 종합심사, 2단계 경쟁, 품목별 조달기준과 개별 공고에는 각각의 기준을 적용합니다.

| 공식 세부항목 | 완료 후 할 수 있는 일 | 산출물 |
|---|---|---|
| 낙찰방법별 가격·기술평가 점수 산정 | 적용 산식과 배점을 특정하고 계산과 반올림을 재현한다. | 평가기준 전사표, 점수계산표 |
| 낙찰자 선정방법별 예상 평가점수 산정 | 정량 증빙점수와 정성 예상범위를 합쳐 통과·순위를 시뮬레이션한다. | 예상점수 시나리오 |
| 심사 규정·절차상 이해상충 문제 식별 | 평가자·제안업체 관계와 사전접촉 징후를 확인하고 보고·배제 절차를 기록한다. | 이해상충 점검표 |

## 오늘의 사례

해솔시스템은 중앙행정기관의 협상계약에 참가했습니다. 담당자는 예전 지방자치단체 공고에서 사용했던 가격산식을 재사용했고, 기술평가 배점도 관행적으로 80점이라고 입력했습니다. 실제 공고는 기술 90점·가격 10점이었고 별도의 세부기준을 명시했습니다. 게다가 평가위원 후보 한 명이 최근까지 해솔시스템의 유사사업 자문을 맡았다는 사실이 발견되었습니다.

이 계산표는 숫자가 정확해 보여도 무효입니다. 잘못된 기준을 정확히 계산한 것이기 때문입니다. 먼저 발주기관과 낙찰방법을 특정하고, 해당 공고의 별표와 정정공고를 전사해야 합니다. 이해상충은 영업상 유불리를 따져 조용히 넘길 문제가 아니라 평가 공정성의 문제이므로 공식 보고·제척·회피 여부를 확인해야 합니다.

## 1단계: 낙찰방법부터 특정한다

| 방식 | 무엇을 비교하는가 | 이 장에서의 주의 |
|---|---|---|
| 최저가격·제한적 최저가격 구조 | 유효입찰, 예정가격 이하 여부, 가격순위 등 | 계약 종류와 현재 법령의 낙찰요건을 확인한다. |
| 적격심사 | 가격 외에 이행능력·경영상태·실적·신인도 등을 기준별로 심사 | 물품·용역·공사와 기관별 세부기준이 다르다. |
| 협상에 의한 계약 | 기술능력평가와 입찰가격평가 후 협상적격·순위를 정하고 협상 | 기술통과기준과 가격산식을 공고에서 확인한다. |
| 2단계 경쟁 등 | 규격·기술 적격과 가격을 단계적으로 평가 | 어느 단계에서 무엇을 개봉·평가하는지 구분한다. |
| 종합심사·품목별 제도 | 가격, 수행능력, 사회적 책임 등 제도별 항목 | 해당 제도의 전용 심사기준을 사용한다. |

공고 제목에 `협상`이 보인다고 모든 국가 협상계약의 기본표를 그대로 적용하지 않습니다. 공고문, 제안요청서, 제안서 평가기준, 가격평점 별표, 정정공고가 하나의 기준 묶음입니다.

## 2단계: 평가기준을 원문 그대로 전사한다

평가표에는 다음 열이 필요합니다.

| 구분 | 확인할 값 | 검증 질문 |
|---|---|---|
| 적용근거 | 법령·예규·기관 세부기준·공고 조항 | 시행일과 적용례가 이번 공고에 맞는가? |
| 총점·배점 | 기술, 가격, 가·감점, 합계 | 합계가 맞고 조정 사유가 공고되었는가? |
| 통과조건 | 기술 최저점, 합산 최저점, 적격·부적격 | 단순 합계 전에 탈락조건이 있는가? |
| 정량항목 | 실적, 인력, 경영상태, 신인도 | 인정범위·기준일·증빙이 명확한가? |
| 정성항목 | 이해도, 방법론, 조직, 품질·위험관리 | 평가척도와 배점단계가 무엇인가? |
| 가격산식 | 기준가격, 최저가격, 구간, 하한처리 | 세금 포함과 반올림 위치가 무엇인가? |
| 동점처리 | 기술점수, 큰 배점항목 등 | 공고의 우선순위 규칙은 무엇인가? |
| 평가절차 | 위원 구성, 설명, 질의, 점수처리·공개 | 최고·최저점 제외 여부를 임의 가정하지 않았는가? |

전사한 값 옆에는 반드시 `공고 12항`, `RFP 별표 4 p.3`처럼 위치를 적습니다. “작년과 동일”은 근거가 아닙니다.

## 3단계: 기술점수를 세 층으로 나눈다

### 정량평가

실적·인력·경영상태처럼 증빙과 산식으로 비교적 재현 가능한 영역입니다. 하지만 확정점수로 만들려면 다음을 확인해야 합니다.

- 유사실적의 대상, 기간, 금액, 완료·진행 인정 여부
- 공동수급 실적의 지분 또는 인정방식
- 인력의 재직·자격·경력 기준일과 중복참여 제한
- 신용평가등급의 발급기관·유효기간·가장 최근 자료 요건
- 신인도 가점과 감점의 중복·상한·적용기간

증빙이 없거나 인정범위가 불명확하면 점수를 `확정`으로 쓰지 말고 `확인 필요`로 둡니다.

### 정성평가

위원이 제안내용을 평가하는 영역입니다. 한 점으로 단정하지 말고 최소·기준·목표 시나리오를 둡니다.

| 평가항목 | 배점 | 보수 | 기준 | 목표 | 점수 근거·개선조치 |
|---|---:|---:|---:|---:|---|
| 사업이해 |  |  |  |  | 발주목표·현황진단 연결 |
| 수행방법 |  |  |  |  | 절차, 도구, 검증, 산출물 |
| 조직·인력 |  |  |  |  | 역할·투입률·대체계획 |
| 품질·위험 |  |  |  |  | 지표·통제·보고·복구 |

조달청 세부기준에서 평가위원 점수의 최고·최저 제외, 점수 보정 등이 쓰이는 경우가 있지만, **어떤 평가에도 자동 적용되는 공통 산식이 아닙니다.** 이번 공고와 적용 세부기준이 그 방식을 채택했는지 확인합니다.

### 기술 통과조건

2026년 1월 2일 시행 국가 계약예규 `협상에 의한 계약체결기준` 제8조의 일반구조에서는 입찰가격이 사업예산 이하이고, 기술능력평가 점수가 기술능력평가분야 배점한도의 **85% 이상**인 자를 협상적격자로 선정합니다. 예를 들어 실제 공고의 기술배점이 80점이면 기준은 68점, 90점이면 76.5점입니다.

`기술점수 + 가격점수`가 높아도 기술통과선에 미달하면 이 국가 기준에서는 협상적격자가 아닙니다. 다만 기관·사업별 조정이나 지방계약 기준을 이 문장으로 판정하지 말고 해당 공고를 확인합니다.

## 4단계: 국가 협상계약 가격평점 산식 연습

다음은 국가 계약예규 별표의 일반 가격평점 구조입니다. 실제 공고가 다른 배점·산식을 공고했다면 그 공고를 사용합니다. `E`는 산식이 적용하는 추정가격 상당 기준, `Pmax`는 가격배점한도, `L`은 유효한 최저입찰가격, `P`는 해당 입찰가격입니다.

### 해당 입찰가격이 E의 80% 이상인 경우

`가격평점 = Pmax × (L ÷ P)`

최저입찰가격이 E의 60% 미만이면 산식상 L을 E의 60%로 계산합니다. 사업예산을 기준으로 평가하면 예규가 정한 부가가치세 포함 처리, 예정가격을 작성한 경우의 대체 기준 등도 함께 적용합니다.

### 해당 입찰가격이 E의 80% 미만인 경우

`가격평점 = Pmax × (L ÷ E의 80% 상당가격) + 2 × {(E의 80% 상당가격 - P) ÷ (E의 80% 상당가격 - E의 60% 상당가격)}`

일반 산식에는 60% 미만 가격의 처리와 SW사업의 별도 처리가 있으므로, 한 줄 산식만 복사하지 말고 별표의 주석 전체를 적용합니다. 계산결과는 현재 기준상 소수점 다섯째 자리에서 반올림하지만 실제 공고가 별도 처리방식을 정했는지 다시 확인합니다.

### 계산 사례

학습용 공고가 국가 일반구조인 기술 80점·가격 20점이고, 가격평가 기준 E가 100,000,000원이라고 가정합니다. 유효 최저입찰가격은 78,000,000원, 우리 가격은 90,000,000원, 기술점수는 72점입니다.

1. 우리 가격은 E의 80% 이상이므로 첫 산식을 적용합니다.
2. 가격점수 = 20 × 78,000,000 ÷ 90,000,000 = 17.333333…
3. 소수점 다섯째 자리 반올림 결과 = **17.3333점**
4. 기술통과선 = 80 × 85% = **68점**
5. 기술 72점은 통과하고, 합산 예상점수는 **89.3333점**입니다.

반대로 기술점수가 67.9점이라면 합산점수가 높아 보여도 기술통과선 68점에 미달합니다. 이 사례의 80·20·100,000,000·78,000,000·90,000,000은 연습값이며 실제 공고의 값이 아닙니다.

## 5단계: 예상점수는 범위와 전제를 함께 쓴다

| 구분 | 처리 | 표시 예시 |
|---|---|---|
| 증빙으로 확정 가능한 정량점수 | 인정요건과 기준일 검증 후 단일값 | `실적 8/10, 증빙 확인` |
| 가격점수 | 경쟁사 최저가격을 알 수 없으므로 여러 L을 가정 | `L=75/80/85백만원 시 16.7~18.9` |
| 정성점수 | 보수·기준·목표 범위 | `42~51/60` |
| 통과조건 | 각 시나리오마다 먼저 검증 | `기술통과: 기준·목표만 충족` |
| 순위 | 경쟁사 점수를 모르므로 확률적·조건부 표현 | `확정 1위` 대신 `A조건이면 선순위 가능` |

예상점수의 목적은 결과를 예언하는 것이 아니라 **낮은 점수의 원인과 보완 우선순위**를 찾는 데 있습니다.

## 6단계: 이해상충과 절차위험을 식별한다

이해상충은 실제 편파가 입증된 경우만을 뜻하지 않습니다. 공정한 평가를 의심하게 할 객관적 관계가 있는지 확인하고 해당 규정의 제척·기피·회피 절차를 적용합니다.

| 징후 | 확인할 사실 | 조치 원칙 |
|---|---|---|
| 업체와 최근 고용·자문·용역 관계 | 기간, 업무, 보수, 평가대상과의 관련성 | 평가기관에 즉시 사실 보고, 해당 기준의 제척·회피 판단 |
| 친족·경제적 이해관계 | 관계, 주식·채권·공동사업 등 직접 이해 | 비공개 은폐 금지, 공식 확인·배제 절차 |
| 제안서 작성·사전검토 관여 | 어떤 문서·의사결정에 참여했는가 | 해당 제안 평가에서 분리 여부 검토 |
| 평가 전 접촉 | 일시, 장소, 상대, 내용, 자료 | 접촉기록 보존, 세부기준상 신고·감점 등 확인 |
| 평가정보 유출·특정업체 유리한 질문 | 정보 접근·전달 경로, 동일기회 여부 | 평가 중단·보고·보안조치 검토 |

입찰업체는 평가위원을 임의로 접촉해 해명하거나 관계를 조정하려 해서는 안 됩니다. 내부 준법책임자와 발주기관의 공식 창구를 통해 사실만 기록·제출합니다. 개인정보와 근거 없는 의혹의 확산도 피해야 합니다.

## 사례 완성

해솔시스템은 먼저 발주기관이 국가기관이고 이번 공고가 협상계약임을 확인합니다. 정정공고를 포함한 평가표에서 기술 90·가격 10, 기술통과선과 가격산식, 반올림을 다시 전사합니다. 이전 지방공고 산식을 폐기하고 세 가지 최저가격 시나리오로 가격점수를 재계산합니다. 정성점수는 범위로 둡니다. 자문관계가 있는 평가위원 후보에 대해서는 관계 일시·업무·대가·이번 사업 관련성을 사실확인서에 적고 평가기관의 공식 절차로 보고합니다. 업체가 직접 위원에게 연락하지 않습니다.

## 자체 제작 문제 10개

1. O/X: 협상계약의 기술·가격 배점은 언제나 80점과 20점이다. 2점
2. O/X: 기술통과선에 미달해도 기술·가격 합계가 가장 높으면 국가 일반 협상기준의 협상적격자다. 2점
3. 평가기준 전사표에 반드시 넣을 항목 여섯 가지를 쓰시오. 6점
4. 정량평가와 정성평가의 예상점수 처리방법을 비교하시오. 6점
5. 국가 일반 협상기준에서 기술배점이 90점일 때 85% 통과선은 몇 점인가? 3점
6. 가격배점 20점, 유효 최저가 72,000,000원, 우리 가격 90,000,000원이고 두 가격 모두 기준가격의 80% 이상 구간이라고 가정한다. 가격점수를 계산하시오. 6점
7. 기술점수 70점/80점, 가격점수 18점인 A사와 기술점수 67점/80점, 가격점수 20점인 B사의 국가 일반 협상기준 적격 여부와 합산점수를 판정하시오. 8점
8. 작년 지방공고 산식을 올해 국가기관 공고에 그대로 쓴 오류를 고치는 절차를 쓰시오. 7점
9. 평가위원 후보가 6개월 전 제안업체의 유사사업 유상 자문을 맡았다. 업체 담당자의 조치를 쓰시오. 7점
10. 해솔시스템 사례를 `결론→기준→적용→조치`로 답하시오. 8점

## 정답과 채점기준

1. **X.** 배점은 계약기준과 공고에 따라 달라질 수 있다. 정답 1점, 공고 우선 이유 1점.
2. **X.** 해당 국가 일반기준에서는 기술배점한도의 85% 이상을 먼저 충족해야 한다. 각 1점.
3. 낙찰방법, 적용근거, 기술·가격 배점, 통과조건, 정량·정성항목, 가격산식과 구간, 반올림, 가·감점, 동점처리, 평가절차 중 여섯 가지. 각 1점.
4. 정량은 인정요건·기준일·증빙을 검증해 확정 가능한 값을 쓰고(3점), 정성은 위원 판단이므로 보수·기준·목표 범위와 근거·개선조치를 쓴다(3점).
5. `90×0.85=76.5`, 정답 **76.5점**. 산식 1점, 계산 1점, 단위 1점.
6. `20×72,000,000÷90,000,000=16`, 정답 **16점**. 산식 3점, 계산 2점, 구간 전제 확인 1점.
7. A는 기술통과선 68점 이상이므로 적격 가능, 합계 88점(4점). B는 합계 87점이지만 기술 67점으로 통과선 미달이므로 협상적격자가 아니다(4점).
8. 발주기관·낙찰방법 확인 1점, 최신 공고·정정·별표 전사 2점, 기존 산식 폐기 1점, 새 산식·입력·반올림 재계산 2점, 독립검증 1점.
9. 자문관계의 기간·업무·대가·관련성을 기록하고(2점), 위원 직접접촉 없이(1점), 발주기관 공식창구에 보고하여 적용기준의 제척·회피 등을 판단받고(3점), 결과를 보존한다(1점).
10. 기존 계산표를 사용할 수 없다는 결론 2점, 실제 공고 90·10과 이전 지방산식의 불일치 2점, 공고별 배점·산식·이해상충 절차 2점, 재계산과 공식 보고·접촉금지 2점.

총점은 55점입니다. 44점 이상이 통과선입니다. 6·7번 합계가 8점 미만이면 가격산식 구간과 기술통과 판단을 다시 연습합니다.
