### 1단계 용역 특화 계약조건으로 체결한다

현행 용역계약일반조건은 공통적인 일반용역조건과 해당 용역 유형의 세부조건을 조합하여 계약에 붙이는 구조입니다. 따라서 제목이 ‘용역’이라는 이유로 한 가지 조건만 적용하지 않습니다. 정보화, 시설관리, 학술·연구, 기술 관련 용역 등 실제 성질과 공고가 채택한 조건을 확인합니다.

### 계약조건 매트릭스

| 분야 | 확인할 질문 | 근거문서 |
|---|---|---|
| 목적·범위 | 무엇을 위해 어디까지 수행하는가? | 과업내용서, 제안요청서 |
| 일정 | 착수일, 단계별 보고, 완료일은 언제인가? | 계약서, 공정계획 |
| 인력 | 필수인력·자격·투입률·교체절차는 무엇인가? | 제안서, 협상결과, 특수조건 |
| 산출물 | 형식·수량·제출방법·권리는 무엇인가? | 과업내용서, 지식재산 조항 |
| 품질·검사 | 검사기준과 보완절차는 무엇인가? | 과업내용서, 일반·특수조건 |
| 보안·정보 | 비밀·개인정보·자료반출 조건은 무엇인가? | 보안특약, 관계 법령 |
| 변경 | 추가·삭제·일정변경의 권한과 절차는 무엇인가? | 용역계약일반조건 |
| 대금 | 선금·기성·완료대가의 조건과 증빙은 무엇인가? | 계약서, 산출내역 |
| 외부수행 | 공동수급·하도급·승인 제한이 무엇인가? | 협정서, 특수조건, 개별법 |

계약 체결 전에 과업내용서, 제안서, 기술·가격 협상결과, 계약서 초안 사이의 차이를 찾아야 합니다. 제안서에 약속한 핵심인력이나 방법이 계약상 의무로 편입되었는지, 발주부서의 기대가 문서에 실제 반영되었는지를 구분합니다.

전자계약에서는 초안에 이견을 표시할 수 있고 최종 체결통보 후 확정된 계약문서를 기준선으로 보존합니다. “담당자가 회의에서 말했다”는 사실은 기록할 필요가 있지만 그것만으로 금액과 기간이 바뀐 변경계약이 완성됐다고 단정하지 않습니다.

### 2단계 착수와 이행 기준선을 만든다

착수 단계에서는 실제 계약이 요구하는 착수신고, 수행계획, 인력현황, 보안서약, 일정표, 연락체계를 확인합니다. 모든 용역에 동일한 서류가 필요한 것은 아니므로 공통조건과 세부용역 조건, 특수조건을 대조합니다.

| 기준선 | 최초 기록 | 변경 시 확인 |
|---|---|---|
| 과업 | 업무목록·제외범위 | 추가·삭제·대체 |
| 일정 | 단계별 마감·완료일 | 지연원인·만회계획 |
| 인력 | 역할·자격·투입계획 | 교체승인·공백 |
| 산출물 | 명칭·형식·검사기준 | 제출형식·수량 변경 |
| 비용 | 계약금액·항목별 내역 | 추가대가·감액 |
| 정보 | 제공자료·보안·권리 | 추가자료·반출·권리변경 |

월간회의와 보고서는 성과 자랑이 아니라 계약 적합성의 증거입니다. 완료율, 제출물, 미해결 과제, 발주기관 의사결정 지연, 자료 미제공, 변경요청을 날짜와 담당자로 남깁니다.

### 3단계 과업내용 변경을 관리한다

용역계약일반조건은 계약 목적상 필요한 경우 추가·특별업무, 용역공정계획 변경, 특정 용역항목의 삭제·감소 같은 과업변경을 예정합니다. 원칙적으로 변경이 필요한 부분을 수행하기 전에 변경을 완료합니다. 품질저하 우려 등 긴급한 필요가 있는 경우에도 계약상대자와 협의하여 변경시기 등을 명확히 해야 합니다.

### 변경판정 다섯 질문

1. 요청 업무가 원래 과업의 해석 범위 안인가?
2. 추가·삭제·대체되는 업무와 산출물은 무엇인가?
3. 인력·비용·완료기한·검사기준에 어떤 영향이 있는가?
4. 지시·승인 권한이 있는 자가 누구이며 어떤 문서가 필요한가?
5. 계약금액·기간·과업내용의 변경이 확정되었는가?

과업내용에 없는 추가업무를 요구하면 정당한 대가를 지급해야 한다는 일반조건의 원칙을 답안에 활용할 수 있습니다. 다만 업체가 승인 없이 임의로 범위를 넓힌 뒤 언제나 추가대가를 받는다는 뜻은 아닙니다. 요청, 필요성, 범위, 가격·기간 영향, 변경 합의를 문서화해야 합니다.

계약상대자가 기본방침을 바꾸지 않으면서 발주기관에 유리한 과업변경을 제안하는 경우, 현행 일반조건에는 제안을 받은 날부터 14일 이내 승인 여부를 통지하는 규정이 있습니다. 이 숫자는 발주기관이 추가업무를 구두 요청한 모든 경우의 일반 답변기한으로 확대하지 않습니다.

### 4단계 검사·인수·대금·종료

용역을 완성하면 서면으로 알리고 필요한 검사를 받습니다. 기성부분 대가를 받으려는 경우에도 해당 부분의 검사가 필요합니다. 국가계약 용역의 기본 검사기한은 완료 통지를 받은 날부터 14일 이내이며, 불가항력 사유가 있으면 일반조건이 정한 범위에서 연장될 수 있습니다. 적법한 대금청구 후 국가계약의 기본 지급기한은 5일입니다. 지방계약·기관 규정·특례·청구 보완 여부를 별도로 봅니다.

### 산출물 검사표

| 기준 | 확인 질문 | 결과 |
|---|---|---|
| 완전성 | 약정한 산출물이 모두 제출됐는가? | 합격·보완·불합격 |
| 정확성 | 데이터·계산·논리가 검사기준에 맞는가? | 오류목록 |
| 기능성 | 프로그램·시스템이 요구기능을 수행하는가? | 시험결과 |
| 형식 | 파일형식·수량·메타데이터가 맞는가? | 제출확인 |
| 보안 | 개인정보·비밀·접근권한을 적법하게 처리했는가? | 점검기록 |
| 권리 | 제3자 권리와 결과물 이용조건을 충족하는가? | 권리자료 |

검사에서 일부 미흡이 발견되면 계약문서에 따라 보완 범위, 기한, 재검사를 관리합니다. 보완 가능 여부와 대금처리는 계약내용과 미이행 정도에 따라 판단합니다. 담당자의 주관적 불만만으로 전액 미지급을 확정하거나, 산출물 미흡만으로 입찰제한을 자동 확정하면 안 됩니다.

### 선금의 현행 숫자

국가계약의 물품 제조·용역 선금은 정부 입찰·계약 집행기준상 일반 상한이 계약금액의 70%입니다. 의무지급률은 계약금액 10억 원 이상 30%, 3억 원 이상 10억 원 미만 40%, 3억 원 미만 50%입니다. 적법한 청구 후 의무지급률 범위의 지급은 원칙적으로 14일 이내입니다.

이 숫자만으로 지급을 판정하지 않습니다. 지급요건, 예산, 보증, 선금 사용범위, 하수급인 배분, 정산·반환 사유, 장기계속계약 여부를 함께 확인합니다.

### 5단계 용역 하도급을 관리한다

### 공동수급과 하도급 비교

| 구분 | 공동수급 | 하도급 |
|---|---|---|
| 발주기관과 관계 | 구성원이 협정에 따라 공동 계약책임 | 원수급인이 계약책임을 지고 일부를 제3자에게 위탁 |
| 기본문서 | 공동수급협정서 | 하도급계약서 |
| 관리 초점 | 지분·분담·대표자·연대 또는 분담책임 | 허용·승인, 범위, 서면, 수행, 검사, 대금 |
| 주의 | 대표사만의 단독 하도급으로 오인 금지 | 하수급인을 공동수급 구성원으로 오인 금지 |

### 하도급법 자동적용 금지

하도급법은 제조·수리·건설·용역위탁 중 법이 정한 거래와 당사자 범위에 적용됩니다. 따라서 용역 일부를 외부업체가 수행한다는 사실만으로 적용을 확정하지 않습니다.

1. 외부수행이 실질적으로 용역위탁인가?
2. 위탁하는 용역이 법령상 대상 범위인가?
3. 원사업자와 수급사업자의 규모·지위 등 법정 요건이 맞는가?
4. 계약서·특수조건이 하도급을 금지하거나 사전승인 대상으로 정하는가?
5. 소프트웨어, 정보통신, 엔지니어링 등 개별 업종법의 승인·관리 규정이 있는가?

적용이 확인되면 서면 발급과 보존, 부당특약·부당대금, 검사·인수, 대금지급, 변경 반영, 기술자료, 직접지급 등 해당 쟁점을 확인합니다. 직접지급은 법정 사유와 절차가 충족되는 경우의 효과이지, 하도급이 존재하면 언제나 발생하는 효과가 아닙니다.

### 용역 하도급 이행순서

**필요성 확인 → 허용·승인 검토 → 수행범위·금액·기간·산출물 서면화 → 인력·보안·품질 통제 → 변경 연동 → 검사·대금 → 종료·자료반환**

원도급 과업이 변경되면 하도급 범위·기간·대금에도 영향이 있는지 함께 검토합니다. 원도급자가 발주기관에서 대가를 받지 못했다는 한 사정만으로 하도급대금 지급의무가 항상 사라지는 것은 아닙니다. 적용 법령과 계약을 확인합니다.

## 반드시 암기할 핵심어·숫자·절차

| 앞면 | 뒷면 |
|---|---|
| 용역계약 구조 | 공통 일반조건 + 해당 세부용역 조건 + 개별 계약문서 |
| 체결 핵심 | 목적·범위·일정·인력·산출물·검사·변경·대금 |
| 변경 원칙 | 필요한 부분 수행 전에 범위·가격·기간을 변경 |
| 검사 흐름 | 완료통지 → 검사 → 보완·재검사 → 인수 → 대금 |
| 공동수급과 하도급 | 발주기관에 공동책임 / 원수급자가 일부 위탁 |
| 하도급 첫 판정 | 대상 거래와 당사자 법정 범위 |
| 자동 연결 금지 | 미흡 산출물 ≠ 전액 미지급 ≠ 입찰제한 |
| 필답 순서 | 범위 → 변경 → 수행주체 → 검사 → 효과 |

> 숫자는 반드시 적용기관·계약유형·기산점·시행일과 함께 쓴다. 공고 사례값이나 이 강의의 학습용 척도를 일반 법정기준으로 단정하지 않는다.

## 혼동 방지와 오답 함정

- 회의에서 말한 기대나 제안서의 홍보내용을 곧바로 계약상 과업으로 보지 않는다. 과업내용서·협상결과·최종 계약문서 편입 여부를 확인한다.
- 승인 없이 과업범위를 넓히면 언제나 추가대가를 받는다고 단정하지 않는다. 요청·필요성·범위·가격·기간을 변경 전에 합의한다.
- 공동수급 구성원과 하수급인을 같은 지위로 보지 않는다. 협정에 따른 공동책임과 일부 제3자 위탁의 법률관계를 먼저 구분한다.
- 일부 산출물 미흡을 전액 미지급이나 입찰참가자격 제한으로 자동 연결하지 않는다. 보완·재검사·대금과 제재 요건을 따로 판정한다.

## 실전 인출·피드백 — 자체 작성

**사례 문제(10점·8분).** 정보시스템 구축 용역에서 과업내용서는 프로그램과 보고서의 범위·검사기준을 정하고 있다. 발주부서 담당자가 과업에 없는 추가 기능을 구두로 요청하자 계약상대자는 범위·가격·기간 변경 없이 개발을 시작했다. 또한 외부업체에 그 기능 일부를 맡기면서 계약서·특수조건의 사전승인 여부를 확인하지 않았고, 보안자료 접근과 산출물 권리·품질 통제도 정하지 않았다. 최종 산출물 일부가 검사기준에 미흡하자 발주기관은 대금 전액 미지급과 입찰참가자격 제한을 동시에 확정하려 한다. 변경·외부수행·검사 단계의 판단과 조치를 쓰시오.

**변형 1.** 다른 사실은 모두 같고 외부수행자의 지위만 하수급인이 아니라 공동수급협정서에 기재된 공동수급 구성원으로 바뀌었다. 수행주체 판단에서 달라지는 부분을 쓰시오.

**수행동사 보강 소문항(4점·5분).** 원 사례의 계약 체결 시점으로 돌아가 용역 특화 계약조건표를 `영역 | 체결 때 확정할 조건 | 연동문서` 3열로 만들고 `과업·산출물 | 인력·수행주체 | 보안·권리 | 변경·검사·대금` 4행을 채우시오.

:::answer 모범답안·채점 보기
**모범답안.** 과업내용서·제안서 중 편입된 내용·협상결과와 최종 계약문서로 원래 과업을 확정하고, 구두 요청이 범위 밖 추가업무인지 먼저 판정한다. 추가업무라면 수행 전에 요청과 필요성, 기능·산출물 범위, 인력·가격·기간·검사기준 영향을 문서화하여 권한 있는 변경을 완료해야 하므로 승인 없는 선이행만으로 추가대가가 항상 확정되지는 않는다. 외부업체 수행은 실질적 용역위탁인지, 법령상 거래·당사자 범위와 계약상 금지·사전승인, 개별 업종 규정이 무엇인지 확인한 뒤 범위·금액·기간·산출물을 서면화한다. 수행 중에는 인력·보안·품질, 자료반환과 지식재산을 통제하고 원도급 변경을 외부수행 계약에도 연동한다. 일부 미흡은 계약문서에 따라 보완범위와 재검사를 정하고 미이행 정도에 맞춰 대금을 판단하며, 전액 미지급과 입찰참가자격 제한은 각각의 요건·절차 없이 자동 확정할 수 없다.

**변형 1 답.** 공동수급협정서상 구성원이라면 원수급자가 일부를 제3자에게 맡기는 하도급관계로 보지 않고, 협정의 분담·지분·대표자와 발주기관에 대한 공동 계약책임을 기준으로 관리한다. 다만 과업변경의 문서화, 구성원별 수행범위와 보안·품질·산출물 통제, 검사와 법적 효과의 분리 판단은 그대로 필요하다.

**수행동사 보강 답안.**

| 영역 | 체결 때 확정할 조건 | 연동문서 |
|---|---|---|
| 과업·산출물 | 과업범위, 단계별 산출물·형식·제출시점과 품질·검사기준 | 과업내용서, 제안서 중 편입내용, 협상결과, 산출물·검사표 |
| 인력·수행주체 | 핵심인력·역할, 공동수급 분담, 외부수행의 금지 여부·사전승인 여부와 보고조건 | 인력계획, 공동수급협정서, 하도급·외부수행 조건과 해당 승인서식 |
| 보안·권리 | 자료 접근·보관·반환·파기, 비밀유지, 산출물·지식재산의 귀속·이용범위 | 보안서약·관리계획, 자료대장, 권리조건, 인계·반환 확인서 |
| 변경·검사·대금 | 과업변경의 요청·영향검토·승인, 보완·재검사·인수와 대가 판단 절차 | 변경계약·회의록, 수정 과업·일정, 검사·인수·청구서류 |

**보강 채점(4점).** 네 영역마다 용역 특화 조건과 이를 계약문서에 고정할 연동문서를 맞게 쓰면 행별 1점이다. 계약 체결 때 과업·수행주체·보안·검사 기준선을 만든 뒤 이행·변경 단계에서 추적할 수 있어야 한다.

**자체 채점(10점).**

- 최종 계약문서로 원과업을 확정하고 구두 요청의 범위 밖 여부를 판정: 2점
- 기능·산출물·인력·가격·기간·검사 영향을 문서화하고 변경 전 합의: 2점
- 외부수행의 법률관계·법 적용범위·금지·사전승인을 확인하고 서면화: 2점
- 인력·보안·품질·자료반환·지식재산 통제를 제시: 2점
- 미흡부분의 보완·재검사·대금과 입찰제한을 별도 판정: 2점

### 오답 분류 체크

- [ ] **개념:** 과업기준선·변경·외부수행·검사와 법적 효과를 순서대로 연결하지 못했다.
- [ ] **혼동:** 하수급인과 공동수급 구성원을 같게 보거나 일부 미흡을 전액 미지급·입찰제한과 자동 연결했다.
- [ ] **숫자:** 추가기능의 인력·가격·기간 영향이 변경합의로 확정됐는지를 구분하지 못했다.
- [ ] **적용:** 구두 추가기능·사전승인 미확인·보안자료 접근·일부 미흡 사실에 각각 필요한 조치를 쓰지 못했다.

- **8~10점:** 하도급과 공동수급의 관계·문서·책임 차이를 3분 안에 재인출한다.
