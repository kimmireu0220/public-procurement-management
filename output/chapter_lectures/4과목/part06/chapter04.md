> 자체 제작 강의입니다. 공식 출제기준의 ‘대응계획 실행 확인·대응 결과 확인·신규 리스크 식별·결과 공유와 조치 제안’을 하나의 모니터링 순환으로 구성했습니다. 이 장의 상태코드, 지표 분류, 보고서·회의 서식은 **법정 공통기준이 아닌 학습·실무 도구**입니다. 실제 계약상 조치와 제재는 적용 법령·계약문서·권한 있는 절차로 따로 확정합니다.

## 이 강의 하나의 완료 기준

이 강의는 위험대응이 실제로 수행되고 효과가 있었는지 추적하며, 새 위험을 발견해 의사결정자에게 행동 가능한 정보로 전달하는 능력을 만듭니다. 다 읽은 뒤 다음을 할 수 있어야 합니다.

- 대응조치의 실행 여부와 위험감소 효과를 서로 다른 증거로 확인한다.
- 선행 위험지표와 후행 결과지표, 일정·성과지표를 구분한다.
- 발동조건을 관측하여 위험을 이슈로 전환하고 비상계획을 가동한다.
- 잔여위험, 대응으로 생긴 2차 위험, 환경변화에서 생긴 신규위험을 기록한다.
- 사실·추정·판단·결정을 구분한 모니터링 보고서를 작성한다.
- 결과를 공유하고 담당자·기한·승인·계약절차가 포함된 후속조치를 제안한다.

## 오늘의 실무 질문

진단장비 사업에서 공급자는 매주 재고와 선적 증빙을 제출하기로 했습니다. 담당자는 대응계획표의 ‘주간 확인’ 칸을 매번 완료로 표시했습니다. 하지만 실제 첨부파일은 두 주 전 자료를 반복한 것이고, 재고수량은 줄었으며, 운송예약 번호도 확인되지 않았습니다. 한편 임시장비를 준비하면서 기존 병원 네트워크와의 호환성 위험이 새로 생겼습니다.

회의 횟수와 확인 체크만 세면 대응은 완료된 것처럼 보입니다. 그러나 통제활동이 형식적으로 수행됐는지, 위험의 가능성과 영향이 실제로 줄었는지는 별개의 질문입니다. 또한 원래 위험만 바라보면 대체조치가 만든 호환성 위험을 놓칩니다.

## 공식 출제기준과 수행능력표

| 공식 수행능력 | 이 강의에서 할 일 | 결과물 |
|---|---|---|
| 리스크 대응계획의 실행 여부 확인 | 조치별 담당·기한·산출물·증빙을 대조 | 조치 이행대장 |
| 리스크 대응 결과 확인 | 지표와 재평가로 가능성·영향·잔여위험 변화 확인 | 위험 모니터링표 |
| 새로운 리스크 식별 | 변화·사건·통제실패·2차 효과에서 신규 위험 발견 | 신규위험 등록·분석 |
| 결과 공유 및 필요한 조치 제안 | 사실·판단·대안·승인요청을 대상별로 보고 | 모니터링 보고서·조치안 |

> 이 장은 Part 6의 마지막 순환입니다. 모니터링에서 발견된 신규위험은 다시 6-1에서 식별·분류하고, 6-2에서 평가하며, 6-3에서 대응계획을 세웁니다.

| 신규위험 | 환경·범위·공급자·법령 변화 등으로 새로 식별된 위험 | 기존 위험의 단순 명칭변경 |
| 이슈 | 위험사건이 실제 발생해 즉시 관리할 문제 | 아직 불확실한 위험 |

## 이 장의 자체 모니터링 순환

**수집 → 검증 → 비교 → 판정 → 조치 → 공유 → 갱신**

이 일곱 단계는 출제기준을 빠짐없이 수행하기 위해 이 강의가 만든 학습순서입니다. 법정 절차명이 아닙니다.

1. 정한 지표와 증빙을 수집합니다.
2. 자료의 출처·시점·완전성을 검증합니다.
3. 기준선·발동조건·이전 평가와 비교합니다.
4. 실행·효과·위험상태·신규위험을 판정합니다.
5. 유지·보완·발동·중단·계약검토 등 조치를 제안합니다.
6. 권한과 필요에 맞게 결과를 공유하고 승인을 요청합니다.
7. 위험등록부, 대응계획, 일정·계약 관련 기록을 갱신합니다.

## 1단계 모니터링 계획을 세운다

대응계획을 승인할 때 모니터링 방법도 함께 정합니다.

| 계획 항목 | 결정할 질문 | 예 |
|---|---|---|
| 대상 | 어떤 위험·조치·통제를 볼 것인가? | R-001 안전재고·운송예약 |
| 지표 | 무엇이 위험 변화를 보여주는가? | 확인 재고일수, 확정 선적증빙 |
| 기준선 | 정상·목표 상태는 무엇인가? | 승인된 납품일정 |
| 발동조건 | 언제 경보·비상조치를 시작하는가? | 확정 증빙 미제출 |
| 자료 | 출처·형식·기준일은 무엇인가? | 공급자 원본, 물류사 조회 |
| 주기 | 언제 정기·수시로 보는가? | 주간, 중대변경 즉시 |
| 책임 | 수집·검증·판정·승인은 누가 하는가? | 구매·기술·사업책임자 |
| 보고 | 누구에게 어떤 수준으로 알리는가? | 주간표·중대위험 수시보고 |
| 보존 | 판단과 원자료를 어디에 연결하는가? | 위험 ID별 증빙폴더 |

‘매주 확인’만 쓰면 무엇을 확인했는지 알 수 없습니다. 지표의 정의, 계산방법, 원자료, 허용되는 대체자료를 정합니다. 모든 위험에 같은 주기를 적용할 필요는 없습니다. 변화속도와 의사결정 마감에 맞춥니다.

## 2단계 조치 실행을 확인한다

조치가 완료됐다는 판정에는 최소한 다음이 필요합니다.

| 확인축 | 질문 |
|---|---|
| 내용 | 승인한 범위와 방법으로 수행했는가? |
| 담당 | 권한·역량 있는 담당자가 수행했는가? |
| 시점 | 기한 안에 완료했는가? |
| 산출물 | 약속한 문서·설비·계약·교육이 생겼는가? |
| 증빙 | 독립적으로 재확인 가능한 원자료가 있는가? |
| 승인 | 필요한 검토·승인을 받았는가? |
| 연계 | 일정·예산·계약·등록부에 반영했는가? |

공급자가 재고확인서를 보냈다는 사실은 ‘서류 수신’ 조치의 완료일 수 있습니다. 하지만 재고가 실제 존재하고 위험기간 동안 사용할 수 있는지는 재고 위치·수량·소유·예약상태 같은 추가 증거가 있어야 합니다.

### 학습용 조치상태

| 상태 | 뜻 |
|---|---|
| 미착수 | 승인됐으나 실행을 시작하지 않음 |
| 진행 | 일부 실행 중이며 완료증빙 없음 |
| 완료-미검증 | 산출물은 제출됐으나 내용·효과를 검증하지 않음 |
| 완료-검증 | 범위·기한·증빙·승인을 확인 |
| 지연 | 승인기한을 넘겼거나 의사결정 시점을 놓칠 우려 |
| 중단·대체 | 원 계획을 중단하고 승인된 대안으로 전환 |

이 상태명도 자체 관리도구입니다. 조직의 공식 상태코드가 있으면 그것을 사용합니다.

## 3단계 대응 결과와 효과를 확인한다

### 지표 세 가지

| 구분 | 질문 | 진단장비 예 |
|---|---|---|
| KRI 성격의 위험지표 | 위험이 커지고 있는가? | 안전재고 감소, 선적예약 미확정 |
| 통제 이행지표 | 대응조치가 작동하는가? | 증빙 제때 제출·검증 비율 |
| 성과지표 | 조달목표를 달성하는가? | 납품·설치·검사 일정 준수 |

위 명칭은 이해를 위한 일반적 구분이며 법정 용어체계가 아닙니다. 회의 4회 개최는 통제활동 지표일 수 있지만 납기위험 감소를 직접 증명하지 않습니다.

### 효과판정 순서

1. 조치 전 가능성·영향·노출 기준선을 확인합니다.
2. 조치가 원인·영향에 작동한다는 인과경로를 확인합니다.
3. 최신 원자료로 지표 변화를 봅니다.
4. 다른 원인이나 계절효과가 결과를 만든 것은 아닌지 검토합니다.
5. 잔여위험과 판단확신도를 다시 평가합니다.
6. 목표 수준에 미달하면 보완·대체·비상계획 발동을 제안합니다.

대응 후 위험점수를 다시 계산할 수 있지만 6-2의 승인된 척도를 그대로 사용해야 합니다. 평가에 불리하다고 등급 경계를 바꾸면 추세 비교가 깨집니다.

## 4단계 발동조건과 이슈 전환

발동조건이 충족되면 다음을 확인합니다.

1. 자료 오류가 아닌 실제 조건 충족인지 검증합니다.
2. 위험사건이 이미 발생했으면 위험을 이슈로 전환합니다.
3. 6-3의 비상계획과 승인·연락체계를 가동합니다.
4. 안전·서비스 보호와 증거보존을 우선합니다.
5. 계약변경·기간연장·대체품·해지 등은 별도 공식 절차를 검토합니다.
6. 원 위험은 사건 처리 중에도 잔여·재발 가능성을 추적합니다.

시스템 경보나 공급자 통보는 중요한 증거이지만 그 자체로 귀책·손해·지체상금·제재를 모두 확정하지 않습니다. 사실, 원인, 계약상 책임, 행정처분 요건을 분리합니다.

## 5단계 새로운 위험을 식별한다

신규위험 탐색은 정기회의의 마지막 질문이 아니라 모든 변경의 필수 점검입니다.

| 변화원천 | 질문 | 예 |
|---|---|---|
| 범위·규격 변경 | 새 기술·품질·검사 위험이 생겼는가? | 대체부품 호환성 |
| 일정·예산 변경 | 여유 감소·추가비용 위험이 생겼는가? | 긴급운송 예산부족 |
| 공급자 변화 | 재무·인력·하도급 구조가 달라졌는가? | 물류사 교체 |
| 법령·공고 변화 | 새로운 의무·자격·기한이 있는가? | 인증 기준 변경 |
| 시스템·데이터 변화 | 전자처리·보안·자료품질 위험이 생겼는가? | 연계 오류 |
| 사건·근접사고 | 발생하지 않은 손실의 선행징후가 있었는가? | 시험 중 간헐 장애 |
| 대응조치 | 대안이 만든 2차 위험이 있는가? | 임시장비 네트워크 충돌 |

새 위험은 6-1의 원인-사건-영향 문장으로 등록하고, 6-2 평가를 거쳐, 6-3 대응을 승인받습니다. 긴급한 경우 안전·서비스 보호를 먼저 하되 사후 기록과 정식 절차를 생략하지 않습니다.

### 중복과 변화 구분

- 원인이 같고 영향 범위만 넓어진 경우: 기존 위험을 갱신할 수 있습니다.
- 책임자·대응·발동조건이 실질적으로 다른 경우: 별도 위험으로 나눌 수 있습니다.
- 위험이 발생한 경우: 이슈 기록을 만들고 원 위험의 재발·잔여상태를 갱신합니다.
- 대응이 새 위험을 만든 경우: 2차 위험으로 연결 관계를 표시합니다.

## 6단계 결과를 공유하고 조치를 제안한다

좋은 보고는 많은 데이터를 붙이는 것이 아니라 의사결정에 필요한 차이를 보여줍니다.

| 보고요소 | 작성방법 |
|---|---|
| 사실 | 출처·기준일이 있는 관측내용 |
| 기준 | 계획·발동조건·계약문서 중 비교기준 |
| 차이 | 정상·목표와 현재 상태의 격차 |
| 판단 | 실행·효과·잔여·신규 위험의 잠정결론 |
| 불확실성 | 자료공백·상충·확신도 |
| 대안 | 유지·보완·대체·발동·중단 선택지 |
| 제안 | 권고안, 담당자, 기한, 필요자원 |
| 승인요청 | 누가 무엇을 결정해야 하는가 |
| 법률절차 | 계약변경·통지·제재 검토가 필요한가 |

사실과 판단을 문장상 구분합니다. “운송예약 증빙이 8월 24일 현재 확인되지 않았다”는 사실이고, “납기위험이 높아졌다”는 승인척도에 따른 판단입니다. “계약상대자 귀책으로 해지해야 한다”는 별도 사실·법률검토와 권한 있는 결정을 요구합니다.

## 필답형 답안 프레임

모니터링형 문제는 **계획 → 수집·검증 → 실행 → 효과 → 신규 → 공유 → 조치·갱신** 순으로 씁니다.

1. 위험·조치별 지표, 기준선, 발동조건, 자료, 주기, 책임자를 정한다.
2. 최신 원자료를 수집하고 출처·시점·완전성을 검증한다.
3. 조치 수행과 증빙을 확인한다.
4. 가능성·영향·잔여위험 변화로 효과를 확인한다.
5. 발동조건·이슈 전환과 신규·2차 위험을 판정한다.
6. 사실·판단·불확실성·대안을 대상별로 공유한다.
7. 담당·기한·승인·계약절차를 포함한 조치를 제안하고 등록부를 갱신한다.

## 자체 제작 연습문제 10선

### 문제

**문제 1.** O/X: 대응조치 문서가 제출되면 위험감소 효과도 확인된 것이다.

> **정답·해설:** **X.** 산출물 제출과 가능성·영향 감소는 별도 증거로 확인한다. 1점.

**문제 2.** O/X: 회의 개최 횟수는 언제나 위험감소를 직접 보여주는 지표다.

> **정답·해설:** **X.** 회의는 활동지표일 수 있으나 위험감소를 직접 증명하지 않을 수 있다. 1점.

**문제 3.** O/X: 위험사건이 발생하면 귀책·해지·입찰제한도 동시에 확정된다.

> **정답·해설:** **X.** 발생 사실, 귀책, 계약상 효과, 제재사유·처분절차는 별도다. 1점.

**문제 4.** 모니터링 순환 일곱 단계를 쓰시오.

> **정답·해설:** 수집, 검증, 비교, 판정, 조치, 공유, 갱신. 각 0.5점, 총 3.5점.

**문제 5.** 모니터링 계획의 항목 여섯 가지를 쓰시오.

> **정답·해설:** 대상, 지표, 기준선, 발동조건, 자료, 주기, 책임, 보고, 보존 중 여섯 가지. 각 0.5점, 3점.

**문제 6.** 조치 실행 확인과 효과 확인의 차이를 사례로 설명하시오.

> **정답·해설:** 재고서류 수신은 실행, 실재고 증가와 지연 가능성 감소는 효과처럼 구분하면 3점.

**문제 7.** 선행 위험지표, 통제 이행지표, 성과지표를 각각 하나씩 예로 드시오.

> **정답·해설:** 재고감소·예약미확정, 증빙 검증률, 납품일정 준수처럼 성격에 맞는 예를 각각 쓰면 3점.

**문제 8.** 신규위험을 찾는 변화원천 다섯 가지를 쓰시오.

> **정답·해설:** 범위·규격, 일정·예산, 공급자, 법령, 시스템·데이터, 사건, 대응조치 중 다섯 가지. 각 0.5점, 2.5점.

**문제 9.** 진단장비 사례의 관측자료를 사실·판단·제안으로 나누어 보고하시오.

> **정답·해설:** 반복·감소 자료와 예약 미확인을 사실 1점, 위험 상승·확신도 한계를 판단 2점, 독립확인·재평가·비상·호환성 신규등록을 제안 2점. 총 5점.

**문제 10.** 결과 공유 시 계약상 조치와 행정제재를 어떻게 다뤄야 하는지 쓰시오.

> **정답·해설:** 계약변경·해지·제재는 사실·귀책·법적 요건과 권한 있는 절차를 별도 검토한다고 쓰면 3점.

총점은 26점입니다. 22점 이상은 수행능력 충족, 17~21.5점은 모니터링표를 다시 작성, 16.5점 이하는 실행과 효과 구분부터 복습합니다.
