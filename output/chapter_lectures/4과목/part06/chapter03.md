> 자체 제작 강의입니다. 공식 출제기준의 ‘대응계획 수립·적정성 평가·계획하지 못한 리스크의 비상계획 수립’을 학습 가능한 절차와 서식으로 구성했습니다. 이 장의 전략 분류, 적정성 질문과 서식은 **법정 공통기준이 아닌 학습·실무 도구**입니다. 계약변경·기간연장·대금·해제·해지·제재의 효력은 반드시 적용 법령과 실제 계약문서로 별도 판단합니다.

## 이 강의 하나의 완료 기준

이 강의는 평가된 위험을 실제 행동계획으로 바꾸고, 계획이 충분한지 검토하며, 예상하지 못한 위험이 현실화됐을 때의 비상대응을 준비하는 능력을 만듭니다. 다 읽은 뒤 다음을 할 수 있어야 합니다.

- 위험별로 회피·감소·이전·공유·수용 중 목적에 맞는 전략을 선택한다.
- 예방조치, 발생징후, 발동조치, 담당자, 기한, 자원, 증빙을 한 표에 적는다.
- 대응책의 적법성·인과성·실행성·경제성·시간성·잔여위험을 평가한다.
- 위험을 다른 당사자에게 이전해도 발주기관·계약상대자의 책임이 자동 소멸하지 않음을 설명한다.
- 계획 밖 위험의 비상대응에서 안전·서비스·증거·권한·소통·복구를 관리한다.
- 대응계획과 정식 계약변경, 법적 권리·의무, 행정제재를 구분한다.

## 오늘의 실무 질문

진단장비 사업에서 핵심부품 선적지연 위험이 1순위로 평가되었습니다. 담당자는 대응란에 “공급자에게 책임 전가, 지연 시 계약해지”라고 적었습니다. 대체부품 후보의 규격도, 승인 소요기간도, 재고도 조사하지 않았습니다. 어느 날 해외항만이 갑자기 폐쇄되어 원래 등록하지 않았던 운송중단 위험까지 현실화됐습니다.

이 계획은 실행할 수 없습니다. 책임을 적는 것과 위험을 줄이는 조치는 다르고, 계약해지도 위험이 발생하면 자동으로 행사되는 버튼이 아닙니다. 누가 언제 무엇을 어떤 근거로 할지, 그 조치가 원인 또는 영향을 실제로 줄이는지, 실패하면 어떤 대안을 발동할지를 적어야 합니다.

## 공식 출제기준과 수행능력표

| 공식 수행능력 | 이 강의에서 할 일 | 결과물 |
|---|---|---|
| 식별·평가한 리스크의 대응계획 수립 | 전략, 예방·발동조치, 담당자·기한·자원·증빙을 설계 | 위험 대응계획 |
| 대응계획의 적정성 평가 | 법적 허용, 원인감소, 실행가능, 비용·기간, 잔여·2차 위험 검토 | 적정성 검토표 |
| 계획하지 못한 리스크의 대응계획 수립 | 탐지·초동조치·권한·대체운영·소통·복구 절차 마련 | 비상대응 카드 |

> 범위 경계: 6-3은 무엇을 할지 설계하고 승인합니다. 실제 조치가 실행됐는지, 결과가 어땠는지, 새로운 위험이 생겼는지는 6-4에서 모니터링합니다.

## 먼저 구분할 여덟 용어

| 용어 | 뜻 | 혼동 금지 |
|---|---|---|
| 대응전략 | 위험을 다루는 큰 방향 | 구체적인 실행조치 |
| 예방조치 | 위험 발생가능성을 낮추는 사전 행동 | 사건 발생 후 복구 |
| 영향완화 | 사건 발생 시 피해를 줄이는 준비 | 원인을 없애는 조치 |
| 발동조건 | 준비한 조치를 실제 시작할 관측 기준 | 막연한 불안 |
| 비상계획 | 예상 위험이 발생하거나 기존 대응이 실패할 때의 대안 | 모든 위험의 일반 문구 |
| 잔여위험 | 대응 후에도 남을 것으로 예상하는 위험 | 반드시 0이 되는 값 |
| 2차 위험 | 대응조치가 새로 만드는 위험 | 원래 위험의 잔여부분 |
| 위험수용 | 근거와 책임 아래 현재 위험을 받아들이는 결정 | 아무것도 하지 않는 방치 |

## 1단계 대응전략을 선택한다

다음 분류는 이 강의의 학습도구입니다.

| 전략 | 뜻 | 공공조달 예시 | 주의 |
|---|---|---|---|
| 회피 | 위험을 만드는 범위·방법을 제거 | 검증 불가능한 기능을 필수규격에서 제외 | 사업목표 훼손 여부 |
| 감소 | 가능성 또는 영향을 낮춤 | 사전 현장조사, 안전재고, 단계검사 | 통제효과 증거 필요 |
| 이전 | 재무·업무 부담 일부를 계약·보험 등으로 배분 | 운송보험, 보증 | 법적 책임 전체 소멸 아님 |
| 공유 | 여러 당사자가 정보·자원·조치를 분담 | 공동 비상물류 계획 | 권한·비용·책임 명확화 |
| 수용 | 현재 수준을 승인하고 감시·비상계획 유지 | 낮은 위험의 정기 관찰 | 승인자·근거·발동조건 필요 |

‘공급자 책임’이라는 계약조항은 손해와 책임을 배분할 수 있지만 병원 개원 지연 자체를 막지는 못할 수 있습니다. 위험 원인을 줄이는 안전재고·대체운송과 영향을 줄이는 임시장비·단계개원 같은 조치를 함께 검토합니다.

### 전략을 고르는 다섯 질문

1. 위험의 원인과 영향 중 무엇을 바꾸려는가?
2. 조치가 사업목표와 법령·계약에 허용되는가?
3. 사건이 발생하기 전에 완료할 수 있는가?
4. 조치비용과 예상 위험감소가 균형을 이루는가?
5. 조치가 실패하거나 새 위험을 만들면 어떤 대안이 있는가?

## 2단계 실행 가능한 대응계획을 쓴다

좋은 대응계획은 동사와 증거가 있습니다. “철저히 관리” 대신 “공급자에게 매주 금요일 재고·생산·선적 증빙을 제출받아 구매담당자가 확인한다”고 씁니다.

| 필드 | 작성 질문 |
|---|---|
| 위험 ID·목표 | 어떤 위험과 목표를 다루는가? |
| 선택전략·이유 | 왜 이 전략이 적합한가? |
| 예방조치 | 발생가능성을 무엇으로 낮추는가? |
| 영향완화 | 발생 시 피해를 무엇으로 줄이는가? |
| 담당·승인 | 누가 실행하고 누가 승인하는가? |
| 시작·완료 | 언제 시작하고 언제까지 끝내는가? |
| 자원·예산 | 사람·예산·기술·계약권한이 있는가? |
| 발동조건 | 어떤 관측값이면 비상조치를 시작하는가? |
| 성과·증빙 | 효과를 무엇으로 확인하는가? |
| 잔여·2차 위험 | 무엇이 남고 새로 생기는가? |
| 비상계획 | 주 대응이 실패하면 무엇을 하는가? |

발동조건은 관측 가능해야 합니다. 예를 들어 “선적 예정일 7일 전까지 선하증권 또는 확정 운송예약 증빙이 없으면 대체운송 검토를 발동”처럼 씁니다. 여기의 7일은 사례용 운영기준일 뿐 모든 계약의 법정기한이 아닙니다.

## 3단계 대응을 세 층으로 설계한다

| 층 | 목적 | 진단장비 예시 |
|---|---|---|
| 예방 | 사건 가능성 감소 | 국내 안전재고 확인, 생산·선적 증빙, 이중 운송경로 |
| 완화 | 발생 시 영향 감소 | 임시장비, 단계 설치, 개원 우선구역 선정 |
| 회복 | 서비스와 정상상태 복원 | 재납기 합의, 검사·설치 재계획, 원인분석 |

계약조항, 보증, 보험은 중요한 통제지만 실제 공급 연속성을 보장하는 운영조치와 함께 봅니다. 한 조치가 여러 위험에 공통으로 작동하면 통합조치로 관리하되 각 위험의 잔여효과를 따로 평가합니다.

## 4단계 계약·법률 조치를 분리한다

리스크 대응계획에 “기간연장”, “대체품 사용”, “계약금액 증액”, “해지”를 적었다고 법적 효력이 생기지 않습니다.

| 계획상 아이디어 | 정식으로 확인할 사항 |
|---|---|
| 납품기한 연장 | 지연원인·귀책, 통지·신청, 계약조건, 변경권한 |
| 대체 규격·품목 | 동등성, 검사·인증, 수요기관 필요, 승인·변경 |
| 계약금액 조정 | 국가·지방계약법령과 계약조건상 조정사유·산식·청구 |
| 업무 추가·삭제 | 범위·가격·기간·산출물 변경과 계약담당자 승인 |
| 하도급·대체업체 | 허용·승인, 자격, 하도급법·개별법 적용 |
| 공사·용역 정지 | 정지사유, 지시권한, 기간·비용 효과 |
| 해제·해지 | 계약상 사유, 이행최고·통지 등 필요한 절차 |
| 입찰참가자격 제한 | 법정 제재사유와 처분권자·절차·소명 |

보험이나 보증으로 손실 일부를 이전해도 발주기관의 공공서비스 책임이나 계약상대자의 이행의무가 자동으로 사라지지 않습니다. 반대로 위험이 발생했다는 이유만으로 계약상대자에게 모든 비용을 전가할 수도 없습니다. 원인·귀책·계약문서를 확인합니다.

## 5단계 대응계획의 적정성을 평가한다

다음 여덟 질문은 이 강의가 만든 적정성 검토도구입니다.

| 검토축 | 질문 | 부적정 신호 |
|---|---|---|
| 적법성 | 법령·계약·권한 범위 안인가? | 승인 없는 규격변경 |
| 인과성 | 위험 원인 또는 영향을 실제로 줄이는가? | 책임전가 문구만 있음 |
| 실행성 | 담당자·자원·기술·정보가 있는가? | 담당자 미정 |
| 시간성 | 선택지가 사라지기 전에 완료되는가? | 납기 후 대체조사 |
| 경제성 | 비용과 위험감소가 균형적인가? | 감소효과보다 비용이 큼 |
| 측정성 | 완료와 효과를 증빙할 수 있는가? | ‘철저히 관리’ |
| 잔여·2차 | 남는 위험과 새 위험을 평가했는가? | 대체품 품질위험 누락 |
| 정합성 | 다른 위험·계획·계약변경과 충돌하지 않는가? | 일정·예산표 불일치 |

각 질문을 충족·보완·부적정으로 판정하고 보완 담당·기한을 정합니다. 점수화를 원하면 기관이 척도와 승인기준을 정해야 하며, 이 강의는 법정 합격점수를 만들지 않습니다.

### 대응효과를 과장하지 않는다

“대체공급자 조사 완료”는 정보수집 성과이지 공급계약과 재고가 확보됐다는 뜻이 아닙니다. “보험 가입”은 재무손실 완화일 수 있으나 납기 회복 효과는 없을 수 있습니다. 계획의 산출물과 위험감소 효과를 구분합니다.

## 6단계 계획 밖 위험의 비상대응

모든 사건을 사전에 예측할 수는 없습니다. 비상계획은 특정 위험명보다 공통 대응능력을 준비합니다.

### 비상대응 여덟 단계

1. **탐지·확인:** 사실, 시각, 출처, 영향범위를 잠정 확인한다.
2. **안전·서비스 보호:** 생명·안전과 필수 공공서비스를 우선 보호한다.
3. **권한·지휘:** 의사결정자, 계약담당자, 기술·법무 연락체계를 가동한다.
4. **확산 억제:** 추가 손실·오류·정보유출·일정연쇄를 막는 임시조치를 한다.
5. **증거 보존:** 시스템 기록, 공문, 사진, 계약·검사 자료를 보존한다.
6. **대안 평가:** 임시공급, 대체절차, 일정재배치의 적법성·효과를 비교한다.
7. **소통·승인:** 사실과 불확실성을 구분해 권한 있는 자에게 보고하고 승인받는다.
8. **복구·학습:** 정상화, 계약정리, 원인분석, 등록부·계획 갱신을 한다.

안전상 긴급조치가 필요한 경우 생명·신체 보호를 지연시키지 않습니다. 다만 긴급조치 이후에도 지시·판단·비용·계약변경을 문서화합니다. 구체적인 신고·보고 기한은 사건에 적용되는 법령과 기관 비상계획을 따릅니다.

### 비상대응 카드에 들어갈 것

| 항목 | 작성 내용 |
|---|---|
| 발동 사건·확인방법 | 무엇을 누가 사실로 확인하는가 |
| 최우선 보호대상 | 사람·서비스·정보·자산 |
| 지휘·연락망 | 의사결정·계약·기술·홍보 담당 |
| 즉시 중지·허용 행위 | 안전·증거·권한 기준 |

## 필답형 답안 프레임

대응형 문제는 **위험 → 전략 → 조치 → 발동 → 검증 → 비상 → 법률절차** 순으로 씁니다.

1. 위험의 원인·사건·영향과 평가결과를 제시한다.
2. 회피·감소·이전·공유·수용 중 전략과 이유를 쓴다.
3. 예방·영향완화 조치, 담당자·기한·자원·증빙을 정한다.
4. 관측 가능한 발동조건과 비상계획을 둔다.
5. 적법성·인과성·실행성·시간성·잔여위험을 검토한다.
6. 계획 밖 사건의 초동·소통·복구 절차를 제시한다.
7. 계약변경·해지·제재는 공식 요건과 절차를 별도 확인한다.

## 정답·해설과 채점기준

1. **X.** 위험 일부를 배분해도 법령·계약상 책임과 서비스 영향이 자동 소멸하지 않는다. 1점.

3. **X.** 기간연장 사유와 권한, 통지·신청, 정식 계약변경이 필요하다. 1점.
4. 각 전략의 핵심을 맞히면 각 0.5점, 총 2.5점.
5. 위험·전략, 예방, 완화, 담당·기한, 자원, 발동, 증빙, 잔여·2차, 비상 중 여섯 가지. 각 0.5점, 3점.

8. 확인, 안전·서비스, 지휘, 확산억제, 증거, 대안, 소통, 복구 중 여섯 단계. 각 0.5점, 3점.
9. 구체조치·담당·기한·증빙·발동이 없고 해지가 자동효과가 아니라는 지적 2점, 재고·대체운송·임시장비·정식 계약절차 보완 2점. 총 4점.
10. 위험·이슈 전환 1점, 비상 초동 1점, 대체안 비교 1점, 승인·계약변경 1점, 잔여·2차 위험 1점, 소통·증거·복구 1점. 총 6점.
