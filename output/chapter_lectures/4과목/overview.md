> 이 과목은 한국산업인력공단의 2026~2028년 적용 출제기준을 8개 Part, 25개 Chapter, 91개 수행능력으로 전개한 자체 제작 강의입니다. 조달청 표준교재를 학습 기준자료로 사용하고, 바뀔 수 있는 숫자·법적 효과는 2026년 8월 24일 현재 공식 원문과 구분해 확인했습니다.

## 이 과목의 최종 목표

4과목은 조달 지식을 기억하는 데서 끝나지 않습니다. 입찰기회를 찾고, 참가자격을 갖추고, 계획·입찰·계약·이행·분쟁을 관리하며, 전자조달과 데이터를 이용하는 전 과정을 **문서로 판단하고 설명하는 능력**을 평가합니다.

모든 사례형 답안은 다음 여섯 질문으로 정리할 수 있습니다.

1. 지금 어느 단계인가?
2. 누가 무엇을 해야 하는가?
3. 적용 근거와 공고·계약조건은 무엇인가?
4. 어떤 사실·자료·증빙을 확인해야 하는가?
5. 판단과 조치는 무엇인가?
6. 결과와 후속기한을 어떤 문서로 남길 것인가?

## 세 번 읽는 방법

### 1회독: 흐름과 구분

- 각 장의 시작사례와 핵심 절차를 읽는다.
- `A와 B는 다르다`는 비교표를 표시한다.
- 숫자는 외우기 전에 적용기관·계약유형·시행일을 확인한다.
- 장 끝 암기카드를 가리고 말한다.

### 2회독: 산출물과 답안

- 완성 예시를 본 뒤 빈 서식을 직접 채운다.
- 절차형은 `주체 → 행위 → 문서 → 기준 → 결과`로 쓴다.
- 사례형은 `결론 → 근거 → 사실 적용 → 조치`로 쓴다.
- 계산형은 산식, 입력값의 출처, 단위, 공고별 적용 여부를 함께 적는다.

### 3회독: 무자료 문제풀이

- 각 장의 문제를 시간 안에 푼다.
- 정답만 맞히지 말고 채점요소별 누락을 표시한다.
- 틀린 원인을 `개념 혼동`, `순서 누락`, `근거·기준일 누락`, `사실 적용 부족`, `계산 오류`로 분류한다.
- 24시간·3일·7일 뒤 틀린 문제만 다시 푼다.

## 시험 답안의 공통 뼈대

### 절차형 5요소

`주체 → 입력자료 → 확인·수행행위 → 판정기준 → 산출물·후속조치`

예: “계약담당자는 계약서·설계서와 완료통지를 검토하고 검사기준에 따라 이행완료 여부를 판정한 뒤 검사조서와 보완·대금청구 후속일정을 관리한다.”

### 사례형 4문장

1. 결론: 가능, 보완 필요, 불가 또는 위험수준을 먼저 쓴다.
2. 기준: 적용 법령·공고·계약조건과 판단요건을 쓴다.
3. 적용: 제시된 사실을 요건별로 대조한다.
4. 조치: 문서, 담당자, 기한, 재확인과 대안을 쓴다.

### 비교형 5칸

`목적 / 적용대상 / 요건 / 절차·증빙 / 효과·위험`

제도명만 나열하거나 “관련 규정에 따라 처리한다”로 끝내면 수행능력이 드러나지 않습니다.

## 숫자와 법령을 공부하는 원칙

| 구분 | 처리 원칙 |
|---|---|
| 법령상 숫자 | 적용 조문·기관·계약유형·시행일과 함께 학습 |
| 공고별 숫자 | 해당 공고의 예시임을 표시하고 다른 공고에 일반화하지 않음 |
| 교재 사례값 | 계산 훈련에만 사용하고 현행 규정과 충돌 여부 확인 |
| 시스템 운영값 | 최신 공지·매뉴얼에서 재확인 |
| 자체 평가척도 | 법정 기준이 아닌 학습·관리도구임을 표시 |

표준교재와 현행 규정이 다르면 둘 중 하나를 숨기지 않습니다. `교재의 시험 학습 맥락`, `현행 시행본`, `실제 공고 적용`을 분리해 기록합니다.
