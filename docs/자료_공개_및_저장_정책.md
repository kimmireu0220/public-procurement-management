# 자료 공개 및 저장 정책

이 저장소는 공개 GitHub 저장소다. Git이 추적하는 파일은 GitHub Pages 배포 여부와
관계없이 외부에서 열람할 수 있다는 전제에서 자료를 관리한다.

## 공개 범위

| 구분 | 저장 위치 | 공개 원칙 |
|---|---|---|
| 학습용 공개본 | `docs/` | 공개 권한을 확인한 자체 정리·문제·해설만 GitHub Pages에 배포한다. 제3자 원문은 복제하지 않는다. |
| 작업 산출물 | `output/` | 저장소에서는 공개될 수 있다. 제3자 원문이나 배포 제한 자료를 포함하지 않는다. |
| 공식 근거 자료 | `sources/공식_*`, `sources/현행_법령_근거/` | 출처·수집일을 기록하고 제공기관의 이용조건을 확인한 자료만 Git에 둔다. Pages에는 배포하지 않는다. |
| 민간 수험서 스캔 | `sources/민간_박문각_수험서_jpg/` | 로컬 전용이다. Git과 Pages에서 제외한다. |

Pages workflow는 `docs/`만 업로드한다. 빌드 도구가 `sources/` 또는 원본 이미지를
`docs/`로 복사하도록 변경해서는 안 된다.

## 저작권과 출처

- 박문각 등 민간 교재의 저작권은 해당 권리자에게 있다. 구매·보유 사실만으로
  재배포 권한이 생기지 않으므로 스캔 원본은 커밋하지 않는다.
- 조달청, Q-Net, 국가법령정보센터 자료도 각 제공기관의 이용조건과 공공저작물
  표시를 개별 확인한다. 저장소에 별도 라이선스가 없다는 이유로 제3자 자료까지
  자유 이용할 수 있는 것은 아니다.
- 현행 규정을 인용하거나 값을 병기할 때에는
  `sources/현행_법령_근거/manifest.json`의 URL·시행일·버전·수집일을 남긴다.
- 학습자료의 시험 기준은 조달청 표준교재다. 현행값은 `현행(시행일)`로 구분하며
  표준교재 기준을 지우거나 대체하지 않는다.

## 대용량 파일

- 공식 PDF와 최종 강의 MP3는 Git LFS로 관리한다.
- 민간 교재 JPG는 LFS에도 올리지 않고 로컬 전용으로 유지한다.
- 민간 교재 JPG의 경로·크기·SHA-256만 `inventory.json`으로 추적한다. 로컬 원본이
  있으면 검증기가 전수 해시를 확인하고, CI에서는 메타데이터와 문제 출처 경로를 확인한다.
- HTML, Markdown, JSON, Python처럼 검토 가능한 텍스트는 일반 Git으로 관리한다.
- 새 바이너리를 추가하기 전에 공개·재배포 권한, 필요성, 파일 크기를 확인한다.

```bash
git lfs install
git lfs pull
python3 tools/private_source_inventory.py
python3 tools/verify_legal_sources.py
```

민간 스캔이 과거 커밋에 포함됐던 이력이 있다면 현재 브랜치에서 삭제하는 것만으로
기존 Git 객체가 사라지지는 않는다. 이력 제거는 백업, 협업자 공지, Pages 재배포를
준비한 뒤 별도의 승인된 history rewrite로 수행한다.
