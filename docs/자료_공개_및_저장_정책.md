# 자료 공개 및 저장 정책

이 저장소는 공개 GitHub 저장소다. `docs/` 배포 여부와 관계없이 Git이 추적하는 파일은
외부에서 열람될 수 있다고 본다.

## 필수 규칙

- 공식기관 자료도 자동으로 재배포 가능한 것은 아니다. 제공기관의 이용조건과 표시 의무를
  확인하고 필요한 출처·수집일·기준일을 남긴다.
- 음성·이미지·PDF 등 바이너리는 내용과 크기뿐 아니라 참조 자료, 화자와 결과물의 공개
  권한까지 확인한 뒤 게시한다.
- 현행 규정을 인용하거나 기준값으로 쓸 때는 공식 원문과 시행일을 확인하여 표준교재의
  시험 기준과 혼동되지 않게 한다.
- 민감하거나 권리 상태가 불분명한 자료를 Git 이력에서 제거하는 작업은 영향이 크므로,
  대상과 백업·협업 영향을 확인하고 사용자의 명시적 승인을 받은 뒤 수행한다.

## 위치와 도구

현재 프로젝트는 대체로 다음 위치를 사용하지만, 권리 보호가 유지되는 한 작업 구조는
바꿀 수 있다.

| 위치 | 일반적인 용도 |
|---|---|
| `docs/` | 공개 가능한 GitHub Pages 산출물 |
| `output/` | 작업 산출물; Git 추적 시 공개 자료로 취급 |
| `sources/공식_*`, `sources/현행_법령_근거/` | 이용조건을 확인한 공식 근거 자료 |

대용량 공개 가능 파일에는 Git LFS를 사용할 수 있고, 저장 자료의 존재와 변조 여부를
확인하려면 인벤토리 도구를 사용할 수 있다.

```bash
python3 tools/private_source_inventory.py
python3 tools/verify_legal_sources.py
```

이 도구들은 저장된 파일과 메타데이터의 무결성을 확인한다. 자료의 최신성이나 재배포
권한까지 자동으로 보증하지는 않는다.
