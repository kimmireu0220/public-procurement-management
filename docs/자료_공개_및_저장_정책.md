# 자료 공개 및 저장 원칙

이 저장소에서 Git이 추적하는 파일은 `docs/` 배포 여부와 관계없이 공개 자료로 취급한다.

- 새 원문·문항·해설·이미지·PDF를 추가하거나 재배포할 때 제공기관과 권리자의 이용조건을
  확인하고 필요한 출처·수집일·기준일을 남긴다.
- 현행 규정을 인용하거나 기준값으로 쓸 때는 공식 원문과 시행일을 확인하고, 조달청
  표준교재의 시험 기준과 혼동되지 않게 한다.
- 민감하거나 권리 상태가 불분명한 자료의 Git 이력을 변경하는 작업은 대상과 협업 영향을
  확인한 뒤 사용자의 명시적 요청으로 수행한다.

`tools/private_source_inventory.py`와 `tools/verify_legal_sources.py`는 저장 파일과
메타데이터의 대응 및 무결성을 검사한다. 자료의 최신성이나 재배포 권한까지 보증하지는 않는다.
