이 강의는 Q-Net 2과목 세부항목 입찰·제안요청 설명의 두 세세항목인 입찰설명회 참석과 입찰 및 제안준비에 필요한 정보 식별 및 요청을 다루는 자체 제작 강의입니다. 조달청 표준교재 2권 인쇄면 192~193쪽을 학습 기준으로 삼되, 설명회 개최·참석의 효력과 질문·답변의 반영은 2026년 8월 25일 현재 적용되는 공식 규정과 개별 공고를 따로 확인합니다.

이 강의의 완료 기준

  1. 입찰설명회·현장설명·제안요청 설명과 제안서 평가 발표를 구분한다.
  2. 설명회 개최와 참석이 언제나 의무라는 단정을 피하고 공고의 참가조건을 판별한다.
  3. 공고·제안요청서·규격서·과업내용서·설계서·계약조건에서 필요한 정보를 식별한다.
  4. 법적·기술적·경제적·일정·평가·제출 질문을 근거 조항과 함께 작성한다.
  5. 구두 답변과 공식 서면 정정·추가안내의 효력을 구분한다.
  6. 설명회 이후 질문·답변·정정사항을 제안서와 참가결정에 추적 반영한다.

1. 설명회는 입찰문서를 대신하지 않는다

입찰설명회는 공고 후 잠재적 입찰자에게 구매규격·과업·설계·계약절차를 설명하고 질의를 받는 정보교환 단계입니다. 복잡한 공사에서는 현장조건을 확인하는 현장설명, 지식·기술 중심 용역에서는 제안요청서 설명이라는 이름을 쓸 수 있습니다.

그러나 설명회에서 들은 말만으로 입찰조건이 확정되는 것은 아닙니다. 공급자는 다음 순서로 근거를 관리해야 합니다.

유효한 공고와 첨부문서 → 공식 정정공고·추가안내 → 공개된 질의답변·회의록 → 설명회에서 얻은 보조정보

설명자의 즉석 답변이 공고문과 충돌하면 어느 쪽이 맞다고 임의로 고르지 않습니다. 질문을 서면으로 다시 제출하고 정정공고·수정 제안요청서처럼 모든 참가자에게 공개되는 공식 문서를 확인합니다.

2. 비슷한 행사를 구분한다

구분 시점·목적 공급자의 핵심 행동
입찰설명회 공고 후 입찰조건·요구사항 설명 참가조건·제출·계약위험 확인
현장설명·현장방문 공사·설치 장소와 현장조건 확인 접근·물량·안전·작업제약 기록
제안요청서 설명 복잡한 물품·용역의 RFP 이해 지원 과업·평가·제안형식·협상범위 확인
사전규격 의견수렴 공고 전 규격·과업의 경쟁성·적정성 검토 부당제한·모순·개선의견 제출
정보제공요청·업계간담회 시장조사 단계의 정보수집 사실·대안·시장정보 제공
제안서 평가 발표 제안서 제출 후 평가위원에게 제안내용 설명 제출한 제안의 범위 안에서 발표·답변

특히 제안요청서 설명과 제안서 평가 발표를 바꾸지 않습니다. 전자는 입찰자가 제안서를 쓰기 전에 발주기관의 요구를 듣는 단계이고, 후자는 제출한 제안을 평가받는 단계입니다.

3. 교재 기준과 현행 규정의 구분

3-1. 교재의 시간 설명

표준교재는 설명회가 대체로 공고 후 약 7일 안팎에 열리고 입찰마감 최소 2주 전에는 진행되는 운영 사례를 설명합니다. 이는 잠재 공급자가 문서를 읽고 질문을 준비하며, 답변을 반영해 제안서를 작성할 시간을 확보해야 한다는 취지입니다.

약 7일과 최소 2주 전을 모든 입찰에 공통으로 적용되는 법정 고정기간으로 암기해서는 안 됩니다. 실제 일시·신청기한·질의기한은 해당 공고와 적용 규정에서 확인합니다.

3-2. 국가 협상계약의 현행 구조

2026년 8월 25일 현재 국가계약법 시행령 제43조제5항은 계약의 성질·규모 등을 고려하여 필요하다고 인정하면 제안요청서 등에 대한 설명을 할 수 있다고 규정합니다. 즉 모든 협상계약에서 설명회 개최가 의무라는 뜻이 아닙니다.

현행 「협상에 의한 계약체결기준」은 설명을 실시하는 경우 입찰공고에 장소·일시를 명시하고, 화상 등 전자적 방식이면 접속방법을 알리도록 합니다. 같은 기준은 제안요청서에 과업내용·요구사항·계약조건·평가요소와 평가방법·제안서 규격 등을 명시하도록 합니다.

잘못된 단정 현행 판단
모든 RFP 사업은 대면설명회가 의무다 필요하다고 인정하는 경우 개최 가능
설명회는 반드시 오프라인이어야 한다 전자적 방식도 가능하며 접속방법을 공고
불참하면 모든 입찰에서 자동 무효다 참석의무·불참효과를 해당 공고와 적용 규정에서 확인
구두 답변은 곧 공고 정정이다 공식 서면 정정·추가안내 여부를 확인

공사 현장설명도 모든 공사에 동일한 참석효과가 생긴다고 일반화하지 않습니다. 해당 공고가 현장설명 참가를 입찰조건으로 두는지, 사전등록·위임장·증명서·현장확인서가 필요한지 개별적으로 판별합니다.

4. 참석 전: 문서를 질문으로 바꾸기

4-1. 문서 세트를 완성한다

설명회 준비는 공고문 한 장만 읽는 일이 아닙니다.

  • 입찰공고와 정정공고
  • 규격서·과업내용서·제안요청서
  • 설계도서·시방서·물량내역서·현장자료
  • 계약일반조건·특수조건·보안·하도급 조건
  • 평가항목·배점·정량 증빙·발표 지침
  • 제출양식·파일규격·전자제출·가격서 분리 지침
  • 사전규격 의견처리와 이미 공개된 질의답변

파일명만으로 최신본을 판단하지 말고 공고번호, 버전·게시일, 정정 전후 내용을 대조합니다. 첨부파일이 열리지 않거나 서로 다른 문서가 같은 조항을 다르게 쓰면 설명회 전 공식 채널로 확인합니다.

4-2. 정보 식별의 여섯 묶음

묶음 확인할 정보 질문 예시
법적·자격 업종·면허·등록·공동수급·하도급·실적 기준일 어느 구성원의 실적으로 인정하는가?
기술·과업 기능·성능·수량·산출물·검사·인수 기준 필수 성능과 권고 성능을 어떻게 구분하는가?
경제·계약 예산·가격범위·세금·운반·보험·보증·유지관리 견적에 포함할 설치·교육 범위는 어디까지인가?
일정·현장 제출·착수·납품·검사·작업시간·현장접근 승인 대기기간이 전체 납기에 포함되는가?
평가·협상 평가항목·배점·정량/정성·발표·협상 가능범위 어느 문서가 평가 증빙으로 인정되는가?
제출·보안 제출경로·파일·서명·암호화·원본·용량 기술제안서와 가격서를 어떻게 분리하는가?

질문은 필수, 선택, 확인 필요로 표시합니다. 참가자격·무효·필수성능·가격서 제출처럼 결과를 바꾸는 질문을 먼저 해결합니다.

4-3. 현장설명에서 추가로 볼 것

  • 출입·작업시간·반입경로·양중·창고·주차
  • 기존 시설·매설물·전기·통신·급배수 연결조건
  • 철거·복구·폐기물·소음·분진·안전관리 책임
  • 수량·치수·도면과 실제 현장의 차이
  • 다른 공정·기관·입주자와의 작업조정
  • 시험·검사·시운전·인수 장소와 책임주체

눈으로 본 현장조건도 사진·메모만으로 계약조건이 되지는 않습니다. 도면·시방과 다르면 질의하여 공식 답변과 변경문서로 연결합니다.

5. 참석과 질문의 실무

5-1. 참가요건부터 확인한다

  1. 사전 참가신청이 필요한가?
  2. 참가자 수·자격·소속증명·위임장이 정해졌는가?
  3. 신분증·보안서약·안전장비·출입승인이 필요한가?
  4. 대면·화상 접속방법과 입장 마감은 언제인가?
  5. 참석확인서가 입찰참가 또는 현장확인의 증빙인가?

이 항목은 공고별 조건입니다. 다른 입찰에서 요구한 위임장이나 자격증을 이번 입찰의 공통 법정요건처럼 옮겨 쓰지 않습니다.

5-2. 좋은 질문의 구조

근거 문서·조항 → 확인된 사실 → 불명확·충돌 지점 → 입찰준비에 미치는 영향 → 요청하는 확인 또는 중립적 대안

예를 들어 “납기가 너무 짧습니다”보다 다음처럼 씁니다.

과업내용서 8쪽은 장비 설치 후 10일 시험운전을 요구하지만 일정표 3쪽의 최종납품일은 설치일과 같습니다. 시험운전기간이 최종납품기한에 포함되는지, 검사·인수 기준일을 어느 문서에 맞출지 확인해 주십시오.

질문은 자사의 영업비밀을 필요 이상 공개하지 않고 특정 업체에 유리한 사양을 요구하지 않으며, 경쟁업체의 가격·참가 여부를 공동으로 조정하려는 내용이 되어서는 안 됩니다.

5-3. 답변을 들을 때 기록할 것

기록 필드 내용
질문번호 회사 내부 번호와 발주기관 번호 연결
원문 위치 공고·RFP·도면의 문서명·쪽·조항
답변요지 해석을 보태지 않고 핵심 발언 기록
답변주체 담당부서·기술담당 등 역할 기록
공식화 여부 현장 구두, 공개 Q&A, 정정공고 중 어디까지 왔는가
영향 자격·가격·일정·기술·평가·go/no-go
후속조치 서면 재질의, 원가·일정·제안서 수정, 불참 판단

경쟁업체의 참석 여부는 시장의 관심도를 보여 주는 참고 신호일 뿐 실제 유효 입찰자 수나 경쟁가격을 확정하지 않습니다.

6. 설명회 후: 공식 문서와 제안서에 반영한다

  1. 질문·답변을 문서별 조항에 연결합니다.
  2. 구두 답변 중 중요한 내용은 공개된 서면 답변·정정공고 여부를 확인합니다.
  3. 수정된 첨부파일의 게시일·버전과 변경부분을 대조합니다.
  4. 요구사항 추적표, 원가표, 일정표, 위험등록부를 갱신합니다.
  5. 자격·필수성능·제출방식이 해소되지 않으면 재질의하거나 불참을 검토합니다.
  6. 팀 전체에 동일한 최신본을 배포하고 옛 파일을 사용하지 않도록 통제합니다.
  7. 제출 전 공고·정정·Q&A·제안서의 최종 교차검토를 실시합니다.

설명회는 참가 결정을 무조건 강화하는 행사가 아닙니다. 새로 확인된 현장제약·납기·평가·계약위험 때문에 불참가가 더 합리적인 결론이 될 수도 있습니다.

7. 통합 사례

한 기관이 데이터 분석 서비스 협상계약을 공고하며 화상 제안요청 설명회를 예고했습니다. 공고에는 12개월 수행이라고 되어 있지만 과업내용서의 월별 산출물은 14개월까지 이어집니다. 평가표에는 보안인증 5점이 있으나 인증 범위와 기준일이 없습니다. 가격서 제출파일의 암호화 방식도 두 첨부문서가 다릅니다.

공급자는 다음과 같이 대응합니다.

  1. 참가등록·접속방법·질의마감과 참석의무 여부를 공고에서 확인합니다.
  2. 세 충돌을 문서명·쪽·조항별 질문으로 작성합니다.
  3. 수행기간은 납기·인력·가격, 인증은 자격·평가, 암호화는 제출무효 위험으로 분류합니다.
  4. 설명회 답변을 기록하되 공식 공개 Q&A와 정정 첨부가 게시되는지 확인합니다.
  5. 정정된 수행기간으로 인력·원가·일정을 다시 계산합니다.
  6. 인증 인정범위와 기준일을 증빙 추적표에 반영합니다.
  7. 가격서 제출방식은 최종 공고문과 시스템 안내에 맞추고 모의제출로 확인합니다.

8. 시험 함정 정리

함정 바로잡기
설명회와 제안서 평가 발표는 같은 단계다 설명회는 제출 전 요구 확인, 발표는 제출 후 평가
모든 협상계약은 설명회를 열어야 한다 필요하다고 인정하는 경우 개최 가능
교재의 약 7일·최소 2주는 공통 법정기간이다 운영 사례이며 실제 일정은 공고·적용규정 확인
설명회 불참은 언제나 입찰무효다 참석의무와 효과를 개별 공고에서 판별
설명자의 구두 답변은 곧 공고 정정이다 공식 서면 정정·추가안내를 확인
참석업체 수가 곧 유효 경쟁자 수다 시장 관심의 참고 신호일 뿐
질문은 모호하게 많이 할수록 좋다 근거·충돌·영향·요청을 구체화
설명회 후에는 제안서만 고치면 된다 자격·원가·일정·위험·참가결정도 함께 갱신

사례 5. 제안요청서 설명회에서 담당자가 “보안인증은 권고사항”이라고 답했지만 공고 평가표에는 필수 제출로 적혀 있고 정정문서는 아직 없다. 공급자는 어떻게 해야 하는가?

정답·해설 보기
구두 답변만 믿고 증빙을 빼면 안 됩니다. 공고·평가표의 문서명과 조항을 특정해 서면으로 재질의하고, 공개 Q&A나 정정공고·수정 제안요청서에서 필수 여부와 기준일이 바뀌었는지 확인합니다. 공식 변경이 없으면 유효한 공고의 필수 제출조건을 기준으로 준비하며, 충족할 수 없다면 무리한 제출보다 불참을 검토합니다.

마지막 1분 정리

  • 설명회는 제출 전 요구 확인, 제안서 발표는 제출 후 평가 단계다.
  • 국가 협상계약 설명은 필요 시 개최할 수 있고 전자적 방식도 가능하다.
  • 교재의 약 7일·최소 2주는 운영 사례이지 공통 법정기간이 아니다.
  • 참석의무·사전신청·불참효과는 해당 공고에서 확인한다.
  • 질문은 근거 조항·충돌 사실·영향·확인요청으로 작성한다.
  • 구두 답변보다 공개 Q&A·정정공고·수정 첨부의 공식 반영을 확인한다.
  • 설명회 뒤 요구추적표·원가·일정·위험·참가결정을 모두 갱신한다.

공식 근거와 기준일

  • Q-Net 공공조달관리사 출제기준, 보고서 1254의 2과목 입찰·제안요청 설명과 두 세세항목
  • 조달청 공공조달관리사 표준교재 2권 게시글, 인쇄면 192~193쪽
  • 국가계약법 시행령, 제43조제3항~제5항, 2026년 6월 3일 시행본
  • (계약예규) 협상에 의한 계약체결기준, 제4조~제6조, 재정경제부계약예규 제40호, 2026년 1월 2일 시행
기준일 이후에는 해당 입찰공고·정정공고와 최신 공식 규정을 다시 확인하십시오.
