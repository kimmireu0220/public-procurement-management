# 공급계획수립하기

좋은 공급계획은 “공고가 나오면 검토한다”는 일정표가 아닙니다. 수요기관과 대상물이 정해졌을 때 경제적으로 감당할 수 있는가, 모든 필수 기술요구를 증명할 수 있는가, 누가 언제 무엇을 준비하고 어떤 조건에서 참가를 중단할 것인가를 하나의 실행문서로 만드는 일입니다.

이 장은 유형별 비용·현금흐름, 공고·규격·과업의 기술요건, 일정·자원·생산·품질·물류·위험 계획을 하나로 연결합니다.

조달청 표준교재는 발주기관의 예정가격 원가계산을 설명합니다. 공급업체는 발주기관의 예정가격과 업체의 입찰 원가·수익성을 혼동해서는 안 됩니다. 두 관점을 분리한 뒤 공급계획에서 연결합니다.

이 강의 하나의 완료 기준

다음을 수행하면 이 장을 완료한 것입니다.

  1. 발주기관의 예정가격과 공급업체의 내부 입찰원가를 구분한다.
  2. 물품 제조·물품 구매·용역·공사의 비용구조를 유형별로 분류한다.
  3. 직접비, 간접비, 입찰별 비용, 금융·현금흐름, 위험비용을 중복 없이 계산한다.
  4. 단가·수량·환율·임금·납기 변화에 대한 민감도와 손익분기점을 분석한다.
  5. 공고, 규격서, 과업내용서, 제안요청서, 도면, 계약조건의 요구사항을 하나의 표로 통합한다.
  6. 필수요건과 평가요건, 계약이행요건을 구분한다.
  7. 각 요구사항의 충족·조건부·미충족·미확인을 증거로 판정한다.
  8. 수요·환경 분석을 조달·생산·인력·품질·물류·일정 계획으로 전환한다.
  9. 단계별 의사결정 관문과 중단기준을 정한다.
  10. 계획·실적·변경·책임자를 추적한다.
  11. 공급계획서와 기술요구사항 대응표를 완성한다.

오늘의 사례: 이익이 보이는데 왜 참가를 보류하는가

해솔테크는 공공기관의 특수제작 이동형 전원장치 발주계획을 발견했습니다. 계획예산은 5억 원입니다. 영업팀은 과거 낙찰률을 적용하면 충분한 매출이 나온다고 판단했습니다. 하지만 설계팀은 요구 출력과 방수등급을 동시에 충족한 시험성적서가 없고, 구매팀은 핵심부품 납기가 14주이며 환율 변동 가능성이 크다고 보고했습니다. 계약조건에는 현장설치, 교육, 장기 보증, 여러 장소 분할납품이 포함될 수 있습니다.

계획예산은 매출·예정가격·투찰가능 금액이 아닙니다. 해솔테크는 기술증거와 숨은 비용을 확인할 때까지 조건부 준비로 두고 시험, 부품 확약, 현금한도, 실제 공고를 관문으로 삼아야 합니다.

1. 두 종류의 가격분석을 구분한다

1.1 발주기관의 예정가격 관점

국가계약법 시행령 제9조는 거래실례가격, 원가계산에 의한 가격, 표준시장단가, 감정가격·유사거래실례가격·견적가격 등의 예정가격 결정기준을 둡니다. 거래실례는 규격·거래조건·시점이 비교 가능한지 확인하고, 거래실례가 충분하지 않은 제조·공사·용역은 대상에 맞는 원가계산을 검토하며, 표준시장단가는 법령상 해당 대상에만 적용합니다. 견적 하나를 객관적인 시장가격으로 단정해서도 안 됩니다.

예정가격 원가계산은 재료비, 노무비, 경비, 일반관리비, 이윤의 구조로 이해하되 대상별 세부 산식이 다릅니다. 세율, 노임단가, 제비율은 개정되거나 계약유형·금액·기간에 따라 달라질 수 있으므로 산정일의 현행 규정과 공고를 적용합니다.

1.2 공급업체의 내부 경제성 관점

발주기관의 예정가격 기준은 회사의 실제 원가나 허용 투찰가를 보장하지 않습니다. 공급업체는 다음 식으로 자기 비용을 계산합니다.

예상 계약수입 - (직접비 + 배부 간접비 + 입찰별 추가비 + 금융비용 + 위험충당) = 예상 내부성과

여기서 예상 내부성과는 회사가 정한 관리지표입니다. 회계상 영업이익과 정확히 같다고 단정하지 않고, 회사의 원가배부·세금·자금정책에 맞춰 정의합니다. 부가가치세 포함·제외 기준도 수입과 비용에서 일관되게 맞춥니다.

예정가격은 계약담당공무원 등 발주기관이 법령·계약예규와 가격자료에 따라 작성하는 계약금액 결정의 기준입니다. 내부 경제성은 업체가 실제 구매·생산·인력·물류·금융·위험자료로 참가·투찰·수행 가능성을 판단하여 목표가격·중단가격과 자원계획을 정하는 작업입니다. 예정가격 구조는 참고하되 회사 원가로 복사하지 않습니다.

2. 유형별 공급대상물의 경제성을 분석한다

2.1 제조물품

비용층 항목 예 검증자료
직접재료 주재료, 매입부품, 포장재, 합리적 손실 BOM, 최근 견적·계약, 사용량 근거
직접노무 공정별 작업시간과 내부 인건비 공정표, 작업시간, 임금·부담비 기준

2.2 구매·유통 물품

매입가격만으로 경제성을 판단하면 안 됩니다.

매입가 + 국내외 운송 + 보험 + 통관·관세 해당비용 + 보관 + 검사 + 포장 + 설치·교육 + 보증·A/S + 금융·환율위험

국산·수입 여부, 인도조건, 최소주문량, 가격유효기간, 반품·하자 책임, 납품장소 수를 확인합니다. 수입품은 환율 기준일과 헤지 여부, 통관지연 시나리오를 기록합니다. 공고가 동등이상 제품을 허용하는지는 임의로 해석하지 말고 규격서와 공식 질의로 확인합니다.

2.3 용역

용역은 투입인력 수만 세지 않고 역할·등급·참여기간·투입률·근무장소를 분리합니다.

비용층 주요 항목
직접인력 역할별 시간·기간, 임금, 회사가 부담하는 관련 비용
직접경비 여비, 회의, 인쇄, 재료, 장비·소프트웨어, 통신, 장소
외주·전문가 하도급 가능 여부, 전문가 자문, 품질검토
관리·품질 PM, 보고, 보안, 교육, 검수·수정, 인수인계
변동·위험 과업범위 불명확, 인력교체, 야간·현장, 일정연장, 자료지연

학술연구, 엔지니어링, 소프트웨어, 시설관리 등은 관련 법령이나 별도 대가기준이 있을 수 있습니다. 발주기관의 원가계산 기준과 회사의 실제 임금·가동률을 각각 확인합니다. 낮은 내부단가를 쓰더라도 실제 투입할 수 없는 인력계획이면 경제성도 기술적 적합성도 없습니다.

2.4 공사

공사는 도면·시방서·물량내역과 현장조건에 따라 단가 근거 → 단가산출서·일위대가 → 직접공사비 내역 → 공사원가계산 순으로 봅니다. 직접재료·노무·장비·경비, 현장·본사 간접비, 보험·보증·안전·환경, 공기·가설·운반·폐기와 물가·설계변경 위험을 검토합니다. 제비율·노임·품셈·시장단가는 산정일의 공식 자료를 적용하고 적격 담당자의 승인을 받습니다.

3. 경제성 계산의 공통 절차

  1. 공고와 계약조건에서 수량, 기간, 납품·검수·대금조건을 추출한다.
  2. WBS 또는 BOM으로 수행범위를 누락 없이 나눈다.
  3. 각 항목의 소요량과 단가를 서로 다른 열에 기록한다.
  4. 직접비와 간접비, 고정비와 변동비를 구분한다.
  5. 운송·설치·교육·보증·보안·보고 등 숨은 과업을 비용화한다.
  6. 선급·기성·잔금, 보증금, 세금, 외상기간을 반영해 월별 현금흐름을 만든다.
  7. 수량·단가·환율·임금·납기·가동률의 기준값과 변동폭을 정한다.
  8. 하향·기준·상향 시나리오의 총원가와 내부성과를 계산한다.
  9. 목표가격 범위와 중단가격을 승인받는다.
  10. 정정공고·견적유효기간·시장가격이 바뀌면 버전을 올려 재계산한다.

손익분기와 민감도

단순한 단위 분석에서는 다음 식을 사용할 수 있습니다.

  • 단위공헌 = 단위수입 - 단위변동비
  • 손익분기수량 = 입찰·수행 관련 고정비 ÷ 단위공헌
  • 가격민감도 = 특정 단가 변화가 총원가·내부성과에 미치는 금액과 비율

단위공헌이 0 이하이면 일반적인 손익분기수량이 성립하지 않습니다. 계약수량이 고정된 경우에는 손익분기수량보다 허용 가능한 최대 총원가와 중단 투찰가격이 더 유용할 수 있습니다. 모든 계산에는 포함·제외 항목과 부가세 기준을 씁니다.

4. 품명별 기술요구사항을 구조화한다

기술적 적합도는 제품 카탈로그를 한 번 읽고 가능이라고 쓰는 것이 아닙니다. 모든 요구가 어디에서 왔고 무엇으로 증명되는지 추적해야 합니다.

4.1 요구사항의 공식 출처

문서 추출할 내용 주의
입찰공고·정정공고 참가자격, 일정, 제출·평가, 필수 조건 최종 정정 우선, 첨부 전체 확인

4.2 요구사항을 원자 단위로 나눈다

고효율이며 방수되고 원격 모니터링이 가능한 장치를 한 행에 쓰지 않습니다. 효율, 방수등급, 통신방식, 모니터링 기능, 시험·인증을 각각 분리합니다. 그래야 일부 충족을 전체 충족으로 오판하지 않습니다.

각 행에 다음 필드를 둡니다.

  • 요구사항 ID와 원문 위치
  • 품명·세부품명·모델
  • 필수·평가·계약이행 구분
  • 수치·단위·허용오차·시험조건
  • 회사 제안값과 충족근거
  • 증빙명·발급주체·유효상태
  • 판정: 충족, 조건부 충족, 미충족, 미확인
  • 차이·위험, 보완행동, 담당자, 완료기한
  • 비용·일정·공급계획 연결번호

조건부 충족은 희망이 아닙니다. 예를 들어 공인시험이 9월 5일까지 완료되고 요구등급 이상이면 충족처럼 사건·판정기준·기한이 있어야 합니다.

5.2 미충족과 모호성을 처리한다

  1. 필수요건 미충족이면 원칙적으로 참가 중단을 검토한다.
  2. 보완 가능한 요건은 방법·비용·책임자·완료기한·실패 시 중단조건을 정한다.
  3. 문서 간 불일치나 모호한 동등 이상은 공식 질의·의견제출 절차로 확인한다.
  4. 기관 답변이나 정정이 나오면 요구사항 버전과 경제성 분석을 함께 갱신한다.
  5. 제안한 성능과 계약이행 가능한 성능이 같은지 최종 승인한다.

기술적 미충족을 가격할인으로 상쇄할 수 있다고 임의로 판단하지 않습니다. 반대로 사양을 초과하는 고급 기능도 평가나 계약가치로 인정되지 않으면 원가만 늘릴 수 있습니다.

6. 환경분석을 통합 공급계획으로 바꾼다

6.1 입력과 계획의 연결

기관별 수요·발주시기는 입찰 캘린더로, 품목·규격 추세는 모델·시험·인증 준비로, 정책·법령 변화는 자격·준법 일정으로 바꿉니다. 경쟁·가격 구조는 가격·차별화 전략으로, 생산·인력·물류 역량은 용량·운송 계획으로, 공급망 변동은 재고·대체업체·위험대응으로 전환합니다. 분석결과마다 어떤 계획이 달라졌는가를 답해야 합니다.

6.2 공급계획의 구성

  1. 목표·근거: 대상기관·품목·기간·제외범위, 수요자료·가정·갱신일
  2. 참가·준법: 조달방법, 자격, 공동·하도급 가능성, 질의계획
  3. 기술: 요구사항, 시험·인증, 설계·샘플, 기술책임자
  4. 조달·생산: BOM, 공급업체, 발주점, 생산용량, 대체품·업체
  5. 인력·품질: 역할·투입시기, 검사·검수, 문서·보안·교육
  6. 물류·이행: 포장·운송·설치, 장소별 일정, A/S·보증

6.3 역산 일정

납품일에서 시작해 설치·검수, 운송, 생산, 자재입고, 발주, 시험·승인, 계약, 투찰·제안 준비 순으로 거꾸로 계산합니다. 각 작업에는 기간뿐 아니라 선행조건과 여유시간을 둡니다. 공고가 나오기 전에 가능한 시험·협력업체 등록·견적·인력확보는 발주계획 단계에서 준비합니다. 그러나 계획만 보고 회수 불가능한 대규모 구매를 확정할 때는 별도 경영승인을 받습니다.

8. 필답형 답안 프레임

유형 A: 유형별 경제성 분석

먼저 발주기관의 예정가격과 업체 내부 입찰원가를 구분한다. 제조물품은 재료·노무·제조경비·간접비·납품비용, 구매물품은 매입·운송·보험·보관·설치·환율, 용역은 역할별 인력·직접경비·외주·품질관리, 공사는 공종별 물량·단가·현장·법정비용을 산정한다. 수량과 단가의 출처·기준일을 기록하고 운송·교육·보증·금융·위험비용과 월별 현금흐름을 포함한다. 하향·기준·상향 시나리오와 민감도, 목표가격·중단가격을 계산하여 참가 적정성을 판정한다.

유형 B: 기술 적합도 검증

최종 공고·정정, 규격서, 과업내용서, 도면, 계약조건에서 요구사항을 원자 단위로 추출한다. 각 요구에 ID, 원문 위치, 요구값·단위·시험조건, 필수·평가·이행 구분을 부여한다. 회사 제안값을 공식 인증·시험·계산·설계·현장·공급망 자료와 대조해 충족·조건부·미충족·미확인으로 판정한다. 조건부 항목은 보완방법·비용·담당자·기한·실패 시 중단조건을 정하고, 문서가 모호하면 공식 질의한다. 결과를 원가와 일정에 연결한다.

유형 C: 공급계획 수립

환경분석과 수요정보에서 대상기관·품목·시기·정책·경쟁·공급망·자사역량을 가져온다. 목표·범위와 가정을 정한 뒤 자격, 기술, 조달·생산, 인력·품질, 물류·설치, 경제·현금, 입찰일정을 납품일에서 역산한다. 작업별 책임자·선행조건·예산을 부여하고 자격·기술·가격·제출·이행 관문과 중단기준을 설정한다. 정정공고, 견적·환율·수량·시험 결과가 바뀌면 기술표·원가표·일정을 같은 버전으로 갱신한다.

9. 자체 제작 문제 10선

아래 문제는 자체 제작이며 총점은 30점입니다.

문제

문제 1. 서술형 3점: 발주기관의 예정가격과 공급업체 내부 경제성 분석의 차이를 세 가지 쓰시오.

정답·채점: 작성주체 차이 1점, 법적 예정가격 작성과 내부 참가·수익·현금 목적 차이 1점, 근거·결과가 다르고 예정가격이 회사 원가를 보장하지 않음 1점.

문제 2. 단답형 3점: 제조물품 경제성에 포함할 비용층 여섯 가지를 쓰시오.

정답·해설: 직접재료, 직접노무, 제조경비, 간접비, 납품별 비용, 위험·금융. 각 0.5점.

문제 3. O/X 2점: 계획예산이 회사의 예상 총원가보다 크면 경제성은 자동으로 적합하다.

정답·해설: X. 계획예산은 확정가격이 아니며 기술·수행·숨은 비용·현금·위험을 함께 검토해야 함. 2점.

문제 4. 계산형 3점: 단위수입 50만 원, 단위변동비 30만 원, 고정비 2,000만 원일 때 손익분기수량을 계산하시오.

정답·해설: 단위공헌 20만 원, 2,000만 원÷20만 원=100개. 단위공헌 1점, 식 1점, 답·단위 1점.

문제 5. 사례형 4점: 수입 부품을 쓰는 구매물품의 경제성 분석에서 매입가 외에 확인할 항목을 네 가지 이상 쓰시오.

정답·해설: 운송, 보험, 통관·관세 해당비용, 보관, 검사, 포장, 설치·교육, 보증·A/S, 금융·환율, 최소주문량, 납기. 타당한 항목당 1점, 최대 4점.

문제 6. 단답형 3점: 기술요구사항 대응표의 판정 네 가지를 쓰시오.

정답·해설: 충족, 조건부 충족, 미충족, 미확인. 각 0.75점.

문제 7. O/X 2점: 비슷한 모델의 유효한 시험성적서는 요구모델 시험자료로 언제나 대체할 수 있다.

정답·해설: X. 대상모델·요구조건·발급주체·기준일 등이 일치해야 함. 2점.

문제 8. 사례형 4점: 방수요구는 필수이나 시험이 미완료다. 조건부 충족으로 관리하려면 무엇을 기록해야 하는가?

정답·채점: 완료할 시험과 판정기준 1점, 비용·일정 1점, 담당자·기한 1점, 실패 시 참가중단 조건 1점.

문제 9. 서술형 3점: 환경분석 결과를 공급계획 항목으로 전환하는 예를 세 가지 쓰시오.

정답·해설: 수요시기→입찰캘린더, 규격추세→시험·인증 계획, 법령변화→자격갱신, 공급망변동→재고·대체업체, 생산역량→용량계획. 타당한 연결당 1점.

문제 10. 단답형 3점: 공급계획 의사결정 관문 G0~G5의 의미를 쓰시오.

정답·해설: G0 탐색, G1 사전준비, G2 공고·자격·기술 검토, G3 가격승인, G4 제출승인, G5 이행전환. 각 0.5점.
