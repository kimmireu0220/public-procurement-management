합격에 필요한 필수 이론

1. 공급 가능 범위를 먼저 정의한다

수집 범위는 회사의 희망이 아니라 증빙 가능한 능력으로 정합니다.

범위축 정의 질문 증거
조달대상물 어떤 물품 세부품명, 용역 업종·과업, 공사 업종·주력분야인가? 등록증, 면허, 제품·서비스 목록
기술범위 필수 성능·인증·인력·장비의 상한은? 시험·인증, 인력·장비 현황
수량·금액 동시 생산·수행 가능한 용량과 현금한도는? 생산·인력계획, 자금계획

기간 제안·제작·납품·착수에 필요한 최소기간은? 표준 일정, 과거 실적
위험한도 보증, 지체, 재고, 가격변동을 어디까지 감수하는가? 내부 승인기준

예를 들어 청소용역처럼 넓은 단어만 쓰면 건물관리, 폐기물처리, 방역, 물품 구매가 함께 검색될 수 있습니다. 회사의 실제 업종, 과업범위, 제외어까지 검색사전에 넣습니다.

표준교재는 조달정보개방포털의 보고서, 공개 API, 시각화, 분석기능을 소개합니다. 이 기능들은 수집 목적에 따라 선택합니다. 소수 중요사업은 원문을 직접 읽고, 대량 추세는 보고서·API를 활용하며, 지도·그래프는 분포 탐색에 씁니다. 데이터의 편리함이 원공고 확인을 대신하지는 않습니다.

3. 발주계획 정보를 수집한다

국가계약법령상 공개되는 조달계획은 물품·공사·용역의 목적, 수량 또는 규모, 예산 같은 정보를 포함합니다. 실제 화면에는 더 많은 필드가 있을 수 있으나 수집의 최소단위는 다음과 같습니다.

분류 필드 확인 포인트
식별 내부 사업ID, 기관코드·명, 사업명 동일사업 연결의 기준
대상 품명·세부품명, 과업·공종, 수량·단위 자사 범위와 일치 여부
규모 예산액, 추정 규모, 계약기간 금액개념과 포함범위
시기 등록일, 발주시기, 예상 공고·납기 계획변경과 최신성
방식 조달방식, 계약방법, 집행기관 준비경로와 적합성
담당 수요기관, 부서, 문의정보 공식 질의·갱신 확인
출처 원문 URL, 수집시각, 검색조건 재현성과 감사추적

현재 조달청 공식 안내의 나라장터 경로는 발주 → 발주목록 → 발주계획입니다. 화면 경로가 달라져도 발주계획 원문과 상세정보를 찾는 목적은 같습니다. 2026년도 공식 발주계획도 기관 등록자료를 취합한 것이며 계획조정으로 실제 사업과 달라질 수 있음을 밝힙니다. 그러므로 발주계획에는 반드시 계획, 확정 아님, 다음 확인일을 표시합니다.

4. 계획에서 계약까지 하나의 사업으로 연결한다

같은 사업의 상태는 시간에 따라 바뀝니다.

발주계획 → 사전규격 → 입찰공고 → 정정·취소 → 개찰 → 계약 → 변경·이행

각 단계의 번호가 처음부터 모두 존재하지 않을 수 있으므로 연결키를 계층적으로 사용합니다.

  1. 공식 연계번호가 있으면 가장 먼저 사용한다.
  2. 없으면 기관코드, 사업명, 대상물, 예산, 예정시기 조합으로 후보를 만든다.
  3. 첨부 규격과 담당부서, 수량을 대조하여 동일사업인지 확인한다.
  4. 확실하지 않으면 병합하지 않고 연결 미확정으로 둔다.
  5. 본공고가 나오면 계획값을 덮어쓰지 말고 계획값과 확정값을 나란히 보존한다.
  6. 정정공고는 최종본 표시와 함께 바뀐 항목·시각을 기록한다.
  7. 취소·유찰·재공고는 원사업과 연결하되 건수 산정규칙을 명시한다.

증거등급

다음 등급은 법정 분류가 아니라 이 강의의 자체 관리기준입니다.

등급 상태 활용
A 유효한 실제 공고·최종 정정과 첨부 확인 입찰 참가판정·단기 자원배치
B 사전규격 또는 구체적 계약요청 정보 확인 기술검토·질의·사전준비
C 공식 발주계획 확인 중기 파이프라인·모니터링
D 과거 계약실적·정책·예산으로 추정 탐색과 가설, 확정계획 아님

등급이 높다고 자동으로 적합한 기회는 아닙니다. A등급 공고도 자격이나 기술을 충족하지 못하면 제외합니다.

5. 수요정보를 정제한다

5.1 중복·정정·취소

상황 처리 수요 건수
발주계획과 본공고가 연결됨 한 사업 아래 단계별 기록 기본적으로 한 기회로 관리
정정공고 원공고에 버전 연결, 변경필드 표시 별도 신규기회로 세지 않음
취소공고 상태를 취소로 보존 활성수요에서 제외
유찰 후 재공고 원사업 연결, 조건변경 비교 분석목적에 따라 공고 횟수와 사업 수를 구분
분할발주 실제 독립 계약인지 확인 계약단위별 기회와 총사업 관계를 함께 기록
기관·사업명 유사 공식 번호와 첨부 비교 근거 없이는 병합하지 않음

5.2 결측과 단위

빈 금액은 0원이 아니며, 수량 1식은 1개가 아닙니다. 금액·수량·기간의 결측을 미상, 비공개, 해당없음으로 구분합니다. 예산, 추정가격, 기초금액, 계약금액을 같은 열에 섞지 않습니다. 부가가치세·옵션·설치·운송 포함 여부도 메모합니다.

6. 공급 가능한 기관과 대상물을 선정한다

수집 후 다음 두 번의 필터를 적용합니다.

필터 통과 질문

7. 체계적으로 분류하고 문서화한다

수요정보 대장은 다음 분류를 동시에 가집니다.

  • 기관: 기관유형, 기관코드, 지역, 담당부서
  • 대상물: 물품·용역·공사, 품명·세부품명, 업종·공종, 규격
  • 단계: 계획, 사전규격, 공고, 정정, 개찰, 계약, 취소
  • 시간: 수집일, 발주시기, 공고·마감·납품일, 다음 확인일
  • 규모: 수량·단위, 예산·추정·계약금액의 구분
  • 적합성: 자격, 기술, 수행, 경제, 일정의 통과·보류·제외
  • 증거: 공식 URL, 첨부파일, 검색조건, 증거등급
  • 책임: 담당자, 후속조치, 기한, 최종검토자

  • 공고별 배점·비율과 일반 법령상 기준, 표준교재의 사례값을 섞지 않는다.
  • 사실이 부족한 사례는 임의로 확정하지 말고 추가 확인사항과 조건별 결론을 짧게 쓴다.

필답형 답안 작성 방법

다음 골격을 먼저 적고 문제의 사실과 핵심어를 끼워 넣는다.

  1. 담당자는 공고·계약서·요구자료와 적용근거를 확인한 뒤 ‘수요기관 발주계획 정보 수집’을 수행한다.
  2. ‘전자조달시스템으로 공급·공급계획 정보 수집’ 단계에서는 적용요건과 제시된 사실·증빙을 대조하고 판단근거를 기록한다.
  3. ‘수요정보 체계적 분류·문서화’ 결과를 문서화·설명하고 관계자 통지와 후속조치를 관리한다.

대표 예상문제 — 자체 작성

문제(10점). 조달 수요정보 수집하기의 수행절차를 설명하고, 각 단계에서 확인할 판단기준과 남겨야 할 결과를 쓰시오. 8분 이내에 답하시오.

시험시간 안에 쓰는 모범답안

  1. 담당자는 공고·계약서·요구자료와 적용근거를 확인한 뒤 ‘수요기관 발주계획 정보 수집’을 수행한다.
  2. ‘전자조달시스템으로 공급·공급계획 정보 수집’ 단계에서는 적용요건과 제시된 사실·증빙을 대조하고 판단근거를 기록한다.
  3. ‘수요정보 체계적 분류·문서화’ 결과를 문서화·설명하고 관계자 통지와 후속조치를 관리한다.

마지막으로 각 단계의 근거자료·판단결과·담당자·기준일을 기록하고, 변경이나 오류가 있으면 보완 후 재확인한다.

채점 핵심어와 부분점수

  • 수요기관 발주계획 정보 수집: 3점
  • 전자조달시스템으로 공급·공급계획 정보 수집: 3점
  • 수요정보 체계적 분류·문서화: 2점
  • 순서·근거·후속조치가 연결된 답안 구성: 2점
동등한 의미의 표현은 인정한다. 문제에 없는 세부 실무지식을 길게 추가해도 별도 점수는 없으며, 핵심 단계의 누락을 보충하지 못한다.
