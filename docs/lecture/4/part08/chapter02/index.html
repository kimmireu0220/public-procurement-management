자체 제작 강의입니다. 조달데이터의 화면·API·필드와 갱신주기는 바뀔 수 있습니다. 분석 결과보다 먼저 출처, 기준일, 단위, 포함·제외 범위와 결측을 기록하는 방법을 학습합니다.

이 강의 하나의 완료 기준

이 단원의 질문은 “입찰·계약 데이터를 어떻게 믿을 수 있는 의사결정 자료로 바꿀 것인가?”입니다. 학습 후에는 다음을 할 수 있어야 합니다.

  • 분석목적에 맞는 조달데이터를 분류하고 정확히 추출한다.
  • 입찰현황·계약실적·경쟁사 자료로 의사결정을 지원한다.
  • 기준에 맞게 정제·분석하고 오해 없는 표와 차트를 만든다.
  • 출처·신뢰성·한계를 밝힌 보고서를 작성한다.

공식 출제기준과 학습 결과

공식 수행능력 학습 결과
목적별 분류와 정확한 추출 분석질문·관측단위·필드·필터를 데이터 요구서로 정의한다.
입찰·계약·경쟁사 분석으로 의사결정 지원 지표와 비교기준을 만들고 행동 제안을 도출한다.
데이터 분석·시각화 정제이력과 분모를 보존한 표·차트를 작성한다.
출처·신뢰성 검토 및 보고서화 데이터 계보, 한계, 재현방법을 분석보고서에 남긴다.

시작 사례

해솔기획은 “지난해 A기관 용역 입찰 100건의 평균 낙찰률이 92%”라는 분석을 받았다. 그러나 표에는 취소공고와 재공고가 각각 한 건으로 섞였고, 복수예가 방식과 협상계약의 낙찰률이 같은 방식으로 계산됐다. 계약변경 후 최종금액 대신 최초계약금액이 사용됐으며, 공동수급체는 구성원별로 중복 집계됐다.

숫자 92%가 계산상 맞더라도 질문에 맞는 데이터가 아니면 의사결정을 왜곡합니다. 분석은 어떤 한 행이 무엇을 뜻하는가와 분모에 무엇이 들어갔는가에서 시작합니다.

1. 목적을 한 문장으로 고정한다

나쁜 질문은 “나라장터 데이터를 분석한다”입니다. 좋은 질문은 다음 구조를 갖습니다.

누가 어떤 기간·시장·업무에서 무엇을 결정하기 위해 어떤 지표를 비교하는가?

예: “영업책임자가 2025년 1월~12월 수도권 공공기관의 특정 세부품명 계약시장을 평가하여 2027년 영업대상 10개 기관을 선정한다.”

목적이 정해지면 필요한 단위와 데이터도 달라집니다.

4. 정확한 추출 절차

  1. 공식 포털·API·통계의 데이터셋 설명과 제공기관을 확인한다.
  2. 관측단위와 식별키를 정한다.
  3. 기간필드가 게시일·개찰일·계약일 중 무엇인지 선택한다.
  4. 업무구분, 기관, 품목·업종, 계약방법, 상태의 포함·제외 조건을 명시한다.
  5. 필드 정의, 코드표, 단위와 갱신주기를 저장한다.
  6. 원본을 변경하지 않고 추출시각·요청조건과 함께 보존한다.
  7. 일부 표본을 원 공고·계약 상세와 대조한다.
  8. 페이지 누락, 호출 제한, 오류응답, 중복 수집을 검사한다.

5. 정제는 삭제가 아니라 규칙의 기록이다

자주 생기는 오류

  • 정정공고·재공고·취소공고의 중복 또는 잘못된 제거
  • 계약변경 차수를 합산해 동일 계약금액을 중복 집계
  • 기관명·업체명 표기변경을 서로 다른 주체로 계산
  • 품명, 세부품명, 물품식별번호를 같은 수준으로 묶음
  • 금액 단위·부가세·통화·0과 결측을 혼동
  • 공동수급 대표·구성원을 각각 전체 계약으로 집계
  • 개찰결과가 없는 공고를 경쟁률 분모에 포함

규칙ID 변경 전 문제 적용 규칙 영향 행 수 검증 판단자
C01 계약변경 차수 중복 계약번호별 최종차수 선택 42 원계약 10건 표본대조 분석자

원본 값을 덮어쓰지 않고 정제본과 규칙을 분리합니다. 제외한 행도 이유와 수를 보고합니다.

6. 의사결정 지표를 올바른 분모로 계산한다

기본 지표

  • 시장금액 = 분석범위에 포함된 최종 계약금액의 합
  • 기관 비중 = 특정 기관 계약금액 ÷ 분석시장 전체 계약금액
  • 업체 점유율 = 특정 업체에 배분한 기준금액 ÷ 분석시장 전체 기준금액
  • 유효 경쟁강도 = 유효 입찰자 수를 계산할 수 있는 개찰 건의 분포
  • 수주율 = 회사의 낙찰 건수 ÷ 회사가 실제 참여한 유효 입찰 건수
  • 공고 전환율 = 후속 계약과 연결된 공고 수 ÷ 분석대상 유효 공고 수

이 식은 분석용 정의입니다. 실제 보고서에서는 공동수급 금액 배분, 계약변경, 복수낙찰·단가계약을 어떻게 처리했는지 반드시 붙입니다.

낙찰률을 함부로 합치지 않는다

낙찰금액 ÷ 예정가격 같은 비율은 해당 입찰에 예정가격과 낙찰금액이 의미 있게 존재할 때만 계산합니다. 협상계약, 단가계약, 예정가격 비공개·다중가격 등 구조가 다른 건을 같은 평균으로 합치면 해석이 깨질 수 있습니다. 계약방법별로 나누고, 분모와 제외건수를 보고합니다.

평균만 보지 않는다

평균은 큰 금액 한 건에 흔들릴 수 있습니다. 중앙값, 사분위 범위, 건수, 금액가중 평균과 분포를 함께 보고 필요하면 이상치를 별도 설명합니다.

7. 세 가지 분석을 의사결정으로 연결한다

입찰현황 분석

기관·월·품목·계약방법별 공고 수, 유효 개찰 수, 경쟁강도, 반복공고를 봅니다. 결과는 어느 시기·기관·방법의 기회를 모니터링할지로 연결합니다.

계약실적 분석

최종 계약금액, 계약건수, 발주기관·품목 집중도, 변경빈도와 공급채널을 봅니다. 결과는 목표시장 규모, 매출 편중, 수행·현금흐름 부담으로 연결합니다.

경쟁사 분석

업체 식별자를 기준으로 품목·기관·계약방법별 실적과 공동수급 역할을 봅니다. 공개데이터는 원가·전략·실제 역량 전부를 보여주지 않으므로 관찰된 조달행동과 추정을 구분합니다.

8. 시각화는 질문 하나에 메시지 하나

질문 적합한 표현 피할 것
월별 추세 시간순 선그래프 월 순서가 섞인 범주형 축
기관 간 금액 비교 정렬 막대그래프 면적 비교가 어려운 3D 차트
시장구성 100% 누적막대 또는 표 범주가 지나치게 많은 원그래프
경쟁률 분포 상자그림·히스토그램 평균값 하나만 표시
금액과 참가자 관계 산점도 원인이 입증된 것처럼 그린 추세선

제목에는 결과가 아니라 질문 또는 핵심 메시지를 씁니다. 축의 단위, 기간, 데이터 범위, 결측·제외, 출처와 추출일을 표시합니다. 차트 색만으로 상태를 구분하지 않고 범례·라벨을 함께 사용합니다.

9. 신뢰성을 여섯 질문으로 검토한다

  1. 권위성: 공식 제공기관·원 시스템인가?
  2. 적합성: 분석질문에 맞는 관측단위·필드인가?
  3. 완전성: 누락 단계·비공개·결측이 얼마나 되는가?
  4. 정확성: 원 공고·계약 표본과 일치하는가?
  5. 최신성: 갱신일과 분석 기준일이 적절한가?
  6. 재현성: 다른 분석자가 같은 조건으로 다시 만들 수 있는가?

신뢰성은 공공데이터이므로 정확이라는 한 문장으로 끝나지 않습니다. 공식 자료에도 단계 누락·정정·갱신 지연이 있을 수 있음을 한계로 적습니다.

분석 가능성과 재배포 가능성도 구분합니다. 데이터셋의 이용허락조건, 개인정보·비공개정보 포함 여부, 목적에 필요한 최소 필드인지 확인하고, 개인·담당자 식별정보가 분석에 불필요하면 제거·가명화하여 접근권한과 보존기간을 관리합니다. 분석표를 외부에 공개할 때는 원 데이터의 이용조건과 영업상 오해 가능성을 다시 검토합니다.

시작 사례 적용

92% 평균을 의사결정에 바로 쓰지 않습니다. 관측단위를 최종 유효공고 또는 낙찰 건으로 다시 정의하고 취소·재공고 처리규칙을 기록합니다. 계약방법별로 예정가격과 낙찰금액의 의미를 확인해 별도 집계하고, 계약금액은 최종변경차수 기준인지 선택합니다. 공동수급의 업체 귀속 규칙과 결측을 명시한 뒤 중앙값·분포·건수와 함께 재분석합니다.

실무 산출물과 빈 서식

조달데이터 분석 통제표

의사결정 질문 기간·범위·관측단위 공식 출처·추출일 식별키·필수필드 포함·제외·중복처리 지표 분자·분모 표본대조·한계 결론·제안 행동

분석보고서 결론표

발견 근거 지표·단위 사업적 해석 대안 해석 데이터 한계·불확실성 제안 행동·담당·기한

통제표와 보고서에는 최종 숫자뿐 아니라 추출조건, 정제규칙, 제외건수와 원 공고·계약 표본대조 결과를 같이 남깁니다. 이렇게 해야 다른 분석자가 결과를 재현하고 평균이나 비율의 분모를 검증할 수 있습니다.

필답형 답안 프레임

  • 추출형: 의사결정 질문 → 관측단위·식별키 → 공식 출처·기간·필터 → 원본 보존 → 페이지·중복·표본 검증
  • 정제형: 오류유형 식별 → 적용규칙·판단자 → 영향 행 수 → 원본·정제본 분리 → 원 공고·계약 대조 → 정제로그
  • 분석형: 비교단위 → 지표 분자·분모·단위 → 계약방법별 분리 → 평균·중앙값·분포 → 대안해석·한계 → 의사결정
  • 보고서형: 결론 → 범위·출처·추출일 → 정제·제외 → 근거 지표·시각화 → 해석·제안 → 신뢰성·한계·재현경로

사례형에서는 계산을 바로 고치기 전에 질문에 맞는 한 행의 의미와 분모에 들어간 건을 먼저 재정의합니다.

문제 3. O/X: 모든 계약방법의 낙찰률을 하나의 평균으로 합치면 비교가 쉬워져 항상 적절하다.

정답·해설 보기
X. 가격구조와 분모가 의미 있는 계약방법끼리 구분해야 한다.

정답·해설 보기

문제 5. 조달데이터 여섯 종류를 쓰시오.

정답·해설 보기
계획·수요, 공고, 개찰·낙찰, 계약·변경, 품목·업체·기관, 이행. 각 1점.

문제 6. 정확한 추출 검증 다섯 항목을 쓰시오.

정답·해설 보기
완전성, 유일성, 유효성, 일관성, 추적성. 각 1점.

문제 7. 정정공고·변경계약 중복을 처리할 때 남길 기록을 설명하시오.

정답·해설 보기
원본은 보존하고 식별키·최종차수 등 적용규칙, 제외·통합된 행 수, 표본검증 결과, 판단자를 정제 로그에 남긴다.

문제 8. 조달데이터 신뢰성 검토 여섯 질문을 쓰시오.

정답·해설 보기
권위성, 적합성, 완전성, 정확성, 최신성, 재현성. 각 1점.

문제 9. 경쟁사 수주율을 계산하기 위한 분자·분모와 한계를 쓰시오.

정답·해설 보기
분자는 해당 업체의 낙찰 건수, 분모는 그 업체가 실제 참여한 유효 입찰 건수다. 업체 식별, 공동수급 역할, 비공개·누락 참여정보, 계약방법 차이를 한계로 적는다.

문제 10. 시작 사례의 분석을 다시 설계하는 절차를 서술하시오.

정답·해설 보기
목적과 관측단위를 다시 정의하고 취소·정정·재공고, 계약변경, 공동수급 처리규칙을 정한다. 계약방법별 낙찰률의 분모를 확인해 분리하고 원 공고·계약 표본과 대조한다. 평균뿐 아니라 중앙값·분포·건수와 제외건을 보고하고 재현 가능한 출처·추출조건을 남긴다.

9·10번은 질문·단위 2점, 추출·정제 3점, 지표·분모 2점, 품질·한계 2점, 행동연결 1점입니다.
