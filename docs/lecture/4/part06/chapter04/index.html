리스크 발생 모니터링

공공조달 관리실무 · 공공조달 리스크 관리

① 한눈에 보기

  • Chapter 3의 대응계획을 받아 실행상태 확인 → 성과 측정 → 변화·신규위험 탐지 → 결과 공유·의사결정 → 계획 보완으로 반복한다.
  • 완료·진행 중·미실행 표시는 조치의 실행상태이며, 실제 발생가능성·영향이 줄었다는 성과와 구분한다.
  • 기준선·목표·현재값을 비교 가능한 기간·범위·분모·측정방법으로 비교하고, 통제상태와 외부변화를 따로 기록해 형식주의를 막는다.
  • 법·정책·시장·사업범위·이해관계자·내부통제 변화와 데이터 이상징후에서 새 위험과 달라진 기존 위험을 찾아 다시 평가한다.
  • 보고에는 현황만 나열하지 않고 원인·추세·추가조치·결정요청·책임자·기한을 담아 책임성과 실제 개선으로 연결한다.

② 차근차근 설명

Chapter 3에서는 대응전략, 세부조치, 책임자, 기한, 자원, 지표와 비상계획을 정했다. Chapter 4에서는 계획서에 적힌 조치가 실제로 실행되는지, 실행한 조치가 위험을 줄였는지, 그 사이 환경이 바뀌어 새 위험이 생기지는 않았는지를 계속 확인한다.

교재 제목은 리스크 발생 모니터링이지만 실제 범위는 위험사건의 발생 여부에 한정되지 않는다. 처리 전·중·후의 계획·통제 실행, 결과의 품질과 효과, 변화한 위험수준과 관리과정 자체가 적절한지를 모두 살핀다.

박문각 교재의 네 소단원은 다음 순서로 연결된다.

리스크 대응계획 실행 여부 확인 → 리스크 대응방안 성과 확인 → 새로운 리스크 식별 → 모니터링 결과 공유 및 필요 조치 제안

조달청 4과목 표준교재에는 독립된 리스크 모니터링 장이 없다. 계약유형별 착수·생산·공정·검사·인수·종결 흐름은 지표와 확인시점을 정하는 실제 업무지도로 연결한다. 필기 2과목 표준교재의 공급리스크 관리도 처리방안·비용·실행계획을 모니터링하고 변화에 따라 반복 검토하는 흐름을 제시한다.

1. 리스크 대응계획의 실행 여부를 확인한다

계획–실행–점검–보완의 선순환을 만든다

실행점검의 목적은 서류상 완료율을 높이는 데 있지 않다. 계획한 통제가 실제 현장에서 작동하도록 하여 대응의 실효성을 확보하는 데 있다.

계획 → 실행 → 점검 → 보완 → 다시 실행

대응조치 담당자는 진행상태와 증빙을 기록하고, 위험책임자와 사업관리자가 기한·자원·의존관계를 점검한다. 계약담당자는 계약조건과 변경·보고절차를, 기술·품질·안전 담당자는 시험·검사·현장통제를, 예산·재무 담당자는 대응비용과 재원을 확인한다. 중대한 위험이나 위임범위를 넘는 편차는 권한 있는 관리자에게 올린다.

점검주기는 위험속도와 의사결정 리드타임에 맞춘다. 교재의 월간·분기 보고는 운영 예시이며 모든 계약의 고정주기가 아니다. 안전·보안·필수서비스처럼 빠르게 확대되는 위험은 실시간·수시 확인과 즉시보고가 필요할 수 있고, 장기 추세 위험은 정기검토가 더 적합할 수 있다. 정기일정 외에도 다음 사건이 있으면 재점검한다.

  • 조기경보지표가 경계값에 도달하거나 비상계획 발동기준을 충족한 때
  • 주요 납품·산출물·기성·검사·승인 또는 계약변경 시점
  • 공급자·핵심인력·하수급자·원자재·운송경로에 중요한 변화가 생긴 때
  • 법·정책·예산·시장·환율·기술·안전환경이 크게 달라진 때
  • 지체·불합격·하자·민원·분쟁·보안사고 같은 사건이 발생한 때

실행상태와 증빙을 함께 본다

교재의 기본상태는 완료·진행 중·미실행의 3단계다. 실무에서는 지연·중단·승인대기·효과검증대기 같은 사유를 별도 상태나 설명란에 붙여 관리한다.

확인항목 확인할 내용 대표 증빙
조치 이행 계획한 조치가 승인된 범위와 방법으로 실제 수행되었는지 계약·변경문서, 발주·보험·보증자료, 시험·점검기록
일정 시작·중간·완료기한과 검토주기를 지켰는지 일정표, 공정·생산현황, 회의·보고일자
책임자 조치담당자·검토자·승인자가 역할을 수행했는지 승인기록, 업무분장, 보고·의사결정 이력
자원 예산·인력·재고·대체자원과 시스템이 실제 사용 가능한지 예산집행, 재고·계약·가동시험 자료
계획 대비 편차 범위·품질·수량·통제강도가 임의로 축소되지 않았는지 원계획과 실적 대조, 현장확인, 예외승인
미이행 원인 권한·예산·인력·기술·시장·선행조치 중 무엇이 막았는지 원인분석, 담당자·현장 의견, 외부자료

보험증권을 받았다고 이전·공유 조치가 완료된 것은 아니다. 담보범위·한도·기간·피보험자·자기부담과 실제 청구 가능성을 확인해야 한다. 대체공급자 명단만 작성했다면 생산능력·인증·납기·계약 가능성을 검증해야 한다. 교육·회의를 열었다는 기록만으로 오류율·지연위험이 감소했다고 판단해서도 안 된다.

서류와 시스템 상태는 중요한 증거지만 현장 사실을 대신하지 않는다. 표본확인, 인터뷰, 재고실사, 장비 가동시험, 시험성적서 원자료와 실제 검사과정을 위험에 비례하여 확인한다. 다만 감독·검사 권한과 계약조건의 범위를 지키고, 공급업체의 영업비밀·개인정보·보안정보를 불필요하게 요구하지 않는다.

실행률은 상태요약이지 효과점수가 아니다

교재의 계산골격은 다음과 같다.

완료기준 실행률 = 완료 조치 수 ÷ 전체 조치 수 × 100

완료·진행 포함 비율 = (완료 + 진행 중 조치 수) ÷ 전체 조치 수 × 100

전체 20개 중 완료 12개, 진행 중 5개, 미실행 3개라면 완료기준 실행률은 12÷20×100 = 60%, 완료·진행 포함 비율은 17÷20×100 = 85%다. 두 번째 값의 이름과 포함기준을 반드시 밝혀 완료율처럼 오해하지 않게 한다.

단순 건수는 중요도를 반영하지 않는다. 경미한 조치 12개를 끝내도 재난급 위험의 핵심조치 1개가 미실행이면 전체 위험은 높게 남을 수 있다. 조치별 중요도·기한·의존관계와 미실행 핵심조치가 관련된 위험의 현재 등급을 함께 보고한다.

여기서 현재위험은 이미 운영되어 효과가 확인된 현재 통제를 반영한 수준이다. 아직 완료·검증하지 않은 조치의 기대효과를 미리 반영하지 않는다. 조치를 완료했다는 사실만으로 위험을 종결하거나 등급을 자동으로 낮추지도 않는다.

미실행·지연이 확인되면 원인을 분석하여 담당·자원·일정을 보완하고, 계획 자체가 비현실적이면 승인절차를 거쳐 수정한다. 위험이 이미 커졌다면 Chapter 2 방식으로 현재 잔여위험을 다시 평가하고, 비상계획 발동 또는 상향보고 필요성을 판단한다.

2. 리스크 대응방안의 성과를 확인한다

실행 여부와 효과를 분리한다

조치를 했는가는 실행점검이고, 조치 때문에 위험이 얼마나 줄었는가는 성과확인이다. 대응의 궁극적 목적은 활동 수가 아니라 목표 달성에 대한 불확실성을 허용 가능한 수준으로 관리하는 데 있다.

교재는 성과의 핵심요소를 다음 다섯 가지로 정리한다.

성과요소 확인 내용
발생가능성 감소 같은 평가기간에 위험사건의 확률·빈도·등급이 낮아졌는지
영향 감소 손실금액·지연일수·재작업·안전·서비스 영향이 줄었는지
조기경보 작동 위험이 현실화되기 전에 징후를 탐지하고 정해진 조치가 시작됐는지
이해관계자 반응 민원·현장평가·사용자·감독·공급망 신호가 개선됐는지
비용 대비 효과 기대손실·공공적 피해의 감소가 통제의 도입·운영비용과 균형을 이루는지

기준선·목표·현재값을 같은 조건으로 비교한다

성과지표에는 지표명, 정의, 분자·분모, 자료원, 기준선, 목표값, 현재값, 측정기간·주기, 책임자와 경계값을 붙인다. 계약규모·물량·평가기간이 달라졌는데 단순 건수만 비교하면 잘못된 결론에 이를 수 있다.

  • KPI는 납기준수율·검사합격률·하자율처럼 사업·대응의 성과를 보여 준다.
  • KRI·조기경보지표는 리드타임 증가·신용악화·안전재고 감소처럼 위험노출이 커지는 징후를 보여 준다.
  • 통제 실행지표는 점검 실시율·보완조치 기한준수율처럼 통제가 계획대로 운영되는지를 보여 준다.

한 지표가 상황에 따라 여러 역할을 할 수 있으므로 이름보다 정의와 의사결정 용도를 기록한다. 지표가 좋아졌더라도 대응조치 때문인지, 수요감소·시장안정·측정방식 변경 같은 외부요인 때문인지 확인한다. 한 기간에 사고가 없었다는 사실만으로 낮은 확률의 위험이 사라졌다고 단정하지 않는다.

KPI·KRI·통제지표의 구분은 현장관리를 돕는 실무 틀이다. ISO 위험관리 지침이 모든 기관에 특정 지표명·구분·개수를 의무화한 것은 아니므로 사업목표와 위험기준에 맞게 정의한다.

감소율과 기대손실을 정확히 계산한다

발생확률이 대응 전 50%에서 대응 후 20%로 낮아졌다면 다음 두 표현을 구분한다.

절대 감소 = 50% − 20% = 30%p

상대 감소율 = (50% − 20%) ÷ 50% × 100 = 60%

30% 감소라고만 쓰면 퍼센트포인트인지 상대비율인지 불명확하다. 기준확률과 계산식을 함께 적는다.

교재 사례처럼 예상손실값 자체가 대응 전 4억원에서 대응 후 1억원으로 줄었다면 감소액은 4억원 − 1억원 = 3억원, 상대감소율은 3÷4×100 = 75%다. 이미 기대값으로 제시된 금액에 확률을 다시 곱하지 않는다.

반대로 4억원과 1억원이 각각 사건 발생 시 조건부 손실액이라는 별도 자료라면 기대손실을 계산할 때 확률을 곱한다.

대응 전 기대손실 = 0.5 × 4억원 = 2억원

대응 후 기대손실 = 0.2 × 1억원 = 0.2억원

기대손실 감소액 = 2억원 − 0.2억원 = 1.8억원

어느 해석인지 자료의 정의를 먼저 확인한다. 기대손실은 동일 평가기간·금액기준과 추정가정을 전제로 한 평균적 의사결정 자료이며, 실제 확정절감액이나 회계상 수익을 뜻하지 않는다. 대응비용까지 포함한 경제성은 Chapter 3의 전 기대손실 − 후 기대손실 − 대응비용으로 다시 확인한다.

확률×손실금액은 하나의 손실사건을 단순화한 식이다. 서로 배타적인 결과가 여러 개라면 Σ(각 결과확률×각 손실)로 계산하고 확률합·기간·단위를 맞춘다.

성과가 부족하면 원인을 찾아 재설계한다

목표 미달의 원인은 조치 미실행, 통제설계 오류, 자료·가정 오류, 담당자의 권한 부족, 공급자 협조 부족, 환경변화 또는 부작용일 수 있다. 원인을 구분하지 않고 통제강도만 높이면 비용과 행정부담이 늘고 다른 위험이 생길 수 있다.

성과가 부족하면 원인 확인 → 현재 위험 재평가 → 대안 비교 → 책임·자원·일정 조정 → 승인 → 계획·계약·대장 반영으로 처리한다. 공고·계약의 범위·가격·기간·책임을 바꿀 필요가 있으면 대응계획만 고치지 않고 적용 법령과 계약조건의 정식 변경절차를 따른다.

3. 새로운 리스크를 식별한다

새 위험과 달라진 기존 위험을 함께 찾는다

교재의 새로운 리스크는 기존 대응계획과 리스크 레지스터에 반영되지 않은 위험이다. 모니터링에서는 완전히 새로운 위험뿐 아니라 원인·발생가능성·영향이 크게 달라진 위험, 서로 결합해 새 경로를 만든 위험, 한동안 잠잠했다가 다시 커진 위험도 찾는다.

변화원천 대표 신호
외부환경 법·정책·예산, 경기·환율·물가, 공급시장·운송, 재난·사회 이슈의 변화
사업범위 설계·사양·과업·물량 추가·축소, 일정단축, 계약구조·인수조건 변화
이해관계자 신규 민원·사용자 불만, 지역사회·언론·감독기관 의견, 공급망 갈등
내부관리 담당자·핵심인력 교체, 의사소통 단절, 승인 지연, 통제 약화·데이터 품질 저하
기술·보안 신기술·노후시스템, 상호운용성, 사이버위협, 핵심기술·자료 의존 변화

신호를 위험문장과 근거로 전환한다

정기 모니터링 회의, 현장 피드백, 이해관계자 의견, 내부감사·검사, 외부정보와 데이터 이상징후를 함께 본다. 계약변경이 2건에서 8건으로 늘고 지연율이 5%에서 18%로 높아졌다면 범위 불명확·의사결정 지연·공급자 역량저하의 신호일 수 있다. 그러나 기간·계약수·물량·분모가 다른 단순 건수만으로 원인을 확정하지 않는다.

민원·하자·불합격·보완요청·입찰자 수·리드타임·재고·가격·인력교체가 평상범위를 벗어나면 누락하지 않도록 리스크 레지스터에 후보·검토 중 상태로 즉시 등록하고 다음 순서로 처리한다.

레지스터 즉시 등록 → 신호 확인·자료검증 → 원인–위험사건–목표영향 정의 → 기존 항목과 중복·연결 확인 → 발생가능성·영향·중요도 평가 → 책임자·대응전략 → 기존 계획 수정·보고

신호가 곧 위험사건은 아니다. 민원 증가는 잠재위험의 단서지만 동일 사유가 반복되는지, 실제 품질·서비스·법적 영향과 연결되는지 분석한다. 수치 이상이 자료입력 오류나 분류변경 때문인지도 먼저 확인한다.

특정 업체의 반복 낙찰도 시장집중·자격요건·공급자 수·가격행태를 더 분석해야 할 신호일 수 있으나, 그 사실만으로 담합이나 경쟁법 위반을 확정하지 않는다. 의심사실은 권한 있는 조사·보고절차로 넘기고 입찰공정성과 관련 정보의 비밀을 지킨다.

최초 등록 때는 발견일·신호·자료원과 검토담당자를 우선 남기고, 검증·평가에 따라 원인–사건–영향, 평가기간, 현재 통제, 현재 잔여등급, 책임자, 대응·발동기준과 다음 검토일을 보완한다. 신호가 데이터 오류이면 근거를 남겨 종료하고, 기존 위험과 중복이면 삭제하지 않고 해당 항목에 병합하여 변화이력·공통원인·연쇄관계를 연결한다.

위험사건이 이미 발생했다면 더 이상 가능성만 있는 위험으로 다루지 않고 사고·현안으로 즉시 통제·복구·계약조치한다. 동시에 원래 위험의 남은 노출, 재발 가능성과 그 사건이 만든 2차 위험은 리스크 레지스터에서 계속 추적한다.

4. 모니터링 결과를 공유하고 필요한 조치를 제안한다

보고가 아니라 의사결정과 개선까지 이어져야 한다

교재의 관리흐름은 다음과 같다.

모니터링 → 보고 → 공유 → 의사결정 → 개선조치

결과를 모으는 것만으로는 위험이 줄지 않는다. 결정권자가 무엇을 언제까지 판단해야 하는지, 승인 뒤 누가 실행할지를 명확히 해야 한다. 공공조달의 책임성과 설명가능성(Accountability)은 누가 어떤 근거로 결정하고 후속조치를 했는지 추적할 수 있게 하는 데서 나온다.

공유내용 포함할 정보
위험현황 주요 위험·현재 잔여등급·추세, 기준선·현재값·자료시점
실행상태 완료·진행·미실행, 기한편차·원인·증빙과 핵심조치 예외
성과 발생가능성·영향·KPI·KRI·비용 변화, 목표 대비 편차와 불확실성
신규·변화위험 신호·원인–사건–영향, 초기평가, 기존 위험과 연결
권고조치 대안·비용·효과·법적·계약상 제약, 추천안과 미조치 결과
결정요청 승인·상향·예산·변경·비상계획 가동 여부, 책임자·완료기한

내부 공유대상은 사업·계약·조달·기술·품질·예산·감사부서와 권한 있는 관리자다. 외부에는 계약상대자·공동수급·하수급 관계자, 감독·감사·상급기관과 필요한 이해관계자가 포함될 수 있다. 모든 정보를 모두에게 공개하는 것이 투명성은 아니다. 법령·계약·직무상 필요범위에 따라 영업비밀·개인정보·보안정보·입찰공정성을 보호하면서 필요한 사실과 결정사항을 적시에 공유한다.

정기보고서·회의·대시보드·전산시스템은 통상 현황을 공유하고, 안전·법 위반·필수서비스 중단·위험기준 초과·비상 발동과 중대한 계약편차는 정해진 경로로 즉시 특별보고한다. 경영진에는 원자료를 무한히 쌓기보다 추세·예외·결정요청을 선명하게 제시하고, 실무담당자에게는 실행 가능한 세부조치와 기한을 전달한다.

필요한 조치를 권한과 절차에 맞게 제안한다

교재가 제시하는 대표 조치는 대응계획 수정, 추가예산 확보, 일정 재조정, 책임자 변경·보강, 통제절차 강화와 사업범위 조정이다. 실제로는 다음을 함께 판단한다.

  • 조치의 효과·비용·시기와 새로 생길 위험
  • 법령·공고·계약문서상 변경 가능성과 승인권한
  • 공급자·사용자·현장·하수급자 등 영향을 받는 주체
  • 임시통제·비상계획과 장기 해결책의 구분
  • 미조치 시 잔여위험, 상향보고와 수용권한

대응실행력이 부족하다는 이유로 담당자를 즉시 교체하는 것이 항상 올바른 해결책은 아니다. 목표·권한·자원·교육·의사결정 지연이 원인인지 먼저 확인하고, 기관의 인사·계약 권한과 절차 안에서 역할을 보강·재배분한다. 사업범위·일정·예산·통제수준 변경도 정식 심사·협의·승인과 계약문서 반영 없이 시행하지 않는다.

기록·종결·학습까지 관리한다

의사결정 근거, 보고받은 사람, 승인·반려·예외, 후속조치와 완료증빙을 리스크 레지스터와 기관의 기록체계에 남긴다. 보존기간과 공개범위는 적용 법령·기관규정·계약문서에 따르며, 감사 대비만이 아니라 책임추적·인수인계·재평가와 다음 조달의 학습을 위해 관리한다.

위험은 일정이 끝났거나 사고가 없었다는 이유만으로 삭제하지 않는다. 원인·노출이 사라졌거나 잔여위험이 기준 안에 들었는지, 기준 밖 위험은 권한 있는 책임자가 정식 수용했는지, 관련 의무·하자·보증·분쟁과 감시 인계가 남았는지 확인한다. 종료근거·승인자·일자·인계·교훈을 기록한 뒤 종결·보관(Closed·Archived) 상태로 전환하고 과거 이력은 보존한다. 실제 사건과 대응성과, 잘 작동한 통제와 실패원인을 다음 시장조사·규격·평가·계약조건에 환류한다.

5. Part 6을 마무리하고 Part 7로 연결한다

Part 6의 전체 흐름은 식별 → 평가·우선순위 → 대응·비상계획 → 실행·성과·신규위험 모니터링 → 재평가·보완이다. 모니터링은 마지막에 한 번 하는 검사가 아니라 전 단계에 걸친 순환활동이다.

다음 Part 7에서는 공공조달 법규, 분쟁과 우대제도를 관리하는 방법을 다룬다. Part 6에서 법·제도 변경, 계약절차 위반과 분쟁 가능성을 위험으로 발견했다면 Part 7의 적용 법령·절차·권리구제 판단으로 연결한다.

③ 시험 포인트

  • 기본 흐름은 실행 확인 → 성과 측정 → 신규·변화위험 식별 → 공유·결정 → 조치·재평가다.
  • 실행상태의 기본 3단계는 완료·진행 중·미실행이며, 기한·책임자·증빙·현장과 계획 대비 편차를 함께 확인한다.
  • 완료기준 실행률은 완료÷전체×100, 완료·진행 포함 비율은 (완료+진행)÷전체×100이다. 포함기준을 명시한다.
  • 실행률은 조치의 상태이지 위험감소 효과가 아니다. 핵심 고위험 조치의 미실행 여부를 별도로 본다.
  • 성과의 다섯 요소는 발생가능성 감소, 영향 감소, 조기경보 작동, 이해관계자 반응, 비용 대비 효과다.
  • 발생확률 50%에서 20%는 30%p 절대 감소, 60% 상대 감소율로 구분한다.
  • 한 손실사건의 기대손실은 발생확률×손실금액, 여러 배타적 결과는 Σ(확률×손실)이며 동일기간·단위에서 전후 기대손실과 대응비용을 비교한다.
  • KPI는 성과, KRI는 위험노출 징후, 통제 실행지표는 조치 운영상태를 보여 준다. 지표 정의·분모·기간·자료원을 확인한다.
  • 새 위험의 흐름은 레지스터 즉시 등록 → 신호 검증 → 원인–사건–영향 → 확률·영향·중요도 → 책임·대응 → 계획 수정·보고다.
  • 민원·하자·계약변경·지연 증가와 수치 이상은 단서이며, 곧바로 원인이나 위험발생으로 확정하지 않는다.
  • 공유내용은 위험현황·등급추세·실행상태·성과·신규위험·권고조치·결정요청이다.
  • 보고는 모니터링 → 보고 → 공유 → 의사결정 → 개선조치로 완성되며, 중대위험은 정기보고일까지 기다리지 않는다.
  • 추가예산·일정·책임·통제·범위 변경은 권한·법령·계약절차에 맞게 승인하고 기록한다.
  • 종료 시 원인·노출·잔여의무·위험인수자를 확인하고, 교훈을 다음 조달에 반영한다.

  • 네 소단원: 실행 여부 → 성과 확인 → 새로운 리스크 → 공유·조치 제안

  • 확인근거: 문서·시스템 + 현장·원자료
  • 완료 실행률: 완료÷전체×100
  • 완료·진행 포함 비율: (완료+진행)÷전체×100
  • 실행 여부 ≠ 위험감소 성과
  • 성과 다섯 요소: 확률 / 영향 / 조기경보 / 이해관계자 / 비용효과
  • 비교조건: 비교 가능한 기간·범위·분모·측정방법 + 통제상태·외부변화 기록
  • 절대 확률변화: 전 확률 − 후 확률, 단위 %p
  • 상대 감소율: (전−후)÷전×100
  • 기대손실: 한 사건은 확률×손실, 여러 결과는 Σ(확률×손실)
  • 지표 역할: KPI 성과 / KRI 위험징후 / 통제지표 실행상태
  • 새 위험 원천: 외부환경 / 사업범위 / 이해관계자 / 내부관리 / 기술·보안
  • 새 위험 처리: 즉시 등록 → 신호검증 → 정의 → 확률·영향·중요도 → 책임·대응 → 계획 수정·보고
  • 공유흐름: 모니터링 → 보고 → 공유 → 의사결정 → 개선
  • 공유내용: 현황·추세·실행·성과·신규위험·권고·결정요청
  • 필요조치: 계획·예산·일정·책임·통제·범위 조정
  • 기록: 근거·승인·예외·후속조치·종료·교훈
  • 위험 종결: 잔여위험 판단·수용권한·감시인계·승인·일자 + 이력보존
