Part 1 · Chapter 2

입찰참가자격 정보 관리

공공조달 관리실무 · 공공조달 입찰참가 준비

학습목표

이 Chapter를 학습한 뒤에는 다음을 할 수 있어야 한다.

  1. 품명·세부품명 신설과 개별 제품의 품목 등록이 서로 다른 절차임을 구분한다.
  2. 품명번호 8자리·세부품명번호 10자리·품목식별번호 8자리를 구분한다.
  3. 물품목록번호 16자리가 품명번호 8자리＋품목식별번호 8자리임을 말한다.
  4. 대분류 2·중분류 4·소분류 6·세분류 8자리의 분류체계를 설명한다.
  5. 일괄요청의 동일 세부품명 10개 이상·최대 500건 기준을 말한다.
  6. 자격에 영향을 주는 정보 변경 시 증빙·심사 절차와 입찰 전 재확인의 필요성을 설명한다.

① 한눈에 보기

  • 입찰참가자격 정보 관리는 회사의 상호·대표자·면허와 공급대상물의 품명·세부품명·품목정보를 나라장터에 정확히 유지하는 업무이다.
  • 품명·세부품명 신설과 개별 제품의 품목 등록은 서로 다른 절차이다.
  • 물품분류는 8자리 품명번호와 10자리 세부품명번호를 사용하고, 개별 제품에는 8자리 품목식별번호가 부여된다.
  • 물품목록번호 16자리는 품명번호 8자리 + 품목식별번호 8자리로 구성된다.
  • 상호·대표자·주소·면허·제조물품처럼 자격에 영향을 주는 정보는 증빙과 심사를 거쳐 변경하고, 입찰 전 등록증을 다시 출력해 공고조건과 대조한다.

전체 흐름은 다음과 같다.

기존 분류 검색 → 품명·세부품명 사용 가능성 판단 → 필요 시 신설 요청 → 품목 등록·식별번호 발급 → 제조·공급 및 면허정보 연결 → 변경사항 정비 → 공고별 제출서류 대조

② 차근차근 설명

나라장터의 자격정보는 한 번 등록하고 끝나는 명부가 아니다. 회사 기본정보, 업종·면허, 제조·공급물품, 입찰대리인이 현재 사실과 일치하도록 계속 관리해야 한다. 등록정보와 법인등기·사업자등록·면허증의 내용이 다르면 입찰 무효나 계약지연의 원인이 될 수 있다.

1. 품명, 세부품명, 품목을 구분한다

조달에서는 물품을 공통 언어로 분류하기 위해 목록정보를 사용한다.

구분 의미 번호 구조
품명번호 물품의 기능·용도에 따른 기본 분류 8자리
세부품명번호 품명을 조달에 필요한 수준으로 더 세분한 분류 10자리
품목식별번호 제조사·모델·규격이 특정된 개별 제품의 식별번호 8자리
물품목록번호 분류와 개별 제품을 결합한 번호 품명번호 8자리 + 품목식별번호 8자리 = 16자리

분류체계는 대분류 2자리, 중분류 4자리, 소분류 6자리, 세분류 8자리로 내려가고 여기에 10자리 세부품명이 연결된다. 입찰공고의 참가범위와 직접생산확인은 흔히 세부품명 단위로 판단하므로, 비슷한 상품명만 맞추는 것으로는 부족하다.

품명·세부품명 신설은 기존 분류로 표현할 수 없는 새로운 기능의 제품군을 만드는 일이다. 품목 등록은 이미 존재하는 세부품명 아래에 특정 제조사·모델·규격의 제품을 올려 품목식별번호를 받는 일이다.

2. 기존 분류를 먼저 검색한다

새 제품이라고 해서 곧바로 새 세부품명을 요청하지 않는다. 먼저 목록정보시스템에서 다음 항목을 검색한다.

  1. 제품의 주된 기능과 용도에 맞는 기존 품명·세부품명
  2. 유사 제품의 품목식별번호와 핵심 속성
  3. 같은 제조사 또는 다른 제조사의 유사 모델
  4. 기존 분류로 수용할 수 있는 부가기능인지 여부

기존 세부품명으로 분류할 수 있으면 해당 분류 아래에서 품목 등록을 진행한다. 기존 분류로 포섭할 수 없고 독립된 기능·기술적 차이와 조달수요가 확인될 때에만 상위분류, 기능, 성능, 기존 제품과의 차이, 기술자료를 갖춰 품명·세부품명 신설을 요청한다. 동일·유사 분류의 중복 신설은 허용되지 않는다.

융복합제품도 이름만 새롭다고 별도 세부품명이 되는 것은 아니다. 여러 기능이 하나의 몸체에 결합된 융합상품인지, 독립된 품목들이 시스템으로 구성된 복합상품인지, 기존 분류로 표현할 수 있는지를 먼저 분석한다.

3. 품목 등록으로 식별번호를 받는다

품목 등록에는 제품을 객관적으로 식별할 수 있는 정보가 필요하다.

  • 제조업체명, 모델명, 원산지
  • 규격·재질·크기·성능 등 세부품명별 필수속성
  • 제품설명서, 시험자료 등 필요한 증빙
  • 실제 제품을 확인할 수 있는 실물 이미지
  • 다수공급자계약, 총액계약, 물품관리 등 활용 목적

제품 이미지는 로고나 개념도만 올리는 것이 아니라 실제 물품을 식별할 수 있는 사진을 사용한다. 품목명은 보통 세부품명, 제조업체명, 모델명과 대표 속성이 드러나도록 구성한다.

교재상 품목 등록 방식은 다음처럼 구분한다.

방식 적용 모습 관리 포인트
개별요청 품목 수가 적거나 건별 입력이 적합한 경우 품목별 속성과 이미지 직접 확인
일괄요청 동일 세부품명 품목이 10개 이상인 경우 지정 엑셀양식 사용, 최대 500건, 양식 임의변경 금지
참조등록 기존의 유사 품목정보를 활용하는 경우 참조값을 그대로 복사하지 말고 실제 제품정보로 수정

10개·500건은 교재와 해당 업무안내의 처리 기준으로 학습하되, 실제 신청에서는 현행 목록정보시스템 안내와 최신 서식을 다시 확인한다. 화면 구성, 처리일수, 보완기한은 개편될 수 있으므로 구교재의 메뉴명이나 일수를 법정 불변값처럼 사용하지 않는다.

4. 공급물품과 제조물품을 정확히 연결한다

등록 구분 실질 핵심 확인사항
공급물품 다른 업체가 만든 물품을 구매·유통하여 납품 적정 세부품명, 공급 가능성, 공고가 공급참여를 허용하는지
제조물품 자기 책임 아래 필요한 설비·인력·공정으로 직접 생산 생산공장, 제조능력, 직접생산확인 적용 여부
공사·용역 관계 법령상 등록·허가를 바탕으로 업무 수행 업종코드, 면허번호, 유효기간, 행정처분

상표권을 가지고 있어도 전 생산공정을 외부 업체에 맡기는 OEM 방식은 제조물품으로 자동 인정되지 않으며 통상 공급물품 관점에서 검토한다. 제조와 공급을 모두 등록할 수는 있지만 각 구분의 요건을 따로 충족해야 한다.

일반 제조물품의 나라장터 제조등록과 중소기업자 간 경쟁제품의 직접생산확인은 같은 제도가 아니다. 일반 제조등록 절차에서 제조공정표 제출이 생략되는 경우가 있더라도, 경쟁제품 입찰에 필요한 유효한 직접생산확인증명서까지 면제되는 것은 아니다.

5. 회사 자격정보를 변경 관리한다

변경항목은 자격에 미치는 영향에 따라 관리방법이 다르다.

변경의 성격 대표 항목 실무 처리
법적 동일성·자격에 영향 상호, 대표자, 주소, 법인등기, 기업구분 등기·사업자 자료를 먼저 정비하고 증빙을 붙여 변경신청
수행능력에 영향 제조공장, 제조물품, 공사·용역업종, 면허 발급기관 변경·갱신 후 나라장터 심사사항 반영
대리권에 영향 입찰대리인 신규·변경, 퇴사자 삭제 위임·재직관계 확인, 권한 종료 즉시 삭제
연락·운영정보 전화, 팩스, 이메일, 홈페이지 등 시스템이 허용하는 범위에서 자체 수정

교재는 입찰대리인 삭제나 연락처 등 일부를 자체수정 항목으로, 상호·대표자·제조물품·면허·입찰대리인 등록 등을 승인 항목으로 구분한다. 다만 실제 승인대상과 제출방법은 시스템 개편에 따라 바뀔 수 있으므로 현재 화면의 안내를 우선한다.

상호가 바뀌면 나라장터 정보뿐 아니라 인증서, 사업자등록, 통장·인감과 제출서류의 명칭이 일치하도록 정비한다. 대표자 변경은 법인의 동일성이 유지되더라도 입찰 전에 변경등록하고, 기존 위임의 범위를 확인하여 입찰대리인 권한을 다시 정비하는 것이 안전하다.

6. 공고별 제출서류를 생애주기로 관리한다

서류는 이름만 목록으로 모으지 않고 발급기관, 기준일, 유효기간과 전자확인 여부를 관리한다.

서류 묶음 예시 관리 포인트
회사·자격 사업자등록, 등기사항증명, 인감, 업종·면허 나라장터 등록정보와 일치
물품·기업 세부품명, 직접생산확인, 중소기업확인 공고 기준일에 유효, 대상번호 일치
가격 입찰서, 산출내역서, 가격제안서, 보증자료 공고 양식·금액·서명 일치
기술·수행 제안서, 인력계획, 실적, 신용평가 인정기간과 증명 발급주체 확인
사후심사 납세·보험 완납, 재무자료, 추가 실적 제출대상과 보완 허용 여부 확인

전자연계로 확인되는 서류는 별도 첨부가 생략될 수 있고, 공고가 별도 파일을 요구하면 다시 제출해야 할 수 있다. 따라서 ‘서류 파일을 올리지 않았다’는 사실만으로 곧바로 무효라고 단정하지 않고, 자격의 실제 보유·전자조회·공고상 필수제출 여부와 보완 가능성을 함께 확인한다.

③ 시험 포인트

  • 품명·세부품명 신설은 분류를 만드는 절차이고, 품목 등록은 개별 제품의 식별번호를 받는 절차이다.
  • 물품분류는 대2·중4·소6·세분8, 세부품명번호는 10자리이다.
  • 품목식별번호는 8자리이고 물품목록번호는 품명번호 8자리 + 품목식별번호 8자리의 16자리이다.
  • 신설 요청 전 기존·유사 품명과 품목을 검색하여 중복 여부를 확인한다.
  • 공급물품, 제조물품, 공사·용역 업종은 등록 근거와 증빙이 다르다.
  • 일반 제조물품 등록절차의 서류 간소화와 경쟁제품 직접생산확인 의무를 혼동하지 않는다.
  • 회사정보 변경은 등기·면허 등 원자료를 먼저 정비한 뒤 나라장터와 인증서까지 일치시킨다.
  • 목록화의 화면·처리일수·보완기간은 개정 가능하므로 교재 수치를 적용할 때 현행 안내를 확인한다.
