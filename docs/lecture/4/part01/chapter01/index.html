Part 1 · Chapter 1

공공조달 참여 준비하기

공공조달 관리실무 · 공공조달 입찰 참가 준비

이 강의는 공식 출제기준과 조달청 표준교재를 바탕으로 새로 작성했습니다. 1-1에서 요구하는 법령·일반제도, 참가자격, 직접생산, 적합 업종의 판정에 필요한 내용만 다룹니다.

이 장에서 배울 것

공식 출제기준의 네 가지 수행능력은 다음과 같습니다.

공식 수행능력 이 장의 학습 결과
관련 고유 법령과 일반제도 확인 발주기관과 조달대상에 맞는 규정 묶음을 찾는다.
경쟁입찰참가자격 요건 검토 공고의 요건과 업체의 등록·증빙을 대조한다.
직접생산확인기준 검토 중소기업자간 경쟁제품과 일반 제조물품의 확인 경로를 구분한다.
적합한 업종 검토 법정 자격과 나라장터 업종 등록의 일치 여부를 판단한다.

판정 순서는 다음 한 줄로 기억합니다.

기관 → 대상 → 자격 → 생산 → 업종 → 증빙

이는 법령에 정해진 신청 절차가 아니라, 네 수행능력을 빠짐없이 적용하기 위한 학습용 검토 순서입니다. 세부품명 신설·정보 갱신은 1-2, 신청서 제출·보완·승인은 1-3에서 자세히 다룹니다.

핵심 사례

한결테크는 중앙행정기관의 물품 제조구매 공고를 발견했습니다. 회사는 사업자등록과 나라장터 조달업체 등록을 마쳤지만, 공고의 10자리 세부품명은 공급물품으로만 등록되어 있습니다. 공고는 같은 세부품명의 제조물품 등록과 유효한 직접생산확인 증명을 요구하고, 납품 범위에는 설치도 포함합니다.

현재는 참가할 수 없습니다. 나라장터 등록 사실만으로 개별 공고의 참가자격이 생기지 않으며, 공급물품 등록은 제조물품 등록을 대신하지 않습니다. 직접생산 요건도 충족하지 못했습니다. 설치에 필요한 별도 업종·면허가 있는지는 규격서와 고유법령을 더 확인해야 합니다.

이 사례에서 가장 중요한 구분은 두 줄입니다.

  • 이용자 등록 ≠ 경쟁입찰참가자격 등록 ≠ 개별 공고 참가 가능
  • 사업자등록 업태·종목 ≠ 제조물품 등록 ≠ 직접생산확인

1. 관련 고유 법령과 일반제도 확인

1) 기관의 법적 지위부터 확인한다

기관 이름만으로 적용 법령을 단정하면 안 됩니다. 설립·운영 근거로 법적 지위를 확인하고, 공고가 인용한 규정까지 대조합니다.

발주기관 검토의 출발점 함께 볼 자료
국가기관 국가계약법령 계약예규, 조달청 규정, 공고·특수조건
지방자치단체 지방계약법령 행정안전부 예규, 자치단체 규정, 공고
공기업·준정부기관 공기업·준정부기관 계약사무규칙 기관 계약규정과 공고
그 밖의 공공기관 설립·운영 근거와 기관 계약규정 준용 규정과 공고

이 표는 조사의 출발점입니다. 실제 적용 규정은 기관의 법적 지위와 개별 공고를 확인해 확정합니다.

  • 일반제도: 기관 유형별 계약체계, 전자조달, 경쟁입찰참가자격 등록처럼 공통으로 작동하는 틀
  • 고유 법령: 특정 물품·용역·공사의 생산·영업·시공에 허가·면허·등록·신고 등을 요구하는 대상별 법령

2) 조달대상의 성질을 분류한다

공고명만 보지 말고 과업내용서·규격서·특수조건으로 실제 계약의 주된 내용을 확인합니다.

대상 핵심 확인사항
물품 공급 공고가 허용하는 10자리 세부품명과 공급 등록 범위
물품 제조 같은 세부품명의 제조 등록과 생산 관련 증빙
용역 고유법령과 공고가 요구하는 업종·자격
공사 공종, 업종, 필요한 경우 주력분야와 법정 면허

물품 납품에 설치가 포함되어도 곧바로 공사라고 단정하지 않습니다. 설치가 납품의 부수업무인지 별도의 법정 공사인지 규격서와 고유법령으로 판단합니다.

2. 경쟁입찰참가자격 요건 검토

1) 등록과 개별 공고 자격을 구분한다

나라장터에서 전자업무를 할 수 있다는 것, 업체의 자격정보가 등록되어 있다는 것, 이번 공고의 모든 조건을 충족했다는 것은 서로 다른 판단입니다.

입찰참가자격 등록은 신청만으로 끝나지 않습니다. 등록담당공무원의 신청내용·제출서류 검토와 등록확인을 거쳐 확정됩니다. 업체는 공급물품·제조물품·공사·용역·기타업종 중 해당 분야를 하나 이상 등록하고, 각 분야의 법정요건을 충족하면 여러 분야를 함께 등록할 수 있습니다.

등록정보가 바뀌면 정해진 절차에 따라 갱신해야 합니다. 허위 정보, 공고와 불일치하는 정보, 미갱신 정보는 자격 미충족이나 입찰 무효 등 불이익의 원인이 될 수 있습니다.

2) 네 층으로 대조한다

검토층 확인 내용 대표 자료
공통요건 사업자등록, 관계 법령상 허가·인가·면허·등록·신고, 필요한 적합판정 사업자등록 자료, 관계기관 증명
나라장터 등록범위 물품 세부품명, 용역 업종, 공사 업종·주력분야 경쟁입찰참가자격등록증, 자기정보
공고별 요건 기업규모, 지역, 실적, 면허·업종, 직접생산 등 공고문, 특수조건, 확인서
배제사유·유효성 참가제한, 휴·폐업, 정지·말소·만료, 요건별 기준일 제재·행정처분 상태, 발급일·만료일

물품 입찰은 등록된 세부품명 등의 범위, 용역은 등록 업종, 공사는 등록 업종 또는 공고가 요구하는 주력분야가 실제 공고와 일치하는지 확인합니다. 비슷한 품명이나 사업자등록 종목으로 대신할 수 없습니다.

또한 모든 자격에 하나의 기준일을 임의로 적용하지 않습니다. 원칙적으로 공고가 각 요건에 정한 기준일과 증빙의 유효상태를 따로 대조합니다. 다만 관계 법령상 허가·면허는 적법하게 갱신했으나 나라장터 등록 갱신만 누락한 경우처럼 등록규정이 사후보완을 허용하는 예외가 있으므로, 공고와 입찰참가자격등록규정 제9조제3항의 적용 여부도 확인합니다.

3. 직접생산확인기준 검토

1) 공급과 제조를 먼저 가른다

  • 공급물품 등록: 신청업체가 직접 생산하지 않고 다른 제조업체의 물품을 구매해 공급하려는 10자리 세부품명 등록
  • 제조물품 등록: 신청업체가 직접 생산·제조하는 세부품명으로, 필요한 생산 요건과 증빙을 확인받은 등록

사업자등록증에 제조업이 적혀 있어도 특정 세부품명의 제조물품 등록을 대신하지 않습니다. 실제 제조업체라도 그 세부품명이 공급물품으로만 등록되어 있다면 제조 등록을 요구한 공고에는 참가할 수 없습니다.

2) 두 확인 경로를 구분한다

구분 핵심 확인 주의점
중소기업자간 경쟁제품 지정 세부품명인지, 법령·공고상 직접생산확인이 필요한지, 판로지원법상 증명이 유효한지 필요한 직접생산확인증명은 제조 등록 신청 때 제출하며, 모든 계약에 같은 증명이 필요하다고 단정하지 않음
일반 제조물품 공장·임차, 생산 인허가, 상시근로자 등 제조 등록자료와 해당 세부품명 현행 등록 신청 때 제조공정표는 제출하지 않고, 등록 후 납품실적에 따른 조사 통지를 받으면 공정표 등 실제 생산자료를 제출

판정은 다음 순서로 합니다.

  1. 공고의 10자리 세부품명을 확인한다.
  2. 중소기업자간 경쟁제품 지정 여부를 확인한다.
  3. 법령과 공고가 직접생산확인을 요구하는지 확인한다.
  4. 중소기업자간 경쟁제품 경로와 일반제품 경로 중 적용 기준을 정한다.
  5. 세부품명, 생산공장, 확인자료와 각 기준일의 유효상태를 대조한다.

타사 완제품을 그대로 납품하거나, 상표·포장만 바꾸거나, 제조 전 과정을 하청 생산하고 직접 생산한 것처럼 납품하면 원칙적으로 직접생산하지 않은 것으로 판정됩니다. 다만 적용 기준에 위탁생산 등 특례가 있는지는 별도로 확인합니다. 품목별 시설·인력·필수공정은 서로 다르므로 해당 세부기준을 확인해야 합니다.

4. 적합한 업종 검토

업종은 다음 세 층을 분리해 확인합니다.

구분 역할 확인사항
사업자등록 업태·종목 영위 사업의 기초정보 해당 사업이 나타나는가
고유법령상 자격 실제 영업·시공·용역 수행의 법정요건 허가·인가·면허·등록·신고가 필요한가
나라장터 업종 등록 전자조달시스템의 참가 범위 공고의 업종코드·주력분야와 일치하는가

사업자등록 종목이 같다고 법정 면허와 나라장터 업종 등록까지 충족한 것은 아닙니다. 반대로 모든 용역이나 설치 업무에 면허가 필요한 것도 아닙니다. 고유법령과 공고가 요구할 때만 해당 자격을 적용합니다.

업종 검토 결과에는 법적 근거, 자격 종류, 발급기관·등록번호, 나라장터 업종코드, 공고상 기준일의 유효상태를 남깁니다.

5. 최종판정과 검토표

판정 의미 조치
참가 가능 모든 필수요건이 각각의 기준일에 충족됨 투찰 전 자기정보 재확인
보완 필요 자료가 부족하거나 기준일 전 적법한 보완 가능성을 확인해야 함 보완 가능 여부와 기한 확인 후 재판정
참가 불가 필수요건을 기준일 안에 충족할 수 없고 공고·규정상 사후보완 예외도 없음 투찰하지 않고 다음 기회 준비

이 세 표현은 검토 편의를 위한 학습용 판정이지 법령상의 처분명은 아닙니다.

한결테크 판정

항목 공고 요구 업체 상태 판정·조치
기관·대상 중앙행정기관의 특정 세부품명 제조구매 기관과 대상 확인 적용 법령·공고 대조
참가자격 같은 세부품명의 제조물품 등록 공급물품으로만 등록 불충족, 기준일 전 보완 가능성 확인

필답형 답안 틀

사례형은 네 문장으로 씁니다.

  1. 결론: 참가 가능, 보완 필요, 참가 불가 중 하나를 먼저 제시한다.
  2. 기준: 적용 법령·공고와 필수요건을 쓴다.
  3. 적용: 업체의 등록·증빙을 요건별로 대조한다.
  4. 조치: 보완 가능성, 기준일, 재판정 또는 투찰 중단을 쓴다.

절차형은 확인 주체 → 확인자료 → 대조항목 → 기준일 → 판정이 드러나게 작성합니다.

핵심 연습문제 10선

  1. O/X: 기관 명칭에 공사가 들어가면 공기업·준정부기관 계약사무규칙이 적용된다고 확정할 수 있다.
  2. O/X: 나라장터 이용자 등록을 마치면 개별 공고의 참가자격도 충족한다.
  3. O/X: 사업자등록증의 제조업 표시는 특정 세부품명의 제조물품 등록을 대신한다.
  4. O/X: 설치가 포함된 물품구매는 언제나 공사업 면허가 필요하다.
  5. 관련 고유 법령과 일반제도를 확인할 때 무엇을 어떤 순서로 검토하는지 쓰시오.
  6. 이용자 등록, 경쟁입찰참가자격 등록, 개별 공고 참가 가능을 구분하시오.
  7. 중소기업자간 경쟁제품과 일반 제조물품의 직접생산 확인 경로를 비교하시오.
  8. 공고를 발견한 뒤 참가 여부를 판정하는 전체 순서를 쓰시오.
  9. 한 업체가 공고의 세부품명을 공급물품으로만 등록했고, 공고는 제조물품 등록과 직접생산확인 증명을 요구한다. 사업자등록에는 제조업이 기재되어 있다. 참가 여부와 조치를 쓰시오.
  10. 용역 공고가 고유법령상 등록과 특정 나라장터 업종코드를 요구한다. 업체는 사업자등록 종목만 일치하고 법정 등록은 만료되었으며 업종코드는 없다. 참가 여부와 조치를 쓰시오.

정답과 핵심해설

  1. X. 기관의 설립·운영 근거로 법적 지위를 확인하고 공고가 인용한 계약법령·기관 규정을 대조해야 합니다.
  2. X. 시스템 이용, 자격정보 등록, 개별 공고 충족은 서로 다른 판단입니다.
  3. X. 사업자등록, 공급·제조물품 등록, 직접생산확인은 서로 대신하지 않습니다.
  4. X. 규격서로 납품의 부수업무인지 별도 법정 공사인지 먼저 판단합니다.
  5. 기관의 법적 지위와 기관별 계약체계, 전자조달·등록제도, 대상물 고유법령, 공고·특수조건 순으로 확인합니다.
  6. 이용자 등록은 시스템 이용의 출발점, 참가자격 등록은 세부품명·업종 등 자격정보의 등재, 개별 공고 참가 가능은 모든 공고 요건과 실제 증빙이 각 기준일에 일치하는지 내린 판단입니다.
  7. 중소기업자간 경쟁제품은 지정 여부와 법령·공고상 필요성을 확인한 뒤 판로지원법상 직접생산 증명과 품목별 기준을 대조합니다. 일반 제조물품은 공장·생산 인허가·근로자 등 제조 등록자료를 확인하며, 납품 후 조달청 기준에 따른 실태조사를 받을 수 있습니다.
  8. 기관 → 대상 → 자격 → 생산 → 업종 → 증빙 순으로 확인하고, 각 요건의 기준일과 유효성을 대조해 참가 가능·보완 필요·참가 불가로 판정합니다.
  9. 현재 참가할 수 없습니다. 공급물품 등록과 사업자등록의 제조업 표시는 제조물품 등록·직접생산확인을 대신하지 않습니다. 두 요건을 공고상 기준일까지 적법하게 충족할 수 있는지 확인하고, 불가능하면 투찰하지 않습니다.
  10. 현재 참가할 수 없습니다. 사업자등록 종목은 법정 등록과 나라장터 업종코드를 대신하지 않으며 만료된 등록은 유효한 증빙이 아닙니다. 기준일 전 적법한 회복·등록이 가능한지 확인하고 불가능하면 투찰하지 않습니다.

시험 직전 핵심정리

  • 공식 네 항목: 법령·일반제도 / 참가자격 / 직접생산 / 적합 업종
  • 검토 흐름: 기관 → 대상 → 자격 → 생산 → 업종 → 증빙
  • 등록 구분: 이용자 등록 ≠ 참가자격 등록 ≠ 개별 공고 충족
  • 제조 구분: 사업자등록 ≠ 제조물품 등록 ≠ 직접생산확인
  • 직접생산: 10자리 세부품명 → 지정 여부 → 법령·공고상 필요성 → 적용 경로 → 유효 증빙
  • 업종: 사업자등록 종목 → 고유법령상 자격 → 나라장터 업종·주력분야
  • 답안: 결론 → 기준 → 적용 → 조치
