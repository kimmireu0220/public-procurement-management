# 경쟁입찰 참가자격신청하기

경쟁입찰참가자격 등록은 회사 이름을 나라장터에 올리는 단순 가입이 아닙니다. 법적 주체, 본점 사업자등록번호, 대표자, 주소, 세부품명, 업종, 제조정보, 입찰대리인과 이를 증명하는 자료가 서로 맞아야 하고, 등록담당공무원의 확인을 거쳐야 합니다. 등록이 끝난 뒤에도 개별 공고의 요건과 기준일에 맞는지는 입찰할 때마다 다시 판단해야 합니다.

이 장은 신청서 작성 → 증빙 제출 → 심사·보완 → 등록확인 → 세부품명 등재 → 입찰대리인 등록 → 자기정보 검증을 한 번에 수행하는 강의입니다. 조달청 표준교재의 업무 흐름을 학습 기반으로 삼되, 화면 위치와 상태값은 개편될 수 있으므로 2026년 현행 국가종합전자조달시스템 입찰참가자격등록규정의 요건을 우선합니다.

이 강의 하나의 완료 기준

다음 아홉 가지를 수행하면 이 장을 완료한 것입니다.

  1. 경쟁입찰참가자격 등록과 나라장터 이용자 등록, 개별 공고 참가 가능성을 구분한다.
  2. 본점 사업자등록번호·대표자·주소·등록분야를 증빙과 일치하게 작성한다.
  3. 대표자가 여러 명일 때 전원을 입력하고 대표대표자 1명을 지정한다.
  4. 공급물품과 제조물품의 세부품명 등록 경로를 구분한다.
  5. 미등록 세부품명은 목록화 절차를 먼저 밟아 번호를 부여받는다.
  6. 입찰대리인의 재직성과 결격·중복등록 여부를 검토한다.
  7. 입찰대리인 등록용 재직증명서와 추가 증빙 중 적합한 자료를 준비한다.
  8. 보완요구에 대응하고 등록담당공무원의 확인과 시스템 반영을 검증한다.
  9. 공고 투찰 전 자기정보 확인표를 작성한다.

공식 수행능력표

공식 세세항목 이 강의의 학습 결과 확인 산출물

오늘의 사례: 등록신청을 급하게 끝내면 생기는 일

다온솔루션은 첫 공공입찰을 준비합니다. 법인등기에는 공동대표 두 명이 있으나 신청서에는 영업담당 대표 한 명만 적었습니다. 제품은 자체 제조한다고 설명했지만 등록하려는 세부품명이 목록에서 검색되지 않았고, 공장 자료도 정리되지 않았습니다. 영업팀장은 외부 프리랜서를 입찰대리인으로 넣으려 하며, 그 사람이 다른 회사의 입찰대리인으로 이미 등록되어 있는지는 모릅니다. 공고 마감은 사흘 뒤입니다.

이 상태에서 신청버튼부터 누르면 안 됩니다. 대표자 정보는 등기와 불일치하고, 세부품명은 목록화 선행 여부가 미확정이며, 외부 프리랜서는 재직 임직원 요건을 충족하지 못할 가능성이 큽니다. 등록담당공무원의 확인 시점과 공고의 기준일까지 고려하면 이번 입찰 참가가 가능한지도 별도로 판단해야 합니다.

1. 등록의 법적 의미를 먼저 정리한다

구분 목적 종료 기준 오해 방지
나라장터 이용자 등록 전자조달시스템을 이용할 사용자 기반 마련 이용에 필요한 인증·사용자 절차 완료 개별 입찰자격을 자동 취득하지 않음
경쟁입찰참가자격 등록 업체의 법적 주체와 물품·용역·공사 등 자격정보 등재 등록담당공무원의 확인과 시스템 반영 모든 공고 참가를 보장하지 않음
세부품명 등록 공급 또는 제조할 물품의 범위를 세부품명 단위로 등재 등록증·자기정보에서 정확한 번호와 구분 확인 개별 모델 목록화와 구분
개별 공고 참가판정 공고가 요구한 모든 조건을 기준일에 충족하는지 확인 요건별 증빙과 자기정보 일치 등록증 하나만 보고 판단하지 않음

현행 등록규정 제10조에 따라 등록자는 시스템에서 경쟁입찰참가자격등록증을 출력할 수 있습니다. 그 등록증은 계약담당공무원이 시스템을 통해 참가자격을 확인할 수 있는 경우에 효력이 있습니다. 출력물의 보유만이 아니라 시스템의 현재 정보가 핵심입니다.

2. 등록신청 문서를 작성한다

2.1 작성 전에 원본 대조표를 만든다

화면에 먼저 입력하지 말고 원본 문서에서 값을 모아 대조표를 만듭니다.

신청영역 기준이 되는 원본 확인 질문
법적 주체 사업자등록·법인등기 개인·법인 구분, 본점 사업자등록번호가 맞는가?
상호·명칭 사업자등록·법인등기 띄어쓰기와 법인표시를 포함해 일치하는가?
대표자 법인등기·사업자등록 대표자 전원을 빠짐없이 적었는가?
대표대표자 대표자 관계 자료 여러 대표자 중 시스템상 대표대표자 1명을 정했는가?
주소 사업자등록 등 현재 증빙 본점 주소와 관할 제출처 판단이 맞는가?
물품·업종 목록정보·허가·면허·등록증 정확한 세부품명·업종코드·주력분야인가?
제조·공장 공장·임대차·생산 인허가·근로자 자료 해당 제조등록 경로의 요건을 충족하는가?
입찰대리인 인사·세무·보험·등기 자료 실제 재직 임직원이며 중복·제재 문제가 없는가?

등록규정 제13조에 따르면 본사 소재지의 사업자등록번호를 입력하고 대표자 전원을 등록해야 합니다. 대표자가 둘 이상이면 대표대표자 1명을 반드시 정하고, 각자대표인지 공동대표인지도 실제 등기 관계와 맞게 구분합니다. 누락된 공동대표가 전자서명을 하지 않았다는 식으로 화면만 맞추는 것이 아니라 법적 대표관계를 정확히 반영해야 합니다.

2.2 신청·제출·확인의 순서

  1. 등록분야를 물품, 공사, 용역 등 실제 사업 범위에 맞춰 정한다.
  2. 법적 주체와 본점 사업자등록번호, 상호, 주소, 대표자 전원을 원본대로 입력한다.
  3. 물품의 공급·제조 세부품명, 용역 업종, 공사 업종·필요한 주력분야를 해당 근거와 함께 선택한다.
  4. 지정된 전자서명 수단으로 시스템에서 신청한다.
  5. 자격별 증빙을 전자적으로 첨부해 본사 소재지를 관할하는 지방조달청 또는 본청 담당부서에 제출한다. 부득이한 경우 규정이 허용하는 우편·방문 경로를 확인한다.
  6. 신청상태와 접수 여부를 확인하고 접수번호·제출파일·제출시각을 보관한다.
  7. 심사 중 보완요구가 오면 요구사항을 항목별로 분석하여 기한 안에 회신한다.
  8. 등록담당공무원의 확인 후 시스템 자기정보와 출력 등록증을 대조한다.
  9. 참가하려는 공고의 요건과 기준일에 다시 대조한다.

신청했다는 사실은 등록 완료와 다릅니다. 등록규정 제15조상 기본적인 효력 발생점은 등록담당공무원이 등록내용을 확인한 때입니다. 자동 연계 정보나 행정처분기관이 직접 입력하는 정보와 같은 예외가 있지만, 수험 답안과 내부 통제에서는 신청 → 접수 → 확인 → 반영 → 자기정보 검증을 구분하는 것이 안전합니다.

2.3 보완과 처리기간을 혼동하지 않는다

제출서류가 불명확하거나 누락되면 담당공무원은 보완을 요구할 수 있습니다. 보완요구 후 20일이 지나도록 회신하지 않으면 신청이 반려될 수 있습니다. 이 20일은 신청 후 20일이면 자동 승인도 아니고 모든 등록신청의 처리기간도 아닙니다.

등록규정 제18조의 기본 처리기간은 신청서류 접수 후 8근무시간 이내입니다. 다만 보완, 사실확인, 전산장애 등으로 더 걸리면 담당자는 지연사유와 처리예정일을 알리도록 되어 있습니다. 근무시간 뒤에 제출한 신청서류는 다음 근무일 09:00에 접수된 것으로 봅니다. 따라서 마감 직전 신청은 처리기간 규정만 믿고 성공을 전제해서는 안 됩니다.

3. 세부품명을 등록한다

3.1 번호보다 먼저 경로를 고른다

경로 등록되는 내용 주요 확인 필요한 선행조치
공급물품 신청한 세부품명을 공급 범위로 등재 실제 공급대상, 정확한 10자리 세부품명 목록에 없으면 목록화 요청
중소기업자간 경쟁제품 제조 직접생산확인이 필요한 경우 그 증명 경로와 제조 세부품명 지정제품 여부, 이번 계약의 직접생산 요구, 증명 유효성 필요한 직접생산 확인
일반제품 제조 제조 증빙을 확인한 세부품명 공장등록 또는 인정자료, 임차관계, 생산 인허가, 상시근로자 등 해당 요건 제조 기반 자료 준비

표준교재는 신청화면에서 공급물품 또는 제조물품의 세부품명을 검색·선택하는 흐름을 보여 줍니다. 그러나 시험 답안은 버튼 이름이 아니라 다음 논리를 적어야 합니다.

  1. 공고와 실제 제품의 세부품명을 10자리 번호로 특정한다.
  2. 목록정보에서 존재 여부와 정의를 확인한다.
  3. 목록에 없으면 품명·세부품명의 목록화 요청을 거쳐 번호를 부여받는다.
  4. 회사가 공급자인지 제조자인지 정하고, 제조라면 제품 유형에 맞는 증빙 경로를 선택한다.
  5. 세부품명을 신청서에 입력하고 해당 증빙을 첨부한다.
  6. 등록담당공무원의 확인 후 등록증에서 공급·제조 구분과 번호를 검증한다.
  7. 공고가 요구한 등록형태와 기준일에 맞는지 다시 확인한다.

사업자등록증에 제조업 기재, 회사에 공장이 있음, 해당 세부품명의 제조물품 등록, 공고가 요구하는 직접생산확인은 서로 다른 사실입니다. 하나가 다른 것을 자동으로 증명하지 않습니다.

3.2 세부품명 등록판정의 예

다온솔루션 제품이 목록에 없는 경우 먼저 목록화 요청으로 분류번호를 받아야 합니다. 이후 단순 판매라면 공급물품 경로를, 실제 제조하고 공고도 제조등록을 요구한다면 제조물품 경로를 검토합니다. 중소기업자간 경쟁제품이면 지정 내역과 해당 계약의 직접생산 요건을 확인하고, 일반제품이면 현행 등록규정 제22조의 공장·생산·근로자 관련 자료를 확인합니다. 제조 예정이라는 진술만으로 제조물품을 등록할 수는 없습니다.

4. 입찰대리인을 등록한다

4.1 등록 가능한 사람

현행 등록규정 제13조제5항의 핵심은 입찰대리인이 해당 업체에 재직 중인 임직원이어야 한다는 것입니다. 외부 영업대행사 직원, 프리랜서, 퇴직자, 이름만 빌린 사람은 이 요건에 맞지 않습니다.

다음 두 묶음을 함께 준비합니다.

필수 묶음 내용
재직증명 해당 회사의 재직증명서
추가 재직확인 최근 3개월 이내 발급된 4대보험 가입증명자료 중 하나, 해당 소속사가 발급·제출하는 근로소득세 관련 납부자료, 또는 법인등기사항증명서 중 하나. 행정정보 조회 동의로 확인 가능한 경우는 그 절차를 따른다.

추가로 다음 결격·중복 조건을 확인합니다.

  • 부정당업자 입찰참가자격 제한을 받고 있는 사람은 제한기간 중 입찰대리인으로 등록할 수 없습니다.
  • 한 사람이 둘 이상의 업체에 입찰대리인으로 중복 등록될 수 없습니다.
  • 등록 이후 퇴사·전보·신분변경이 생기면 즉시 변경신청 대상인지 확인하고 자기정보를 정리합니다.

입찰대리인 등록은 그 사람에게 회사 내부의 모든 계약권한을 자동으로 부여한다는 뜻이 아닙니다. 실제 입찰·계약행위의 내부 위임범위, 전결규정, 보안통제도 별도로 정해야 합니다. 반대로 내부 위임장만 있다고 나라장터 등록요건이 생략되는 것도 아닙니다.

4.2 입찰대리인 등록 절차

  1. 후보자가 현재 재직 임직원인지 인사원장으로 확인한다.
  2. 제재 중인지, 다른 업체에 중복 등록되어 있는지 본인 확인과 시스템 조회로 점검한다.
  3. 재직증명서를 발급하고 추가 재직확인자료 중 적합한 하나를 준비한다.
  4. 성명·식별정보·직위 등 신청항목을 증빙과 일치하게 입력한다.
  5. 개인정보 처리와 행정정보 조회 동의가 필요한 경우 적법하게 받는다.
  6. 증빙을 첨부하여 등록·변경신청하고 접수번호를 남긴다.
  7. 등록담당공무원의 확인과 시스템 반영을 조회한다.
  8. 실제 업무권한, 인증수단 보관, 퇴사 시 말소 책임자를 내부 규정에 연결한다.

신원확인입찰이 적용되는 경우에는 등록규정이 정한 개인인증수단으로 신원을 확인한 뒤 참가해야 합니다. 어떤 인증수단과 화면을 쓰는지는 실제 공고와 최신 나라장터 안내를 확인합니다.

7. 필답형 답안 프레임

유형 A: 경쟁입찰참가자격 등록문서 작성

사업자등록과 법인등기 등 원본을 기준으로 법적 주체, 본점 사업자등록번호, 상호, 주소, 대표자 전원을 대조한다. 대표자가 여러 명이면 대표대표자 1명을 지정하고 각자·공동대표 관계를 실제 등기와 맞춘다. 물품은 공급·제조 세부품명을, 용역·공사는 업종과 필요한 주력분야를 근거자료에 맞게 입력한다. 전자서명하여 신청하고 자격별 증빙을 관할 조달청에 제출한다. 보완요구에 대응한 뒤 등록담당공무원의 확인과 시스템 반영, 등록증 출력내용을 검증한다. 마지막으로 개별 공고의 요건과 기준일에 다시 대조한다.

유형 B: 세부품명 등록

실제 제품과 공고의 10자리 세부품명을 특정하고 목록정보에서 존재 여부와 정의를 확인한다. 없으면 목록화 요청으로 번호를 부여받는다. 공급물품인지 제조물품인지 판정하고, 제조이면 중소기업자간 경쟁제품 또는 일반제품 경로에 맞는 직접생산·공장·생산 증빙을 준비한다. 신청·확인 후 등록증의 공급·제조 구분과 세부품명번호를 검증하고 공고 기준일 충족 여부를 판단한다.

유형 C: 입찰대리인 등록

후보자가 해당 업체의 현재 재직 임직원인지 확인하고 재직증명서와 최근 3개월 이내 4대보험 가입증명자료, 소속사의 근로소득세 납부자료, 법인등기사항증명서 중 적합한 하나를 준비한다. 입찰참가자격 제한 중인지와 둘 이상의 업체에 중복 등록되어 있는지를 확인한다. 신청 후 담당공무원 확인과 시스템 반영을 검증하며, 퇴사·신분변동 시 즉시 변경하도록 내부 책임자를 정한다.

원본대조, 신청항목 입력, 전자서명 신청, 증빙 제출, 접수 확인, 보완, 담당공무원 확인, 시스템 반영 검증, 등록증 출력, 공고 기준일 재판정. 타당한 단계당 0.5점, 최대 4점.

문제 10. 사례형 3점: 외부 프리랜서를 내부 위임장만으로 입찰대리인으로 등록하려는 계획을 평가하시오.

정답·채점: 재직 임직원이 아니므로 부적합 1점, 내부 위임장만으로 등록요건을 대체할 수 없음 1점, 재직자와 공식 증빙으로 다시 준비 1점.

자기채점 및 재학습 기준

  • 총점: 30점
  • 권장 통과선: 24점 이상(80%)
  • 취약영역 재학습 게이트: 총점과 관계없이 문제 3의 대표자 등록, 문제 5의 공급·제조 구분, 문제 6의 입찰대리인 증빙, 문제 8의 보완요구 대응 가운데 하나라도 절반 미만이면 해당 절과 빈 서식을 다시 작성한다. 문제 9의 전체 절차에서 신청·확인·시스템 반영·공고 기준일 재판정 중 하나를 빠뜨렸다면 답안 프레임을 보지 않고 순서를 다시 써서 모두 연결될 때까지 재학습한다.

10. 최종 점검

  • □사업자등록과 법인등기 원본으로 신청값을 대조했다.
  • □본점 사업자등록번호와 관할 제출처를 확인했다.
  • □대표자 전원과 대표대표자, 대표방식을 정확히 입력했다.
  • □공급·제조 세부품명의 정확한 번호와 목록 존재 여부를 확인했다.
  • □제조등록의 공장·생산·직접생산 자료를 적용 경로별로 준비했다.
  • □입찰대리인이 현재 재직자이며 제재·타사 중복이 없음을 확인했다.
  • □대리인의 재직증명서와 추가 재직확인자료를 준비했다.
  • □접수번호, 보완요구, 회신, 담당공무원 확인을 기록했다.
  • □시스템 자기정보와 출력 등록증을 대조했다.
  • □개별 공고의 요건과 기준일에 참가 가능성을 다시 판정했다.

근거와 기준일

  • 출제범위: 한국산업인력공단 Q-Net, 공공조달관리사 출제기준, 실기 PDF 12쪽, 적용기간 2026-03-01~2028-12-31.
  • 표준교재: 조달청 공공조달역량개발원, 공공조달관리사 4과목 공공조달 관리실무, PDF·인쇄 9~19쪽. 교재의 등록 화면은 절차 이해에 활용하고, 현행 화면의 세부 상태값은 실제 신청 시 최신 조달청 매뉴얼로 재확인한다.
  • 현행 공식 원문: 국가종합전자조달시스템 입찰참가자격등록규정, 조달청고시 제2026-6호, 2026-01-23 시행, 제9조의2·제10조·제13조~제16조·제18조·제22조~제25조의2.
  • 최신 이용안내 확인처: 조달청 차세대 나라장터 이용자등록 매뉴얼 게시물. 화면과 상태값은 게시된 최신 버전을 적용한다.
