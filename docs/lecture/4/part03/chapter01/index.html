가격작성의 출발점: 가격 네 가지를 구분한다

용어 작성 주체·기능 주의점
추정가격 발주기관이 계약방법·공고 등에 사용하는 기준가격 원칙적으로 부가가치세를 제외하는 개념이므로 사업예산과 같다고 단정하지 않는다.
예정가격 발주기관이 낙찰·계약금액 결정 등에 쓰기 위해 정한 가격 입찰자가 임의로 확정할 수 없다. 작성 여부도 계약방식에 따라 확인한다.
견적원가 입찰자가 실제 이행에 필요한 비용과 위험을 내부 산정한 값 누락·중복·비현실적 단가가 없어야 한다.
입찰가격 입찰자가 경쟁전략과 이행가능성을 고려해 제출한 가격 공고상 상한, 세금 처리, 가격평가 산식과 일치해야 한다.

국가계약법 시행령 제9조는 예정가격의 결정기준으로 적정한 거래가 형성된 경우의 거래실례가격, 신규개발품·특수규격품처럼 거래실례가격이 없는 경우의 원가계산가격, 공사의 표준시장단가, 그 밖의 감정가격·유사 거래실례가격·견적가격 등을 둡니다. 적용할 수 있는 기준을 건너뛰고 편한 숫자를 고르는 절차가 아닙니다.

대상물별 원가구조 비교

구분 기본 구조 특히 확인할 자료 흔한 누락
제조 재료비 + 노무비 + 경비 + 일반관리비 + 이윤 소요량, 단가, 손실률, 공정별 시간, 외주·시험·운송 포장, 검사, 폐기, 납품·설치 비용

공사 재료비 + 직접노무비 + 경비 + 간접비·보험료 등 + 일반관리비 + 이윤 설계서, 물량내역, 표준품셈·시장단가, 현장조건 가설, 안전, 운반거리, 법정 보험·부담금

국가계약법 시행규칙 제8조의 이윤율은 원가계산 예정가격에 적용하는 원칙적 상한으로, 공사 15%, 제조·구매 25%, 수입물품 구매 10%, 용역 10%입니다. 다만 특별한 사유가 있는 경우에는 재정경제부장관과 협의하여 그 상한을 초과해 정할 수 있습니다. 또한 「소프트웨어 진흥법」에 따른 소프트웨어개발은 제조·구매의 25% 분류에 포함되고 용역 10% 분류에서는 제외됩니다. 이 비율을 입찰자가 언제나 보장받는 이윤으로 해석해서도 안 됩니다. 일반관리비율도 업종별 상한이 다르므로 하나의 공통률을 만들어 쓰지 않습니다. 실제 견적에서는 공고, 예정가격 작성기준, 적용 업종과 회사의 실현 가능한 비용을 각각 확인합니다.

계산 사례: 제조 견적의 구조

다음은 산식 연습을 위한 자체 가정입니다. 공고가 이 비율을 정했다는 뜻도, 법정 고정률이라는 뜻도 아닙니다.

  • 재료비 42,000,000원
  • 노무비 18,000,000원
  • 경비 6,000,000원
  • 연습용 일반관리비율 7%
  • 연습용 이윤율 8%, 이윤기초는 노무비·경비·일반관리비의 합계라고 가정
  • 과세거래로 부가가치세 10% 적용

계산은 다음과 같습니다.

  1. 제조원가 기초 = 42,000,000 + 18,000,000 + 6,000,000 = 66,000,000원
  2. 일반관리비 = 66,000,000 × 7% = 4,620,000원
  3. 이윤 = (18,000,000 + 6,000,000 + 4,620,000) × 8% = 2,289,600원
  4. 공급가액 = 66,000,000 + 4,620,000 + 2,289,600 = 72,909,600원
  5. 부가가치세 = 72,909,600 × 10% = 7,290,960원
  6. 합계 = 80,200,560원

정답보다 중요한 것은 각 비목의 적용근거, 계산기초, 포함·제외 여부입니다. 면세사업자도 가격입찰 시 부가가치세를 포함하도록 공고가 정한 경우가 있으므로, 과세유형만 보고 임의로 빼지 말고 공고의 가격 제출조건과 계약 시 처리를 확인합니다.

가격 검증 다섯 질문

  1. 수량과 단위가 규격서·산출내역서·제안서에서 같은가?
  2. 인력의 등급, 인원, 개월, 참여율을 모두 곱했는가?
  3. 직접비와 간접비를 중복 계상하거나 빠뜨리지 않았는가?
  4. 세금 포함 여부와 총액·단가 절사·반올림 규칙이 공고와 같은가?
  5. 최종 입찰가격으로 제안한 품질·일정·인력을 실제 이행할 수 있는가?

기술제안서: 요구사항을 문장으로 베끼지 말고 증명한다

제안서 한 항목은 요구 → 해법 → 수행주체 → 일정 → 산출물 → 검증 → 증빙의 일곱 칸을 가져야 합니다. “최선을 다한다”는 해법도 증빙도 아닙니다.

RFP 요구 제안서에 쓸 내용 증빙
월별 품질점검 대상·표본·점검방법·오류등급·시정기한 점검표 견본, 책임자 경력
장애 대응 접수→분류→복구→원인분석→재발방지 절차 대응조직도, 보고서 견본
보안 준수 인력·계정·자료반출·파기 통제 보안서약·교육계획
최종 인수인계 자료목록, 교육, 지식이전, 인수기준 인수인계 체크리스트

평가항목의 배점은 제안서 분량 배분의 중요한 단서지만, 낮은 배점의 필수요건을 생략할 수 있다는 뜻은 아닙니다. 필수요건은 통과조건으로 모두 충족하고, 차별화할 자원은 고배점 평가항목에 집중합니다.

요구사항 추적번호를 쓴다

요구마다 R-001 같은 번호를 부여하고 공고 문단, 제안서 쪽, 증빙 파일, 가격 비목을 연결합니다. 그러면 “기술에는 있는데 가격에 없는 약속”과 “비용은 있는데 제안서에 설명되지 않은 항목”을 찾을 수 있습니다.

제안설명: 제출한 약속을 평가언어로 되찾아 준다

발표는 새 제안서를 만드는 시간이 아닙니다. 다음 순서로 구성합니다.

  1. 발주목표와 핵심 문제를 한 문장으로 재확인한다.
  2. 평가항목 순서와 발표 목차를 맞춘다.
  3. 각 항목에서 주장 → 방법 → 수치·일정 → 증빙 위치 → 기대결과를 말한다.
  4. 위험요인에는 담당자, 예방통제, 발생 시 조치, 보고시점을 붙인다.
  5. 답변은 제출본의 쪽과 표를 근거로 하고, 확인되지 않은 내용은 확인 후 공식 절차로 답하겠다고 구분한다.

질문을 받았다고 필수 규격을 낮추거나 가격·인력·기간을 즉석에서 바꾸지 않습니다. 설명 과정의 답변이 사실상 새로운 약속이 될 수 있으면 협상·계약 반영 여부와 권한을 확인해야 합니다.

필답형 답안 작성 방법

다음 골격을 먼저 적고 문제의 사실과 핵심어를 끼워 넣는다.

  1. 담당자는 공고·계약서·요구자료와 적용근거를 확인한 뒤 ‘예정가격기준에 따른 견적서 작성’을 수행한다.
  2. ‘제안요청서와 평가요소를 고려한 기술제안서 작성’ 단계에서는 적용요건과 제시된 사실·증빙을 대조하고 판단근거를 기록한다.
  3. ‘평가기준에 부합하도록 제안서 내용 설명’ 결과를 문서화·설명하고 관계자 통지와 후속조치를 관리한다.

대표 예상문제 — 자체 작성

문제(10점). 입찰서류 작성하기의 수행절차를 설명하고, 각 단계에서 확인할 판단기준과 남겨야 할 결과를 쓰시오. 8분 이내에 답하시오.

마지막으로 각 단계의 근거자료·판단결과·담당자·기준일을 기록하고, 변경이나 오류가 있으면 보완 후 재확인한다.
