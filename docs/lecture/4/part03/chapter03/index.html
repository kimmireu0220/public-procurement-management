협상 관리하기

공공조달 관리실무 · 입찰실행 관리

자체 제작 강의입니다. 조달청 표준교재 4권 166~172쪽과 2026년 8월 24일 현재 국가계약법령·계약예규를 근거로 작성했습니다. 사례의 금액과 요구사항은 자체 제작이며 실제 공고의 조건이 아닙니다.

이 강의 하나의 완료 기준

협상은 “가격을 깎는 회의”가 아닙니다. 제안요청서와 제출 제안서 사이의 차이를 확인하고, 추가·삭제·변경된 기술내용과 가격영향을 서면으로 확정해 계약문서로 넘기는 절차입니다. 다음 능력을 모두 갖추면 완료입니다.

  • 공고·RFP의 요구기준이 제출 제안서에서 추가·삭제·변경되었는지 항목별로 찾는다.
  • 기술협상의 요청을 명확화, 보완, 추가, 삭제, 변경으로 구분한다.
  • 과업 조정이 인력·수량·일정·품질·위험·가격에 미치는 영향을 계산한다.
  • 내용의 가감이 없는 경우와 있는 경우의 가격협상 한계를 구분한다.
  • 우선순위 협상, 불성립 시 차순위 진행, 협상기간과 서면통보의 흐름을 설명한다.
  • 합의사항을 협상합의서, 변경대비표, 가격영향표와 최종 계약문서에 추적 연결한다.
  • 사례형 답안을 기준선 → 변경분류 → 기술영향 → 가격영향 → 서면확정 순으로 쓴다.
적용 경계: 이 장의 15일·10일 등은 2026년 1월 2일 시행 국가 계약예규 협상에 의한 계약체결기준을 설명합니다. 지방자치단체나 기관별 세부기준은 별도로 확인합니다. 법령상 필수요건, 공고의 본질적 조건, 경쟁의 공정성을 해칠 변경을 협상이라는 이름으로 자유롭게 바꿀 수 있다는 뜻이 아닙니다.

공식 수행능력표

공식 세부항목 이 강의에서의 수행 핵심 산출물
공고 요구기준의 추가·삭제·변경 여부 협상 공고·RFP·제안서를 요구사항 ID별로 대조한다. 협상쟁점대장, 변경대비표
기술협상에서 추가·변경·삭제 과업 조정 변경마다 수용·조건부·불수용 근거와 이행영향을 제시한다. 기술협상안, 합의서
조정결과로 가격 증감 조정 변경된 수량·인력·기간·직접비를 근거로 증감액과 한도를 계산한다. 가격영향표, 수정 산출내역

오늘의 사례

누리온은 중앙행정기관의 정보시스템 운영용역 우선협상대상자입니다. 발주기관은 기술협상에서 주간보고 52회를 월간보고 12회로 줄이는 대신 실시간 현황판과 외부 API 한 종을 추가하자고 요청했습니다. 누리온 영업담당자는 “보고서가 줄었으니 현황판을 무료로 주고 계약부터 하자”고 답하려 합니다.

이 답은 위험합니다. 보고 횟수 감소가 실제로 어떤 인력·검토시간을 줄이는지, 현황판과 API가 개발·시험·보안·운영비를 얼마나 늘리는지 계산하지 않았습니다. 무료라는 말도 계약범위와 하자·유지관리 책임을 없애지 않습니다. 먼저 각 변경을 식별하고 기술·가격·일정·검수 영향을 함께 협상해야 합니다.

협상의 기준선 네 문서

기준선 역할 확인할 것
입찰공고·정정공고 경쟁조건과 계약방식의 외곽 사업예산, 기간, 참가·평가·협상 조건
제안요청서·규격서 발주기관이 요청한 요구와 성과 필수요건, 산출물, 검수·서비스 수준
제출 제안서·가격서 협상대상자가 경쟁에서 약속한 내용 방법, 인력, 일정, 성과, 가격과 전제
평가·질의 기록 평가과정에서 확인된 쟁점 보완이 필요한 불명확성, 조건부 답변

협상 결과는 이 기준선을 지워버리는 메모가 아닙니다. 무엇이 왜 바뀌었는지, 최종 문서의 어느 위치로 들어가는지를 보여 주는 변경이력이어야 합니다.

협상 관리 9단계

단계 실행 통제 질문
1. 통보·권한 확인 협상순위, 일정, 참석자와 의사결정 권한을 확인한다. 누가 어떤 범위까지 합의할 수 있는가?
2. 기준선 동결 공고·RFP·제안·가격서의 최종 제출본을 고정한다. 협상 중 기준파일이 바뀌지 않는가?
3. 쟁점 등록 요구사항 ID별 질문·차이를 쟁점대장에 적는다. 누락된 구두요구가 없는가?
4. 변경 분류 명확화·보완·추가·삭제·변경으로 구분한다. 실제 과업량이 바뀌는가?
5. 허용성 검토 법령·공고·필수규격·공정성에 어긋나지 않는지 본다. 본질적 경쟁조건을 바꾸는가?
6. 기술영향 분석 품질, 인력, 일정, 보안, 시험, 인수·유지관리 영향을 계산한다. 연쇄영향까지 반영했는가?
7. 가격영향 분석 증감 물량·단가·직접비·간접비·세금과 가격한도를 검토한다. 변경과 금액이 1:1로 연결되는가?
8. 합의·미합의 기록 합의문구, 담당자, 기한, 미결사항을 서면화한다. 검토한다 같은 미완료 문구가 남는가?
9. 계약 연결 합의서·수정규격·산출내역·일정을 최종 계약문서에 반영한다. 충돌 시 해석할 수 있게 문서가 정리됐는가?

국가 계약예규 제10조에 따라 우선순위 협상대상자와 협상이 성립하면 다른 협상적격자와 협상하지 않습니다. 성립하지 않으면 같은 기준과 절차에 따라 차순위자와 순차 협상합니다. 선순위 업체가 다른 업체와 직접 거래하거나 순위를 조정하는 절차가 아닙니다.

변경을 다섯 종류로 분류한다

분류 뜻 가격영향의 출발점 예시
명확화 기존 약속의 뜻·방법을 구체화 과업량이 같으면 통상 0, 전제 확인 신속 대응을 1시간 내 접수로 설명
보완 누락된 세부 실행·증빙을 채움 원래 필수범위인지 새 과업인지 판정 보고서 목차·검수증빙 구체화
추가 기준선에 없던 성과·작업을 넣음 증가 수량·인력·기간·비용 API 추가, 교육 회차 증가
삭제 기준선의 성과·작업을 뺌 절감 가능한 실제 비용 보고서·장비·인력 일부 삭제
변경 방식·규격·일정·수량을 다른 것으로 치환 삭제분과 추가분을 각각 계산 월간보고를 현황판으로 대체

명칭이 아니라 실질을 봅니다. 명확화라고 적었어도 새 개발·추가 시험·상시인력을 요구하면 추가 또는 변경일 수 있습니다. 반대로 문구가 바뀌어도 이미 제출 제안서에 포함된 방법을 정확히 표현한 것이라면 별도 과업증가가 아닐 수 있습니다.

기술영향 분석: 여섯 축

각 쟁점에 다음 여섯 축을 붙입니다.

  1. 범위·성과물: 무엇을 몇 개, 어느 수준으로 완성하는가?
  2. 인력·역할: 직무, 인원, 참여기간, 승인책임이 바뀌는가?
  3. 일정·선후관계: 착수·시험·인수일과 다른 과업의 경로가 바뀌는가?
  4. 품질·검수: 합격기준, 시험자료, 재수행 책임이 무엇인가?
  5. 보안·법적 의무: 개인정보, 접근권한, 저작권·라이선스, 하도급 등 영향이 있는가?
  6. 운영·하자: 교육, 자료이관, 유지관리, 장애대응 기간과 범위가 바뀌는가?

현황판 한 종을 추가하면 화면 개발비만 생기는 것이 아닙니다. 데이터 연계, 권한, 시험, 사용자 교육, 운영 모니터링, 인수자료와 유지관리 범위가 함께 움직일 수 있습니다.

가격협상의 법적 경계

국가 계약예규 제12조의 핵심은 다음과 같습니다.

  • 가격협상의 기준가격은 해당 사업예산 이하이며, 예정가격을 작성한 경우에는 예정가격 이하인 협상대상자의 제안가격입니다.
  • 제안내용을 가감하면 그 가감내용에 상당하는 금액을 사업예산 또는 예정가격 범위에서 조정할 수 있습니다.
  • 제안내용의 가감조정이 없다면 협상대상자의 제안가격을 증감조정할 수 없습니다.
  • 예정가격을 작성하는 경우 이를 제안서 제출 전에 정해진 절차로 작성해야 하며, 참가자의 제안가격을 기준으로 사후 작성해서는 안 됩니다.

따라서 발주기관이 “협상이니 일괄 5% 인하”라고 요구하거나 업체가 “기술내용은 같지만 가격을 올려 달라”고 요구하는 식의 설명은 제12조의 구조와 맞지 않습니다. 가격증감에는 대응하는 내용변경과 계산근거가 있어야 합니다.

가격영향 계산 사례

누리온의 제안가격이 120,000,000원이라고 가정합니다. 협상 분석 결과는 다음과 같습니다.

변경 증감 근거 금액
주간보고 52회 → 월간보고 12회 실제 절감 가능한 작성·검토 인력 -6,000,000
실시간 현황판 추가 분석·개발·시험·교육 +9,000,000
외부 API 1종 추가 연계개발·보안시험·문서화 +4,000,000
순변동 -6,000,000+9,000,000+4,000,000 +7,000,000

단순 계산상 조정안은 127,000,000원입니다. 그러나 사업예산 또는 예정가격이 125,000,000원이라면 127,000,000원으로 그대로 합의할 수 있다고 결론 내리면 안 됩니다. 범위·수량·방법을 다시 조정하거나, 근거단가와 부담주체를 검토해 허용 한도 안에서 기술·가격을 함께 확정해야 합니다. 반대로 예산 한도 아래라는 이유만으로 근거 없는 금액을 모두 인정하는 것도 아닙니다.

무료 제공도 가격영향을 0으로 숨기는 표현이 아닙니다. 계약금액이 늘지 않더라도 개발·시험·하자·유지관리 책임과 일정영향을 기술합의서에 명확히 적고, 회사가 그 비용을 감당할 권한과 이행가능성이 있는지 확인해야 합니다.

협상기간과 종결

국가 계약예규 제13조 기준으로 협상기간은 협상대상자에게 통보한 날부터 15일 이내입니다. 사업의 규모·특수성·난이도 등에 따라 협상대상자와 협의하여 5일 범위에서 조정할 수 있고, 정한 기간 안에 협상이 이루어지지 않으면 10일 범위에서 연장할 수 있습니다. 숫자는 국가 기준이므로 실제 공고의 적용기준과 통보기산점을 확인합니다.

협상이 성립되면 계약담당공무원은 해당 협상대상자와 다른 협상적격자에게 결과를 서면 통보합니다. 국가 기준은 협상 성립 후 10일 이내 계약체결을 규정합니다. 계약의 이행은 서면통보한 협상결과와 법령, 일반조건, 특수조건, 입찰유의서 등에 따르므로 협상합의서를 계약파일 밖에 방치해서는 안 됩니다.

사례 완성

누리온은 주간보고 감소, 현황판, API를 각각 쟁점 ID로 등록합니다. 삭제되는 보고업무의 실제 절감시간과 추가 개발의 분석·시험·보안·교육을 계산합니다. 127,000,000원이라는 첫 계산이 예산상한 125,000,000원을 넘는다면 API 범위나 현황판 기능을 재설계하고, 최종 합의범위와 금액을 함께 확정합니다. 구두로 무료라고 끝내지 않습니다. 합의된 산출물·검수기준·일정·하자·가격을 변경대비표와 수정 산출내역에 반영하고 양측 권한자의 서면확인을 받은 뒤 계약문서로 연결합니다.

자체 제작 문제 10개

  1. O/X: 협상은 제안내용의 변경 여부와 무관하게 제안가격을 일괄 인하하는 절차다. 2점
  2. O/X: 우선순위자와 협상이 성립하면 다른 협상적격자와 계속 가격을 비교협상한다. 2점
  3. 협상의 기준선 네 문서를 쓰시오. 4점
  4. 명확화, 추가, 삭제, 변경을 각각 설명하시오. 8점
  5. 기술영향 분석의 여섯 축 중 네 가지를 쓰시오. 4점

  7. 6번의 계산상 조정안이 예정가격 92,000,000원을 넘는다면 어떻게 처리해야 하는가? 6점
  8. 국가 협상기준의 기본 협상기간, 협의 조정범위, 불성립 시 연장범위를 쓰시오. 6점
  9. 추가기능 무료 제공 합의에서 반드시 문서화할 사항을 네 가지 쓰시오. 6점
  10. 누리온 사례를 결론→기준→적용→조치로 답하시오. 8점

정답과 채점기준

  1. X. 내용 가감이 없으면 제안가격을 증감조정할 수 없고, 변경이 있으면 그 상당액을 근거로 조정한다. 정답·이유 각 1점.
  2. X. 선순위와 성립하면 다른 협상적격자와 협상하지 않는다. 각 1점.
  3. 입찰공고·정정공고, RFP·규격서, 제출 제안서·가격서, 평가·질의기록. 각 1점.
  4. 명확화는 기존 약속의 뜻 구체화, 추가는 새 과업 투입, 삭제는 기존 과업 제거, 변경은 기존 방식·규격·수량을 다른 것으로 치환한다. 각 2점.
  5. 범위·성과물, 인력·역할, 일정, 품질·검수, 보안·법적 의무, 운영·하자 중 네 가지. 각 1점.
  6. 90,000,000-5,000,000+8,000,000=93,000,000원. 산식 2점, 정답 2점.
  7. 93,000,000원을 그대로 확정하지 않는다(2점). 삭제·추가 단가와 범위를 재검토하고(2점), 예정가격 범위 안에서 기술범위·수량·가격을 함께 조정해 서면합의한다(2점).
  8. 통보일부터 15일 이내 2점, 규모·특수성·난이도 등에 따라 협의하여 5일 범위 조정 2점, 불성립 시 10일 범위 연장 2점.
  9. 기능범위·성과물, 일정·인력, 시험·검수, 보안, 하자·유지관리, 지식재산·라이선스, 가격영향과 부담주체 중 네 가지. 각 1.5점.
  10. 구두 무료합의를 하면 안 된다는 결론 2점, 보고삭제·현황판·API 변경 특정 2점, 내용 가감 상당액과 예산한도 기준 2점, 영향분석·재설계·서면합의·계약반영 2점.
