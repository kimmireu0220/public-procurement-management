이 과목의 최종 목표

4과목은 조달 지식을 기억하는 데서 끝나지 않습니다. 입찰기회를 찾고, 참가자격을 갖추고, 계획·입찰·계약·이행·분쟁을 관리하며, 전자조달과 데이터를 이용하는 전 과정을 문서로 판단하고 설명하는 능력을 평가합니다.

모든 사례형 답안은 다음 여섯 질문으로 정리할 수 있습니다.

  1. 지금 어느 단계인가?
  2. 누가 무엇을 해야 하는가?
  3. 적용 근거와 공고·계약조건은 무엇인가?

  5. 판단과 조치는 무엇인가?
  6. 결과와 후속기한을 어떤 문서로 남길 것인가?

세 번 읽는 방법

1회독: 흐름과 구분

  • 각 장의 시작사례와 핵심 절차를 읽는다.
  • A와 B는 다르다는 비교표를 표시한다.
  • 숫자는 외우기 전에 적용기관·계약유형·시행일을 확인한다.
  • 장 끝 암기카드를 가리고 말한다.

2회독: 산출물과 답안

  • 완성 예시를 본 뒤 빈 서식을 직접 채운다.
  • 절차형은 주체 → 행위 → 문서 → 기준 → 결과로 쓴다.
  • 사례형은 결론 → 근거 → 사실 적용 → 조치로 쓴다.
  • 계산형은 산식, 입력값의 출처, 단위, 공고별 적용 여부를 함께 적는다.

3회독: 무자료 문제풀이

  • 각 장의 문제를 시간 안에 푼다.
  • 정답만 맞히지 말고 채점요소별 누락을 표시한다.
  • 틀린 원인을 개념 혼동, 순서 누락, 근거·기준일 누락, 사실 적용 부족, 계산 오류로 분류한다.
  • 24시간·3일·7일 뒤 틀린 문제만 다시 푼다.

사례형 4문장

  1. 결론: 가능, 보완 필요, 불가 또는 위험수준을 먼저 쓴다.
  2. 기준: 적용 법령·공고·계약조건과 판단요건을 쓴다.
  3. 적용: 제시된 사실을 요건별로 대조한다.
  4. 조치: 문서, 담당자, 기한, 재확인과 대안을 쓴다.

25개 장 완료 점검표

  • □Part 1: 참가판정, 정보관리, 등록신청을 서로 구분한다.
  • □Part 2: 동향·수요자료를 경제성·기술적합도·공급계획으로 전환한다.
  • □Part 3: 견적·제안·평가·협상의 숫자와 변경을 검증한다.
  • □Part 4: 계약 공통사항을 체결·이행·변경·종결로 관리한다.
  • □Part 5: 공사·물품·용역의 특화조건과 하도급을 구분한다.
  • □Part 6: 위험을 식별·평가·대응·모니터링하는 순환을 실행한다.
  • □Part 7: 법령근거, 분쟁증거, 우대효과를 실제 조치로 연결한다.
  • □Part 8: 시스템 처리의 완료증거와 데이터 분석의 분모·출처를 남긴다.
