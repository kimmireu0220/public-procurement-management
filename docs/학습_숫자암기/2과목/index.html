주제 암기값 구분·함정 문제

5. 바로 외울 묶음

  • 사전규격은 5-3-10: 일반 5일, 긴급 3일, SW 10일.
  • 복수예비는 ±2 → 15 → 4: 국가 ±2% 범위 15개 중 4개 평균.
  • 협상평가는 70:30, 기술 통과는 85%, 경쟁적 대화는 90:10.
  • 가격평가는 80%에서 분기, 하한 계산은 70%, 지나친 저가는 배점의 30%.
  • 물가변동은 90일 + 3%.
  • 소액수의는 88 / 90 / 89.745 = 물품·일반 / 단순노무 / 공사.
