# 4과목 — 숫자·기한·비율·법적 효과 비교표

> 2026 제1회 실기 대비 · **기준일 2026-08-24**. 숫자만 외우지 말고 `적용대상 → 기산점 → 예외 → 효과`를 한 묶음으로 회상한다.

## 시험 직전 필수표

| 주제 | 현행 국가계약 기준의 핵심 | 적용대상·기산점 | 혼동 금지 |
|---|---|---|---|
| 협상적격 기술점수 | 기술능력 배점한도의 **85% 이상** | 국가 협상계약, 실제 기술배점 기준 | 모든 공고의 고정점수 아님 |
| 협상 가격평가 하단 | 일반 산식의 **70% 하한**, 그 미만은 가격배점의 **30%** | 예규 별표와 실제 공고 산식 전체 적용 | SW사업 별도 처리·공고별 배점 확인 |
| 협상기간 | 통보일부터 **15일 이내**, 협의해 **5일 범위 조정**, 미성립 시 **10일 범위 연장** | 협상대상자 통보일부터 | 계약기간·입찰기간과 혼동 금지 |
| 계약보증금 | 원칙 **계약금액 10% 이상** | 계약체결 시 유효한 시행령 | 유효한 기간특례가 확인되면 5% 가능; 자동 적용 아님 |
| 국가 선금 상한 | 일반 **계약금액 70%** | 지급요건·예산·보증·사용·정산 모두 충족 | 70%가 자동 지급권이라는 뜻 아님 |
| 공사 선금 의무지급률 | 100억 이상 30% / 20억 이상~100억 미만 40% / 20억 미만 50% | 국가 공사계약, 적법한 최초 신청 | 표준교재의 중간구간 30%와 현행값 차이 |
| 제조·용역 선금 의무지급률 | 10억 이상 30% / 3억 이상~10억 미만 40% / 3억 미만 50% | 물품 **제조**·용역, 적법한 최초 신청 | 단순 물품구매에 일률 적용 금지 |
| 선금 지급기한 | 적법한 청구일부터 **14일 이내** | 보완 시 보완서류 제출일부터 다시 기산 | 초안 작성일·내부 결재일부터 아님 |
| 선금 정산 | `선금액 × 기성·기납대가 상당액 ÷ 계약금액` | 기성·기납대가 지급 시 | 계약변경·기정산액 반영 필요 |
| 물가변동 일반요건 | **90일 이상 AND 3% 이상 증감** | 계약체결일 경과 + 입찰일 기준 조정률 구조 | `OR` 아님; 예외·수의계약·재조정 기준일 별도 |
| 검사기한 | 완료사실 통지일부터 원칙 **14일 이내** | 국가계약 이행완료 통지 | 유효한 특례 시 7일 가능; 적용 여부 확인 |
| 대금지급기한 | 적법한 대가청구일부터 원칙 **5일 이내** | 검사 후 적법한 청구 | 유효한 특례 3일, 반송·보완·휴일 처리 확인 |
| MAS 공고·계약 | 공고 10년 원칙 / 차기 공고 종료 6개월 전 원칙 / 계약 3년 원칙 | 2026-07-21 시행 업무처리규정 | 필요 세부품명은 3년 미만 가능; 계약종료일은 공고종료일 이내 |

## 숫자보다 먼저 써야 할 법적 효과

| 혼동쌍 | 안전한 답안 |
|---|---|
| 검사 합격 vs 모든 책임 종료 | 검사 합격 뒤에도 계약상 하자담보책임은 남을 수 있다. |
| 지체상금이 보증금 상당액 도달 vs 자동 해지 | 이행가능성과 계약유지 필요성을 판단하여 해제·해지 또는 추가 보증 후 유지 여부를 결정한다. |
| 계약보증금 국고귀속 vs 제재 | 보증금 귀속·계약 해제해지·입찰참가 제한은 각각 요건과 절차를 검토한다. |
| 등록 완료 vs 공고 참가 가능 | 시스템 이용등록·입찰참가자격등록·공고별 자격 충족을 각각 판정한다. |
| 우대확인서 보유 vs 실제 가점 | 기본자격 충족 후 해당 공고가 정한 대상·효과·증빙·기준일을 확인한다. |

## 계산형 답안 검산 순서

`산식 → 기준금액 → 단위 → 적용률 → 공제·제외 → 반올림 → 적용시점 → 결론`

- 공고 사례값을 일반 법정값처럼 쓰지 않는다.
- 표준교재와 현행값이 다르면 둘을 병기하고 시행일을 적는다.
- 숫자를 확정할 자료가 부족하면 필요한 공고·계약조건·시행본을 명시한다.
