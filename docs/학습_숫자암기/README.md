- **대상:** 필기 1~3과목 · 실기 4과목

- **형식:** 주제별 표 · 우선순위(S/A/B/C) · 헷갈리는 쌍

## 우선순위 기준

| 등급 | 의미 |
|------|------|
| **S** | 법령·고시 핵심 + 문제은행·모의 선별에서 반복 |
| **A** | 시험 빈출·Part 3·5·6·7 등 실무 숫자 |
| **B** | 함정은 크나 모의 빈도 낮음 — 짧게 |
| **C** | 통계·연도 실적·국제 사례 세부 — 개념만 |

## 작성·갱신 워크플로 (과목 추가 시)

1. `output/standard_textbook/<과목>/INDEX.md` · `ch0N_*.md`의 「숫자·기준·법령」·「함정」 수집
2. `output/problem_book_final/<과목>/` · `output/mock_exam/필기/{통합,N과목}/**/manifest.json`으로 빈도 보조 (선택)
3. 본 폴더에 `<과목>.md` 작성 — **숫자만 나열하지 말고 의미(무엇의 기준인지) 병기**
4. 표준교재 장·Part 대응은 각 과목 `INDEX.md`와 맞출 것
