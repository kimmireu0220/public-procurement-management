## 1. 사전규격·발주 일정 · **S**

| 숫자 | 의미 |
|------|------|
| **5일** | 사전규격공개 **일반** 기간 |
| **3일** | 사전규격 **긴급** 기간 |
| **10일** | **SW(소프트웨어)** 사전규격 기간 |
| **5/3/10일** | 위 세 가지 **묶음** 암기 (Part 2 빈출) |
| **5,000만↓** | 사전규격 **제외** 대상 (긴급·비밀·수의 등과 함께) |
| **~90일+** | **발주계획** — 입찰공고보다 **먼저** (약 3개월 선행, Part 3) |
| **9단계** | 발주~사전규격~입찰공고 **업무 흐름** (표 18) |
| **~20업무일** | 발주 9단계 **소요** (입찰공고 전 ~1개월 준비) |

**함정:** 발주 **90일** vs 입찰공고 **7·10·40일** — **선행 관계**만 기억

## 2. 입찰·협상 공고기간 · **S**

| 숫자 | 의미 |
|------|------|
| **7일 전** | **국가** — 입찰마감 **7일 전**까지 입찰공고 (시행령 §36) |
| **10일** | **1장 일반론** — 공고~마감 **최소 10일** (국가 **7일**과 **교재 이중 표기**) |
| **40일 전** | **협상계약**(물품·용역) **일반** 공고 |
| **10일** | 협상 공고 **예외** 단축 |
| **10 / 20 / 40일** | **지방** — 추정 **1억↓ / 1~10억 / 10억↑** 공고기간 |
| **10~15일 전** | **입찰설명회** — 마감 10~15일 전 (대규모·고난도 공사) |
| **10~15일** | **낙찰 후 계약** 체결 권장 기간 (1장) |

**함정:** 시험 지문이 「국가」면 **7일**, 「교재 1장 일반론」이면 **10일**

## 4. 입찰보증 vs 계약보증 · **S**

| 숫자 | 의미 |
|------|------|
| **5%** | **입찰(참가)보증금** — 입찰금액의 100분의 5 (시행령) |
| **10%** | **계약보증금** — 계약금액의 10% 이상 |
| **5%** | 계약보증 **조정**(재난 등 고시) 하한 |
| **10일** | **착수계** — 계약 체결 후 **10일 이내** 제출 |

**함정:** 「입찰보증 **10%**」→ **오답** (정답 **5%**)

## 5. 협상·RFP 평가 · **S**

| 숫자 | 의미 |
|------|------|
| **85%** | **국가** 협상 — 기술 배점의 **85% 이상** = 1차 **합격선** |
| **68/80** | 80점 만점 시 **68점** (= 85%) |
| **70점** | **지방** 협상 — 기술 **Pass** 기준 (**국가 85%와 별개**) |
| **70 : 30** | **국가** 협상 **기본** 기술:가격 배점 (조정 **±20**) |
| **80 : 20** | **지방** 협상 기본 배점 (조정 **±10**) |
| **10~30%** | RFP **가격 가중치** (단순 시 **50%**) |
| **7 : 3 ~ 9 : 1** | RFP **기술 : 가격** 배점 범위 (Part 4·5) |
| **80%** | 가격평가 — 투찰가 ≥ 예정가(예산) **80%**일 때 산식 적용 |
| **70%** | 가격평가 **하한** (SW 등 **80%** 상향 가능) |
| **88~90%** | **수의계약** — 예정가·예산 대비 **최저가** 하한 |
| **89.745%** | 수의 **공사** 낙찰하한 (1·3과목과 동일) |

**가격평가 산식:** 투찰 ≥ 예정가 80% → `배점한도 × (최저가 ÷ 해당가)` / 70% 미만 → **70%**로 평가
