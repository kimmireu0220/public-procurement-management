>

>
> 정리일: 2026-09-23

아래의 `문제`는 [3과목 전체 CBT](../3과목/)의 누적 문항 번호다. 3과목은 숫자가
많으므로 `기산점·분모·계약유형`까지 한 줄로 함께 암기한다.

## 8. 마지막 암기 묶음

- 보증: **입찰 5% / 계약 10% / 공사 방식 15%**.
- 선금: **일반 상한 70%**, 3억원 미만 물품제조 의무 **50%**.
- 물가변동: **90일 + 3%**, 단품은 **15%**, 처리 **30일**.
- 외자: 공고 **40일·긴급 10일**, 사전규격 **7일·긴급 3일**.
- MAS: **3천만원 업체 3개사**, 적격 **70점**, 제안 **5인·5일**, 회피합산 **30일**.
- 공사 구간: 종심 **100억원**, 간이형 **100~300억원**, PQ·대형공사 **300억원**.
- 하도급 심사: **발주자 예정가격 64% / 도급금액 중 하도급부분 상당금액 82%** — 분모를 반드시 함께 외운다.
- 현행 보정: 문제은행의 **95.5%·200MB·300억원 사례**는 그대로 외우지 않고, 각각 **97.5%·300MB·500억원**을 우선한다.
