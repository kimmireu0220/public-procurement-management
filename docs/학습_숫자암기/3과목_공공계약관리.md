## 1. 물가변동 · **S**

| 숫자 | 의미 |
|------|------|
| **90일** | 계약 체결(장기=1차) 또는 **직전 조정기준일**로부터 **90일 이상** 경과 |
| **±3%** | 입찰일(수의=체결일) 기준 **품목·지수 조정률 ±3% 이상** |
| **동시** | **90일 + ±3%** 둘 다 충족한 날 = **조정기준일** |
| **90일** | 조정기준일 후 **90일 이내 재조정 불가** |
| **30일** | 증액 조정 — 대가 청구 후 **30일 이내** (규칙 §74) |
| **±15%** | 공사 **단품슬라이딩** — 특정 자재(공사비 **5‰** 초과) |
| **3%** | MAS 납품 — **90일+ 거래가 3%↑** 시 금액 조정(MAS 특례) |

**함정:** 조정기준일 ≠ 신청일 · **증액=상대자 신청** / **감액=기관 작성**

## 2. 보증금 3종 · **S**

| 숫자 | 의미 |
|------|------|
| **5%** | **입찰(참가)보증금** — 입찰금액의 100분의 5 (외자 **100만$+** 현금 5%) |
| **10%** | **계약보증금** — 계약금액 **10% 이상** |
| **5%** | 계약보증 **조정**(재난 등) · 입찰보증과 **혼동 금지** |
| **5,000만↓** | 계약보증금 **면제** 등 (MAS·일반 공통) |
| **지급각서** | 입찰보증 **원칙** (현금 대신) |

**함정:** 입찰 **5%** vs 계약 **10%** · MAS도 **10%**(5천만 면제)

## 3. 지체상금 · **S**

| 숫자 | 의미 |
|------|------|
| **0.75‰** | **물품**(제조·구매) — 1일 지체상금률(천분의 0.75) |
| **1.25‰** | **용역** |
| **0.5‰** | **공사** (= **0.0005/일** × 계약금액) |
| **30%** | 지체상금 **상한** (공사) |
| **= 보증금 상당** | 지체상금이 계약보증금 상당 → **해제·해지** |

**함정:** **지체상금**(지연) vs **국고귀속**(불이행) — **병과** 가능

## 5. 적격심사(물품) · **S**

| 숫자 | 의미 |
|------|------|
| **85점** | 물품 **10억+ 제조** — 적격 **통과** (가격 55+능력 45) |
| **80.495%** | 위 구간 **낙찰하한율** — **표준교재 기준(시험 기준)** |
| **82.495%** | 같은 구간 **현행값**(2026. 5. 26. 이후 입찰공고분) — 참고 |
| **90%** 등 | 예정가 **체감** — 덤핑 방지(저가 방지) |
| **95.5%→40점** | 고시금액 이상 — **95.5% 미만** 투찰 시 가격 **40점** (세부기준, 모의 빈출) |
| **86.245%** | 고시금액 **미만** 낙찰하한 (1·2과목과 교차, 2026 현행) |
| **5일 / 3일** | 적격심사 서류 — **5일**(고시 미만 **3일**) |
| **공고일** | **심사기준일** = 입찰**공고일**(정정도 최초 공고일) |

**함정:** 적격심사 **적용** vs **수의계약 미적용** · **PQ(공사)** 와 **물품 적격** 별개

## 6. MAS·2단계 · **S**

|------|------|
| **2인+** | MAS **최소 공급자** — 단가·다수공급자계약 |

|------|------|
