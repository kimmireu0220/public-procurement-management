## 마지막 암기 묶음

- 번호: **8자리 분류 → 10자리 세부품명**, 계층은 **4단계**.
- 공공계약: 전형계약 **15종**, 기술개발제품 **13종**, 권장구매 **15%**.
- 이의신청: `4억 / 1억 / 8천만 / 5천만` = 종합 / 전문 / 기타 / 물품·용역.
- 기한: `15일 회신 → 30일 재심`, 조정안은 `15일 무이의`.
- 국가·지방: 계약서 생략 `3천 / 5천`, 실적보고 `30일 / 60일`.
