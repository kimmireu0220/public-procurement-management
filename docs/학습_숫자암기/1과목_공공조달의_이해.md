## 1. 구매목표비율 · **S**

| 숫자 | 의미 |
|------|------|
| **50%+** | **중소기업** — 수요기관 **총구매액** 중 중소기업 제품·용역·공사 구매 **법정 의무** (판로지원법 §5) |
| **15%+** | **기술개발** — **중소기업 물품** 구매액 기준 (**총 50%와 별개**) (§13) |
| **5%+ / 3%+** | **여성기업** — 물품·용역 **5%**, 공사 **3%** (여성기업법 §9) |
| **1%+** | **장애인기업** — **총구매액** 기준 (장애인기업법 §9의2) |
| **8%+** | **창업기업** — **총구매액** 기준 (중소기업창업 지원법 §38) |
| **1.1%** | **중증장애인생산품** — 2025 상향 목표 (특별법, 타 우선구매법 **우선**) |

**함정:** EU 「GDP 50% 할당」= **선언** / 한국 **50%** = **판로지원법 법정 의무**
