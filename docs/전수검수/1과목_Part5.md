## 주요 사실 재검증

| 항목 | 판정 | 근거 |
|---|---|---|
| 한국 GPA 양허와 중소기업 별도배정 | 일치하도록 범위 교정 | WTO e-GPA 한국 Annex 1·2는 중소기업 별도배정 조치를 적용대상에서 제외 |
| 중소기업제품 총구매 50%, 기술개발제품 15% | 일치 | 각각 총구매액과 **중소기업 물품 구매액**이라는 서로 다른 분모를 사용 |
| 기술개발제품 13종·수의계약 가능 9종 | 일치 | 중소벤처기업부 현행 우선구매제도 운영 등에 관한 시행세칙과 표준교재 구분 |
| 혁신제품 구매책임자 면책 | 조건 보완 | 고의 또는 중대한 과실이 입증되지 않은 경우에 한해 구매로 생긴 손실 면책 |
| 우수조달물품 지정대상 | 현행화 | 중소기업 외에도 시행령상 요건을 충족한 중견기업 포함 |
| 미국 소기업 유보구간 | 현행화 | 2025-10-01 개정 임계값: MPT 1.5만 USD, SAT 35만 USD |
| 미국 범주별 목표 | 현행화 | 여성 5%, SDB 5%, SDVOSB 5%, HUBZone 3% |
| 캐나다 원주민 조달 | 기준 분리 | 계약가치 5% 목표, PSIB 기업 소유·통제 51%+, 작업가치 33%+ |
| 호주 IPP | 시점 명시 | 8만~20만 AUD 의무 상계와 2027 가치 3% 목표는 유지; 누적 실적은 2026 공식값으로 갱신 |
| 계약이행능력심사 낙찰하한·통과점수 | 현행화 | 투찰 하한 **89.995%**, 종합평점 **88점**은 서로 다른 기준 |

## 잔여 위험

캐나다 2018년 계약액, 미국 FY2021 실적, 국내 2023년 구매실적, 호주 누적실적은 기준연도가 붙은 역사 통계이며 법정 고정값이 아니다. 박문각 교재가 출간 당시 수치를 그대로 묻는 문제는 교재 맥락에서 답할 수 있으나, 현행 법령 문제에 과거 미국 임계값을 적용하면 안 된다. 다른 Part는 전수검수 대장의 각 Part 보고서에서 독립적으로 완료 판정했다.
