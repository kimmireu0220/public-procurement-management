# 공공조달관리사 자료 전수검수 대장

기준일: **2026-08-08**

이 대장은 저장소의 박문각 원본 이미지, 파생 문제·정답·해설, 조달청 표준교재 요약 및 학습 문서를 실제 공공조달 지식과 대조하는 전수검수의 범위와 완료 증거를 관리한다. 기존 `검수_종합.md`의 표본 확인 결과는 참고자료로만 사용하며, 이 대장에서 원본 전체와 파생 항목 전체를 대조한 범위만 `완료`로 표시한다.

## 기준 자료 우선순위

1. Q-Net 시행공고와 출제 안내
2. 검수일 현재 시행 중인 국가법령정보센터 법령·행정규칙
3. 조달청 공공조달관리사 표준교재
4. 박문각 수험서

조달청도 표준교재에 오류·누락 또는 최신 법령 미반영 가능성이 있으므로 의문사항은 현행 법령 등으로 확인하라고 안내한다. 표준교재 자체도 공식적인 시험 출제기준은 아니다.
