# 공공조달관리사 학습 저장소 프로젝트 분석

기준일: **2026-08-09**

## 결론

이 저장소는 단순 문제 모음이 아니라 원본 자료, 정답 원장, 학습용 문제집, 표준교재 요약,
모의고사와 CBT 배포본이 연결된 학습 파이프라인이다. 전수검수 결과 최종 모집단은 조달청
표준교재 **1,574쪽/27장**, 박문각 **23 Part/84 Chapter/1,300 JPG/3,536항목**이다.

검수 전에는 파생본끼리 정합성이 맞더라도 원본의 장 전체가 빠지거나 원문과 다른 지문이
동일 stable ID에 들어간 사례가 있었다. 따라서 자동검증 통과만으로 원본 충실도를 증명할 수
없고, 원본 전쪽 시각 대조와 현행 공식 기준 확인이 함께 필요하다.

## 데이터 흐름

| 단계 | 기준 경로 | 역할 | 우선 확인 사항 |
|---|---|---|---|
| 원본 | `sources/` | 박문각 JPG, 조달청 PDF, Q-Net 공고·예제 | 페이지 연속성, 장·문항 누락 |
| 정답 원장 | `output/agent_extract/` | 문항·선지·정답·해설의 기준 | 원문 충실도, 정답·해설 일치 |
| 문제은행 | `output/problem_book_final/` | 모의 출제용 MD와 학습용 HTML | stable ID·source·원장 동기화 |
| 주제 설계 | `output/standard_textbook/` | 조달청 표준교재 핵심·현행 보정 | 구법·오류·시점 통계 구분 |
| 학습·시험 | `output/study/`, `output/mock_exam/` | 학습 CBT와 필기·실기 모의 | 재사용 문항의 교정 전파 |
| 배포 | `docs/` | GitHub Pages CBT | 현재 빌드 자산과 완전 일치 |

모의고사는 표준교재에서 출제 주제를 먼저 정하고 박문각 문제은행에서 지문을 수동 선별한다.
코드는 문항을 자동 추첨하지 않고, 병합·CBT 생성·무결성 검증만 담당한다.

## 구조 평가

### 강점

- `source`와 stable ID로 모의 문항을 원본 Part·Chapter까지 역추적할 수 있다.
- 문제지·정답·manifest·CBT HTML·Pages 배포본의 기계적 정합성을 재현 가능하게 검사한다.
- 표준교재 기반 주제 설계와 박문각 기반 지문 선별을 분리해 출제 범위와 문항 출처가 명확하다.
- 원본은 보존하고 교정은 파생 Markdown·HTML에 반영해 변경 이력을 감사할 수 있다.

### 검증 사각지대

- 기존 검증기는 파생 문제은행 내부 정합성에는 강하지만, 원본 JPG의 모든 문제를 소진했는지
  또는 stable ID의 지문이 실제 source와 같은지는 의미론적으로 판정하지 못한다.
- 원장과 문제집이 함께 잘못되면 모의고사·CBT도 일관되게 잘못된 상태로 검증을 통과할 수 있다.
- 법령·행정규칙과 통계는 개정되므로 검수일 이후에도 시험 직전 최신성 확인이 필요하다.

## 운영 권고

1. 학습 기준은 원본 이미지가 아니라 교정된 `agent_extract`, 문제집, 표준교재 요약과 CBT로 둔다.
2. 신규 원본을 추가할 때 Part별 페이지·Chapter·유형별 항목 수를 먼저 확정하고 파생 수와 대조한다.
3. 문제은행을 대량 재생성한 뒤에는 source 존재 여부뿐 아니라 원본 연락지 표본과 역방향 대조를 한다.
4. 현행 숫자·기관명·기간에는 기준일과 공식 근거를 남기고 시험 직전에 다시 확인한다.
5. `tmp/`의 OCR·렌더·검사용 산출물은 근거 생성에만 사용하고 커밋하지 않는다.

## 완료 판정 기준

- 23개 Part의 원본 JPG 전쪽과 3,536개 파생 항목을 대조한 Part별 보고서가 모두 존재한다.
- 조달청 표준교재 1,574쪽과 박문각 추록 4쪽을 전쪽 확인하고 현행 공식 기준 보정이 반영된다.
- 문제·정답·source·stable ID, 문제집 MD/HTML, 학습·모의 CBT와 Pages가 동기화된다.
- `git diff --check`, 정적 검사, 단위 테스트, `tools/validate_mock_exam.py`가 모두 통과한다.
- `tmp/` 등 임시 자료를 제외한 의도된 변경만 커밋하고 `main`에 푸시한다.
