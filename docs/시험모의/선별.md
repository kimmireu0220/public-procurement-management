# 모의고사 문항 선별·배포

## 1. 공통 원칙

문항 선별은 에이전트가 직접 수행한다. 코드는 확정된 문제지의 CBT 변환·배포·검증에만 사용한다.

1. `output/standard_textbook/<과목>/INDEX.md`와 장별 Markdown으로 출제 주제와 범위를 정한다.
2. 해당 주제의 지문을 `output/problem_book_final/<과목>/` Markdown에서 고른다.
3. 정답을 `output/agent_extract/<과목>/partN.md`와 대조한다.
4. 기존 manifest 전체를 확인하여 1차 lap의 `stable_id` 재사용을 막는다.
5. 중복·유사 지문, Part·Chapter 쏠림, 정답 오류를 검토한 뒤 최종 파일을 만든다.

### 제외·분배 규칙

- O/X와 최종점검 퀴즈는 필기에서 제외한다.
- `단원별 출제예상문제`를 우선하고 ㉠㉡·빈칸형을 보완적으로 사용한다.
- `Check Q&A`는 필요한 경우에만 사용하며 과목당 20%를 넘지 않는다.
- Part·Chapter를 고르게 분산한다.
- 동일 지문, 유사 쌍둥이, 동일 클러스터의 과도한 반복을 피한다.
- 오답 클러스터는 새 지문으로 보강할 수 있다.

주요 클러스터에는 파레토, MAS, 보증금, 해제·해지, 낙성·요물, 물가변동, 지체상금, PQ,
조정가격, 부정당업자, 고시금액·예정가격, 하도급 등이 있다.

## 2. 필기 규모

| 프로필 | 구성 | 문항 | 시간 |
|---|---|---:|---:|
| `full` | 1과목 30 + 2과목 20 + 3과목 30 | 80 | 120분 |
| `subject1` | 1과목 | 30 | 45분 |
| `subject2` | 2과목 | 20 | 30분 |
| `subject3` | 3과목 | 30 | 45분 |

통합 필기 번호는 1과목 1~30, 2과목 31~50, 3과목 51~80이다.

## 3. 문항 형식

각 문항에는 다음 주석을 유지한다.

```html
<!-- source: Part N/page_XXXX.jpg -->
<!-- id: 과목:part:chapter:stype:qn -->
```

필기 `stype`은 `exam`, `check`, `cqa` 중 하나다.

`manifest.json` 예시:

```json
{
  "round": 1,
  "total": 80,
  "items": [
    {"exam_no": 1, "stable_id": "1:1:1:exam:10", "answer": "②"}
  ]
}
```

## 4. 회차 산출물

통합 필기는 `output/mock_exam/필기/통합/<K>회차/`, 과목별 필기는
`output/mock_exam/필기/<N>과목/<K>회차/`에 둔다.

기본 산출물은 다음 네 개만 유지한다.

```text
<K>회차/
├── manifest.json
├── 필기_모의_문제.md
├── 필기_모의_정답.md
└── index.html
```

응시 후 `필기_풀이.md`, `출제_피드백.md`, `풀이/`는 필요한 경우에만 추가한다.
초안 폴더, 과목별 분리 중간본, 동일한 HTML 별칭, 검수 보고서는 남기지 않는다.

## 5. CBT 빌드·배포

```bash
python3 tools/build_cbt_viewer.py --round K --pages
python3 tools/build_cbt_viewer.py --profile subject1 --round K --pages
python3 tools/build_cbt_viewer.py --profile subject2 --round K --pages
python3 tools/build_cbt_viewer.py --profile subject3 --round K --pages
```

`--pages`는 `docs/`의 해당 공개본을 갱신한다. 완료 전 다음 검사를 실행한다.

```bash
python3 tools/validate_mock_exam.py
python3 -m unittest discover -s tests -v
```

## 6. 다음 회차 반영

다음 회차를 만들기 전 오답노트, 기존 manifest, 선택적 `출제_피드백.md`를 읽는다.
1차 lap에서는 모든 기존 `stable_id`를 제외한다. 문제은행을 한 차례 소진한 뒤에는 오답과
핵심 개념 복습 목적의 2차 lap을 사용할 수 있으며 재출제 여부를 출제 메모에 밝힌다.

## 7. 실기

실기는 4과목 표준교재로 주제를 정하고 4과목 문제은행에서 지문을 선별한다. 약 20문항으로
구성하며 문제와 정답을 `output/mock_exam/실기/<K>회차/`에 둔다.
문항에는 `source`와 `4:part:chapter:essay|final:qn` 형식의 id를 유지한다.
