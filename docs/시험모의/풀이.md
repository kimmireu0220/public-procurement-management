# 모의고사 채점·풀이 가이드

답안 채점의 목표는 정확한 결과와 다음 학습에 도움이 되는 피드백이다. 설명 분량, 파일
형식, 오답노트 여부와 보강 방식은 사용자 요청과 학습 상황에 맞춰 정한다.

## 채점

- 사용자가 `1② 2④ 3① …` 형태의 답안 문자열을 보내면 채점 요청으로 볼 수 있다.
- 대화, CBT 메타와 최신 회차에서 대상 시험을 안전하게 특정할 수 있으면 바로 채점한다.
  서로 다른 회차·과목이 가능해 결과가 달라질 때만 필요한 정보를 확인한다.
- `manifest.json`과 정답지를 우선 대조하고, 불일치가 있으면 원문 근거까지 확인한다.
- 누락이나 해석이 여러 가지인 답은 임의로 정상 답안처럼 처리하지 않고 결과에 밝힌다.
- 복수선택 문제의 부분점수 여부 등은 해당 시험의 채점 기준 또는 사용자 지시를 따른다.
- 응시가 진행 중이라면 미제출 구간의 정답을 노출하지 않는다. 사용자가 원하면 공개할 수
  있다.

기존 공식 프로필의 번호 범위는 다음과 같다.

| 유형 | 번호 |
|---|---|
| 통합 필기 | 1~80: 1과목 1~30, 2과목 31~50, 3과목 51~80 |
| 1과목 단독 | 1~30 |
| 2과목 단독 | 1~20 |
| 3과목 단독 | 1~30 |

자유 연습이나 실기에는 위 범위를 강제하지 않는다.

## 피드백과 기록

채팅에는 점수와 사용자가 바로 이해해야 할 내용을 전달한다. 맞은 문항과 틀린 문항 중
어디에 얼마나 설명을 붙일지, 개념 요약·선지 분석·비교표·추가 예시·보강 문제 중 무엇을
쓸지는 학습 효과를 기준으로 선택한다.

필요하면 다음 위치에 풀이와 오답 기록을 남길 수 있다.

```text
output/mock_exam/필기/<통합|N과목>/<K>회차/
output/mock_exam/필기/<통합|N과목>/오답노트.md
```

파일 형식은 자유지만, 나중에 재현할 가치가 있는 경우에는 다음 정보를 남기는 것이 좋다.

- 시험과 회차, 응시일 또는 시도 번호
- 총점과 필요한 경우 과목별 점수
- 문항 번호, 내 답, 정답과 판정
- 정답 정정 또는 채점 기준 변경 이력
- 다음 학습에 유용한 핵심 근거나 취약 주제

재응시는 기존 기록을 덮어써야 할 이유가 없다면 별도 시도로 보존한다. 잘못된 정답이나
기록은 수정할 수 있으며, 무엇이 바뀌었는지 알 수 있게 남긴다.

## 보강과 다음 회차

보강 문항 수, 유형, 난이도, 반복 범위와 다음 회차 반영 여부는 에이전트가 판단한다.
같은 문항의 재사용, 변형 문제, O/X, 단답형, 사례형과 서술형을 모두 사용할 수 있다.
오답을 반복시키는 것보다 다른 각도에서 이해시키는 편이 유용한지 함께 고려한다.

## Git과 공개

답안 제출이나 채점 요청은 커밋·푸시·공개 배포 권한을 뜻하지 않는다. 사용자가 명시적으로
요청한 경우에만 Git 반영이나 외부 게시를 수행한다. 풀이 파일을 공개할 때는 문제 원문과
개인 학습정보의 공개 가능 여부도 확인한다.
