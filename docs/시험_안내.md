## 과목·문항 수 (Q-Net 출제기준 보고서 1254)

적용기간 **2026.3.1.~2028.12.31.**

| 구분 | 시험 과목 | 문항 수 | 비고 |
|------|-----------|--------:|------|
| 필기 1 | 공공조달과 법제도 이해 | **30** | 4지 택일형 |
| 필기 2 | 공공조달계획 수립 및 분석 | **20** | 동일 |
| 필기 3 | 공공계약관리 | **30** | 동일 |
| **필기 합계** | | **80** | **2시간** (CBT 연속) |
| 실기 4 | 공공조달 관리실무 | **20 내외** | **2시간 30분** 필답형 |

### 합격 기준 (Q-Net 시험정보)

- **필기:** 100점 만점, **과목당 40점 이상** + **전과목 평균 60점 이상**
- **실기:** 100점 만점, **60점 이상**
- 응시 자격: 학력·경력 제한 없음

### 출제 항목 비중

Q-Net 공식 보고서는 1과목 1~5쪽, 2과목 5~7쪽, 3과목 7~10쪽,
4과목 11~18쪽에 과목별 주요항목·세부항목·세세항목을 제시한다.

## 학습 문항은행과 실제 시험

| | 실제 시험 | 프로젝트 학습 문항은행 |
|---|-----------|----------------------|
| 규모 | 위 표 (80+20) | 과목당 수백~천 문항 (학습 은행) |
| OX | 없음 | 최종점검 OX 다수 (개념 확인용) |
| 출제기준 태그 | 문항마다 | 공식 세부항목에 매핑 |
| 모의 출제 | 표준교재·출제기준 범위 | 공식 출제기준·표준교재·현행 공식 원문을 근거로 자체 작성 ([`시험모의/선별.md`](시험모의/선별.md)) |

새 문항은 Q-Net 공식 예제의 형식을 참고하되 공식 자료를 근거로 자체 작성한다. 민간 문항·해설의
문구나 고유 사례를 복제·변형하지 않으며, 기존 민간 파생 자료는 완성 후 유사성 검사에만 사용한다.
